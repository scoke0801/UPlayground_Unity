# NPC 작업 접촉 전 정렬

## 목적과 범위

작업점에 도착한 NPC가 손을 뻗기 전에 몸의 작은 위치·방향 오차를 줄인다. 첫 대상은 연목의 P09 R3 수선 시작·반복·종료와 같은 실물 망치다. 기존 모션·소품 인계 이벤트·예약 세대·일과 중단을 재사용한다. 작업 상태는 [구현·검증 기록](../../../../docs/work-status/npc-work-alignment.md)을 따른다.

## 계약

- 작업점의 선택적 `NpcWorkAlignmentSO`가 구간 종료 시각·진입 거리·속도·회전·허용 오차를 소유한다. 설정이 없는 작업점은 기존 행동을 유지한다.
- 목표는 물건 중심이 아닌 기존에 저작한 작업점의 NPC 루트 위치·방향이다. 실제 NPC 체형에 맞춘 손 접촉 위치를 전제로 한다.
- 작업 시작 시 목표를 고정한다. 손으로 인계된 물건을 계속 추적하지 않는다.
- 이동은 `NpcRoutineState.UpdateVelocity`, 회전은 `UpdateRotation`, 도착 판정은 `AfterCharacterUpdate`에서 처리한다. 별도 LateUpdate나 Transform 직접 이동은 추가하지 않는다.
- 모션의 실제 평가 시각으로 누적 목표를 계산한다. 현재 모터 위치에서 해당 목표까지의 잔여량만 요청하여 같은 애니메이션 표본의 중복 소비를 막는다. KCC scaled deltaTime이 0이면 이동·회전·완료 판정을 보류한다.
- 수평 위치와 방향만 보정한다. 접지·중력·외부 충격은 기존 KCC 경로를 유지한다. 높은 턱·큰 거리·큰 회전은 보정으로 숨기지 않는다.
- 마지막 요청을 KCC가 소비한 뒤 실제 위치·회전을 검사한다. 정렬 종료 시점에 도착하지 못했거나 접지를 잃으면 작업을 취소한다. 마지막 위치를 순간이동으로 맞추지 않는다.
- 소품 집기 이벤트에서도 실제 도착을 재검사한다. 프레임 지연으로 접촉이 모터 적용보다 먼저 발생해도 원격 집기를 허용하지 않는다. 이미 손에 있는 망치의 중단·재개 정책은 기존 계약을 유지한다.

## 첫 적용 데이터

`RepairWorkAlignment.asset`: 최대 진입 거리 0.015m, 종료 0.55초, 최대 속도 0.5m/s, 위치 오차 0.003m, 회전 오차 1도. 기존 집기 접촉 시각 0.8초는 변경하지 않는다. R3 시작 모션은 보행 모션이 아니므로 기존 도착 반경 1.5cm를 넓히지 않고 마지막 접촉 오차만 보정한다. SO 클래스의 범용 기본값 0.15m를 그대로 적용하지 않는다. 이 값은 첫 검증용 설정이며 시각 품질 승인을 뜻하지 않는다. 연목 원본 프리팹과 월드 재생성의 기존 접촉 복원 경로에서 같은 SO를 참조한다.

이번 범위는 KINEMATION 컴포넌트를 별도 실행하는 방식이 아니다. 검토에서 선택한 기존 NPC/KCC 실행 경로에 접촉 전 보정 원리를 적용한다. IK·신규 모션·임의 월드 아이템 수집·저장 재고 시스템은 추가하지 않는다.

## 다른 생활 행동으로 확대

시작부터 손이 작업물에 닿는 반복 모션은 `alignBeforeMotion=true`로 설정한다. 이 경우 `NpcRoutine`은 `positionTolerance`까지 기존 보행으로 접근하고 `angleTolerance` 안으로 방향을 맞춘 뒤 작업을 시작한다. 작업 중 위치 보정은 하지 않는다. 기존 연목은 false를 유지한다.

| 대상 | 연결 | 방식 |
|---|---|---|
| 조이 | JoyRoutine의 lake.meal.prep / CookWorkAlignment | 재생 전 6mm·1도 안으로 정렬 |
| 헤이즐 | HazelRoutine의 lake.care.pack / HerbWorkAlignment | 재생 전 4mm·1도 안으로 정렬 |
| 모건 | MorganRoutine의 lake.transport.cart·inspect / CargoWorkAlignment | 기존 보정 클립의 기준 작업점에 3mm·1도 안으로 정렬 |
| 소담 | 원본 NPC Brain / StationaryHerbWorkAlignment | 고정 작업 자리로 복귀·정렬 후 기존 약초 모션 재개 |

소담은 작업점 일과가 아니라 `NpcIdleState`의 고정 작업 경로를 사용한다. 선택적 Brain 설정과 기존 HomePosition/HomeRotation을 사용하며 일과가 이동을 소유하면 개입하지 않는다. 허용된 복귀 거리 안에서 기존 Walk로 접근하고 KCC 충돌을 유지한다. 3초 안에 도착하지 못하거나 허용 거리 밖이면 작업을 시작하지 않고 대기한다. 대화·위험 반응 뒤 Idle 재진입은 새 시도다. 위치·모션을 복원하는 기존 SetHomePose/SetWorkMotion은 정렬 설정을 보존한다.

휴식·방문·미완성 작업은 확대 대상이 아니다. 기존 임시 손 소품과 약초 모션 이벤트를 보존하며, 실물 집기·놓기 이벤트가 없는 행동에 새 집기 기능까지 구현한 것으로 계산하지 않는다. 여기의 허용값은 초기 설정이며 실제 접촉·발 미끄러짐은 대상 모델별 사용자 인수가 필요하다.
