# NPC 일상 애니메이션 사용자 확인

대상 씬: `Assets/01.Scenes/Scenario/OpenWorld/LakeVillageWorld.unity`. R3 클립과 2026-11-15 연결본. 키보드·마우스 또는 평소 사용하는 게임패드로 기존 시작 경로에서 Play한다. 기존 저장을 덮어쓰지 않고 별도 테스트 슬롯을 사용한다.

연목 수선점은 월드 좌표 `(988.4, 63.04, 431.8)`, 휴식점은 `(987, 63.03, 429)`이다. 플레이어가 가까이 있어야 거리 시뮬레이션이 활성화된다. 검수에서는 플레이어를 `(992.5, 64, 433.5)` 근처에 두었다. 09:00~18:00의 작업 시간대, 비·강풍·대화 없는 상태에서 시작한다. 접근/재시도/휴식 시간이 있으므로 90초 관찰한다. 시작 지점에서 기다리기만 하면 해당 주민은 정지 상태일 수 있다.

| ID | 실행 | 기대 / 실패 기준 |
|---|---|---|
| V01 | 연목에게 접근해 한 일과를 90초 관찰 | 접근·정렬·망치 집기·수선·내려놓기·휴식 이동. 상자가 망치로 바뀌거나 망치가 복제되면 실패 |
| V02 | 작업대 측면으로 이동해 타격 3회 이상과 집기/놓기 확인 | 발 미끄러짐, 손잡이 이탈, 망치의 작업면 관통·공중 타격이 없어야 함 |
| V03 | 집기 전, 집은 직후, 반복 중, 놓기 직전에 각각 화면에 표시되는 상호작용 입력으로 대화를 시작하고 종료. 각 회차 90초 내 재개 관찰 | 대화 진입·복귀가 자연스럽고 도구 중복·소실·예약 고착 없음. API 일시정지 검사와 실제 대화 UI 검사는 구분 |
| V04 | 위험 중단은 현재 공개 `NpcRoutine.SetRiskActive(true/false)` 진입점 검사만 가능. 연결된 플레이어 재현 입력이 없어 일반 사용자 조작 검사는 미수행 | 위험 켬/해제 후 피신·복귀와 같은 도구 유지. 신규 사건/치트 입력은 이 작업에서 추가하지 않음 |
| V05 | 기본 플레이 거리와 근접, 정면·측면에서 각각 V01 확인 | 동작 목적이 읽히고 관절·의상·도구 접촉이 자연스러움 |
| V06 | 현재 인수 조합은 연목/P09/현재 작업복/반 크기 망치/현재 작업대만 | 다른 체형·의상·소품에 통과를 확대하지 않음. 추가 조합은 연결 대장 확정 후 별도 검사 |
| V07 | 별도 테스트 슬롯을 저장·다시 로드하고 같은 주민에게 재접근. 씬을 나갔다 돌아와 V01 반복 | 도구 하나, 기존 일과 유지, 진행 불능 없음. 월드 재생성은 기존 생성 함수의 격리 중복 검사만 수행했으며 실제 월드 전체 재생성은 하지 않음 |
| V08 | 마을에서 90초 동안 여러 주민의 대기·교류·작업 관찰 | 손 흔들기 인사, 허리 펴기, 양손을 하늘로 드는 동작 없음. 같은 위상 반복·떨림·성능 이상 기록 |

함께 볼 위치: 교류 `(982,61.06,420.5)`, 약재 `(1005.1,62.48,408)`, 요리 `(1031.5,62.08,406)`, 화물 `(1086.6,56.25,410.8)`. 수선 외 직업의 전체 접촉·전환 품질은 아직 인수되지 않았다.

회신 형식: **항목 ID / 통과·실패·미수행 / 실제 결과 / 화면·영상·로그**. 사용자 결과가 도착하기 전에는 사용자 테스트 대기다.
