# 라온 FootStep 첫 제작 검수

기존 Bokusei 모델을 사용하는 현재 플레이어 `Raon`의 비무장·기본 도(Katana) 걷기, 달리기, 질주, 착지를 검수한다. 적용 월드는 `Assets/01.Scenes/Scenario/OpenWorld/LakeVillageWorld.unity`다. 다른 무기, 다른 캐릭터, 발자국 자국, 날씨에 따른 젖음은 이번 제작 범위에 포함하지 않는다.

## 준비

- Unity 6에서 기존 월드 테스트 진입 절차로 LakeVillageWorld에 진입한다. 기존 저장 데이터는 유지한다.
- 활성 캐릭터를 라온으로 하고 기본 도를 장착한다. 소리 설정의 SFX 음량을 확인한다.
- 입력은 현재 바인딩의 이동·걷기·점프·무기 장착/해제·파티 교대를 사용한다. 키보드와 게임패드에서 각각 확인한다.
- 테스트 중 모델의 `ActorFootstep`에서 `PlayedCount`, `LastSurface`, `LastPosition`을 디버거로 확인할 수 있다. 런타임 진단 값이며 저장 데이터가 아니다.

## 확인 순서와 기대 결과

| ID | 조작 | 기대 결과와 실패 기준 |
|---|---|---|
| F01 | 흙길에서 천천히 걷고 달리기·질주로 전환한다. 도를 해제한 뒤 반복한다. | 발을 디딜 때 소리가 나고 달리기에서는 짧은 먼지가 증가한다. 떠 있는 발에서 먼저 소리가 나거나 한 주기 후 소리가 끊기면 실패다. |
| F02 | 풀밭과 흙길 경계를 왕복한다. | 풀밭의 부드러운 소리와 흙길 소리가 구분된다. 풀의 걷기·달리기는 소리 위주이며 착지만 작은 먼지를 사용한다. `LastSurface`가 실제 발밑과 다르면 실패다. |
| F03 | 바위 Terrain과 석재 바닥을 걷고 점프 후 착지한다. | 단단한 소리가 나고 평소에는 먼지가 거의 없다. 착지는 발걸음보다 무겁고 1회만 재생한다. |
| F04 | 호수나 바닷가의 발목 깊이 물을 왕복한다. | 수면에서 작은 물튀김과 물결이 나고 물소리가 난다. 마른 해안까지 물 효과가 따라오거나 수면 아래 바닥 높이에 물결이 생기면 실패다. |
| F05 | 수면보다 높은 다리·돌 위에서 이동하고 물 영역의 외곽을 걷는다. | 물 효과가 나오지 않는다. 깊이 0.55m를 넘는 곳도 얕은 물 효과 대상이 아니다. 메시 바닥에 별도 지정이 없으면 석재를 기본 재질로 사용한다. |
| F06 | 이동·착지 직후 공격·회피를 입력하고 잠시 정지한다. | 공격·회피 반응을 방해하지 않으며 정지 중 반복 소리가 없다. 착지 직후 발소리가 이중으로 겹치지 않는다. |
| F07 | 다른 캐릭터로 교대하고 라온으로 돌아온다. 지역을 이동한 뒤 다시 걷는다. | 이전 모델의 발에서 효과가 나오지 않고 라온으로 돌아오면 재개된다. 이전 지역에 파티클 풀이 남아 예외가 발생하면 실패다. |
| F08 | 30fps와 평소 프레임에서 반복 보행하고 일시정지·복귀한다. | 타이밍이 크게 어긋나지 않고 반복 시 샘플 변화가 들린다. 분홍색 입자, 지속되는 루프, 화면을 가리는 먼지, 새 Console Error가 있으면 실패다. |

## 조정 위치

- `Assets/10.Datas/Actor/Footsteps/Raon_FootstepSettings.asset`: 접촉 허용 높이, 중복 억제, 바닥 레이어, 풀 크기.
- 같은 폴더의 `Surface_Dirt`, `Surface_Grass`, `Surface_Stone`, `Surface_ShallowWater`: 동작별 샘플·음량·입자·크기.
- `Motions/`: 기본 도와 비무장 전용 복제본. Animation Editor에서 `FootstepEvent`의 좌우 발·동작·시간을 조정한다. 반복 이벤트는 `EveryCrossing`, 애니메이션 평가 후 실행을 유지한다.
- 월드 Terrain의 `FootstepSurface`: 현재 레이어의 우세 재질을 구운 지도. Terrain을 다시 칠했다면 지도도 다시 베이크해야 한다.
- 수면의 `FootstepWaterSurface`: 실제 수면 메시, 최소·최대 수심. 물리 충돌체를 추가하지 않는다.

`FootstepAuthoring.Build`는 초기 콘텐츠 제작용이다. 수작업 튜닝 뒤 다시 실행하면 초기 설정으로 돌아가므로 일반 검수에서는 실행하지 않는다. `BindWorld`도 다른 씬 작업을 저장한 상태에서만 실행하며, 새 TerrainLayer가 생기면 매핑을 먼저 검토한다. 두 진입점은 일회성 저작용으로 툴 런처에 노출하지 않는다.

## 결과 회신

`항목 ID / 통과·실패·미수행 / 실제 결과 / 입력 장치 / 필요 시 영상·Console 로그`로 기록한다.

컴파일·데이터 연결·EditMode 자동 검사와 실제 음량·타이밍·화면 품질은 구분한다. 실제 플레이 품질은 사용자 테스트 대기다. 검증용 Player 및 Addressables 빌드는 수행하지 않는다.
