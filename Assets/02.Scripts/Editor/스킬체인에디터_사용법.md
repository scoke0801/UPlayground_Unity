# 스킬 체인 에디터 사용 가이드

## 📌 개요

스킬 체인을 시각적으로 편집할 수 있는 노드 기반 에디터입니다.

## 🚀 에디터 열기

### 메뉴에서 열기
```
Unity 상단 메뉴 → Tools → Skill Chain Editor
```

## 🎨 인터페이스

### 툴바 버튼
```
┌─────────────────────────────────────────────────┐
│ [Add Node] [Load JSON] [Save JSON] [Clear All]  │
└─────────────────────────────────────────────────┘
```

- **Add Node**: 새 스킬 노드 추가
- **Load JSON**: Json 파일에서 스킬 체인 불러오기
- **Save JSON**: 현재 편집 내용을 Json으로 저장
- **Clear All**: 모든 노드 삭제

### 노드 구조
```
┌─────────────────┐
│ ● ID: 2001   ● │
│   Branches: 2   │
│   Window: 0.5-0.9│
└─────────────────┘

● (녹색) = 입력 포인트 (다른 노드로부터 연결)
● (빨간색) = 출력 포인트 (다른 노드로 연결)
```

## 🎮 기본 사용법

### 1. 노드 추가
**방법 1: 툴바 버튼**
```
1. 상단 [Add Node] 클릭
2. 화면 왼쪽 상단에 새 노드 생성
```

**방법 2: 우클릭 메뉴**
```
1. 빈 공간에서 우클릭
2. "Add Node" 선택
3. 클릭한 위치에 노드 생성
```

### 2. 노드 이동
```
1. 노드를 좌클릭
2. 드래그하여 원하는 위치로 이동
```

### 3. 노드 연결
```
1. 시작 노드의 빨간 점(출력) 클릭
2. 목표 노드의 녹색 점(입력)으로 드래그
3. 분기 키 선택 메뉴 표시
   - Add X Branch
   - Add Y Branch
   - Add A Branch
   - Add B Branch
4. 원하는 키 선택
5. 연결 완료!
```

### 4. 노드 편집
```
1. 노드에서 우클릭
2. "Edit Node" 선택
3. 편집 창에서:
   - Skill ID 수정
   - Input Window 조정
   - 분기 추가/삭제
   - 설명 수정
```

### 5. 노드 삭제
```
1. 노드에서 우클릭
2. "Delete Node" 선택
3. 확인 다이얼로그에서 "Yes"
```

## 📊 시각적 요소

### 연결선 색상
```
🔴 빨간선 (X 입력) - X키 분기
🟡 노란선 (Y 입력) - Y키 분기
```

### 노드 색상
```
🔳 회색 - 일반 노드
🔵 파란색 - 선택된 노드
```

### 포인트 색상
```
🟢 녹색 점 - 입력 포인트 (들어오는 연결)
🔴 빨간 점 - 출력 포인트 (나가는 연결)
```

## 🔧 노드 편집 창

### Skill ID 설정
```
Skill ID: [2001]
          ↓
해당 스킬의 고유 ID
(SkillJsonData의 skillID와 일치해야 함)
```

### Input Window 설정
```
Window Start: [━━━●━━━━━━] 0.50
Window End:   [━━━━━━━━●━] 0.90

0%                50%                100%
├──────────────────┼──────────────────┤
                   └─────────┘
                   입력 감지 구간
```

- **Start**: 입력 받기 시작 지점
- **End**: 입력 받기 종료 지점
- 녹색 영역 = 입력 가능 구간

### 분기 목록
```
┌─────────────────────────────────┐
│ [X] → Next Skill ID: [2002]     │
│     Description: [연속 공격]     │
│                           [삭제] │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│ [Y] → Next Skill ID: [2010]     │
│     Description: [상승 공격]     │
│                           [삭제] │
└─────────────────────────────────┘
```

## 💾 파일 저장/불러오기

### Json 저장
```
1. 상단 [Save JSON] 클릭
2. 저장 위치 선택
3. 파일명 입력 (예: SkillChainData)
4. 저장 완료
```

**저장되는 내용:**
- 모든 노드의 Skill ID
- 입력 윈도우 설정
- 분기 정보 (inputKey, nextSkillID, description)

### Json 불러오기
```
1. 상단 [Load JSON] 클릭
2. 불러올 파일 선택
3. 자동으로 노드 생성
4. 불러오기 완료
```

**참고:**
- 기존 노드는 모두 삭제됨
- 노드 위치는 자동 배치

## 🎯 실전 예시

### 예시 1: 3단 연속 공격 만들기

**Step 1: 노드 3개 추가**
```
[Add Node] × 3
→ 노드 2001, 2002, 2003 생성
```

**Step 2: 노드 배치**
```
드래그로 가로로 정렬
[2001] → [2002] → [2003]
```

**Step 3: 연결**
```
2001 빨간점 → 2002 녹색점
→ "Add X Branch" 선택

2002 빨간점 → 2003 녹색점
→ "Add X Branch" 선택
```

**Step 4: ID 설정**
```
각 노드 우클릭 → Edit Node
- 노드 1: Skill ID = 2001
- 노드 2: Skill ID = 2002
- 노드 3: Skill ID = 2003
```

**Step 5: 저장**
```
[Save JSON] → SkillChainData.json
```

**결과:**
```
X → X → X (3단 콤보)
```

### 예시 2: 분기 공격 만들기

**Step 1: 노드 4개 추가**
```
[2001] - 시작
[2002] - X 분기
[2010] - Y 분기
[2003] - X-X 종료
```

**Step 2: 배치**
```
        [2002] → [2003]
       ↗
[2001]
       ↘
        [2010]
```

**Step 3: 연결**
```
2001 → 2002: X Branch
2001 → 2010: Y Branch
2002 → 2003: X Branch
```

**결과:**
```
X → X → X (연속 콤보)
X → Y (상승 공격)
```

## 🔍 팁과 트릭

### 1. 노드 ID 규칙
```
2000번대: 검 스킬
3000번대: 창 스킬
4000번대: 활 스킬
5000번대: 마법 스킬
```

### 2. 입력 윈도우 권장값
```
빠른 콤보:  0.3 ~ 0.8  (넓은 윈도우)
보통 콤보:  0.5 ~ 0.9  (중간 윈도우)
어려운 콤보: 0.6 ~ 0.85 (좁은 윈도우)
```

### 3. 체인 종료 노드
```
분기가 없는 노드 = 체인 종료
→ 출력 포인트만 있고 연결 안 됨
```

### 4. 순환 참조 방지
```
❌ 잘못된 예:
[2001] → [2002] → [2001]
(무한 루프!)

✅ 올바른 예:
[2001] → [2002] → [2003]
(선형 진행)
```

### 5. 빠른 작업
```
Ctrl + S: 빠른 저장 (예정)
Ctrl + L: 빠른 로드 (예정)
Delete:   선택 노드 삭제 (예정)
```

## 🐛 문제 해결

### Q: 노드가 생성되지 않아요
```
A: 툴바 버튼이 안 보이면:
   1. 윈도우 크기 확대
   2. Tools → Skill Chain Editor 다시 열기
```

### Q: 연결선이 안 그려져요
```
A: 순서 확인:
   1. 출력 포인트(빨간 점) 먼저 클릭
   2. 입력 포인트(녹색 점)으로 드래그
   3. 순서가 반대면 연결 안 됨
```

### Q: Json 저장이 안 돼요
```
A: 확인 사항:
   1. 폴더가 존재하는지 확인
   2. 파일 쓰기 권한 확인
   3. 파일명에 특수문자 없는지 확인
```

### Q: 불러온 노드 위치가 이상해요
```
A: 정상 동작입니다:
   - Json에는 위치 정보가 없음
   - 자동으로 격자 배치
   - 드래그로 재배치 가능
```

### Q: 분기가 중복돼요
```
A: 같은 키는 한 번만:
   - X 분기: 노드당 1개만
   - Y 분기: 노드당 1개만
   - 중복 시 에러 메시지 표시
```
