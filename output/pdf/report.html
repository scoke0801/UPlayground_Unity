카메라 영상 분석과 프로젝트 적용

여섯 게임의 장점을 조합하되 플레이어의 시점 조작과 적의 공격 가독성을 우선한다. 충돌·락온의 기존 구조를 활용하고 이동 자동 정렬의 과한 개입을 보완했다.

분석 대상: 다운로드 종합 영상 1개(1,042,737,144바이트 / 14분 58.96초 / 2560×1440)와 PicPick 폴더의 개별 MP4 21개. 전체에서 276개 비교 프레임을 추출했고 핵심 구간 146개를 0.5초 간격으로 추가 비교했다. 개별 영상에 찍힌 게임은 니어, 데빌 메이 크라이, 닌자 가이덴, 스텔라 블레이드, 카잔, 엘든 링이다.

관찰과 설계의 경계
시간순 화면에서 확인한 결과를 분석했다. 입력 오버레이·게임 내부 코드·카메라 파라미터는 제공되지 않아 자동 회전과 수동 회전, FOV와 카메라 거리의 기여를 완전히 분리할 수 없다. 아래 적용 수치는 UPlayground의 첫 튜닝값이며 해당 게임의 내부 수치를 역산한 값이 아니다. 종합 영상은 개별 영상과 장면이 겹친다.

현재 구현과 적용 판단

항목영상 근거프로젝트 대응처리판단
벽 충돌여러 게임의 벽 근접 → 이탈 장면에서 근접 구도와 거리 복귀를 관찰CameraCollision + CollisionCameraModifier기존 유지시선과 충돌 거리 계산을 분리하고, 즉시 수축·유예 후 부드러운 복귀를 유지한다. 기존 수치는 다시 바꾸지 않았다.
탐색 이동짧은 이동마다 시점을 강제로 뒤집는 방식은 화면에서 얻을 장점이 적음AlignCameraModifier이번 보완연속 이동 유예, 수평 각도 허용 범위, 후진 보정 억제, 대상·모드 변경 시 상태 초기화를 추가한다.
수동 시점기본 시점 외에도 높은·낮은 구도로 이동하는 사례가 존재InGameCameraBehavior + 사용자 옵션기존 유지수동 입력 우선권과 1.1초 유예, 이동 정렬 기본 꺼짐을 유지한다. 보정은 사용자가 켰을 때만 작동한다.
락온플레이어와 적을 함께 보여주는 접근·후퇴·횡이동 구도LockOnFramingCameraModifier기존 유지대상 추적에 축별 응답과 최대 각속도를 적용하며, 벽에서 줄어든 실제 암 길이를 추적 각도에 역류시키지 않는다.
공중·대형 적DMC 전투 43–55초에서 넓은 구도와 공중 대상 노출LockOnFitDistanceCameraModifier + CameraDistanceController기존 유지·현장 확인높이차에 대한 피벗 상승과 거리 피팅, 플레이어 최소 투영 배율 0.6을 유지한다. 적 전신을 담기 위해 플레이어를 지나치게 작게 만들지 않는다.
타격 시야니어와 DMC에서 모든 타격마다 화면이 대상 중심으로 재배치되지는 않음CameraHitAssist기존 유지명중당 작은 보정·간격 제한과 수동 입력 우선권을 유지한다. 공격·BT·GAS 데이터는 변경하지 않았다.
옵션카메라 축·감도·추적 옵션을 분리하는 메뉴SettingsData + 카메라 어댑터 + 기존 설정 화면기존 활용현재의 감도 X/Y·Y 반전·이동 정렬·명중 보정 선택권을 활용한다. X 반전·사용자 거리/피치 보정 분리는 별도 UI 작업 후보로 남긴다.

이번에 추가한 동작

  • 접지 이동이 0.25초 연속 유지된 뒤 자동 정렬을 시작한다. 정지 상태의 짧은 발걸음은 화면을 바꾸지 않는다.
  • 수평 오차 8도를 벗어나면 정렬을 시작하고 3도 허용 범위의 가장자리에서 멈춘다. 작은 방향 흔들림으로 계속 시점을 끌지 않는다.
  • 현재 시점과 이동 방향이 120도를 넘으면 자동 yaw·pitch 보정을 하지 않는다. 카메라 쪽으로 물러날 때 보던 전방을 유지한다.
  • 정지·수동 입력·전투·공중·입력 잠금·연출 시선·추적 대상 교체·모드 재진입에서 진행 중 보정 상태를 정리한다.
  • 기존 사용자 옵션과 수동 입력 유예 1.1초를 지킨다. 유예가 끝난 다음 유효한 연속 이동 0.25초를 새로 기다린다.

조정 위치: Assets/10.Datas/Camera/CameraSettings.asset → 인스펙터 ‘이동·연출’ 탭 → ‘이동 자동 리센터링’. 신규 항목은 recenterMovementDelay, recenterYawDeadZone, recenterMaxHeadingAngle이다. 기존 인스펙터에 잘못된 각도 관계를 경고하는 검증도 추가했다. 게임 설정의 ‘이동 시 카메라 정렬’을 켜야 보완한 동작을 체감할 수 있다. 이 옵션의 기본 꺼짐은 유지했다.
