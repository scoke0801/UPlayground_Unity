# Humanoid 등급 공격 사용자 검수

대상: Unity 6000.3.21f1 / URP의 현재 작업본. Editor Play Mode에서 진행한다. Player 빌드는 필요 없다. 실제 체감·혼성 조우 항목은 사용자 테스트 대기다.

## 준비

1. 현재 씬의 사용자 작업을 보존하고 `UPlayGround > 툴 런처`에서 **전투 테스트 맵 열기 / 전투 테스트 준비**를 연다. 대상 씬은 `Assets/01.Scenes/Test/CombatTestMap.unity`다.
2. 기존 저장 슬롯을 로드/저장하지 않는 시험장 세션을 사용한다. 같은 출전 캐릭터·장비를 유지한다. 패드와 키보드/마우스를 각각 한 번 확인한다.
3. 준비 창의 일반 적 슬롯에 원하는 ActorDefinition을 지정한다. 기존 Random 대검 002, P09 Armor06/08/10 대검, Bow를 우선 사용한다. 보스는 `Assets/10.Datas/Actor/DataBase/Humanoid/MonsterLili.asset`을 지정한다.
4. 반복 검수는 **공격 반복 관찰**에서 공격을 하나씩 제한할 수 있다. 이 기능도 실제 거리·쿨다운·HP·BT 조건을 유지한다. 전체 전투 검수 때는 제한을 해제한다. 새 실험은 Play 종료 후 재실행해 HP·쿨다운·투사체를 초기화한다.
5. 레벨 경계 자동 검사는 Test Runner의 PlayMode `HumanoidGradePlayModeTests`를 실행한다. 직접 경계 비교 시에는 Play 중 MonsterActor의 Debug Inspector `_level`만 9/10, 19/20, 29/30으로 바꾼다. 이는 공격 해금 관찰용이며 스탯 성장 재계산 검증이 아니다. 원본 SO를 수정하지 않는다. HP 조건은 실제 공격으로 보스 체력을 50% 아래로 낮춰 관찰한다.

## 알려진 문제와 제외 범위

- P09 전체 검증은 기존 Armor06 Bow HP bake 불일치로 실패한다. 이번 검사에서 HP를 재생성하지 않는다.
- SeolA 스킬트리의 TautString 검사 실패, 플레이어/패시브 데이터의 GAS Error 7건은 기존 문제다.
- MonsterSera/Nenmir는 대검/활 프리팹 연결을 교정했다. 아래 G12~G15의 체감 검수는 아직 통과하지 않았다.
- 사용자는 Reien 변경 대신 신규 일반 창병 제작을 선택했다. `Actor/HumanoidSpear/Enemy_Field_Spear_001.asset`를 시험장에서 지정한다. Reien과 월드 배치는 보존한다. 제작 상세·실행 결과는 `HUMANOID_SPEAR_SOLDIER_RESULT.md`에 기록한다.

자동 검사에서 FX 서비스는 시험용 대체 구현을 사용한다. 따라서 실제 위험 링 화면, 투사체 외형, VFX/SFX 정리와 실제 다단 적중 횟수는 이 명세의 사용자 검수 대상으로 남는다. 고정 피해 합계는 전 Phase가 한 번씩 적중했을 때의 예산이며 실측 DPS가 아니다.

회신 형식: `ID / 통과·실패·미수행 / 실제 결과 / 사용 입력 장치 / Ability ID·레벨·등급·HP / 영상 또는 Console 로그`. 진행 성공과 조작·연출 품질을 각각 판정한다.
