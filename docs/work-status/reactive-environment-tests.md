# 반응형 환경 — 사용자 테스트 명세

[현재 상태](reactive-environment.md) · [통합 계약](../../Assets/docs/design/world-art/environment/REACTIVE_ENVIRONMENT_INTEGRATION.md) · [저작 지침](../../Assets/docs/guide/REACTIVE_ENVIRONMENT_AUTHORING_GUIDE.md)

현재 사용자 테스트 대기다. Editor 자동 검사 55건과 실제 게임·아트 인수를 구분한다.

## 준비

- Unity 6000.3.21f1에서 기존 Boot/시나리오 맵 실행 경로를 사용한다. 실제 날씨와 SceneContext/RegionOwnership이 연결된 맵의 테스트용 사본을 사용한다. 기존 진행 저장을 덮지 않는 폐기 가능한 슬롯을 준비한다. 이 작업은 정규 씬을 자동 저장하지 않았다.
- Assets/03.Prefabs/Environment의 ReactiveEnvironmentCrateSample/TreeSample/RockSample/RoofSample/GrassSample을 평지에 배치한다. 배치마다 SceneEntityId GUID가 다르고 비어 있지 않아야 한다. 처음에는 상자 두 개를 1~2m 간격으로 두고, 다른 상자 하나를 지붕 아래에 둔다.
- 지붕의 Ground 레이어가 기존 날씨 EnvironmentEffects의 roofLayers에 포함되는지 확인한다. 보호 볼륨을 쓰면 같은 원본 Collider를 연결한다. 불꽃 시각 효과가 없어도 논리는 동작한다. 샘플은 기능 확인용 형상이며 최종 아트가 아니다.
- 툴 런처 → 월드/맵 → 환경 반응 모니터에서 Play 중 대상을 선택한다. 강수는 기존 날씨 미리보기로 바꾼다. 실제 근접은 키보드/마우스 또는 게임패드로 조작하고 입력 장치를 기록한다.
- GAS 원소 확인은 원본을 보존한 테스트용 Ability/Payload/Set 사본을 사용한다. Ability Editor에서 유효한 기존 Motion의 HitPhase.environment.heatImpulse=1 또는 waterImpulse=1로 명시하고 테스트 플레이어에 그 사본을 연결한다. 기존 공유 스킬을 이름/색으로 일괄 변환하지 않는다.

## 항목

| ID | 실행 | 기대 결과 / 실패 기준 |
|---|---|---|
| RE-01 | 맑은 날 상자 선택 후 열 충격 1 | 다음 화학 tick에 발화·연료/내구도 감소·그을림 증가. 등록 오류/예외가 없어야 함 |
| RE-02 | 탄 상태를 기록하고 물 충격 1 | 연소 발광/불꽃과 연료 소비가 멈춤. 젖음 증가. 그을림/균열/내구도는 복구되지 않음 |
| RE-03 | 야외/지붕 아래 상자를 가열하고 폭우 적용 | 야외는 젖어 소화, 차폐된 상자는 같은 속도로 젖지 않음. 카메라만 실내로 들어가도 야외 논리는 유지 |
| RE-04 | 새 상자를 실제 근접으로 파괴 | 명중 즉시 구조 피해, 같은 타격 다중 Collider 중복 없음. 원형 충돌 해제·잔해·장작 1개 |
| RE-05 | 새 상자를 열만으로 파괴 | 잔해가 남은 연료/그을림을 유지. 화재 샘플은 보상 없음. 연료 재충전/정상 자원 중복 지급은 실패 |
| RE-06 | 장작을 줍기 전 저장→줍기→로드, 다시 줍기→저장→로드 | 첫 저장의 미획득 장작만 복원. 획득을 저장한 뒤 추가 지급되지 않음 |
| RE-07 | 반쯤 탄 대상과 파괴 잔해를 저장/재방문 | 표면/연료/구조/포즈 복원. 언로드 중 화학 정지는 명시된 정책. 다른 배치에 상태가 옮겨가면 실패 |
| RE-08 | 새 게임과 일시정지 확인 | 초기 상태 복원. 정지 중 연료/구조/바람이 진행하지 않음. 기존 몬스터/채집 저장·재생 회귀 없음 |
| RE-09 | 테스트 GAS의 열/물 HitPhase를 근접·잔상·투사체로 적중 | 같은 명시 원소가 환경에 전달됨. 일반 Damage를 올렸다는 이유로 열이 늘지 않음 |
| RE-10 | 가까운 상자 둘 중 하나만 점화. 벽/서로 다른 surfaceLayerId 조건도 비교 | 다음 tick 이후만 전파. 거리/벽/층 차단이 유효하며 장식 품질을 바꿔도 논리 결과 동일 |
| RE-11 | 물 rate 공급원을 짧은 lifetime으로 켜고 끔 | 마지막 부분 tick까지 수분 공급. 중단 뒤 무한 물 공급/중복 냉각 없음 |
| RE-12 | TreeSample을 개방 공간과 막힌 공간에서 파괴, 진행 중 저장/로드 | CutPivot 기준 낙하. 막힌 후보는 fallback 또는 안전 정착. 액터 관통/강제 밀기 없음. 저장 포즈를 처음부터 재생하지 않음 |
| RE-13 | RockSample을 Slash/Blunt 종류로 각각 타격 | 검 저항, 둔기 구조 피해·사전 파손·돌 1개. Nav carving 지연 후 접근/우회에 진행 불능 없음 |
| RE-14 | 지붕 아래 상자 점화→비→지붕 파괴 | 지붕/보호 볼륨 Collider가 꺼지고 하부 상자 노출/소화에 반영. 카메라 실내 가드·충돌/길찾기가 실제 형상과 어긋나지 않음 |
| RE-15 | 나무 LOD 전환·풀 소진·마름/젖음/그을림/연소를 낮/밤에서 확인 | 모든 슬롯/LOD와 절단면 상태 일치. 잎만 명시적으로 소거. 그림자/깊이/노멀/외곽선/모션 벡터의 coverage·바람 일치. 소화 후 발광 없음 |

실패 시 항목 ID, 실제 증상, 입력 장치, 시작 슬롯/상태, Console 오류와 필요한 화면/영상을 전달한다. 회신 형식: RE-번호 / 통과·실패·미수행 / 실제 결과 / 근거.

낙목 접촉 피해·지형 대량 셀 atlas·원거리 proxy·전체 콘텐츠 게이트는 이 명세의 완료 대상이 아니다. GPU 평면 테스트는 월드 아트·성능 확인을 대신하지 않는다. 별도 지시 없는 Player/Addressables 검증 빌드는 실행하지 않는다.


## 치트 진입 확인 (RE-C01~03)

- RE-C01: 위 저작 지침의 에디터 치트 콘솔 → 환경 에셋 테스트에서 Play 중 각 샘플을 소환한다. 플레이어 앞 지면에 나타나고 등록=True·서로 다른 배치 ID여야 한다. 지역/지면 미준비 시 실패 문구가 나와야 한다.
- RE-C02: 대상을 선택해 열/물/구조 피해를 각각 조절한다. 상태/툰 반응과 파괴·기존 보상이 일치해야 한다. 게임 시간을 멈춘 상태에서는 화학 tick을 진행시킨 뒤 판정한다.
- RE-C03: 새 개체로 교체·대상 제거·모두 제거를 실행한다. 이 창이 소환한 개체에만 적용되고 원본/기존 씬 배치는 유지되어야 한다. 이미 나온 보상은 유지된다. 세 항목은 사용자 테스트 대기이며 Editor 마우스/키보드로 확인한다.
