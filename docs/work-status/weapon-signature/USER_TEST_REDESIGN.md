# 신규 궁극기 사용자 검수

현재 적용본과 손·무기/FX 집중 확인 항목: [후속 수정 상태](GRIP_FX_REVISION.md). 이전 반려 이력은 유지하며 수정본의 사용자 판정은 아직 없다.

[제작 상태](MOTION_PRODUCTION.md) · [설계](../../../Assets/docs/design/combat/player/ULTIMATE_MOTION_REDESIGN.md)

구현 반영한 12명 개편의 직접 검수 명세다. 구현 반영과 아래 항목의 사용자 통과를 구분한다. 새 빌드나 저장 데이터 초기화는 필요하지 않다.

## 준비와 공통 절차

**2026-11-15 사용자 결과: 12명 모션 품질 전체 반려.** 사용자가 전원 모션 품질 실패를 보고했으므로 미술 검수 상태를 대기에서 실패·재작업 필요로 변경한다. 개별 UR 항목의 세부 증상이나 UR13~16 기능 검사 결과까지 추정하지 않는다. 아래 명세는 재작업 후 재검수용으로 보존하며 이번 정정에서 재검사는 수행하지 않았다.

열린 Unity의 기존 전투 테스트 흐름에서 캐릭터를 선택하고 궁극기 게이지를 채운다. 적 하나를 전방에 둔 경우, 적이 없는 경우, 여러 적이 모인 경우를 차례로 확인한다. 각 캐릭터는 기본 전투 카메라로 처음부터 복귀까지 한 번 끊지 않고 본다. 얼굴 패널의 눈·표정을 읽을 시간이 있는지, 패널이 무기 해제나 타격 순간을 가리지 않는지도 확인한다.

| ID | 대상 | 기대 결과·실패 기준 |
|---|---|---|
| UR01 | 화린 | 양손 도끼로 준비→끊기지 않는 회전→머리 위 정점→날로 지면 내려찍기. 회전 중 준비 자세로 되감거나 정지하면 실패. |
| UR02 | 레이네 | 창끝 조준→몸을 감아 도약→손에서 창 이탈→팔로스루→착지. 손에 창이 남거나 발사보다 먼저 사라지면 실패. 착지 후 공중에 남거나 이중 상승하면 실패. |
| UR03 | 세라 | 두 손이 자루를 잡고 크게 끌어올린 뒤 내려찍는다. 거대검 형상의 지면 도달과 본타가 일치해야 한다. |
| UR04 | 릴리 | 세라와 다른 뒷다리 준비·사선 진입·앞다리 제동. 대검을 쓰더라도 세라의 동일 모션이 재생되면 실패. |
| UR05 | 라온 | 칼집 손이 버티는 준비→발도 일섬→검 회수. 발도 때 칼집이 검과 함께 이탈하거나 돌아가면 실패. |
| UR06 | 아린 | 이미 뽑힌 검으로 사선 진입과 런지. 없는 칼집을 쥐거나 납도하는 자세면 실패. |
| UR07 | 설아 | 만작에서 활·시위·당기는 손이 맞고 손을 놓는 순간 발사. 시위가 손과 따로 움직이면 실패. |
| UR08 | 연화 | 축적→전방 밀기→빔 반동 버티기→출력 종료. 준비 자세를 정지시킨 채 빔만 계속되면 실패. |
| UR09 | 묘묘 | 지팡이 원형 유도→전방 수렴→빔 버티기. 연화와 동일 준비 동작이거나 지팡이와 빔 축이 어긋나면 실패. |
| UR10 | 유라 | 양검의 교차 두 번→상승→회오리에서 빠져나오는 보법. 화린처럼 지속 회전만 하면 실패. |
| UR11 | 리안 | 몸통의 두 원과 채찍 끝의 지연→마지막 전방 스냅→회수. 채찍이 몸과 다른 시간으로 움직이거나 순간이동하면 실패. |
| UR12 | 묘령 | 방패를 밀어 던짐→빈손 팔로스루→낙하 결과→재포획. 손을 고정한 채 방패만 사라지거나 이중 표시되면 실패. |

## 중단·조작·지형

- UR13: 준비 중 피격, 공격 후 허용 시점 회피, 종료 직후 이동을 확인한다. 무기 숨김·중력·카메라·얼굴 패널이 남거나 입력이 계속 막히면 실패.
- UR14: 궁극기 중 가능한 교대와 시전자 사망을 확인한다. 살아 있는 투사체의 기존 수명 정책이 유지되고 사망 회수 뒤 유령 판정이 남지 않아야 한다.
- UR15: 가까운 벽·완만한 경사·무타깃에서 레이네와 묘령을 사용한다. 지형 아래 착탄, 캐릭터 공중 고정, 무기 영구 소실이 없어야 한다.
- UR16: 12명 각각 한 번 사용해 비용·쿨다운이 기존 정책과 같은지, 끝난 뒤 다시 사용 가능한지 확인한다. 공유 무기 두 캐릭터를 연속 교대해 동작·카메라가 섞이지 않아야 한다.

결과 회신: `항목 ID / 통과·실패·미수행 / 증상과 캐릭터·전투 상황`. 이 문서의 존재는 테스트 통과를 뜻하지 않는다.
