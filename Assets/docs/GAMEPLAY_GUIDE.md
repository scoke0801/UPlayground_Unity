# 게임 플레이 가이드 (조작 & 전투)

> 플레이어 관점의 "어떻게 플레이하는가" 가이드. 조작키, 전투 흐름, 방어/회피, 캐릭터 교체, 회복 메커니즘을 다룬다.
> 모든 조작키는 실제 입력 에셋(`Assets/Resources/Input/PlayerInputActions.inputactions`)과 `PlayerActor` 입력 처리 기준이다.

---

## 1. 조작키 (키보드 / 마우스)

### 이동 & 카메라

| 키 | 동작 | 비고 |
|----|------|------|
| `W` `A` `S` `D` | 이동 | 카메라 기준 8방향 이동 |
| 마우스 이동 | 카메라 회전 (Look) | |
| 마우스 휠 | 줌 인/아웃 (Zoom) | |
| `Space` | 점프 | |
| `Z` | 질주 토글 (Sprint) | 이동 중에만 토글, Run ↔ Sprint 전환 |

### 전투

| 키 | 동작 | 비고 |
|----|------|------|
| 마우스 좌클릭 | 공격 (Attack) | 연타로 콤보 연결 |
| 마우스 우클릭 | 강공격 / 차지 | **짧게** = 강공격, **길게 누름** = 차지 공격 |
| `Left Ctrl` | 회피 구르기 (Dodge) | 무적 + 퍼펙트 도지 |
| `Left Shift` | 대시 (Dash) | 무적, 적을 통과, 쿨다운 있음 |
| `V` | 가드 (Guard) | 누르고 있는 동안 방어, 떼면 해제 |
| `E` | 스킬 (Ability) | 스킬 게이지 소모 |
| `R` | 궁극기 / 무기 발도·납도 | |
| `F` | 상호작용 / 특수 브레이크 공격 | 브레이크된 적 근처에서 마무리 공격 |

### 락온 & 캐릭터 교체

| 키 | 동작 | 비고 |
|----|------|------|
| 마우스 휠클릭 | 락온 토글 (Lock-On) | 가장 가까운 적 고정 |
| `Tab` | 락온 대상 전환 | 다음 타깃으로 |
| `1` `2` `3` `4` | 캐릭터 교체 (슬롯 1~4) | 파티 슬롯 직접 선택 |

### 메뉴 / 시스템 키

| 키 | 동작 |
|----|------|
| `I` | 인벤토리 |
| `O` | 장비 |
| `M` | 맵 |
| `P` | 파티 |
| `` ` `` (백쿼트) | 메뉴 패널 |
| `Esc` | 뒤로 / 닫기 |

> 참고: 걷기 토글·웅크리기 등 일부 동작은 키보드 기본 바인딩이 없다(게임패드 위주). 게임패드 매핑은 입력 에셋(`PlayerInputActions.inputactions`)을 참조한다.

## 2. 전투 기본 흐름

```
       [이동/대기]
          │  좌클릭            우클릭(짧게)        우클릭(길게)
          ▼                      ▼                  ▼
        공격 콤보 ───────▶  강공격          ───▶  차지 공격
          │                                          │
          │  (적 포이즈 누적)                         │ (강하게 포이즈 깎음)
          ▼                                          ▼
     적 브레이크(경직) ◀──────────────────────────────┘
          │
          │  F (브레이크 대상 근처)
          ▼
     특수 브레이크 공격 (강력한 마무리)
```

### 약공격 / 강공격 / 차지

- **약공격(좌클릭):** 빠른 기본 공격. 연타하면 콤보로 이어진다. 회복 오브를 가장 많이 떨어뜨려 공세 유지에 유리하다.
- **강공격(우클릭 짧게):** 느리지만 강한 일격. 적의 포이즈(강인도)를 크게 깎는다.
- **차지 공격(우클릭 길게):** 일정 시간 이상 눌러 차지하면 발동. 가장 강력한 단발 타격.

### 콤보 & 선입력

- 입력은 **선입력 버퍼**로 처리되어, 현재 모션이 끝나기 직전에 다음 입력을 미리 넣어두면 끊김 없이 콤보가 이어진다.
- 공격 도중에도 정해진 캔슬 타이밍에 회피/대시/가드로 빠져나갈 수 있다(공격 캔슬 시스템).

## 3. 방어 & 회피 (생존 3종)

이 게임에는 성격이 다른 세 가지 방어 수단이 있다. 상황에 맞춰 골라 쓰는 것이 핵심이다.

### 회피 구르기 — `Left Ctrl`

- 발동 즉시 **무적**이 되며, 구르는 동안 적을 통과한다.
- 시작과 동시에 **퍼펙트 도지 판정 창**이 열린다. 적 공격이 닿기 직전 타이밍에 구르면 퍼펙트 도지가 성립한다.
- 이동 입력 방향으로 구른다(전/후/좌/우). 입력이 없으면 제자리/후방.

### 대시 — `Left Shift`

- 마찬가지로 **무적**이며, 직선으로 빠르게 이동하고 적을 통과한다.
- **쿨다운**이 있어 연속 남발은 불가(쿨다운은 HUD에 표시된다).
- 대시로 적 공격을 흘리면 회피 보상 연출(타임스케일 슬로우)이 1회 발동한다.
- 공중에서 대시 중 **강공격(우클릭)** → 점프 대시 공격으로 연결된다.

> 회피(Ctrl)는 짧고 정밀한 카운터용, 대시(Shift)는 거리 벌리기/접근용이라고 생각하면 된다.

### 가드 — `V` (누르는 동안 유지)

- 누르고 있는 동안 정면 공격을 막는다. 떼면 해제된다.
- **퍼펙트 가드(저스트 가드):** 가드를 시작하고 **0.3초 이내**에 공격을 막으면 성립.
  - 적이 경직되고, 막은 공격이 **패리 가능(Parryable)** 타입이면 **반격 창**이 열린다 → 이때 **좌클릭**으로 즉시 반격.
  - 패리 불가/방어 전용 공격은 퍼펙트 가드 피드백은 받되 반격은 열리지 않는다.
- **가드 브레이크:** 가드를 너무 오래/자주 의존하면 누적치가 초과되거나, 가드 브레이크 전용 공격에 맞으면 가드가 깨지고 잠시 무방비 상태가 된다. 가드 브레이크 직후엔 잠깐 가드를 다시 올릴 수 없다.

## 4. 회복 — 바이탈 오브 (Vital Orb)

이 게임은 포션이 아니라 **전투 행동으로 회복 자원(바이탈 오브)을 떨어뜨려 줍는** 공격적 회복 구조다.

오브가 떨어지는 트리거(전투 코드의 이벤트 발생 지점과 1:1 대응):

| 트리거 | 발생 상황 |
|--------|-----------|
| 약공격 히트 (LightAttackHit) | 약공격을 적중시킬 때 — 전투 중 가장 자주 발생 |
| 강공격 히트 (HeavyAttackHit) | 강공격을 적중시킬 때 |
| 가드 (Guard) | 공격을 가드로 막을 때 |
| 퍼펙트 가드 (PerfectGuard) | 저스트 가드 성공 시 |
| 회피 (Dodge) | 회피 구르기 |
| 처형 공격 (FinishAttackHit) | 마무리/처형 타격 적중 |
| 처치 / 킬캠 (KillKillCam) | 적을 처치할 때 |

> 트리거별 실제 드랍 확률·최대 개수·쿨다운은 `VitalOrbTriggerConfig` 에셋에서 데이터로 설정된다(코드 고정값 아님). 따라서 정확한 드랍량은 밸런스 설정에 따라 달라진다.

> 핵심: **계속 싸우고 잘 막고 잘 피할수록 체력이 돈다.** 약공격 적중이 가장 흔한 트리거라, 공세를 유지하는 플레이가 회복에도 유리하다. 거리만 두고 도망치면 회복원이 마른다.

---

## 5. 적 공략 — 포이즈 & 브레이크

- 모든 적은 **포이즈(강인도)** 수치를 가진다. 공격을 누적해서 포이즈를 깎으면 적이 **브레이크(경직)** 상태가 된다.
- 강공격·차지 공격이 포이즈를 크게 깎으므로, 약공격으로 흔들다 강공격으로 마무리하는 식의 운영이 효과적이다.
- 적이 브레이크되면 근처에서 **`F`(특수 브레이크 공격)**로 강력한 마무리 공격을 넣을 수 있다.
- 적의 강한 공격은 **퍼펙트 가드 → 반격** 또는 **퍼펙트 도지** 후 반격으로 받아치는 것이 가장 큰 이득이다.

## 6. 캐릭터 교체 (파티 스왑)

기본 조작 캐릭터는 **Bokusei**이며, 적을 처치하면 합류 가능한 캐릭터가 파티에 들어온다. 전투 중 슬롯 키로 즉시 교체할 수 있다.

- **교체 키:** `1` `2` `3` `4` (파티 슬롯)
- **빠른 교체:** 기본 쿨다운 약 0.5초. 전투 흐름을 끊지 않고 캐릭터를 바꿀 수 있다.
- **독립 자원:** 각 캐릭터는 고유 무기·공격·스킬 게이지·체력을 **따로** 유지한다.
- **공유되는 것:** 위치, 카메라 타깃, 전투 타깃은 교체 후에도 이어받는다.
- **대기 캐릭터는 무적:** 교체로 빠진 캐릭터는 전투 타깃에서 제외되어 피해를 받지 않는다.
- **교체 불가 상황:** 사망(Death) / 잡힘(Grab) / 다운(Knockdown) / 스토리 시네마틱 중, 파티 인원이 1명일 때.

> 활용 예: 한 캐릭터의 체력이 위험하면 교체로 빼서 회복시키고, 스킬 게이지가 찬 다른 캐릭터로 들어와 화력을 이어간다. (DMC5의 캐릭터 스왑, 원신의 파티 전환과 유사한 감각)

---

## 7. 캐릭터별 스킬 / 궁극기

- **스킬(`E`):** 캐릭터 고유 능력. 스킬 게이지를 소모한다.
- **궁극기(`R`):** 게이지가 충전되면 사용하는 강력한 기술. (같은 키로 무기 발도·납도도 처리된다.)
- 스킬 게이지는 전투 중 누적되며, 캐릭터마다 독립적으로 관리된다. 교체 타이밍과 궁극기 충전 상태를 함께 보고 운영하면 좋다.

## 8. 빠른 참조 (치트시트)

```
이동      WASD          질주        Z(토글)        점프    Space
공격      좌클릭         강/차지     우클릭(짧/길)
회피      Ctrl(무적)     대시        Shift(무적)
가드      V(유지)        퍼펙트가드  V 시작 0.3초 내 → 좌클릭 반격
스킬      E              궁극기      R
상호작용   F             브레이크    F (경직된 적 마무리)
락온      휠클릭         타깃전환    Tab
교체      1 / 2 / 3 / 4
```

**전투 한 줄 요약:** 약공격으로 흔들고 → 강공격/차지로 포이즈 깎고 → 위험하면 회피·대시·가드로 받아치고 → 브레이크되면 `F`로 마무리, 떨어진 회복 오브를 주우며 공세를 유지한다.
