# 프로젝트 문서

현재 정본과 진행 상태는 [작업 위키](wiki/README.md)에서 찾는다. Agent는 작업 시작 시 위키의 해당 분야를 읽고 원문·실제 코드·에셋과 대조한다.

| 위치 | 역할 |
|---|---|
| `wiki/` | 정본 연결·진행 상태·남은 검증과 다음 작업 |
| `dialogue-bake/` | 대사 Bake 공통 계약·절차·검수·조사. 현재 개발 중 자료 보존 |
| `reviews/` | 구현·검증 시점의 근거와 재현 자료. 최신 상태는 위키의 콘텐츠 페이지에서 선택 |
| `balanceguide/` | 스탯 계산 참고. 현행 소비 코드와 대조 |
| `_archive/` | 대체되거나 현재 프로젝트 범위 밖인 역사 자료. 현재 구현 지시로 사용하지 않음 |

상세 저작 규칙은 `Assets/docs/guide/`, 시스템 구조는 `Assets/docs/onboarding/`에 유지한다. 이 폴더로 복사해 두 개의 정본을 만들지 않는다.
