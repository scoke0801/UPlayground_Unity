# River Basin 4KM 항구도시 구현 설계

남부 해안의 교역항이다. 내륙길이 상점가로 물리고, 시장 광장에서 세관과 중앙 부두로 내려간다. 안벽에서 서쪽으로 가면 상선과 창고, 동쪽으로 가면 조선소와 어선 선착장에 닿는다. 상부 지붕 사이로 돛대가 먼저 보이고, 하부 부두에 서면 일렬로 이어지는 창고와 서로 다른 작업장이 도시 규모를 보여 준다. [권역 부지](RIVER_BASIN_REGION_CONCEPT_DESIGN.md) · [구현과 검증 상태](../../../../../docs/work-status/river-basin-world.md#항구도시-1차-구현)

## 시안과 목표 규모

| 내장 ImageGen 시안 | 구현에서 볼 것 |
|---|---|
| [항구도시 조감](../../../../../docs/work-status/river-basin-harbor-evidence/harbor-city-overview.png) | 연속 지붕 4~5개 블록, 시장 광장과 해안 사이의 길, 두 상선의 접안장과 동쪽 조선소. 레퍼런스의 밀집된 상업가와 대형 선박이 만드는 스케일을 적용했다. |
| [시장 출구 TPS](../../../../../docs/work-status/river-basin-harbor-evidence/harbor-city-market-tps.png) | 아케이드가 시장 입구를 감싸고 아래쪽 포석길 끝으로 바다와 돛대가 보이는 구도. 그림에서 넓게 보이는 대로는 블록아웃에서 유효 폭 7~9m로 시작한다. |

**목표는 해안 약 300m, 내륙 깊이 170~200m, 건물 35~45동**이다. 대부분 2~3층으로 묶고 창고는 층수보다 지붕 폭과 큰 출입문으로 규모를 준다. 접안 중인 대형 상선 2척과 조선소에서 작업 중인 선체 1척으로 수변 작업을 구분한다. 시안의 건물·선박 수, 광장 폭, 접안장 형상은 가늠용이다.

## 월드 배치

X/Z 월드 좌표 기준이다. 부지 검토 범위는 X 2675~2975, Z 145~340이며 방파제와 외항은 그 남쪽 수면을 별도로 측량한다. 기존 시장 Y 약 11.12, 중앙 부두 부근과의 높이 차를 이용해 상부 시가지, 중부 광장과 하강로, 하부 안벽의 세 층을 만든다. 실제 지형·물 깊이·타일 경계에서 구역 경계를 조정한다.

| 구역 | 배치와 역할 |
|---|---|
| 상부 진입·주거 | 기존 초견 지점 **2760 / 276**과 내륙길을 도시 입구로 사용한다. 상점가가 모이는 입구와 민가 골목이 이어지고, 지붕 사이를 통해 상선 돛대를 먼저 본다. |
| 중앙 시장과 상회 | 기존 시장 기준 **2790 / 270**에서 시장 광장 약 45 × 32m를 시작값으로 잡는다. 상회 건물과 아케이드를 광장 옆에 두고, 차양·좌판·적재는 가장자리로 보낸다. 주거길, 창고 뒤편 길, 중앙 항만 대로로 갈린다. |
| 항만 대로와 중앙 세관 | `coast-dock` 결절 **2816 / 248**에서 유효 폭 7~9m의 무계단 경사로를 중앙 부두 **2826 / 155** 방향으로 잇는다. 세관은 길 옆에 두고 중앙의 바다 시야와 부두 연결을 확보한다. 골목 지름길에는 단차와 계단을 활용한다. |
| 서쪽 상선 부두 | 연속된 석재 안벽에 상선 선석 두 곳, 화물창고 열, 기중기와 적재 면을 둔다. 안벽을 따라 걸을 수 있게 적재 공간과 유효 보행 폭을 확보한다. |
| 동쪽 조선소·어선 선착장 | 작업장 지붕과 경사 선대, 작업 중 선체를 조선소 표식으로 삼는다. 기존 어항 소품과 작은 배는 구역 끝의 어선 선착장에 모은다. 조선소 바깥길에서 시장 쪽으로 복귀한다. |
| 방파제와 외항 | 기존 양쪽 방파제를 기점으로 확대 범위를 검토한다. 대형선 선체 폭, 회전 여유, 수심이 확보된 뒤 항로와 선석을 확정한다. 짧은 등대는 외항 접근과 밤의 복귀 표식으로 둔다. |

중앙 부두에서 **서쪽 하역장 → 창고 뒤편 길 → 시장**, **동쪽 조선소 외곽 → 어선 골목 → 시장**으로 복귀할 수 있게 한다. 낮에는 시장 쪽 상회 지붕과 해안의 돛대가 이동 방향을 나눠 보여 준다. 밤에는 시장 입구, 하강로 아래 교차점, 세관 입구를 기존 시계 연동 등잔으로 잇는다.

## Unity 제작 순서

1. **측량과 회색 매스.** [RiverBasin4km 프리뷰](../../../../WorldBuilder/Worlds/6effd90b68ea4b3d8f8caa5197fcfe34/Preview/RiverBasin4km.unity)에서 확장 범위의 지형 높이·수심·인접 경로·타일을 확인한다. 건물 35~45동을 개별 디테일 없이 블록으로 잡고, 대형 선체 두 척을 대체 매스로 넣어 항로·안벽·건물 시야를 동시에 검토한다. 기준 사진은 조감, 내륙 초견, 시장 출구, 안벽에서의 역방향 네 구도를 쓴다.
2. **첫 제작 구간.** 내륙 입구–중앙 시장–세관 안벽을 잇고 건축 10~14동을 먼저 마감한다. 이 구간에서 층고, 아케이드 폭, 창고 입면, TPS 동선을 확인한 뒤 좌우 구역으로 반복 사용한다. 통행이 필요한 1층과 작업장에 우선 투자하고 상층과 먼 지붕은 외관 중심으로 만든다.
3. **항만 확장.** 기존 `HarborHouse`, `HarborWarehouse`는 소형 상점·어선 구역, `HarborPier`와 닫힌 줄눈 에셋은 중앙 부두, `HarborLighthouse`는 방파제 표식 후보로 사용한다. 새 제작 우선순위는 연속 상점 입면·아케이드, 큰 창고와 석조 안벽, 상선 선체·돛대와 조선소 선대다. 기존 중앙 부두 접합은 재배치 후 다시 점검한다. 지형 변경이 필요하면 타일 전용 TerrainData 사본을 적용한다. [기존 물가 재작업](../../../../../docs/work-status/river-basin-world.md#사면과-물가-재작업)
4. **플레이와 성능.** 길 변경 후 접지·이음·NavMesh를 검사하고, 주도로와 두 복귀 루프를 낮과 밤에 왕복한다. [가림 규칙](../../../../10.Datas/Camera/CameraOccluderNameRules.asset)에 따라 지붕 건물의 Auto·지붕 충돌과 보행 구조물의 Solid를 확인한다. 블록별 LOD·공용 재질을 적용하고 시장·안벽에서 가시 렌더러, CPU/GPU 프레임 시간과 그림자 비용을 기존 프리뷰와 같은 조건으로 비교한다. ## 건축과 주변 환경

시장에는 회벽 상가와 차양, 서쪽 하역장에는 큰 홍예문이 있는 보세창고, 동쪽에는 환기창이 있는 어망창고를 둔다. 가옥은 지붕색·돌출창·간판을 섞고 입구 돌계단을 지형에 맞춘다. 건물 사이 공간은 화물 적재, 어망 건조, 시장 상품, 민가 텃밭으로 쓰임을 나눈다. 낮은 돌담과 해안 식생은 작업 마당 가장자리에 두고 주 통행로를 비운다. [구현과 검증 상태](../../../../../docs/work-status/river-basin-world.md#항구-건축과-주변-환경-개선)

## 프리뷰 확인 기준

RiverBasin4km Editor Play에서 기본 TPS 카메라로 지도 마커 없이 시작한다. 정오와 22시에 동일 경로를 확인하고 실패 지점은 좌표 또는 화면과 입력 장치로 기록한다.

| ID | 확인 동선 | 기대 결과 |
|---|---|---|
| RB-HARBOR-01 | 내륙 접근 → 시장 → 세관과 중앙 부두 | 내륙에서 돛대나 상회가 보인다. 시장 출구에서 하강 방향을 읽고 계단·적재물에 막히지 않고 중앙 부두에 도달한다. |
| RB-HARBOR-02 | 중앙 부두 → 서쪽 상선 구역 또는 동쪽 조선소 → 시장 | 두 구역이 실루엣과 작업물로 구별되고 각 길의 복귀 방향을 알 수 있다. 안벽을 뛰어도 적재 소품에 걸리거나 의도치 않게 수영으로 바뀌지 않는다. |
| RB-HARBOR-03 | 아케이드·세관 모서리·선착장 카메라와 수변 복귀 | 카메라가 구조물을 관통하거나 캐릭터를 지속해서 가리지 않는다. 의도한 수변 사다리나 경사에서 지상으로 복귀하고 야간에 다음 등잔을 찾는다. |

회신 형식은 `항목 ID / 통과·실패·미수행 / 실제 결과 / 화면 또는 로그`다.
