# 스킬 체인 에디터 - 5분 빠른 시작

## 🚀 1단계: 에디터 열기 (10초)

```
Unity 상단 메뉴 → Tools → Skill Chain Editor
```

## 🎨 2단계: 첫 체인 만들기 (2분)

### 노드 3개 추가
```
1. 상단 [Add Node] 버튼 클릭 × 3
   또는
   빈 공간 우클릭 → Add Node × 3
```

### 노드 배치
```
드래그로 가로 정렬:
[노드1] → [노드2] → [노드3]
```

### 노드 연결
```
1. 노드1의 빨간 점 클릭
2. 노드2의 녹색 점으로 드래그
3. "Add X Branch" 선택

4. 노드2의 빨간 점 클릭
5. 노드3의 녹색 점으로 드래그
6. "Add X Branch" 선택

결과:
빨간선으로 연결된 3개 노드
```

## ⚙️ 3단계: ID 설정 (2분)

### 각 노드 편집
```
노드1 우클릭 → Edit Node
  Skill ID: 2001

노드2 우클릭 → Edit Node
  Skill ID: 2002

노드3 우클릭 → Edit Node
  Skill ID: 2003
```

## 💾 4단계: 저장 (30초)

```
1. 상단 [Save JSON] 클릭
2. Assets/10.Datas/Json 폴더 선택
3. 파일명: MyFirstChain
4. 저장 완료!
```

## ✅ 완료!

이제 다음 체인이 만들어졌습니다:
```
2001 (X) → 2002 (X) → 2003
```

## 🎮 테스트하기

### 1. Json을 Addressable로 설정
```
MyFirstChain.json → Addressable
Address: "SkillChainDataTable"
```

### 2. 코드에서 사용
```csharp
// PlayerBrain.cs
if (Input.GetKeyDown(KeyCode.X))
{
    SetData("CurrentSkillID", 2001);
    ChangeState(skillChainState);
}
```

### 3. 플레이!
```
게임 실행 → X 키 누르기
→ X키로 체인 진행 확인
```

## 📚 다음 단계

### 분기 추가하기
```
노드1에서:
  빨간점 → 노드4 녹색점
  → "Add Y Branch"

결과:
2001 (X) → 2002 (X) → 2003
     (Y) → 2004
```

### 입력 윈도우 조정
```
노드 우클릭 → Edit Node
  Window Start: 0.5
  Window End: 0.9
  
→ 녹색 타임라인으로 확인
```

## 🔧 자주 사용하는 작업

### 노드 빠르게 추가
```
빈 공간 우클릭 → Add Node
```

### 연결 빠르게 만들기
```
빨간점 → 녹색점 → 키 선택
```

### 노드 삭제
```
노드 우클릭 → Delete Node
```

## 💡 꿀팁

### ID 체계적으로 관리
```
2001, 2002, 2003... (검 체인)
3001, 3002, 3003... (창 체인)
4001, 4002, 4003... (활 체인)
```

### 화면 정리
```
노드를 드래그로 깔끔하게 정렬
→ 트리 구조가 한눈에 보임
```

### 자주 저장
```
작업 중 자주 [Save JSON]
→ 실수로 닫아도 안전
```
