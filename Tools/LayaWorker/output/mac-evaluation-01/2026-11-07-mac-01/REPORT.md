# Mac Laya 고정 평가

**결론은 규칙 정책 우선이다.**

- 환경 Apple M2 / macOS 14.0 / Python 3.12.16.
- 패키지 laya-mlx 0.6.0, mlx 0.32.4, tokenizers 0.23.3, numpy 2.5.4, huggingface-hub 1.33.0.
- 본 평가 요청 960/960건 실행 시도.
- 규칙 기준선 40/40건 일치.
- 한국어 입력의 물음표 손상 40개 사례. 원본 그대로 실행했으며 한국어 및 언어 일치율은 정상 번역 평가에 사용할 수 없다.
- Unity 전투와 Windows↔Mac 통신은 이번 Mac 단독 작업 범위 밖이다.

## 수행 결과

- M01 자동 검사 0, 참고 데이터 검사 0.
- M02 토큰 검사 4/4 통과.
- M03 기존 행동·확률 동시 재현 6/6건.
- M04 960/960건 시도. 오류 0건, 미수행 0건.
- M05 Mac loopback 7/7 통과. 서버 정리 True.
- M06 고정 기준 채점, 언어 손상 기록 및 권고 산출.
