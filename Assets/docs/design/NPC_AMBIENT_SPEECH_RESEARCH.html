NPC 일상 말풍선 조사와 적용 기준

상태: 조사 반영 설계. 조사일: 2026-11-09. 기존 초안의 문장 조합 1,024개는 사용하지 않는다. 외형에 맞는 어미만 바꾸는 것으로 주민의 개성을 만들 수 없으며, 반복 억제는 문자열 중복과 소재 중복을 구분해야 한다.

1. 확인한 자료와 근거의 범위

자료직접 확인한 내용프로젝트 적용 판단
넥슨: 말풍선 만들기 · 공식 한국어 제작 문서머리 위 위치, 꼬리, 글자 위치·크기·색, 표시·비표시 시간을 각각 다룬다. 빈 문구는 표시하지 않는다.머리 위 꼬리와 이름으로 화자를 식별하고, 표시 시간과 침묵 시간을 분리한다. 문서 예제의 시간을 이 게임의 최적값으로 간주하지 않는다.
던전앤파이터: 호감도 · 공식 가이드호감 단계의 NPC 곁을 지날 때 친근한 말풍선을 표시하는 사례를 설명한다. 검색 색인으로 확인했으며 직접 열기는 403이었다.친근한 호명은 관계와 접근 맥락이 있어야 한다. 현재 프로젝트에 없는 관계 사실을 대사로 꾸며 넣지 않는다.
메이플스토리 마파, 학자 다니엘, 브루스 · 비공식 한국어 대사 채록상인의 호객, 머무는 장소에 관한 개인 사정, 연구 관심과 관계에 따른 인사처럼 화자별 관심사가 드러난다. 공식 구현 사양이나 전체 대사의 정확성을 증명하는 자료는 아니다.한국어 발화 목적을 비교하는 참고로만 쓴다. 기존 게임의 대사를 복사하지 않으며 고전 게임의 문어체 어미도 그대로 이식하지 않는다.
Valve / Elan Ruskin: AI-driven Dynamic Dialog · GDC 2012 발표 소개세계 사실과 이력을 대사 후보와 맞추고 특수한 상황에서 일반 상황으로 내려가는 선택 방식을 설명한다. 발표 소개를 확인했으며 19MB 슬라이드 전문은 웹 도구 용량 제한으로 읽지 못했다.현재 행동·시간대로 후보를 거른 뒤 추첨한다. 조건에 맞는 새 대사가 없으면 침묵한다. 거대한 규칙 엔진을 새로 만들지는 않는다.
Naughty Dog / Jason Gregory: A Context-Aware Character Dialog System · GDC 2014 발표 소개개인·집단 지식, 세계 상태, 주변 환경을 사용하는 대화 시스템의 목적을 설명한다. 소개문을 확인했으며 발표 영상을 시청한 것은 아니다.NPC가 확인하지 못한 사건을 아는 척하거나, 위험을 피해 달아나는 중 평온한 일상 대사를 하는 일을 막는다.
Natalie Mikkelson: Adding Life To Worlds With Dialogue Barks · 저자의 실무 저작 글혼잣말과 엿들은 대화, 하던 행동을 출발점으로 삼는 저작, 직업 안에서도 다른 성격을 만드는 접근을 제안한다.문장은 삶의 교훈 대신 작은 실수·욕심·불평·기억·말버릇을 드러낸다. 한 줄로 독립해도 발화 이유를 설명할 수 있어야 한다.
Microsoft XAG 104 · 공식 접근성 지침화자 식별, 충분한 대비, 배경, 자막 종류별 설정 등을 권장하며 대화·주변 발화의 구분 사례를 보여준다.이름과 본문을 분리하고 불투명한 어두운 배경을 사용한다. 이번 머리 위 UI만으로 게임 전체 접근성 준수를 주장하지 않는다.
국립국어원 모두의 말뭉치 · 공식 구어 자료 안내일상 대화의 음성·전사 자료와 맥락상 생략된 성분을 다루는 자료를 구분한다. 제한된 말뭉치 원문을 내려받거나 게임에 전재하지 않았다.구어의 생략과 머뭇거림을 허용하되 의미를 이해할 단서는 남긴다. 게임 말풍선에 맞는 길이는 플레이 검수로 판단한다.

2. 초안이 실패한 이유

첫 문장 4개와 뒷문장 8개의 곱은 서로 다른 장면 32개가 아니다. 같은 주민이 매번 식사·옷·휴식의 교훈으로 돌아가면 문자열이 달라도 같은 말을 들은 느낌이 난다. 해요체와 반말의 차이만으로는 관심사, 사소한 결점, 현재의 목적을 구분할 수 없다. 특히 혼잣말을 모두 정중한 완결 문장으로 쓰면 누군가에게 교훈을 전달하는 독백처럼 들린다.

3. 한국어 저작 기준

  • 완성된 한 발화를 독립 저작한다. 앞뒤 문장 조합, 동의어 치환, 어미 변환으로 개수를 채우지 않는다.
  • 뭘 잊었는지, 어디가 거슬리는지, 무엇을 먹고 싶은지처럼 구체적인 욕구와 마찰을 쓴다. 여유·마음·소중함을 반복하는 격언은 제외한다.
  • 독백은 꼭 남에게 설명하듯 끝낼 필요가 없다. 다만 지시 대상 없는 질문만 연달아 내보내거나 모든 발화에 감탄사를 붙이지 않는다.
  • 외형은 목소리의 인상을 정하는 단서다. 갑옷을 입었다고 군인, 로브를 입었다고 학자라는 직업을 확정하지 않는다. 작업 도구나 관계가 필요한 대사는 실제 저작 근거가 있을 때만 사용한다.
  • 고유 NPC는 실제 초상·모델과 기존 정식 대사를 함께 확인한다. 범용 주민의 말투를 무작정 덮지 않는다.
  • 날씨·시간·작업·상대가 필요한 문장에는 조건을 붙인다. 현재 작업을 구체적으로 알 수 없으면 재봉·요리·경비 등을 지어내지 않는다.

4. 선택·반복·중단 처리

선택 순서: NPC 말투 연결 → 실제 행동·시간 조건 → 최근 같은 문장 제외 → 화자와 주변의 같은 소재 제외 → 오래 안 한 후보 우선 추첨. 같은 문장을 다른 NPC가 곧바로 반복하는 것도 막는다. 후보가 없으면 다음 판단까지 침묵한다. 이를 해결하려고 조건에 맞지 않는 문장을 강제로 출력하지 않는다.

정식 대화·메뉴·일시정지·위험 반응·상호작용·서사 제어·비언어 교류 중에는 발화를 막고 떠 있는 말풍선을 정리한다. 대상이 비활성화되거나 등록 해제되면 풀을 반환한다. 표시 중에도 행동·시간 조건이 바뀌면 정리한다.

5. 말풍선 UI 적용

ImageGen으로 만든 어두운 갈색 바탕과 얇은 금색 테두리를 고정 레이아웃 프리팹에 사용한다. 그림에 글자를 굽지 않고 기존 한국어 TMP 폰트로 이름과 본문을 렌더한다. 배경과 꼬리의 비율을 유지하고 문장은 한두 줄로 제한한다. 타자 연출로 지나가는 플레이어를 붙잡지 않고 짧은 페이드로 등장·퇴장한다. 모든 트윈은 SetUpdate(true)로 동작하고 반환 때 Kill한다.

머리 소켓을 따라가되 화면 끝으로 말풍선을 강제로 밀지 않는다. 화면 밖·후방·차폐된 화자는 숨긴다. 같은 위치의 말풍선은 겹쳐 띄우지 않는다. 입력 포커스·커서·게임플레이 액션은 점유하지 않는다.

초기 조정값: 거리 16m, 최대 2개, 발화 시작 간격 5초, 주민별 휴지 22~48초, 읽기 4~8초. 모두 이 프로젝트의 튜닝 시작값이며 조사 자료가 입증한 최적값이 아니다. 화면 밀도와 TPS 이동 속도로 사용자 플레이 검수 후 조정한다.

6. 검수와 남은 범위

1,024개 숫자 검사는 품질 검수와 다르다. 정확 중복·길이·ID·조건·참조를 자동 검사하고, 첫 문장 반복과 같은 소재의 연속 노출도 확인한다. 실제 한국어 어투, UI 대비와 줄바꿈, 이동 중 읽기, 캐릭터별 어울림은 사용자 Editor Play Mode 검수 대상으로 남긴다. 이번 구현은 일상 발화이며, 두 사람이 서로 응답하는 유성 대화나 새로운 스토리 사실·퀘스트를 추가하지 않는다.
