## P1 차단: 공통 보정 배율의 해가 없음

[적용 후 실제 장비 기여도](item-economy-contribution.csv), [P1 예산 공통 배율 검산](item-economy-correction.csv). 수치 기준 프로필은 라온, 무기 수치 표준시료는 소검 1001/1003/1005다. 라온이 소검을 실제 장착할 수 있다고 주장하는 테스트는 아니며 P2 카타나 승급 전의 오프라인 비교다. 실제 카타나 B1 수정값은 표준시료와 같은 AP/치명이다. 순수 Calculate에 확정 인스턴스/롤을 전달하며 추첨하지 않는다. P1 제안은 저장하지 않는 SO에서 검산했다.

P0 실제 B2 소검 1003은 0.07/0.07이어서 공격 기여 9.63%, 생존 58.48%다. 위 P1 제안 행은 문서의 0.08/0.06을 사용하므로 구분한다. 방어구 HP 랭크2를 5부위에 고정한 별도 사례는 예산 ×0에서도 롤만으로 생존 기여가 Lv1 62.5%, Lv5 50%, Lv10 40%여서 25~35% 합격 구간 자체가 없다. CSV의 `empty`가 이 뜻이다. P3 rankValueScale은 아직 미반영이다.

양 축을 맞추려면 무기와 방어구 예산의 상대 비율을 바꿔야 한다. 이는 9-1절 ⑤의 **해당 밴드 방어구·무기에 같은 배율** 조건을 변경하는 결정이다. 자율 판단 규칙은 그 조건을 따르도록 명시하므로 독립 배율을 임의 도입하거나 목표를 낮추거나 몬스터 HP를 수정하지 않았다. 게이트를 통과했다고 처리해 후속 단계로 진행할 수 없다. 다음 재개 조건은 공통 배율 조건을 두 축별 예산 보정으로 바꾸거나 기여도 기준을 재정의한 정본 결정이다.

**현재 P0 결과는 전체 경제 개편의 배포 완료본이 아니다.** P0의 빈 값 공식 적용과 기존 x04·x05 보존 조건 때문에 상의/하의 x03→x04, 모자 x06→x07 등에 하락 구간이 남는다. P1 전체 사다리 재산정 전에는 제작 사슬 전체가 성장한다는 인수를 할 수 없다. 3단계<다음 밴드·드랍/레시피 참조·세이브 호환·UI·새 스킨 검사는 미수행이다.

## 사용자 확인 명세

현재 전체 경제 밸런스는 차단 상태다. 20분 드랍 체감·제작 선택지·중복 수·골드 수급 검사는 P1 이후 실제 데이터가 반영된 뒤 수행한다. ImageGen 미술 품질·체형별 적용은 P4 산출물 생성 이후 **사용자 테스트 대기**이며 지금 확인할 새 스킨은 없다.

D14 회귀를 직접 확인할 때는 LakeVillageWorld의 테스트 저장 슬롯에서 라온과 HP 롤이 붙은 모자를 준비한다. E01: 착용 전후 최대 체력 증가가 고정 HP+롤 HP와 맞는지 확인. E02: 다른 캐릭터로 교체했다가 돌아와 최대 체력·현재 체력 비율이 일관적인지 확인. 실패 시 캐릭터·아이템 ID·롤 랭크·교체 전후 HP를 기록한다. 기존 저장에 테스트 장비를 추가해 저장하지 않는다. 회신 형식은 `E01/E02 / 통과·실패·미수행 / 수치·증상 / 로그`다.

## 보존과 미수행

기존 다수 미커밋·미추적 변경 보존. Player·Addressables 빌드, 커밋 없음. 구매 원본·미추적 아트·meta 삭제/덮어쓰기 없음. 임시 측정 코드는 scratchpad/item-economy에만 두며 런처에 등록하지 않는다. 20분 플레이와 스킨 미술 품질은 사용자 테스트 대기다.
