# D 주변 반응

## 재개 후 현재 반영

대표 4명의 기존 휴식점에 기존 Farm 지붕 프리팹 4개와 지면부터 실제 지붕 접점까지 맞춘 기둥 16개를 연결했다. 실제 위쪽 roof ray와 캡슐 바닥 여유, 출입 경유점을 검사했다. 보호 플래그만 바꾼 것이 아니다. 보호점은 기존 Joy `(1033,404)`, Yeonmok `(987,429)`, 일반 주민 `(975,414)`/`(986,417)`의 같은 pointId를 유지한다.

정적 경로 30건/지붕 4건, 실패 0이다. 실제 비/강풍 안정·피신·복귀는 LIFE05 사용자 검수다. 기존 위험/대화 우선권은 유지한다. 같은 자극 생산자를 다시 연결해도 중복 기록을 지우지 않으며, NaN/Infinity 위치도 거부한다. 예약 전 지연된 관심 반응도 대화/서사 중단에서 취소하도록 보완했다.

아래의 보호점 저작 미완료는 최초 기록이다. 실물 보호점 보완은 반영됐고 실제 플레이 검수와 신규 주민 활성화 승인은 남아 있다.

위험은 기존 NpcThreatScanner/CombatReaction/React/Return과 PauseRoutine이 소유한다. 별도 공포 AI나 전투 반응 인원 제한을 추가하지 않았다. 기존 EnvironmentController→NpcRoutineEnvironmentBinding의 맵/생산자/revision/히스테리시스를 유지한다. 대표 생성 주민 두 명도 같은 환경 바인딩에 추가했다.

국소 자극은 실제 `GatheringActor.OnHitEvent → ImpactOccurred → NpcLifeStimulusSource → NpcLifeController.ConsumeStimulus` 경로다. 테스트 버튼 전용 입력이 아니다. 생산자 토큰, 생산자 내 사건 번호, 논리 mapId, 위치, 발생/만료 시각, 중요도를 전달한다. 교체 전 생산자·다른 맵·역순/중복 사건·만료/미래/NaN/Infinity 시각은 거부한다. 소란만 직렬화된 인원 상한을 두고 시작 순서를 분산한다. 역할 프로필의 확률·거리·지연·관심 시간·재사용 대기를 사용한다.

이번 입력은 **청각 자극**이다. 시야/가림 검사를 생략한 청각 관심을 시각 감지로 표시하지 않는다. 자유 활동의 짧은 시선으로만 소비하며 필수 작업/대화/교류/피신을 선점하지 않는다. 사건에 따라 퀘스트·자원·보상 플래그를 쓰지 않는다.

씬 참조 검사에서 실제 채집 생산자에 연결된 NpcLifeStimulusSource 1개를 확인했다. 정확한 오브젝트와 위치는 최종 씬 기록에 남긴다. 실제 채집 타격 및 사용자 시각 반응은 대기다.

**보호점 콘텐츠 미완료:** 기존 보호 플래그 12개는 false였으며 실제 지붕/안전 경로 승인 근거가 없다. true로 바꾸지 않았다. 따라서 비/강풍 피신·안정 후 복귀 전체를 완료로 표시할 수 없다. 실제 지붕과 접근 동선을 저작한 후 LIFE05가 필요하다. 국소 사건 입력 경계는 신규 EditMode 검사에 포함하며 실제 자연 날씨/전투는 LIFE04/05로 구분한다.
