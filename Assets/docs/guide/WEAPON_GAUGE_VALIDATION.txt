캐릭터 무기 스킬 게이지 검증

반영: ImageGen 무기 원본 13종, 기존 이미지 GUID 보존, H09 전용 프로필 추가.
WeaponChannel 모드에서 원본 청록색을 내부 채널로 읽고 테두리는 고정한다.
캐릭터 색·충전 범위·UV·충전 연출 값은 CharacterGaugeVisualProfileSO에서 조정한다.
원본 및 프롬프트: Assets/04.Images/UI/CharacterGauge/WeaponGaugeGeneration.json

자동 보조 검사: UI.Tests csproj 및 의존 프로젝트 컴파일 오류 0 (경고 33).
13종 PNG 투명 영역·채널 픽셀 확인. Shader Graph 노드·슬롯·신규 입력 연결 정적 검사 통과.
Unity 에셋 로드, Shader Graph 컴파일, EditMode 테스트 실행, 실제 HUD 검수는 사용자 테스트 대기.
Player 전용 경로·모듈 경계 변경이 없어 Windows Player 빌드는 수행하지 않음.

준비
Unity 6000.3.21f1에서 프로젝트 임포트가 끝난 뒤 Console을 확인한다.
기존 테스트는 씬을 바꾸므로 편집 중인 씬을 저장한 뒤 실행한다.
Test Runner > EditMode > UPlayGround.UI.Tests.CharacterGaugeTests를 실행한다.
실제 화면은 CombatTestMap에서 사용 중인 테스트 세션의 캐릭터 교체 기능으로 확인한다.

G01 / 에셋 임포트 및 테스트
위 테스트 클래스 전체 실행. 프로필 14개(13명 + Neutral), 캐릭터 정의 13개 연결.
기대: 컴파일·셰이더 오류 0, 모든 테스트 통과. 핑크색·누락 스프라이트·예외는 실패.

G02 / 캐릭터별 모양
Raon·Arin=카타나, Hwarin=양날 도끼, Reine=창, Lian=직선 분절 체인블레이드, SeolA=활,
Sera·Lili=대검, Yura=쌍검, MyoRyeong=검방패, YeonHoa·Myomyo·H09=지팡이.
기대: 교체마다 해당 모양과 캐릭터 고유색으로 변경. HP·레벨·속성 아이콘과 겹치지 않음.
Hwarin/Lian/MyoRyeong은 최대 360x48 안에서 원본 비율을 보존한다. 나머지는 430x36이다.
실제 플레이 해상도에서 테두리·내부 채널이 식별되어야 한다.
검방은 손잡이와 가드가 보이고, 확대된 방패가 검날 중앙에 있어야 한다.
리안은 실제 WhipWeapon 모델처럼 분절된 칼날이며 휘어진 가죽 줄이 아니어야 한다.

G03 / 충전·소비
0%, 약 25%, 50%, 100%를 비교하고 스킬 사용으로 자원을 소비한다.
기대: 빈 내부는 어둡고, 왼쪽에서 오른쪽으로 고유색이 채워짐. 은색 테두리 고정.
0%에 잔광이 남거나 100%에 빈 틈이 남으면 실패. 소비 시 잔상은 짧게 사라짐.
채찍·활·쌍검은 가로 진행 기준이며 곡선 경로를 따라 흐르는 방식은 아님.

G04 / 사용 가능 상태·일시정지
스킬 사용 가능 상태 진입, 쿨다운, 일시정지, HUD 연출 감소 옵션을 각각 확인한다.
기대: 사용 가능 진입 시 짧게 강조. 쿨다운 중 완충만으로 사용 가능 표시하지 않음.
일시정지 중 UI 트윈 정상 동작, 연출 감소 옵션은 흐름·펄스 억제. 패드 조작 변화 없음.
