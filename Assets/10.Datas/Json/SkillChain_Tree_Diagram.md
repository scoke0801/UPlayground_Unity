# 스킬 체인 트리 다이어그램

## 🗡️ 검 스킬 체인 (2000번대)

```
시작: Basic Slash (2001)
│
├─ [X 입력] → Slash Combo 2 (2002)
│   │
│   ├─ [X 입력] → Triple Slash (2003) ⭐ 종료
│   │                └─ 데미지: 높음
│   │                └─ 마나: 0
│   │
│   └─ [Y 입력] → Spin Slash (2011)
│       │         └─ 데미지: 중간
│       │         └─ 마나: 15
│       │
│       └─ [X 입력] → Power Smash (2014) ⭐ 종료
│                     └─ 데미지: 매우 높음
│                     └─ 마나: 30
│                     └─ 쿨다운: 5초
│
└─ [Y 입력] → Rising Slash (2010)
    │         └─ 데미지: 중간
    │         └─ 마나: 10
    │
    ├─ [X 입력] → Plunging Attack (2012) ⭐ 종료
    │             └─ 데미지: 높음
    │             └─ 마나: 20
    │             └─ 쿨다운: 3초
    │
    └─ [Y 입력] → Air Combo (2013) ⭐ 종료
                  └─ 데미지: 다단히트
                  └─ 마나: 25
                  └─ 쿨다운: 2초
```

## 📊 체인별 특징 비교

### 검 체인 특징
| 경로 | 키 입력 | 총 단계 | 총 마나 | 난이도 | 추천 상황 |
|------|---------|---------|---------|--------|-----------|
| X→X→X | XXX | 3 | 0 | ⭐ | 마나 부족 시 |
| X→X→Y→X | XXYX | 4 | 45 | ⭐⭐⭐ | 높은 단일 데미지 |
| X→Y→X | XYX | 3 | 30 | ⭐⭐ | 빠른 고데미지 |
| X→Y→Y | XYY | 3 | 35 | ⭐⭐ | 다단히트 필요 시 |

### 창 체인 특징
| 경로 | 키 입력 | 총 단계 | 총 마나 | 난이도 | 추천 상황 |
|------|---------|---------|---------|--------|-----------|
| Y→Y→X | YYX | 3 | 20 | ⭐⭐ | 단일 타겟 |
| Y→Y→Y | YYY | 3 | 35 | ⭐⭐⭐ | 다수 타겟 |

## ⏱️ 입력 윈도우 타이밍

### 검 스킬 타이밍
```
2001 (Basic Slash)
├─ 애니메이션 길이: 1.0초
├─ 입력 윈도우: 0.5초 ~ 0.9초 (0.4초)
└─ 권장 입력: 0.6초 ~ 0.7초

2002 (Slash Combo 2)
├─ 애니메이션 길이: 1.2초
├─ 입력 윈도우: 0.5초 ~ 0.9초 (0.4초)
└─ 권장 입력: 0.7초 ~ 0.8초

2010 (Rising Slash)
├─ 애니메이션 길이: 1.5초
├─ 입력 윈도우: 0.4초 ~ 0.85초 (0.45초)
└─ 권장 입력: 0.5초 ~ 0.6초

2011 (Spin Slash)
├─ 애니메이션 길이: 1.8초
├─ 입력 윈도우: 0.6초 ~ 0.95초 (0.35초)
└─ 권장 입력: 0.7초 ~ 0.8초
```

### 창 스킬 타이밍
```
3001 (Thrust)
├─ 애니메이션 길이: 0.8초
├─ 입력 윈도우: 0.5초 ~ 0.9초 (0.4초)
└─ 권장 입력: 0.6초 ~ 0.7초

3002 (Double Thrust)
├─ 애니메이션 길이: 1.0초
├─ 입력 윈도우: 0.5초 ~ 0.9초 (0.4초)
└─ 권장 입력: 0.6초 ~ 0.7초
```

## 💡 전략적 활용

### 마나 효율 최대화
```
XXX (마나 0) → 기본 딜링
└─ 마나가 부족할 때 안전한 선택
```

### 폭딜 콤보
```
XXYX (마나 45)
└─ 2001 → 2002 → 2011 → 2014
└─ 최고 단일 데미지
└─ 보스전 추천
```

### 다단히트 콤보
```
XYY (마나 35)
└─ 2001 → 2010 → 2013
└─ 공중 적 처리
```

### 빠른 마무리
```
YYX (마나 20)
└─ 3001 → 3002 → 3003
└─ 빠른 실행, 준수한 데미지
```

## 🎮 플레이 팁

### 초보자 추천
1. **XXX**: 가장 안전하고 쉬운 콤보
2. **YYX**: 간단한 창 콤보

### 중급자 추천
1. **XYX**: 마나 효율적인 고데미지
2. **YYY**: 범위 공격

### 고급자 추천
1. **XXYX**: 최고 데미지 체인
2. 상황별 분기 선택 마스터

## 🔧 커스터마이징 가이드

### 새 분기 추가하기
```json
{
  "currentSkillID": 2003,
  "branches": [
    {
      "inputKey": "X",
      "nextSkillID": 2020,
      "description": "추가 연계"
    }
  ]
}
```

### 입력 윈도우 조정
```json
// 쉬운 입력 (긴 윈도우)
"inputWindowStart": 0.4,
"inputWindowEnd": 0.95

// 어려운 입력 (짧은 윈도우)
"inputWindowStart": 0.65,
"inputWindowEnd": 0.8
```

### 다른 입력 키 사용
```json
{
  "inputKey": "A",  // 또는 "B", "LT", "RT" 등
  "nextSkillID": 2030
}
```
