# 연속 월드 재설계 인수 테스트

호수·여울마을·돌등성(`StonegateCitadel`)·소금바람항(`SaltwindHarbor`) 사이의 지형과 순환 동선을 재작업했다. 아래 항목은 모두 **사용자 테스트 대기**다. 자동 검사 결과를 실제 플레이 합격으로 대신하지 않는다. [변경 전후와 검수 기록](../../../output/OpenWorld/Redesign/RESULT.md), [전체 구조도](../../../output/OpenWorld/Redesign/map-after.svg)를 함께 본다.

## 준비와 동선

Unity 툴 런처 → **호수·여울마을·돌등성·항구 도보 연결**. 저장 경로 호환을 위해 생성 월드 이름은 `LakeVillageWorld`다. 원본 3.4 저장은 기존 Single 씬에서 열린다. 저장 검사는 복사 슬롯에서 수행하고 원본 슬롯을 덮어쓰지 않는다.

- 여울마을은 시작 지점 서쪽의 기존 길이다.
- 돌등성 길: 기존 성채 표지판 `(1005, 약63, 430)` → 집 사이의 흙길 → 남쪽 접근로 → 성채 입구 `(860, 약62, 225)` → 광장 `(860, 약62, 76)`.
- 항구 길: 기존 항구 표지판 `(1125, 약52, 380)` → 남동쪽 흙길 → 항구 입구 `(1220, 약50, 225)` → 시장 `(1220, 약50, 136)`.
- 도시 간 교역로: 성채 앞 `(860,62,245)` → `(900,62,270)` → `(970,61,285)` → 하곡 `(1090,53,270)` → 항구 북문 `(1220,50,275)`. 호수 쪽으로 되돌아가지 않고 두 도시 사이를 걷는다.
- 능선 대안: 분기 `(1020,62,310)` → `(985,65,320)` → `(950,69,335)` → 조망 `(910,72,345)` → `(875,71,330)` → `(845,68,300)` → `(835,65,275)` → 성채 앞 `(860,62,245)`. 72m 조망에서 성채 방향을 읽고 낮은 교역로로 돌아온다.
- 하곡 귀환: 교역로 `(1130,51.5,270)` → `(1125,53,305)` → `(1135,54,330)` → `(1150,54.25,350)` → 기존 항구 표지판. 새로운 길은 수영/등반/탈것을 요구하지 않는다.
- `ContinuousWorldController.Regions`에서 지역별 `State`, `Failure`, `Generation`, `LoadCount`, `UnloadCount`, `HasHandle`과 진단 지연/실패를 확인한다. 도시 논리 경계는 Z=260 부근이다. 지면·건물은 상주하고 주민·생활 콘텐츠는 지역별로 로드된다.
- 기본 게임패드 동쪽 버튼은 대시/열린 UI의 뒤로 가기, Start는 메뉴 열기/닫기다. 키보드 Escape와 Shift는 유지한다. 이전 대시→Pause 충돌에 코드 수정이 반영됐지만 실물 패드 합격은 아직 아니다.

## 실행 항목

먼저 아래 탐험 항목을 지도 없이 진행한다. 기존 CITY 항목은 회귀 검사다. 좌표는 진행자가 시작점을 찾는 용도이며 플레이어에게 다음 목적지를 계속 알려 주지 않는다.

| ID | 동선과 조작 | 관찰할 경험 | 실패 기준 |
|---|---|---|---|
| WORLD-01 | 호수 남쪽 분기에서 성채로 처음 이동 | 성채 실루엣을 읽고 낮은 길/능선길 중 하나를 고를 수 있음 | 어느 쪽이 성채인지 전혀 읽히지 않거나 한 길만 통행 가능 |
| WORLD-02 | 능선 조망 → 성채 앞 → 교역로로 돌아오기 | 높은 조망, 일부 차폐, 새로운 접근 각도 때문에 우회의 이유가 있음 | 같은 경관만 반복되거나 줄기가 정면 목표를 가림 |
| WORLD-03 | 성채 → 하곡 → 항구 → 강변 귀환 | 성채가 뒤로 사라지고 하곡/항구 랜드마크가 드러남, 귀환 중 마을과의 관계를 이해 | 모든 목적지가 계속 노출되거나 저지대/항구의 방향을 잃음 |
| WORLD-04 | `(970,285)`, `(1090,270)`, `(1135,330)`에서 길 밖으로 10~15m 이동, 대시·점프·카메라 회전 | 도로 밖 완만한 지면, 탐색/후퇴 공간, 줄기 관통/부유/직선 절개 없음 | 보이지 않는 벽, 지형 틈, 갑작스러운 카메라 압박 |
| WORLD-05 | 접근로에서 현재 전투 조작으로 락온·회피·후퇴·원거리 교전 | 지형 변화가 전투 선택을 주며 카메라를 계속 막지 않음 | 지형 때문에 적/플레이어가 고착되거나 공격 판독 불가 |
| WORLD-06 | 항구 진입 → 시장 → 창고 → 하역장 → 부두, 성채의 창고/시장, 마을 밭/우물 | 건물 지반과 접근로, 물자/작업 이동이 이해됨 | 부유 주택, 지지 없는 부두, 작업점 접근 불가 |

수면과 서쪽 외곽 급사면은 보행 검수 경로가 아니다. 멀리 보이는 해안/절벽이 접근 가능하다고 오해되는지 별도로 기록한다. 현재 미니맵 배경은 이전 지역 이미지이므로 새 순환로와 일치하지 않는 알려진 미완료 항목이다. 지도 배경 불일치를 정상으로 인수하지 않는다.
