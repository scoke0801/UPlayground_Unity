다온 목 연결면 — 사용자 직접 테스트

준비
Unity 6000.3.21f1, 현재 작업본. 기존 작업 씬은 사용자가 원하는 방식으로 보존한다.
기존 시작 경로로 생명의 호수의 다온을 만난다. 저장이 필요하면 별도 테스트 슬롯을 사용한다.
키보드/마우스 또는 사용 중인 게임패드와 실행 씬을 결과에 적는다.
AI Editor 검사와 실제 스킨 정지 화면은 통과했지만 아래 Play Mode 항목은 사용자 테스트 대기다.

DN01 / 근접 화면
다온의 얼굴과 목을 정면·좌우 45도·측면에서 관찰한다.
기대: 턱 아래 검은 빈 공간·배경 투과·얼굴 소실 없음. 얼굴부터 목·목 아래까지 피부색이 자연스럽게 이어짐. 재질 경계가 띠처럼 보이면 실패.

DN02 / 대화·고개 회전
대화를 시작하고 위치를 바꾸어 시선을 유도한다. 입 벌림·눈 감기와 좌우 고개 회전을 관찰한다.
기대: 표정과 회전 중에도 목이 벌어지지 않고 헤어·얼굴·목이 함께 움직임.
진행 성공과 Console 신규 오류 유무는 별도로 판정한다.

DN03 / 이동·재진입
다온의 대기·보행을 관찰하고, 카메라를 멀리했다 가까이한 뒤 지역을 재진입한다.
기대: 같은 외형이 유지되고 얼굴·목이 갑자기 사라지지 않음.

실패 시: 항목, 각도/동작, 시작 씬·입력 장치, 화면 또는 신규 Console 로그를 전달한다.
회신: ID / 통과·실패·미수행 / 실제 결과 / 화면 또는 로그
