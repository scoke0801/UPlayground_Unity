# 궁극기 품질 재작업 (2026-11-15)

사용자 피드백: 얼굴 컷인 과속, DoubleAxe 회전 중 반복 정지, Spear 투척 부조화, 나머지 캐릭터 전수 개선. **후속 데이터·저작 코드 개선 반영, 실제 전투·미술 인수 대기.** 아래 첫 단계 기록보다 후속 결과를 우선한다.

정본: [시그니처 설계](../../../Assets/docs/design/combat/player/WEAPON_SIGNATURE_SKILL_CLIP_DESIGN.md). [전투 위키](../../wiki/combat.md).

## 적용한 첫 단계

Player/Signature의 얼굴 이벤트가 있는 MotionSet 10개를 Unity API와 Undo로 수정·개별 저장했다. 등장 0.24초, 퇴장 0.30초, 유지 최대 1.20초이며 모션 종료 0.05초 전 퇴장하도록 제한했다. Bow 전체1.55초, DualBlade1.45초, Katana 두 버전1.65초, 나머지1.74초다. 기존 전체0.52~1.18초보다 늘렸다. 취소 시 소유권 정리 정책은 변경하지 않았다.

Unity 로드 상태에서 10개 표시 길이와 모션 길이 조건을 확인했다. SignatureAbilityDataTests 10/10 통과(job e91b788d0fa44a999827a2aa28b571f0). 최초 잘못된 namespace 필터 실행은 0건이라 통과 근거에서 제외한다. 실제 화면·빠른 캔슬 가독성은 사용자 테스트 대기다.

## 조사 결과와 남은 작업

이 절은 첫 단계의 미수정 상태 기록이다. 다음 후속 결과가 현재 상태다.

- DoubleAxe: 동일 클립 0.7375~2.2125초를 속도2.95로 5회 되감는다. 반복 경계의 자세·각속도 연속성을 확인하지 않은 구간 분할이다. 다단타 payload에 0.01초 hitstop도 존재한다. 두 원인을 실제 재생에서 분리하고 연속 회전 클립/구간으로 수정해야 한다. 아직 수정하지 않았다.
- Spear: 원본 제작 스크립트의 팔 스윙 F27~31, 손 펴기 F30과 실행 발사/무기 숨김1.0초는 숫자상 대응한다. 실제 KCC 도약(0.3초, 9m/s, 중력0.3), 고정 몸 기준 발사 오프셋(0,1.4,0.4), 손과 창 정렬·카메라를 함께 보아야 한다. 타이밍 숫자만 바꿔 해결됐다고 할 근거가 없으며 미수정이다.
- 나머지 무기는 컷인 데이터 검사까지 진행했으며 모션·FX·카메라 전수 품질 검수와 개선은 미완료다.
- WeaponSignatureSkillAuthoring.BuildFace는 기존 생성값을 유지한다. 재생성 시 이번 컷인 조정이 덮어써질 수 있어 후속 수정 대상이다.

Unity MCP 일시 timeout은 재요청으로 복구됐다. 현재 연결 차단 상태가 아니다. 새 코드·클립 제작, Player/Addressables 빌드, 커밋은 하지 않았다. 기존 미커밋 변경은 보존했다. 변경 에셋은 Git diff에 잡히지 않는 로컬 데이터이므로 Unity 저장본을 확인해야 한다. 준비표: output/harness/20261115-110847-4733a9d9 (초기 대표3개 범위, 전체10개 준비표 보완 필요). 임시 대용량 산출물 없음.

## 후속 적용·전수 확인

12명 모델과 9무기 실행 모션을 조회하고 각 모델 4시점 포즈를 렌더링했다. [포즈 시트](../../../output/ultimate-quality/poses.png)는 위에서부터 Raon, Arin, Hwarin, Reine, Lian, SeolA, Sera, Lili, YeonHoa, Myomyo, Yura, MyoRyeong이다. 실제 장비 초기화·무기별 Animator·KCC·FX는 실행하지 않았으므로 떠 있는 보조 무기나 대시 화면 이탈은 이 캡처로 합격/결함 판정하지 않는다. 최초 빈 렌더는 URP 지원 렌더 호출로 교정해 유효 캡처로 덮어썼다.

## 후속 검증과 남은 인수

- Unity 컴파일 실패 false. 최종 EditMode **17/17** 통과: SignatureAbilityDataTests와 SignatureMotionEventTests, job `9a8c85216c324958ab35b39f0a99f6d3`.
- 화린 회전부 120Hz 301샘플: yaw 정지·역행0, 각속도289.21~710.21도/초, 누적1538.24도. [측정](../../../output/ultimate-quality/validation.txt). 이는 무피격 클립 샘플이며 실전 검증은 아니다. 5회 타격과 실제 회전수는 서로 다른 수치다.
- Ability 전수 검사 오류7, Signature 경로 오류0. [오류 원문](../../../output/ultimate-quality/ability-errors.txt). 기존 공유 Default 및 패시브 오류로 전체 통과를 주장하지 않는다.
- [카메라 변경 전](../../../output/ultimate-quality/camera-before.txt), [화린 모션 변경 전](../../../output/ultimate-quality/doubleaxe-before.json), [창 변경 전](../../../output/ultimate-quality/spear-before.json)을 보존한다. payload 변경 전 백업 요청은 통신 실패로 생성되지 않았으며 수정은 hitstop0.01→0 한 필드다.
- PlayMode 실전 발동·카메라 프레이밍·FX 합성·Spear 도약/투척 동작 자연스러움은 미수행/사용자 테스트 대기. 창의 발사점 교정만으로 투척 연기 전체가 해결됐다고 보고하지 않는다. 신규 클립·FX 제작은 하지 않았다.
- 기존 사용자 변경·씬·프리팹은 보존했다. Player/Addressables 빌드·커밋 없음. 포즈 캡처는 제한이 명시된 조사 근거로 보존한다.
