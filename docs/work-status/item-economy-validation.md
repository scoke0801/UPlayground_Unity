# 아이템 경제 밸런스 검증 — 이전 실패 기록

**후속 보정으로 대체됨:** [최신 자동 수치 합격 보고](item-economy-acceptance.md). 아래는 보정 전 입력과 실패 원인을 보존한 기록이다. 현재 판정으로 사용하지 않는다.

2026-11-13. 정본: [아이템 경제 설계](../../Assets/docs/design/content/ITEM_ECONOMY_BALANCE_DESIGN.md). [분야 위키](../wiki/content.md). 사용자 후속 요청의 범위는 **빌드 없이 밸런스 검증까지**다. 검증 수행 완료와 전체 밸런스 합격·전체 경제 구현 완료를 구분한다.

## 현재 판정

- **장비 기준 수치·데이터 검사는 통과:** B1~B3 실제 장비 103종, 실제 방어구 사슬 60종 단조 상승, 기본 3단계<다음 밴드 0단계, 무기 기본 밴드 상승, CSV 수치/롤 풀/GUID/DB 일치. 기준 라온 0단계 평균 롤의 9개 레벨 사례에서 공격·생존 각각 25~35%.
- **전체 전투 밸런스는 미통과:** 같은 장비 수치에 대한 캐릭터 12종 민감도 108사례 중 55 통과·53 범위 밖. 기본 몬스터 스케일링 TTK 36사례 중 8 통과·28 범위 밖. 이를 숨기거나 장비 테스트 통과로 승격하지 않는다.
- **전체 경제 구현은 미완료:** 기존 드랍표 재배선·신규 재료·승급/골드 레시피·제작 롤 승계·상인 매입/일괄 판매 UI·B4~B5 실제 장비/스킨은 이번 검증 완료 범위에 포함하지 않는다. 신규 무기 SO 발급/등록을 획득·소비 경로 연결 완료로 보고하지 않는다.

## 자율 판단·남은 인수

1. 공통 배율의 해가 없는 상황에서 장비 수치 검증을 끝내기 위해 공격·HP·방어 예산과 롤 크기를 독립 보정했다. 슬롯 가중치·단계 배율·GUID·데이터 단일 소스는 보존했다. 정본 5절·9-1절을 갱신했다.
2. 합격 기준은 표가 정의하는 0단계 예산에 맞춰 기준 라온의 평균 롤로 명확히 했고, 타 프로필·높은/낮은 롤·단계III·TTK는 별도 실패/민감도로 공개했다. 기준을 모든 캐릭터가 통과했다고 바꾸지 않았다.
3. 기존 중앙 Attribute SO에 방어 범위를 저작해 새로운 정책 SO와 중복 런타임 경로를 만들지 않았다.
4. 실제 게임의 전체 경제 개편, 새 장비 획득·승급 경로, UI/패드·저장/로드 전체 인수, B4~B5 실제 SO·ImageGen 스킨·Unity 미술 적용은 완료하지 않았다. 자동 수치 통과를 콘텐츠·플레이 인수로 바꾸지 않는다.

사용자 테스트 대기: 20분 처치·드랍 체감·중복 수·제작 선택·골드 유입, 캐릭터별 공격/피격 감각. 기존 사용자 미커밋 변경·아트·meta는 보존했다. 임시 진단·초기 상태·정리 스크립트는 scratchpad/item-economy/verification에만 둔다.

부산물 정리: 기존 에셋의 원본에 없던 기본 필드 추가만 제거했고 새 롤·수치·희귀도는 보존했다. 신규/미추적 에셋과 meta는 정리 대상에서 제외했다. AttributeRegistry의 자동 공백·인용부호 변경을 정리한 최종 diff는 방어 정책과 상한 두 값뿐이다. 로컬 링크 누락0, 지정 변경 diff 공백 검사 통과. 임시 파일·테스트 입력은 scratchpad에 보존/정리했으며 구매 원본·Blender 파일·사용자 미커밋 파일을 삭제하지 않았다.
