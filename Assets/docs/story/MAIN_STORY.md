# UPlayground 메인 스토리

> 작성일: 2026-04-26  
> 기준 문서: `BASE_STORY.md`  
> 목적: 1800x1800 오픈 필드와 추후 마을 퀘스트 구조에 맞는 실제 메인 스토리 진행안을 정의한다.

---

## 로그라인

마을 주변 초원에 몬스터가 늘어나고 오래된 던전 입구가 다시 열릴 조짐을 보이자, 플레이어는 마을의 의뢰를 받아 필드 곳곳의 이상 징후를 조사하고 던전 입구를 막고 있는 Lich를 쓰러뜨린다.

---

## 스토리 전제

마을은 넓은 초원과 숲, 중앙 호수 근처에서 살아가는 작은 정착지다. 예전에는 호수 주변의 길과 석등 길을 따라 사람들이 오갔지만, 최근 길목마다 몬스터가 늘고 실종자가 생기면서 마을 밖 이동이 끊기기 시작했다.

마을 사람들은 원인을 정확히 모른다. 다만 공통으로 말하는 것은 하나다.

- 호수 쪽에서 밤마다 푸른 불빛이 보인다.
- 숲길에는 거미줄이 갑자기 늘었다.
- 바위 고지대에서는 돌이 움직이는 소리가 난다.
- 오래된 석등 길 끝에서 죽은 자가 걸어 나온다는 소문이 있다.

플레이어는 이 네 가지 소문 중 일부를 확인하면서 던전 입구가 다시 열리고 있다는 사실을 알게 된다.

## 핵심 인물

### 마을 촌장

메인 퀘스트를 시작시키는 NPC. 마을 밖 상황을 정리해 주지만 직접 해결할 힘은 없다.

역할:

- 첫 메인 퀘스트 제공
- 필드 조사 결과를 보고받음
- 단서가 모이면 던전 입구 조사를 요청

대사 톤:

```text
마을 밖 길이 하나씩 끊기고 있네.
호수 쪽부터 확인해 주게. 어디서부터 잘못됐는지 알아야 하네.
```

### 사냥꾼

필드 몬스터 정보를 주는 NPC. 거미 숲과 고지대 강적에 대한 힌트를 제공한다.

역할:

- Spider Queen, Ent, Golem 관련 토벌 의뢰
- 몬스터 위치 힌트
- 전투 전 위험도 안내

대사 톤:

```text
작은 거미가 문제가 아니야.
숲 안쪽에 둥지를 틀고 있는 큰 놈이 길을 막고 있어.
```

### 길잡이

석등과 목조 등롱의 의미를 알려주는 NPC. 맵 길찾기와 던전 입구 단서를 담당한다.

역할:

- 중앙 호수, 붉은 나무, 석등 길 설명
- 던전 입구 방향 힌트
- 길을 잃었을 때 기준점 제공

대사 톤:

```text
호수 가운데 붉은 나무가 보이면 아직 길을 잃은 건 아니야.
던전 쪽 길은 석등이 이어지는 방향을 보면 된다.
```

### 떠돌이 생존자

던전 입구 근처에서 도망쳐 온 인물. 후반 메인 퀘스트를 여는 증언을 제공한다.

역할:

- Lich 목격담
- 실종자 단서
- 던전 입구 위험도 전달

대사 톤:

```text
사람이 아니었어.
뼈들이 그걸 따르고 있었고, 입구 앞에서 우리를 기다리고 있었어.
```

## 메인 스토리 구조

메인 스토리는 고정 순서가 아니라 “단서 수집 → 던전 입구 확인 → Lich 처치” 구조다.

```
마을 의뢰 시작
  ├─ 중앙 호수 조사
  ├─ 거미 숲 문제 해결
  ├─ 바위 고지대 문제 해결
  └─ 석등 길 조사
        ↓
단서 2개 이상 확보
        ↓
던전 입구 위치 확인
        ↓
Lich 처치
        ↓
던전 진입
```

플레이어는 중앙 호수, 거미 숲, 바위 고지대, 석등 길을 원하는 순서로 탐색할 수 있다. 단, 던전 입구 메인 이벤트는 충분한 단서가 모인 뒤 열리는 것이 좋다.

## 메인 퀘스트

### quest_main_001: 끊긴 길

| 항목 | 내용 |
|------|------|
| 시작 NPC | 마을 촌장 |
| 목표 | 중앙 호수 주변을 조사한다. |
| 권장 지역 | 중앙 호수, 남쪽 강길 |
| 주요 몬스터 | Skeleton, HumanType, Dryad |
| 완료 조건 | 중앙 호수 랜드마크 발견 또는 호수 주변 적 처치 |
| Progress | 0 → 10 |

내용:

마을 촌장은 호수 주변 길에서 실종자가 생겼다고 말한다. 플레이어는 중앙 호수까지 이동해 붉은 나무와 주변 길을 확인한다. 이 퀘스트는 플레이어에게 맵의 기준점을 알려주는 역할을 한다.

필드 대사:

```text
호수 가운데 붉은 나무가 보인다.
저걸 기준으로 삼으면 어느 길에서든 돌아올 수 있겠어.
```

완료 후 촌장 대사:

```text
역시 호수까지 길이 완전히 끊긴 건 아니군.
하지만 몬스터가 길목을 차지했다면 그냥 지나갈 수는 없겠지.
```

### quest_main_002: 거미줄에 막힌 숲

| 항목 | 내용 |
|------|------|
| 시작 NPC | 사냥꾼 |
| 목표 | 거미 숲 깊은 곳의 Spider Queen을 처치한다. |
| 권장 지역 | 거미 숲 |
| 주요 몬스터 | Spider, Spider Queen |
| 완료 조건 | Spider Queen 처치 |
| Progress | 단서 카운트 +1 |

내용:

거미 숲은 마을 사람들이 가장 먼저 접근을 포기한 길이다. 작은 Spider들은 길목에서 플레이어를 소모시키고, Spider Queen은 숲 안쪽에서 우회로를 막는다.

필드 대사:

```text
거미줄이 길을 덮고 있다.
이 정도면 우연히 생긴 둥지는 아니야.
```

보스 처치 후 대사:

```text
숲 안쪽 길이 보인다.
이제 이쪽으로도 호수 반대편에 갈 수 있겠어.
```

완료 후 사냥꾼 대사:

```text
그 큰 거미를 잡았다고?
그럼 숲길은 곧 다시 쓸 수 있겠군. 적어도 낮에는 말이야.
```

### quest_main_003: 움직이는 바위

| 항목 | 내용 |
|------|------|
| 시작 NPC | 사냥꾼 또는 촌장 |
| 목표 | 바위 고지대의 Golem 또는 Ent를 처치한다. |
| 권장 지역 | 바위 고지대, 숲 경계 |
| 주요 몬스터 | Golem, Ent, Dryad |
| 완료 조건 | 권역 강적 1체 처치 |
| Progress | 단서 카운트 +1 |

내용:

바위 고지대는 맵을 넓게 내려다볼 수 있는 곳이다. 이곳의 Golem과 Ent는 플레이어에게 중형 몬스터 전투를 경험시키고, 던전 입구가 있는 방향을 시각적으로 암시한다.

필드 대사:

```text
바위가 길을 막고 있다.
아니, 움직이고 있어.
```

강적 처치 후 대사:

```text
고지대가 조용해졌다.
저 아래, 석등이 이어지는 길 끝에 입구 같은 게 보인다.
```

완료 후 촌장 대사:

```text
고지대에서 던전 입구가 보였다고?
그 길은 오래전에 닫혔다고 들었네. 다시 열렸다면 좋지 않은 징조야.
```

### quest_main_004: 등롱이 가리키는 곳

| 항목 | 내용 |
|------|------|
| 시작 NPC | 길잡이 |
| 목표 | 석등 길 끝을 조사한다. |
| 권장 지역 | 석등 길, 던전 주변 |
| 주요 몬스터 | Skeleton, HumanType, Dryad |
| 완료 조건 | 던전 입구 근처 트리거 도달 |
| Progress | 단서 카운트 +1 또는 30 → 40 |

내용:

길잡이는 목조 등롱과 석등이 예전 길 표식이었다고 알려준다. 플레이어가 그 표식을 따라가면 던전 입구 근처에 도달하고, 주변에 언데드가 모이고 있음을 확인한다.

필드 대사:

```text
등롱과 석등이 같은 방향으로 이어져 있다.
길을 숨기려던 게 아니라, 잊지 않으려고 세워 둔 표식 같아.
```

던전 입구 근처 대사:

```text
여기가 끝이다.
그리고 무언가가 이 앞을 지키고 있다.
```

완료 후 길잡이 대사:

```text
그 길 끝까지 갔다고?
그럼 이제 마을에 숨길 수는 없겠군. 던전 입구가 다시 열렸어.
```

### quest_main_005: 던전 입구의 Lich

| 항목 | 내용 |
|------|------|
| 시작 NPC | 촌장 또는 떠돌이 생존자 |
| 선행 조건 | 단서 2개 이상 확보 또는 `quest_main_004` 완료 |
| 목표 | 던전 입구의 Lich를 처치한다. |
| 권장 지역 | 던전 입구 |
| 주요 몬스터 | Lich, Skeleton |
| 완료 조건 | Lich 처치 후 던전 진입 이벤트 |
| Progress | 40 → 50 |

내용:

단서가 모이면 떠돌이 생존자가 마을에 도착한다. 그는 던전 입구에서 Lich와 언데드 무리를 봤다고 증언한다. 촌장은 더 늦기 전에 입구를 확인해 달라고 부탁한다.

시작 대사:

```text
그자는 입구 앞에 서 있었다고 했네.
뼈들이 그 뒤를 따랐고, 아무도 안으로 들어가지 못했다고 하더군.
```

전투 전 대사:

```text
던전 입구가 맞다.
여길 지나가려면 저걸 먼저 쓰러뜨려야 해.
```

처치 후 대사:

```text
입구를 막던 기운이 사라졌다.
이제 안으로 들어갈 수 있다.
```

완료 후 촌장 대사:

```text
마을 밖 길은 당분간 버틸 수 있겠지.
하지만 진짜 문제는 이제부터일지도 모르네.
```

## 단서 시스템 권장안

오픈 필드 구조에서는 메인 스토리 진행을 단일 순서로 묶지 말고, 단서 카운트로 관리하는 편이 자연스럽다.

| 단서 ID | 획득 조건 | 연결 퀘스트 |
|---------|-----------|-------------|
| `clue_spider_forest` | Spider Queen 처치 | `quest_main_002` |
| `clue_highland_guardian` | Golem 또는 Ent 처치 | `quest_main_003` |
| `clue_lantern_path` | 석등 길 끝 도달 | `quest_main_004` |
| `clue_lake_undead` | 중앙 호수 주변 언데드 확인 | `quest_main_001` |

권장 해금:

- 단서 1개: 마을 NPC가 각 권역에 대한 추가 힌트 제공
- 단서 2개: 던전 입구 위치 공개
- 단서 3개 이상: Lich 전투 전 추가 대사 또는 보상

## StoryManager 진행도 매핑

| Progress | 스토리 단계 | 조건 |
|----------|-------------|------|
| 0 | 마을 의뢰 시작 전/필드 진입 전 | 기본 상태 |
| 10 | 필드 조사 시작 | `quest_main_001` 수락 또는 중앙 호수 발견 |
| 20 | 첫 단서 확보 | 단서 1개 획득 |
| 30 | 던전 의심 단계 | 단서 2개 획득 |
| 40 | 던전 입구 확인 | `quest_main_004` 완료 또는 마을 보고 |
| 50 | 야외 필드 메인 완료 | Lich 처치, 던전 진입 가능 |

`StoryManager.CurrentProgress`는 큰 단계만 관리한다. 권역별 완료 여부는 퀘스트 목표 또는 별도 플래그로 관리한다.

## 대화 작성 원칙

- NPC 대화는 목표를 명확히 전달한다.
- 필드 대화는 방향과 위험만 짧게 말한다.
- 몬스터의 기원 설명을 길게 하지 않는다.
- 신사풍 오브젝트는 길 표식으로 다룬다.
- 던전 내부의 진짜 원인은 이 문서에서 확정하지 않는다.

## 엔딩 상태

야외 필드 메인 스토리의 끝은 세계 구원이 아니라 “던전 입구 개방”이다.

완료 후 상태:

- 마을 밖 주요 길이 다시 열림
- Spider Queen 처치 시 거미 숲 통행 가능
- Golem/Ent 처치 시 고지대 위험 감소
- 석등 길을 통해 던전 입구 위치 확인 가능
- Lich 처치 후 던전 진입 가능

후속 스토리:

- 던전 내부에서 몬스터가 늘어난 진짜 원인을 다룬다.
- 마을 NPC는 야외 필드 반복 의뢰와 보상을 담당한다.
- 야외 필드는 이후 파밍, 서브 퀘스트, 보스 재도전 공간으로 유지한다.

## 장면 단위 진행안

### 1. 마을 의뢰 시작

목적은 플레이어에게 “호수로 가라”가 아니라 “끊긴 길의 원인을 확인하라”는 문제를 주는 것이다. 호수는 목적지이면서 이후 모든 방향 판단의 기준점이다.

권장 대화:

```text
촌장: 마을 밖 길이 하나씩 끊기고 있네.
촌장: 호수 근처에서 돌아오지 못한 사람들이 있어. 먼저 그 길이 아직 살아 있는지 확인해 주게.
```

생성 데이터:

| 종류 | ID |
|------|----|
| QuestSO | `quest_main_001` |
| DialogueGraphSO | `dlg_quest_main_001_start` |
| StoryEntrySO | `field_lake_first_arrive` |

### 2. 중앙 호수 발견

호수 발견은 긴 설명보다 시각 기준점 확보가 중요하다. 붉은 나무는 세계관의 비밀이 아니라 플레이어 위치 인식 장치로 먼저 사용한다.

권장 대화:

```text
호수 가운데 붉은 나무가 보인다.
저걸 기준으로 삼으면 어느 길에서든 돌아올 수 있겠어.
```

처리:

- `QuestManager.NotifyLocationReached("loc_central_lake")`
- `StoryManager.SetProgress(10)` 또는 퀘스트 완료 보고 후 10으로 상승
- `flag_clue_lake_undead = true`

### 3. 권역 단서 수집

거미 숲, 바위 고지대, 석등 길은 순서를 강제하지 않는다. 각 권역은 완료 시 단서 하나를 준다.

| 단서 | 연결 퀘스트 | 완료 처리 |
|------|-------------|-----------|
| `clue_spider_forest` | `quest_main_002` | `NotifyMonsterKill(SpiderQueen_1)` |
| `clue_highland_guardian` | `quest_main_003` | `NotifyMonsterKill(Golem_Normal)` 또는 `NotifyMonsterKill(Ent_Normal)` |
| `clue_lantern_path` | `quest_main_004` | `NotifyLocationReached("loc_lantern_path_end")` |

단서 2개 이상 확보 후:

- `CurrentProgress`를 30 이상으로 올린다.
- 마을 또는 생존자 대화에서 던전 입구 정보를 공개한다.
- `quest_main_005` 수락 조건을 만족시킨다.

### 4. 떠돌이 생존자 등장

생존자는 후반 전환용 NPC다. 이 인물은 세계관 설명을 길게 하지 않고 “입구 앞에 강적이 있다”는 정보를 전달한다.

권장 대화:

```text
생존자: 그 앞에는 사람이 아닌 것이 서 있었어.
생존자: 뼈들이 그걸 따르고 있었고, 입구 안쪽에서는 계속 같은 소리가 났어.
```

### 5. Lich 처치와 던전 개방

Lich는 야외 필드의 최종 보스지만 전체 세계관의 최종 원흉은 아니다. 처치 후에는 “이제 들어갈 수 있다”만 확정하고, 내부 원인은 던전 콘텐츠로 남긴다.

처리:

- `QuestManager.NotifyMonsterKill(Lich_Normal)`
- `StoryManager.SetProgress(50)`
- `flag_dungeon_entrance_open = true`

## 자동 생성 툴 사용안

메뉴:

```text
UPlayGround/Story/Main Story Generator
```

기능:

- 메인 스토리 퀘스트 5종 생성/갱신
- 필드 발견용 `StoryEntrySO` 생성/갱신
- 기본 대화 그래프 생성/갱신
- 프로젝트의 `QuestDatabase`가 있으면 `Assets/10.Datas/Quest` 기준으로 DB 갱신

생성 툴은 같은 ID의 에셋이 있으면 새로 만들지 않고 값을 갱신한다. 따라서 초안 생성 후 문구를 코드에서 수정해 다시 생성할 수 있지만, Unity Inspector에서 수동 수정한 텍스트는 덮어써질 수 있다. 수동으로 다듬은 뒤에는 생성 버튼을 다시 누르기 전에 백업하거나 별도 폴더로 복제한다.

## 구현 연결 체크리스트

- `StoryTriggerZone`에 `field_lake_first_arrive`, `field_lantern_path_end`, `dungeon_entrance_arrive`를 연결한다.
- 중앙 호수와 석등 길 트리거에서 `QuestManager.NotifyLocationReached`를 호출할 별도 위치 트리거를 둔다.
- `MonsterActor` 사망 처리 또는 그룹 컨트롤러에서 보스 ID별 `NotifyMonsterKill` 호출 여부를 확인한다.
- `StoryManager.SetProgress`가 퀘스트의 `StoryProgress` 목표와 동기화되는지 확인한다.
- 생성된 `QuestSO`가 `QuestDatabase`와 Addressables 로드 경로에 포함되는지 확인한다.
