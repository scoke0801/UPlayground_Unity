# 생활 AI 사용자 검수

모든 항목은 **사용자 테스트 대기**다. 자동 검사나 상태 주입을 실물 입력/자연 전환 통과로 바꾸지 않는다. 실물 작업물·지붕·경로 보완과 사용자 승인에 따른 일반 주민 2명/교류 장소 게이트 true를 저장했다. LIFE01~05/08 → LIFE06/07 → LIFE09 순서로 실행한다.

Unity 6000.3.21f1 URP, 툴 런처의 호수·여울마을 도보 연결을 통한 Boot 진입을 사용한다. 별도 저장 슬롯을 만들고 입력 장치·시각·날씨·기존 플래그 상태를 기록한다. 원본 슬롯 삭제/덮어쓰기를 하지 않는다. 씬 직접 Play나 플래그 강제 해금을 본편 성공으로 표시하지 않는다.
