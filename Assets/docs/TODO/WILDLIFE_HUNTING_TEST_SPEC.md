# 환경 동물 사냥·보상 테스트

## 대상과 준비

- 씬: `Assets/01.Scenes/Scenario/OpenWorld/LakeVillageWorld.unity`, Editor Play Mode. 같은 프리팹을 사용하는 `LakeOfLifeScenario.unity`에도 반영된다.
- 현재 씬의 사슴·돼지·새와 APD 소·닭·염소·산양·멧돼지·토끼·거위·늑대·곰·쥐·개구리·도롱뇽·달팽이·뱀을 포함한 사냥 프로필 19종. 나비 4종 프로필은 장식 생물로 유지한다.
- 키보드·마우스 또는 게임패드로 근접 무기와 원거리 공격을 준비한다. 저장이 필요하면 별도 테스트 슬롯을 쓴다.
- 획득 아이템과 제작법은 기존 인벤토리·제작 저장 정책을 따른다. 개체 사망은 현재 씬 인스턴스에만 남으며 씬 재로드 시 초기 배치로 복원된다. 영구 사냥 소진이나 별도 시간제 재생성은 추가하지 않는다.

## 확인 절차

| ID | 절차 | 기대 결과·실패 기준 |
|---|---|---|
| H01 | 사슴·돼지를 락온하고 일반 공격을 맞힌다. | 락온과 공격 보정이 동작한다. 피해 숫자·타격음이 나오고 살아 있으면 도망간다. 동물이 먼저 공격하거나 NPC 대화가 열리면 실패. |
| H02 | 사슴을 처치하고 시체에 다단 공격을 계속한다. | 사망 모션 후 사라진다. 고기 2~3개 확정, 가죽 60% 확률 1~2개. 보상과 획득 연출은 처치당 한 번만 나온다. 사망 즉시 락온이 풀린다. |
| H03 | 돼지를 처치한다. | 사망 모션 후 사라진다. 고기 3~4개 확정, 가죽 35% 확률 1~2개. |
| H04 | 지면과 공중의 새를 각각 원거리 공격으로 처치한다. | 피격하며 고기 1개·깃털 1~2개를 확정 획득한다. 새가 추락 후 사라지고 죽은 개체를 계속 추적하지 않는다. |
| H05 | 토끼·소·곰 등 추가 동물을 각각 공격·처치하고, 나비를 공격한다. | 추가 동물은 피격·사망·고기 보상이 동작한다. 종별 수량·부산물은 `Tools/Wildlife/Hunting.catalog.json`을 따른다. 나비는 피격·락온·고기 드랍이 발생하지 않는다. |
| H06 | 제작 화면에서 고기 1개와 장작 1개로 구운 고기 1개를 만든다. | 제작법이 처음부터 보이고 재료가 정확히 소모된다. 부족할 때 제작할 수 없다. |
| H07 | 체력이 충분히 줄어든 상태에서 구운 고기를 사용한다. | 최대 체력의 25%를 회복하고 1개 소모, 재사용 대기 10초. 인벤토리와 퀵슬롯에서 사용 가능하다. |
| H08 | 보상 획득·제작 뒤 저장하고 로드한다. | 고기·음식·가죽·깃털과 소모량이 보존되고 아이콘·설명이 정상이다. 씬 재로드 시 동물은 초기 배치로 돌아온다. |

가죽·깃털은 기존 장비 보강 제작에 사용한다. 사냥 판정 콜라이더는 이동을 막지 않는 Enemy 레이어 트리거다. 구운 고기는 기존 소비 아이템 규칙을 사용하므로 체력이 가득 찬 상태에서도 소모될 수 있다.

## 결과 회신

`항목 ID / 통과·실패·미수행 / 실제 결과 / 화면 또는 Console 오류`

실패 시 시작 상태, 사용 동물·무기·입력 장치, 중복 지급 여부를 함께 기록한다. 화면·입력·타격감·사망 모션 품질·저장/로드는 사용자 테스트 대기이며 자동 검사 통과와 별도로 판정한다.

## AI 보조 검증 결과

- Unity에서 로드한 월드 씬: 사냥 대상 87마리·19종 프로필, 장식 나비 17마리. 피격 콜라이더·Enemy 레이어·드랍 연결 오류 0건.
- 등록된 고기·구운 고기, 회복 비율 0.25, 제작법 1개·재료 2개 확인. 사망 클립의 반복 설정과 대기 클립 대비 본 경로 교집합 검사 오류 0건. 실제 모션 품질 판정은 H01~H05에서 한다.
- Unity Console 오류 0건. 환경 생물·공격 보정 관련 EditMode 선택 테스트 34개 통과.
- 별도 CLI 보조 컴파일은 동시에 추가된 NPC 반응 테스트와 기존 빌드 DLL의 타입 불일치로 실패했다(`Logs/WildlifeHunting-combat-compile.log`). Unity 검사 결과와 별도로 기록한다.
- Editor Play Mode 직접 조작과 저장/로드는 사용자 테스트 대기. 검증용 Player 빌드는 프로젝트 지침에 따라 미수행.
