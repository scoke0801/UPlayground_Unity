## 3 경험 목표와 구성

로그라인: 보물 소문을 따라 호수에 온 여행자가 길에서 헤어진 사람들의 재회를 돕고, 자신을 다른 사람으로 기억하는 인물과 함께 신전으로 들어가 같은 얼굴의 상대를 마주한다.

주제: 함께 위험을 지난 사람이 돌아갈 때는 서로를 기다려 준다.

전체 동선은 도착길 → 생활 마을 → 숲의 화린 → 옛길의 리안 → 숲 끝 묘령 → 호수 조망 → 수호자 → 신전 → 귀로 → 마을 후일담이다. 호수 섬과 외곽 탐험은 곁가지다. 메인 사건의 인과와 영입 순서는 명확히 유지하되, 지리적 접근 자체는 열어 둔다.

- 첫 5분: 어디에 왜 왔는지 알고 직접 움직인다.
- 첫 15~20분: 기본 전투를 익히고 첫 동료와 교체를 경험한다.
- 30~40분: 리안 재회와 묘령의 오인을 통해 개인적인 문제가 생긴다.
- 55~75분: 신전 사건과 안전한 귀로를 마친다.
- 선택 탐험 포함 90~120분: 생활 의뢰, 섬, 서쪽 숲·폐허를 경험한다.

시간은 최초 플레이의 설계 범위다. 실제 이동과 독서·전투 시간을 재기 전 확정 분량이나 성과로 사용하지 않는다. 마을을 넓혀 체류 시간을 늘리거나 적 체력으로 시간을 채우지 않는다.

| 지역 | 호수·숲·신전·생활권의 관계 | 지형, 지평선, 연결 경로, 전체 음향 |
| 구역 | 안전·경계·분쟁·핵심 위험·귀환 | 건물 사용, 적 침범 한계, 생활 동선 |

| 조우 | 한 번의 판단과 전투 | 진입 시야, 적 역할, 이탈, 보상 |
| 개체 | 사람·적·상호작용·소품 | 고유 ID, 외형, 발밑, 참조, 복원 |

같은 변경은 한 권위 소스에 기록한다. 기존 생성기와 수작업 씬이 서로 덮어쓰지 않게 소유권 표를 먼저 작성한다. 건물의 문 앞 위치가 바뀌면 주민·상호작용·카메라·NavMesh를 같이 고친다.

## 5 우선 해결할 품질 문제

- Village_Courtyard와 기존 Hwarin 공터는 데이터상 수십 미터 수준으로 가깝다. 안전 마을과 첫 영입 전투 사이에 굽은 길·시야 차단·추격 경계를 확보한다.
- world의 외곽 적에는 Hwarin, Lian, Raon, MyoRyeong 계열과 다른 영입 캐릭터 외형이 포함된다. 첫 만남과 분신 공개를 무효화하므로 본편 배치에서는 제외하고 일반 적 또는 별도 후속 사건으로 교체한다. 기존 프리팹과 전투 테스트 자산 자체를 삭제하지 않는다.
- 원본 맵의 최근 대화 이동·보스·귀로 좌표는 새 지형에서 자동으로 맞지 않는다. 등장 위치만 옮기지 말고 모든 동작 목적지·볼륨·시선·복구 위치를 함께 이전한다.
- RequireEnvironmentPrefab은 ExternalAssets/Environment 경로만 허용한다. 신규 Blender 프리팹을 자체 경로에 넣으려면 검증된 소스 경로를 지원하는 작은 도구 확장이 선행된다. 외부 에셋 폴더에 자체 제작물을 위장해서 넣지 않는다.
- Dryad/Training Dummy 모션 미해결, 기존 Ability 검사 오류, 맵 연속 로드 HUD 참조 문제는 기존 보고의 미해결 항목이다. 현재 재현 여부를 확인하고 본편 경로에 해당하면 출시 차단 항목으로 관리한다.

## 6 변경 범위와 확정 경계

이번 기획은 제1장을 상세 제작 대상으로 한다. 제2장 이후 동료의 이름·소원·영입 순서를 임의 확정하지 않으며, 추가 영입 사건은 같은 저작 템플릿으로 확장한다. 전면 개편은 기존 지형의 좋은 부분과 실행 계약을 보존하면서 생활과 사건의 배치를 바꾸는 작업이다.

현행 확정 문서와 실행 에셋은 이번 작성으로 수정하지 않는다. 개발 착수 시 담당 범위의 초안을 구체 구현 기준으로 확정하고, 테스트 결과에 따른 변경은 이유·영향 문서·복구 계약과 함께 기록한다. 사용자가 이미 승인한 범위의 일반적인 배치 조정마다 별도 승인을 요구하지 않는다.
