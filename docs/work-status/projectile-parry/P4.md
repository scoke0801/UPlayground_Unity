## 일시적 Editor 차단과 해소

같은 Editor UPlayground@fddd0702, PID21792. 다른 Staff/BT·Pet 세션의 테스트/컴파일과 MCP 호출을 관측했다. MCP stdio host는 새 연결에서 기존 연결을 닫는 구현이며 중복 명령 억제 진단이 반복됐다. 한동안 MCP와 기존 Hot Reload 파일 Bridge status도 응답하지 않아 기능 C# 오류로 단정하지 않았다.

status 요청 d0cf0572de884fa8b7a595a238747df1이 뒤늦게 completed/Ok로 응답했다([원본](bridge-status.json)). 기존 job을 확인하고 유휴 Editor에서 정상 컴파일/리로드·Console 오류0을 확인한 뒤 최종 PlayMode job dfb5a02398424dddb155158968aed03a의7건 성공을 회수했다. 토큰 기록·두 번째 Editor·재시작·Library/Temp/잠금 삭제·다른 세션 강제 종료 없음.

## 사용자 인계·정리

[PP01~PP10 실행·회신 명세](USER_TEST.md). 기존 CombatTestMap·전투 테스트 준비 창을 재사용한다. 사용자 결과 전 전체 플레이 인수 완료가 아니다. 가드 재진입 시 근접 내구도 초기화는 기존 동작이며 이번 범위에서 개편하지 않았다.

구매 원본·기존 미커밋 변경·GUID/meta 보존. 새로 생긴 무관한 SO 기본값 재직렬화는 정리하고 기존 Staff 필드는 유지했다. 상태 조회 임시 JSON은 제거하고 단계 원자료·baseline 보존 패치·Unity 감사·최종 에셋은 남긴다. 시험 오브젝트는 finally에서 제거했다. 별도 빌드·캐시·프로젝트 사본 없음. [전투 위키](../../wiki/combat.md).
