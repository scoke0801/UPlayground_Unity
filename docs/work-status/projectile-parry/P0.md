## 소비자와 수정 경계

- `CombatResolutionPipeline.Execute`: 관계 필터 → 순수 Resolve → Apply. Resolve/Apply 사이 탄 commit을 삽입한다.
- `DefenseResolver`: 현재 GuardBreak preview가 먼저이며 투사체 PerfectGuard가 근접 타이머를 사용. 적격 투사체 후보를 먼저 승인하고 부적격 탄은 Block/Break로 제한한다.
- `PlayerDefenseController`: ActorTime 내구도/assist/카운터. 투사체 Guard 입력 세대·전역 시간 창·재개방·보상 소비만 추가. 기존 근접 동작 유지.
- `PlayerGuardState.ApplyGuardOutcome`: 내구도 증가·Guard 오브·원격 OnParried·카운터·성공 알림·PerfectGuard passive. 투사체 전용 적용으로 우회한다.
- `PlayerActor.OnAttackClashSuccess`: assist fallback 취소, 공격 종료/Idle 유지. 원격 OnParried·카운터 제외.
- `DefenseSuccessFeedbackHandler`: 공격자 freeze·전체 tail·VitalOrb 생성. 투사체 전용 프로필과 공격자 없는 context로 제한.
- 구독자 `PartyManager.OnPlayerDefenseSucceeded`(협주 보상), `PassiveAbilityController`(PerfectGuard 활성화)는 행동당 한 번만 알린다.
- `ProjectileRuntime.ApplyPlayerFeedback`: NotifyAttackHit가 공격 proc/게이지를 재발동하므로 반환탄은 피해표시만 유지.
- `DamageResolver`: attacker power/element 실시간 조회를 반환탄 발사 스냅샷으로 교체. 일반 탄 계산 유지.
- `MonsterActor` → `CombatContributionLedger` → kill context: 반사자 ID/진영/credit을 불변 보관해 사망·스왑 후에도 귀속 보존 필요.
- `ProjectileManager.OnUpdate`는 Time.deltaTime 사용. 지원 탄 owner local scale 비종속. 긴 sweep의 접촉 시각을 같은 Time.time 축으로 계산해야 한다.
