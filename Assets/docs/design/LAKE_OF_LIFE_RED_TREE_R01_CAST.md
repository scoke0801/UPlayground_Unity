S06 리안과 묘령, S07 레이네·유라·U는 한 번에 지급하지 않는다. 영입 이유는 기록 공개, 관계에 대한 책임, 명령 거부, 인계 협력, 보호 대상 인계로 다르다. 적 처치가 필요한 카드도 처치만으로 동료를 지급하지 않는다.

이미 보유한 구 저장에서는 카드의 ‘이미 보유’ 원고를 사용한다. 재소개·영입 배너·중복 보상은 없지만 새 사건의 책임과 행동은 남는다. 보유 12명과 출전 최대 4명은 별개다. 비출전 인물은 필요한 카드/작업점에서만 나타나며 현재 활성 인물과 겹치는 대역은 제거한다. H09와 일반 NPC는 영입 목록에 넣지 않는다.

### 공통 기준과 확정 수준

**확정된 내용:** 확정 기획의 역할·갈등, 선택 주인공/활성 캐릭터 구분, 각 장면에서 말하는 이유. **잠정 내용:** 아래 문장 길이·말끝·감정 표현·원고 전부. 2D 이미지 확인만으로 모델·표정·목소리 검수를 완료하지 않는다.

초면에는 필요부터 말하는 해요체를 기본 후보로 둔다. 성별/의상으로 하오체·반말·앳된 말투를 부여하지 않는다. 친해진 뒤에도 자동으로 반말 전환하지 않는다. 전투의 “피해!” 같은 긴급 외침은 평상시 존대 변화와 다르다. 아래 대표 3줄은 평상시/갈등 또는 위기/후반 행동의 원고이며 카드 또는 선택 재방문 대화에 사용한다. 동일 의미를 카드마다 반복 재생하지 않는다.

기존 `DLG_ScenarioHwarinRescue.asset`를 열어 P의 해요체와 화린의 “난 괜찮아”, “이 길 안쪽에서” 등 반말을 확인했다. 새 화린 원고의 해요체는 기존 어투와 차이가 있는 **잠정 캐스팅 변경안**이다. 새 사건으로 바뀐다고 아무 설명 없이 혼용하지 않으며, R00-V04 모델·구 전체 화린 발화 검수에서 반말 유지 여부를 결정하고 새 라인 전체를 한 기준으로 맞춘다. 기존 에셋의 말투를 이번에 수정하지 않았다.

## 5. 장면 밖 생활 대사와 공개 순서

카드의 본 대사 외 선택 대화는 위 대표 원고에서 필요한 한 줄만 쓴다. 모든 NPC가 T1/T2/T3를 설명하지 않는다. 생활 대화의 조건은 현재 세계 상태와 그 인물이 실제 확인한 사실이다.

| 시점 | 선택 대화의 내용 | 말하지 않는 것 |
|---|---|---|
| S00~S03 | 식사·자리·물품·남은 사람·귀향/정착 | 루시아 사전 인지, 표식 효과, 신의 세계관 |
| T1 뒤 | 세라/조이의 다음 식사, 헤이즐 물품, 상인 재고 | 전 주민이 루시아 은폐를 안다는 반응 |
| T2 뒤 | 레이네의 명령 판단, 모건의 운송 기록, 묘령의 직접 대면 | E08 확인 전 표식이 흡수한다고 해설 |
| T3 뒤 | 묘묘 회수·연화 봉헌 철회·세라 공급 준비 | 피해 주민이 자동 용서, 모든 신앙 포기 |
| 중단 뒤 | 반환 비용·다음 식사·수선·귀향/정착 선택 | 루시아 생사/처우, 세계 전체 구원, 피해 즉시 삭제 |

P의 발화는 두 시작 선택 모두 가능한 협력 제안/판단으로 작성했다. A의 “당신/Player”는 핵심 결론 화자로 쓰지 않았다. U는 고정 라온/아린 화자이고 별도 인물이다. 재방문 때 현재 A가 고정 동료와 같으면 대사 상대/대역을 중복 생성하지 않고 필요한 대사만 가능한 표현으로 정리한다. 이 동작의 실제 지원은 R02/R03 이후 확인한다.

## 7. S02 화린 준비 원고의 어투 조정

R03 준비 과정에서 기존 실행 원고의 “난 괜찮아”, “고마워. 난 화린이야. 말은 편하게 해도 돼”를 재대조했다. R01 해요체는 실물 검수 전 초안이므로 S02 준비 에셋은 기존 반말을 유지한다. 긴급 요청은 “이쪽으로 와!”, 동의는 “안쪽엔 아직 못 가 봤어”, “난 화린이야. 아까처럼 길을 나눠서 보자”, 이미 보유하면 “이번에도 같이 가자. 아직 안쪽이 남았어”로 통일한다. 긴급 요청의 실제 전투 발화 연결은 아직 없다.

관계 근거는 함께 퇴로를 확보한 동행 상대이며, 외형에서 나이·혈연·새 과거사를 추정하지 않았다. 이번 초상화 열람은 현행 3D 모델·발화 연기 검수를 대신하지 않는다. **R03 원고용 잠정 정리**이고 Profile 전체 확정이 아니다. Reine의 표시명 차이와 enum·저장 별칭·파일명·GUID는 변경하지 않았다.
