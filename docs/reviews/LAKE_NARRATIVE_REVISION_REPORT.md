# LakeOfLife 대화·진행 수정 검증 기록

작성: 2026-09-15 (KST)

## 반영 내용

- 안내인에게 주인공이 먼저 길을 묻도록 변경. 조안은 목격한 싸움과 사람만 이야기한다.
- 미아·준의 의뢰를 먼 호숫가 낚시에서 귀로에 놓친 짐을 찾는 사건으로 변경. 퀘스트 표시 문안도 함께 수정.
- 화린은 구조 직후 친구의 안부를 먼저 말하고 이후 이름을 교환한다. 리안은 화린과의 재회 뒤 조사에 동의한다.
- 화린·리안은 구조 후 한 대화에서 합류까지 마친다. 닫혔다 다시 열리는 필수 후속 대화를 실행 그래프에서 제거하고 기존 저장의 PostDialogue 단계를 완료로 복원한다.
- 존재하지 않는 통행 차단과 발 디딤 경고를 제거. 리안 참가자 준비 전 대화 호출을 제거.
- 문맥에 맞지 않는 천 삽화 호출 제거.
- 묘령은 같은 얼굴의 공격자를 보았다는 경험 때문에 오인한다. 패배 후 공격을 사과하고 증언을 확인하기 위해 동행한다. 혼자 보낼 수 없다는 기존 동기는 제거.
- 묘령 승리 대화 중단을 완료로 소진하지 않고, 정상 종료 시 신전 메인 퀘스트 추적을 명시한다.
- 준 조사 기준점은 지면 아래 1.219m에서 지면 위 0.05m로 수정. 기존 환경 모델의 짐 소품 추가.

기존 ID·GUID·보상은 유지했다. 시작 전부터 존재한 코드·데이터 변경은 보존했다. 씬 자체에는 의도한 수정이 없어 Unity 검증 과정의 자동 재직렬화만 작업 시작 시 파일로 복구하고 다시 불러왔다. 배치 변경은 Story_LakeSideQuestRoute 프리팹에 있다. 현재 저장소 규칙에서 이 프리팹은 git status에 표시되지 않으므로 파일 단위 변경도 인계 대상이다.

## 남은 수동 확인

새 게임에서 안내인 → 화린 구조 → 리안 재회 → 흔적 → 묘령 → 신전 순서로 실제 조작 완주가 필요하다. 미아 의뢰를 수락한 경우 길가 짐에서 상호작용 UI가 나타나고 준 구조·미아 복귀까지 이어지는지 확인해야 한다. 기존 저장에서 이미 묘령 영입이 완료된 경우 새로 추가한 완료 직후 추적 노드는 과거 이벤트를 재발화하지 않는다. 해당 저장에서는 퀘스트 목록에서 신전 메인을 선택할 수 있으며, 준의 조사 소품·높이 수정은 프리팹에 적용된다.

전체 경험을 완전히 검증한 상태로 보고하지 않는다.
