성채와 장터

불합격 근거 오르막 끝의 성벽은 강하게 읽혔지만 양쪽 풀밭이 같은 경사로 흘렀다. 근접에서는 옹벽이 풀밭에 놓인 독립 벽처럼 보였고, 조감에서는 장터 가옥과 문루가 지형 위에 따로 섰다.

씬 변경 옹벽 뒤 둔덕과 반대편 낮은 배수 지형을 조형했다. 기단 방향에 풍화암 층을 섞고 고립 담 모듈을 숨겼다. 장터 노면을 건물 전면까지 이어 보이게 재질을 섞었다. 첫 시안에서 시야를 가린 끝단 암반은 낮췄다.

남은 문제 문루 남쪽 기단과 지형의 접합, 가판 뒤 작업 공간은 조감에서 여전히 엷다.

화면 비교에서 적용한 기준 《Ghost of Tsushima》 성곽 구도에서 건축에 앞서 사면과 성벽 하단이 높이를 읽히게 한다. 쿠텐베르크에서는 가판과 주택 전면이 도로 가장자리를 형성한다. 이를 성채의 사면과 장터의 작업 노면에 적용했다.
