# 생명의 호수 제1장 수렴형 플로우 구현 스펙

> 문서 버전: **v2.0-implementation**  
> 작성일: **2026-08-26**  
> 상태: **데이터·FlowGraph·LakeOfLife 배치 반영, Unity Play Mode 검증 대기**  
> 적용 범위: 생명의 호수 제1장 메인 플로우, 화린·리안·묘령 합류 동기, 지역 곁가지 퀘스트, 신전 결말

이 문서는 생명의 호수 제1장의 현재 기준 문서다. 기존 Quest ID, GlobalFlag ID, FlowGraph ID와 에셋 GUID는 저장 호환성을 위해 유지하되, 플레이어에게 보이는 이야기는 아래 수렴형 구조를 따른다.

## 1. 이야기 원칙

제1장은 인물을 차례로 구조해 수집하는 이야기가 아니다. 서로 다른 목적을 가진 인물들이 같은 이상 현상을 좇아 신전에서 수렴하는 이야기다.

| 인물 | 당장의 목적 | 대사와 행동의 기준 |
|---|---|---|
| 주인공 | 보물의 소문과 자신의 소원을 확인한다 | 정보를 모아 방향을 결정한다 |
| 화린 | 변한 길과 밀려 나온 괴물의 원인을 찾는다 | 먼저 움직이고 직접 확인한다 |
| 리안 | 정체불명의 끌린 흔적을 끝까지 추적한다 | 관찰하고 근거가 생길 때까지 단정하지 않는다 |
| 묘령 | 신전의 이상과 보물을 봉쇄한다 | 위험을 경고하고 처음에는 길을 막는다 |
| 조안 | 보물 소문을 바라보는 현지 시각을 전한다 | 퀘스트나 화린 위치를 주지 않는다 |

환경 현상은 하나의 원인에서 갈라진다. 사람은 욕망 때문에 신전으로 향하지만, 동식물은 위험을 느끼고 호수에서 멀어진다. 길·등불·소리의 규칙은 보물의 불안정 때문에 어긋난다.

## 2. 메인 플로우

플레이어 노출 퀘스트명은 전 구간에서 `신전의 보물`로 유지한다. 아래 내부 Quest ID는 기존 저장 데이터와 Flow 연결을 보존하기 위한 단계 키일 뿐, 별개의 의뢰처럼 표현하지 않는다.

| 단계 | 내부 Quest ID | 플레이 흐름 |
|---|---|---|
| 도입 | `quest_sub_lake_missing_villagers` | 보물 소문을 듣고 안내인에게 신전 길과 숲의 이상을 확인한다 |
| 막힌 숲길 | `quest_sub_lake_rescue_hwarin` | 먼저 싸우고 있던 화린과 길목을 정리하고, 막힌 구간까지만 임시 동행한다 |
| 흔적 추적 | `quest_sub_lake_rescue_lian` | 흔적을 조사하던 리안과 만나 역할을 나누고 함께 이동한다 |
| 신전 접근 | `quest_sub_lake_follow_tracks` | 거대한 흔적을 확인하고 접근을 막는 묘령과 대치한다 |
| 신전 | `quest_main_lake_shrine` | 구체적인 정적, 들어가기만 한 발자국, 보물과 다른 자신을 확인한다 |

중간 단계의 완료 알림은 숨기고 다음 단계를 자동 수락한다. 최종 단계만 제1장 완료를 명시한다.

### 합류 감정선

1. 화린은 구조 대상이 아니라 공동 전투자다. `막힌 구간까지만` 동행한 뒤 원인을 확인하려고 스스로 동행을 연장한다.
2. 붉은 천은 조안의 퀘스트 표식이 아니라 화린이 남긴 귀환 경로다.
3. 리안은 흔적을 먼저 좇고 있다. 화린과 조사 방식이 충돌하고, 주인공이 역할을 나눈 뒤 정식 동행을 제안한다.
4. 묘령은 신전 접근을 물리적으로 막는다. 대치 후에도 친구가 아니라 감시자이자 안내자로 동행한다.
5. 신전에서는 장면마다 필요한 인물만 말한다. 화린은 행동, 리안은 관찰, 묘령은 경고, 주인공은 결정을 담당한다.

### 결말에서 확인되는 사실

- 보물은 실제로 존재하며 숲의 이상 현상과 연결되어 있다.
- 보물은 소원을 그대로 이루기보다 방문자가 원하는 모습이나 두려워하는 가능성을 밖으로 꺼낸다.
- 다른 자신을 쓰러뜨린 뒤 숲의 기운은 잠시 가라앉지만 보물은 남는다.
- 다른 자신, 보물의 불안정 원인, 주인공의 구체적인 소원은 다음 장의 질문으로 남긴다.

## 3. 지역 곁가지

| NPC | Quest ID | 형태 | 메인 서사 기여 |
|---|---|---|---|
| 미아·준 | `quest_sub_hunter_skeleton_patrol` | 전언과 짧은 공동 전투 | 사람이 위험 속에서도 일상을 붙드는 모습을 보여 준다 |
| 헤이즐 | `quest_sub_hazel_moved_herb` | 경로상 조사·채집 3개 | 식물이 호수를 피한다는 단서를 준다 |
| 페니 | `quest_sub_penny_lantern_order` | 등불 3개 순차 조사 | 신전에서 내려온 무언가의 이동 순서를 드러낸다 |
| 모건 | `quest_sub_morgan_west_road` | 선택 전투·수레 조사 | 짐승이 수레를 노린 것이 아니라 호수에서 도망쳤음을 드러낸다 |

조안·루시아·상인·조이는 퀘스트를 주지 않는다. 조안은 소문의 모순, 루시아는 소리의 변화, 상인은 지역 피해, 조이는 제1장 전후의 일상 변화를 담당한다.

## 4. LakeOfLife 배치

신규 배치는 `Story_LakeSideQuestRoute.prefab` 하나로 묶어 `LakeOfLife.unity`의 루트에 연결했다. 루트 기준점은 `(1000, 60, 430)`이다.

| 지점 | 월드 좌표 | 배치 의도 |
|---|---:|---|
| 물가 약초 자리 | `(1070, 59, 430)` | 시작 마을을 떠난 직후 생태 이상을 먼저 본다 |
| 준의 흔적 | `(1057, 59.5, 432)` | 주 경로에서 물가 샛길을 인지시킨다 |
| 준 조우 | `(1042, 60, 437)` | 길에서 짧게 벗어난 선택 전투로 끝낸다 |
| 첫 등불 | `(1007, 62, 445)` | 화린 구간 직후 조사 흐름을 시작한다 |
| 둘째 등불 | `(988, 65, 478)` | 변형된 숲길에서 진행 방향을 유지한다 |
| 마지막 등불 | `(968, 69, 514)` | 리안 조우 지점과 흔적 추적을 연결한다 |
| 멈춘 짐수레 | `(982, 69, 526)` | 메인 경로 인접 선택 분기로 둔다 |

화린 `(1011.21, 62.54, 430.63)`, 리안 `(966.37, 68.91, 515.69)`, 묘령 `(933.8, 72.61, 480.9)`의 기존 연출 위치는 유지했다. 신규 볼륨과 채집물은 이 세 지점의 진행 방향과 높이를 기준으로 인접 배치했다.

## 5. 진행·복구 계약

- 곁가지 퀘스트는 모두 `QuestDatabase`에 등록하고 콘텐츠를 활성화한다.
- 퀘스트 수락 전 지나간 볼륨은 진행을 소진하지 않는다. 활성 상태에서 다시 진입하면 이벤트를 받을 수 있다.
- 등불은 세 개의 독립 StoryEvent를 순서대로 요구한다. 잘못된 순서로 먼저 밟아도 해당 볼륨은 재진입 가능하다.
- 준 전투는 두 적을 동시에 감시하고 둘 다 쓰러진 뒤 대화를 연다. 전투 완료 플래그가 저장된 뒤 대화가 중단되면 현장 재진입으로 복구한다.
- 채집물 세 개는 고유 `SceneEntityId`를 갖고 소모 상태를 저장한다.
- 기존 내부 ID의 `rescue`, `salt`, `honoka`, `siuha` 명칭은 저장 호환 때문에 유지하며 플레이어 노출 문안에는 사용하지 않는다.
