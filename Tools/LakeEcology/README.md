# 호수 수중 생태계

정규 `LakeVillageWorld` 씬에 수초 509개, 낮은 암석 85개, 농어 6무리 30마리를 추가했다. 기존 Terrain·수면·진행 개체를 보존한다. 농어는 순환 애니메이션으로 움직이는 장식 생물이며 사냥·도주 AI는 없다.

수중 카메라 전용 거리별 색 흡수·청록 산란, 수면 뒷면의 물결, 바닥 빛무늬, 부유 입자 6구역을 반영했다. 수초는 느린 흐름으로 흔들리고 농어는 전용 유영 컨트롤러를 사용한다. 전역 날씨·안개·카메라 모듈을 덮어쓰지 않으며 HUD에는 수중 패스를 적용하지 않는다.

## 저작과 복원

- 입력: `ecology.json`. 실제 수면 삼각형과 Terrain 높이를 사용한다.
- 정규 에셋: `Assets/10.Datas/World/OpenWorld/LakeUnderwaterEcology/`의 프리팹, 순환 애니메이션 6개, 전용 재질 9개. 외부 패키지와 지상 재질은 수정하지 않는다.
- `apply.csx`, `polish.csx`를 저장된 정규 씬의 정상 Edit Mode에서 MCP execute_code로 순서대로 실행한다. 이미 배치된 씬에서 apply를 반복 실행하지 않는다. 실패 시 이번에 만든 루트와 신규 전용 폴더만 정리한다.
- 이후 `finish-environment.csx`, `polish-life.csx`를 실행한다. 이 두 스크립트는 반복 실행해도 영역·렌더러 기능·입자를 중복 생성하지 않는다. `LakeWater`의 `UnderwaterRegion`과 PC_Renderer의 `Lake Underwater` 기능이 연결되어야 한다.
- `LakeOptics.asset`에서 색 흡수·가시 거리·수면 전환·빛무늬를 조정한다. 물결은 `LakeUnderside.mat`, 부유물은 프리팹의 `SuspendedLife`와 `SuspendedParticles.mat`, 식생 흐름은 `Lake_Grass_*` 재질에서 조정한다.
- 전체 생성기를 다시 실행하지 않는다. 이후 월드를 재생성할 때는 저장된 프리팹을 월드 원점, 회전 0, 스케일 1로 복원하고 `finish-environment.csx`로 수면 메시·광학 영역을 재연결한다. 변경된 수면·지형에 맞는지 재검사한다. 생성기 자동 연결은 하지 않았다.
- `output/LakeEcology/scene-before.unity`는 미커밋 사용자 데이터를 포함한 적용 전 사본이므로 임의 삭제하지 않는다. 배치 기록은 같은 폴더의 `placement.json`이다.

## 검증과 한계

Unity 컴파일 성공. EditMode `UnderwaterEnvironmentTests` 6개 통과: 수면 진입의 연속성, 실제 삼각형 외부 제외, 회전·스케일, 수면 위 제외, 영역과 수면 비활성화. 초기 배치에서 Missing Script 0, 지원되지 않는 셰이더 0, Standard 재질 잔존 0, 수면 위 식생·암석 Renderer 0, 신규 Collider 0, 물고기 경로 480개 표본의 수면·바닥 침범 0을 확인했다.

`check-rendering.csx`로 실제 URP 렌더 비교 통과. 수면 위 평균 RGB 바이트 차이는 0.0304로 반복 렌더 잡음 0.0455보다 작고, 수중에서는 57,595/57,600픽셀에 효과가 적용됐다. 광학·물결·입자 셰이더 오류 0. 증거는 `output/LakeEcology/Finished/render-check.txt`와 수중·수면 위 캡처다.

짧은 Editor Play Mode 검수에서 무리 6개와 Animator 30개가 활성화되고, 무리 회전이 238.89도에서 359.91도로 진행되며 유영 클립 시간도 증가했다. 입자 126개 활성, Console 오류 0, 종료 후 정규 씬 복귀·미저장 변경 없음. `playmode-fish.png`는 임시 수중 카메라로 촬영했으며 플레이어 입력 검수는 아니다. 검수 카메라·RenderTexture와 임시 백그라운드 실행 설정은 정리·복구했다.

수면 뒷면은 불투명한 스타일화 표현이며 물리 기반 굴절·반사는 아니다. 수초는 기존 잔디 메시를 녹색 전용 재질로 재사용했다. 식생 LOD·재질 인스턴싱·화면 밖 애니메이션 컬링을 유지하며 부유물은 최대 144개다. 실측 프레임 성능과 플레이어 TPS 조작 품질의 최종 확인은 남아 있다.

## 사용자 테스트

준비: 정규 `Assets/01.Scenes/Scenario/OpenWorld/LakeVillageWorld.unity`, 기존 시작 경로로 Editor Play Mode 진입. 저장 데이터 초기화 없이 키보드·마우스 또는 게임패드 사용.

| ID | 실행 | 기대 결과·실패 기준 |
|---|---|---|
| L01 | `(1011,77,759)` 부근 입수 후 아래를 보며 전진해 잠수 | 수초·바위가 바닥에 붙고 물 위로 나오지 않음. 부유·관통이 두드러지면 실패 |
| L02 | 군락 사이를 왕복하고 해안으로 복귀 | 신규 배치에 걸리지 않고 기존 수영 상태 전이 유지 |
| L03 | `(988,76,787)`, `(1155,76,958)`의 농어를 40초 관찰 | 몸통·꼬리가 움직이고 경로를 순환. 역방향 유영·순간이동·수면 이탈·분홍 재질은 실패 |
| L04 | 낮·밤·비에서 잠수와 출수 반복 | 잠수 시 먼 배경의 청록 안개와 수면 아래 물결이 보이고 출수 시 즉시 정상 경관으로 복원. HUD 색 변화·지상 안개 잔류·과도한 밝기·수면 깜박임은 실패 |
| L05 | 같은 위치 입수 전후 프레임과 Console 비교 | 반복적인 프레임 저하·신규 오류가 없어야 함 |

회신: `ID / 통과·실패·미수행 / 실제 결과 / 화면 또는 Console 오류`. TPS 조작·시간대별 체감·실측 성능은 사용자 테스트 대기다. Play Mode의 유영·입자 활성은 AI 검사 완료다. Player 빌드는 지침에 따라 실행하지 않았다.
