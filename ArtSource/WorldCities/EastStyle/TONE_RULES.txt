두 화면은 조명 조건이 다르므로 픽셀색을 머티리얼 원색으로 직접 복사하지 않는다.

호수에서 읽히는 기준
- 목재: 따뜻한 황갈색 중간 면, 어두운 짙은 갈색 구조선. 결은 길고 단순하다.
- 명암: 햇빛 면/그늘 면/접합부의 3단계가 먼저 읽힌다. 검은 윤곽선과 흰 반사를 추가하지 않는다.
- 지붕: 초가는 따뜻한 황토색의 큰 면과 수직 결. 새 기와는 저채도 회청으로 재료만 구분한다.
- 질감 밀도: 사람 눈높이에서 목재 결과 지붕 골이 보이되 멀리서는 한 덩어리로 정리된다.
- 캐릭터: 밝은 피부·의상의 대비가 건물 세부보다 먼저 읽혀야 한다.

새 기와 기준 팔레트 (디자인 목표 sRGB; 화면의 계측값 아님)
- 깊은 면 #374447
- 중간 면 #505F60
- 작은 밝은 면 #737A70
- 목재와 기단은 TGV 원본 재질을 유지한다.

조달 후보와 판정
1. TGV Building Kit TGV_Wall_01A/02A/04A/06A: 채택. 호수와 동일 재질·비례, 1m/2m 벽 간격, 높이3m.
2. TGV_Roof_01A~04A: 비교용 초가 지붕으로 유지. 기존 경사 지붕의 실루엣은 동양 기와 처마/추녀 모서리가 아니어서 신규 기와 원형으로는 탈락.
3. FarmLand House Modules/Roofs와 T_Farm_RoofTiles_C: 기존 서양식 농가 기와 모듈 후보. 경사와 처마 끝 형태가 요청한 동양 지붕과 다르고 TGV 벽 격자와 직접 결합되지 않아 탈락.
4. DreamscapeEastLands Props/StoneStairsWalls: 후속 도시 생활 장식 후보. 주택 지붕 모듈이 아니므로 이번 기준판의 지붕 대체재로는 탈락.
5. DreamscapeEastLands 도리이/금줄/여우상: 호수 신앙 전용이므로 제외.
6. 기존 WorldCities CastleTownHouse/HarborHouse 및 CityMaterialsAtlas.png: 문화권·질감 불일치 때문에 기준판에서는 제외. 원본 변경 없음.
7. LowPolyFantasyArena2 Ruins/Tile: 바닥·폐허 타일이며 지붕 용도가 아니므로 제외.

머티리얼 규칙
- EastRoofClay.png는 내장 ImageGen으로 생성한 불투명 albedo. 기와 골은 텍스처가 아닌 메시가 담당한다.
- 타일링 접합선은 최종 Unity 캡처에서 확인한다. 생성만으로 seamless 검증 통과라 표시하지 않는다.
- 새 재질은 EastStyle 전용 사본. 기존 공유 atlas/재질/프리팹/FBX를 덮어쓰지 않는다.
- metallic 0, 낮은 smoothness, 새 고밀도 normal map 없음.
- TGV 원본 셰이딩과 동일 조명 아래에서 비교한 후 사용자가 승인해야 도시 적용 가능.

치수 규약
- Unity 1 unit = 1m. FBX up Y, forward -Z. Blender up Z.
- TGV_Wall_01A 폭1m/높이3m/두께0.52m; Wall_02A 폭2m/높이3m/두께0.52m (Blender 실제 모델 bounds 확인).
- EastRoof_Straight_2m: 용마루 방향 2m, 반쪽 지붕 깊이3.2m. 기본 처마 기준 높이0, 용마루 약2.005m.
- EastRoof_Corner_3p2m: 용마루 끝을 원점으로 한 3.2m 사분면 추녀. 90도 회전으로 4모서리 조립. 장식 추녀 캡은 표면 밖으로 약0.085m 나온다.
- EastRoof_Ridge_2m: 길이2m, 폭0.32m. 직선 모듈과 같은 길이로 반복.
- 기준 주택 몸체: 벽 중심선8m×4m, 벽높이3m. 지붕 표면10.4m×6.4m, 처마 중심선 돌출1.2m. 추녀 장식 포함 외곽 약10.57m×6.57m.
- FBX 루트의 -90도 X 축 보정을 제거하지 않는다. Unity 조립 회전은 Quaternion.Euler(0, 목표방향+180, 0) * 원본 루트 회전이다.
- PrefabInstance Transform/Renderer 변경은 RecordPrefabInstancePropertyModifications로 기록해야 재임포트/재로드에서 보존된다.
- 직선/모서리는 개별 FBX 원점 유지. 음수 스케일로 법선 반전을 만들지 않고 회전으로 조립한다.
- 지붕 코너는 2m 격자를 끝내는 엔드캡이며 반복 폭을 늘리는 데 쓰지 않는다.

원본
build_roof_modules.py: 재생성 파라미터와 메시 생성 근거.
EastRoofModules.blend: 모듈 전용 씬·메시·재질. 소스 파일에서는 비교를 위해 X축4.5m 간격으로 펼쳐 보인다. FBX는 위치 이동 전에 원점에서 내보낸다. 기존 Blender 도시 씬을 덮어쓰지 않는다.
mesh_validation.json: 버텍스/삼각형/규격 기록.
