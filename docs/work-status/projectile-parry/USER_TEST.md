# 투사체 패리 사용자 테스트 · PP01~PP10

구현 식별자: `ProjectileParry-P0-P4-20261114`. 최종 자동 검사 결과는 [상태 정본](../projectile-parry.md)에서 확인한다. 아래 항목은 모두 **사용자 테스트 대기**다. 체감·가독성·청감 합격을 자동 검사 결과로 대체하지 않는다.

## 공통 준비

1. 다른 Unity 작업 세션의 테스트·컴파일을 종료한 후 같은 Editor 하나를 사용한다. 현재 편집 중인 씬은 먼저 저장한다.
2. 툴 런처 → 월드/맵 → **전투 테스트 맵 열기**를 실행한다. 실제 씬은 `Assets/01.Scenes/Test/CombatTestMap.unity`, `PlayerSpawn=(0,0,0)`, 평지 바닥 윗면 y=0이다. 기존 `전투 테스트 준비` 창을 사용한다. 원본 저장 슬롯·정규 월드 진행은 변경하지 않는다.
3. 시작 파티에 라온(기본 가드 지원 무기)과 스왑 비교할 캐릭터를 선택한다. **플레이어 무적은 끈다**. AI 정지도 끈다. Play를 시작하고 파티 준비 완료를 기다린다. 재시험은 Play 종료→재시작으로 HP/쿨다운/탄/시험 제한을 초기화한다.
4. P09 등급은 Armor06/Lv10으로 선택한다. **단일 적 무기 Bow**, 전방 거리 **10m**, `선택한 일반 적 1체 소환`. 대상은 `Enemy_P09_Armor06_Bow`, ActorDefinition은 `Assets/10.Datas/Actor/P09Progression/Generated/Enemy_P09_Armor06_Bow/Enemy_P09_Armor06_Bow_ActorDef.asset`이다. 플레이어가 +Z를 바라보면 적은 대략 (0,0,10)에 생성된다. `공격 반복 관찰 / 허용할 공격`에서 `Actor.Humanoid.BowAttackData.Attack.1.01`을 고른다. 공격 제한은 기존 BT 거리/쿨다운 조건을 유지한다.
5. 마법탄은 새 Play에서 단일 적 무기 **Staff_M**을 고른다. 실제 `Enemy_P09_Armor06_Staff_M`의 `Monster.P09Staff.Bolt`만 허용한다. 같은 Set/Motion을 사용하는 Staff_F도 동일 대상이다. 빔 비교는 `Monster.P09Staff.Beam`을 선택한다.
6. 입력은 현재 Input 설정의 **Guard/Attack/Dodge/캐릭터 교체** 바인딩을 사용한다. 키보드/마우스와 실제 게임패드를 각각 기록한다. 키 이름을 고정하지 않고 프로젝트 Input 설정에 표시된 바인딩을 따른다. Guard는 누른 뒤 유지, 새 창은 뗐다가 다시 누른 입력만 인정한다.
7. 형상 확인: 화살은 기존 화살 모델, 마법탄은 기존 StaffBolt VFX에 밝은 중심과 **나란한 두 꼬리**가 추가된다. 반환 순간에는 짧은 반환 트레일로 바뀐다. 발사음에는 기존 Basic RPG Sounds의 `Gattling Laser 1.wav`를 별도 음량/피치로 얹는다. 소리가 불쾌하거나 기존 공격음과 구별되지 않으면 실패로 기록한다.

시험 탄: 화살 `Projectile_EnemyArrow_Parry.asset` GUID `0a743771d8a2ad04ab910d0f4bc981fd`, 마법탄 `Projectile_P09Staff_Bolt_Parry.asset` GUID `d73b4c6db99583f4c852b8eb05597c92`. 화살 비행20/반환25m/s, 마법탄 비행20/반환20m/s(maxSpeed 상한)이며 모두 반환 수명2초다. 수치는 사용자 검수 전 초깃값이다.

PP04의 다중 사격과 PP06의 assist는 기존 파티/혼합전 진입 조건이 필요하다. 준비가 안 되면 **미수행**으로 기록하고 다른 항목을 계속한다. 가상 입력·새 저장/월드 진행 변경으로 조건을 대신 만들지 않는다. Play 중 만든 Cube는 씬에 저장하지 않고 Play 종료로 제거한다.

## 회신 양식

`PP번호 / 통과·실패·미수행 / 실제 결과 / 키보드·마우스 또는 게임패드 / 구현 식별자 / 탄 종류·거리·몸 방향 / 영상 또는 Console 로그`

실패 시 탄 도착과 입력 시점이 보이는 짧은 영상, 해당 Console 오류만 첨부한다. 전체 로그나 세이브 파일은 필요하지 않다. 세션 종료 뒤 공격 제한·가상 입력·시험 Cube가 남지 않았는지 확인한다.
