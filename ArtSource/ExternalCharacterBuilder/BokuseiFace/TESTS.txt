Bokusei P09 r01 사용자 테스트 명세

준비: 현재 씬을 원하는 방식으로 보존한 뒤 Assets/01.Scenes/Tests/Equipment/Bokusei_P09_Review.unity를 연다.
이 씬은 모델 비교용이다. 액터·대화·전투 서비스가 포함된 게임 플레이 씬이 아니다.
Unity 버전과 그래픽 설정을 기록한다. 기존 플레이어/월드/저장 데이터 교체는 필요하지 않다.

B01 / 미술 승인 대기
기본형·대체형을 정면, 35도, 측면, 후면에서 관찰. 머리·이마·귀·턱·목을 확대한다.
기대: 두피 관통, 목 틈, 분홍 재질, 중복 얼굴 없음. 목 피부색/경계선이 거슬리면 실패로 기록.

B02 / 미술 승인 대기
활성 Male_Face_01의 Eye_Blink, Mouth_Smile, Lip_aa/ii/uu/ee/oo를 0→100으로 조절하고 원복한다.
기대: 눈꺼풀 닫힘, 눈/입 내부 비정상 노출 없음. 표정의 자연스러움은 별도 판단.
36개 슬롯의 매핑 의미를 모두 미술 승인한 것은 아니므로 사용 감정은 추가 확인한다.

B03 / Editor 조합 자동 검사 통과, 사용자 외형 판단 대기
P09 빌더에서 Bokusei_P09_BuildPreset을 불러오고 헤어 13↔03, 의상 03↔05를 바꾼다.
기대: 같은 얼굴/눈/피부 유지, 옷과 헤어 정상 표시. 테스트만으로 정규 플레이어 프리팹을 덮어쓰지 않는다.

B04 / Play Mode 사용자 테스트 대기
검수 씬을 Play하고 카메라를 멀리/가까이 이동한 뒤 시야 밖으로 돌렸다가 복귀한다.
기대: SkinnedMeshRenderer 소멸·깜빡임·vertex stride 오류 없음. 검수 씬은 정적 Idle 배치다.

B05 / 추후 Actor 통합 시 필수, 현재 미수행
별도 테스트 액터에 모델 연결 후 Idle/보행/대화/시선/립싱크와 재진입을 확인한다.
기대: 머리와 몸 추종, 눈/입 표정 정상, 씬 재진입 후 같은 모델 유지.
Player/Enemy로 사용할 때는 무기 소켓·GAS·모션·충돌·관련 전투 검증을 별도로 수행한다.

B06 / 미수행
긴 머리·투구·망토·MagicaCloth 및 실제 목표 인원 성능은 각 조합별 검증이 필요하다.
Hair_03 대체형의 정적 표본 통과를 물리·전투 동작 통과로 해석하지 않는다.

회신: ID / r01 / Unity 버전 / 통과·실패·미수행 / 실제 결과 / 화면 각도·동작 또는 Console 로그.
기존 다온 메시·재질 오류는 이번 모델의 오류와 구분한다.
