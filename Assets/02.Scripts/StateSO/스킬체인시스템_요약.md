# 스킬 체인 시스템 - 빠른 시작 가이드

## ✅ 완료된 구현

### 1. 데이터 구조
- ✅ **SkillChainData.cs** - 스킬 연계 정보 클래스
- ✅ **ComboJsonData.cs** - 순차 콤보 정보 클래스
- ✅ **SkillJsonData.cs** - 개별 스킬 정보 클래스

### 2. 시스템 로직
- ✅ **SkillActionStateSO.cs** - 스킬/콤보/체인 통합 처리
- ✅ **JsonDataManager.cs** - Json 데이터 로드 및 캐싱

### 3. 예시 데이터
- ✅ **SkillChainData.json** - 체인 분기 정보 (12개 체인)
- ✅ **SkillData_ChainExample.json** - 체인용 스킬 정보 (12개 스킬)
- ✅ **ComboData.json** - 순차 콤보 정보 (3개 콤보)

## 🚀 5분 만에 시작하기

### Step 1: Addressable 설정 (1분)
```
1. SkillChainData.json → Addressable 그룹 추가
   Address: "SkillChainDataTable"

2. SkillData_ChainExample.json → Addressable 그룹 추가
   Address: "SkillDataTable"

3. ComboData.json → Addressable 그룹 추가 (옵션)
   Address: "ComboDataTable"
```

### Step 2: InputAction 설정 (1분)
```
1. SkillActionStateSO 에셋 선택
2. Attack X Action 필드에 X키 InputAction 연결
3. Attack Y Action 필드에 Y키 InputAction 연결
```

### Step 3: PlayerBrain 설정 (3분)
```csharp
using Game.FSM;
using UnityEngine;

public class PlayerBrain : CharacterBrain
{
    [SerializeField] private SkillActionStateSO skillChainState;
    
    void Update()
    {
        // X키로 검 체인 시작
        if (Input.GetKeyDown(KeyCode.X))
        {
            SetData("CurrentSkillID", 2001);  // Basic Slash
            ChangeState(skillChainState);
        }
        
        // Y키로 창 체인 시작
        if (Input.GetKeyDown(KeyCode.Y))
        {
            SetData("CurrentSkillID", 3001);  // Thrust
            ChangeState(skillChainState);
        }
    }
}
```

### Step 4: 테스트!
```
1. 게임 실행
2. X 키 누르기 → 기본 공격 시작
3. 애니메이션 중간에 X 또는 Y 입력
4. 콘솔에서 체인 진행 확인
```

## 📊 시스템 구조

```
Json 데이터 (Addressable)
  ├─ SkillChainData.json ───────→ 스킬 분기 정보
  ├─ SkillData.json ────────────→ 개별 스킬 정보
  └─ ComboData.json ────────────→ 순차 콤보 정보
              ↓
    JsonDataManager
              ↓
    SkillActionStateSO ←─────────→ PlayerBrain
              ↓
    입력 감지 & 체인 실행
```

## 🎮 체인 실행 흐름

```
1. 체인 시작
   SetData("CurrentSkillID", 2001)
   ChangeState(skillChainState)
   
2. 첫 스킬 실행
   2001 애니메이션 재생
   
3. 입력 윈도우 활성화 (50%~90%)
   isInInputWindow = true
   
4. 사용자 입력
   X키 → 다음 스킬 2002
   Y키 → 다음 스킬 2010
   없음 → 체인 종료
   
5. 다음 스킬 실행
   2~4 반복
```

## 💡 주요 기능

### 1. 다양한 분기
```
X → X → X  (기본 3연타)
X → Y → X  (상승 → 낙하)
X → X → Y → X  (최강 콤보)
```

### 2. 입력 윈도우
```json
{
  "inputWindowStart": 0.5,  // 50% 지점부터
  "inputWindowEnd": 0.9     // 90% 지점까지
}
```

### 3. 무한 확장
- 새 스킬 추가는 Json 편집만으로 가능
- 코드 수정 불필요
- 입력 키 자유 설정 가능

## 🚨 문제 해결

### 체인이 시작되지 않음
- JsonDataManager가 초기화되었는지 확인
- CurrentSkillID가 올바르게 설정되었는지 확인
- SkillJsonData에 해당 스킬이 있는지 확인

### 입력이 감지되지 않음
- InputAction이 연결되었는지 확인
- 입력 윈도우 타이밍 확인 (콘솔 로그)
- InputAction이 활성화되었는지 확인

### 애니메이션이 재생되지 않음
- AnimationData에 해당 키가 등록되었는지 확인
- actionAnimKey 철자 확인
- Animancer가 정상 작동하는지 확인

### 다음 스킬로 연계되지 않음
- SkillChainData에 해당 분기가 있는지 확인
- nextSkillID가 존재하는 스킬인지 확인
- 입력 윈도우 내에 입력했는지 확인
