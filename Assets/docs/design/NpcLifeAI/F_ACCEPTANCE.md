# F 인수 검토

## 재개 후 현재 판정

전체 완료가 아니다. 대표 4명의 실물 작업물·지붕·접근로와 런타임 보완을 반영했다. 사용자 승인 후 일반 주민 2명/교류 장소 1곳의 게이트를 켜고 저장했다. 최종 EditMode 58/58, 기존 생활 행동 PlayMode 12/12, 정적 활동 간 캡슐 경로 30건·실제 지붕 4건은 통과했다. 활성화 후 현장 검수는 대기다. 아래 표는 재개 전 이력이며 현재 상태는 STATUS와 `output/NpcLifeAI/verification.json`을 따른다.

- B: 조리대/용기·수선대/목재, 정상 종료, 보류 활동 제외, 벽을 가로지르지 않는 중간 합류를 반영했다. 실제 접점·반복·길막 검수는 대기다.
- C: 참여자별 고정 자리·접근로·취소 복구와 전체 인사 모션 길이(2.5초씩 교대)를 보장했다. 일반 주민 2명/교류 장소 1곳은 사용자 승인 후 활성화·저장했다.
- D: 보호점 4곳에 기존 프리팹 지붕 4개·기둥 16개를 배치하고 실제 지붕 충돌을 확인했다. 자연 날씨/전투 검수는 대기다.
- E: 로더 간 동일 맵/GUID 충돌과 충돌 해제 후 재연결, 소유한 몸만 해제하는 경계를 검증했다. 실제 저장·왕복·Reload 설정별 검사와 성능 측정은 대기다.
- F: 발소리/작업 접촉음과 나머지 주민 확대는 남았다. LIFE01~09 사용자 결과가 없어 시각·조작 품질을 승인하지 않는다.

## 재개 전 기록

현재 결과는 전체 완료가 아니다. A~E 기반 구현·대표 연결을 반영했으며 미검수 콘텐츠의 전체 확대를 보류한다. 사용자가 전달한 LIFE 결과는 없다.

|요구|구현|자동 검사|사용자 검수/보류|
|---|---|---|---|
|단일 일과 진입/우선권|LifeController→Routine/KCC, 프로필 없는 기존 경로 유지|기존·신규 EditMode 43/43|자연 전투/대화·전체 시각 대기|
|대체 작업점/취소|예약 실패 시 다른 작업/휴식, 공통 반환·세대|기존 예약·신규 취소 회귀 통과|복잡한 경유점 중간 합류 미완료|
|정상 종료 모션|Step.endMotion/완료 구독·세대·제한시간|컴파일 및 취소 회귀|조리/수선 접점·3회 반복 대기|
|2인 교류|두 동의/예약, 단일 진행자, 쌍 대기/취소|이전 세션 재취소/준비 거부 통과|부분 예약·동시 제안·소실 통합 회귀와 장소 승인 남음|
|실제 국소 사건|채집 타격 생산자→청각 관심, 입력 검증/인원 제한|맵/생산자/순서/시각 경계 통과|정상 입력·시선 자연스러움 대기|
|날씨 피신|기존 환경 생산자/히스테리시스 재사용|기존 환경 계약 통과|실제 지붕·보호 경로 미완료|
|생성·디스폰|GUID별 기존 몸 바인딩/해제|준비 전·해제 회귀|전역 충돌·저장·왕복·재스폰 통합 대기|
|거리별 중단/성능|강제 일과 lease 제거, 시뮬레이션 상태 소비|보조 컴파일|실측/Reload 비활성 검증 대기|
|역할별 확대/접촉음|대표 4명 프로필만 저작|대표 참조 검사|전체 확대·작업물·접촉음 정합 미완료|

Windows Player/Addressables 빌드는 단계 요청에 따라 실행하지 않았다. 원본 슬롯/진행도/보상 데이터는 변경하지 않았다. 변경 전달은 CHANGED_ASSETS를 따른다. 전체 완료 판정은 남은 코드·콘텐츠·자동 회귀와 LIFE01~09의 필수 사용자 결과가 모두 확보된 뒤 내린다.

최종 결과와 재실행 대기는 STATUS의 검사 job별 기록을 따른다. 추가 교류 검사 5개는 fixture 수정 후 `tests_running/busy`와 연결 단절로 재검증하지 못했다. 기존 43개 통과와 PlayMode 12개 성공 상태를 새 48개 전체 통과로 합치지 않는다.
