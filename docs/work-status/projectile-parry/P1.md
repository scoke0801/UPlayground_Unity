# P1 판정·단일 확정

구현: `ProjectileContact`(발사 ID/풀 세대/접촉 ID/전역 접촉시각/중심), `DefenseResult`(Guard·Attack·Assist/행동 ID/None·Reflected·Absorbed), 순수 후보 → 탄 commit → Actor 적용 경로. 같은 Guard 행동 보상 1회, 내구도 소모 0. 공격·assist는 기존 종료/폴백 취소를 유지하고 원격 OnParried·근접 카운터는 실행하지 않는다.

입력 시작/해제 콜백 → `PlayerDefenseController`의 누름 세대 → 실제 Guard 진입에서 소비. 0.18초/0.35초/140도는 DefensePolicy 소유. 유지·조기 재입력·재진입으로 자동 재개방하지 않는다. 접촉시각 이전 입력만 인정하며 근접 ActorTime 창은 유지한다.

검증: Unity 정상 컴파일/리로드 뒤 새 ProjectileContact 타입 로드 확인, Console error 0. `CombatTuningPolicyTests` 첫 실행 **23/23 통과**, [원본 MCP 결과](p1-editmode.json). 창 시작·종료 직전/경계/직후, 재개방/유지/조기입력, 정면 및 기존 근접 가드·공격쳐내기·회피 검사 포함. 세 경로×방어타입×적격성 행렬은 추가 작성해 후속 실행에 포함한다.

런타임과 판정은 같은 commit 계약으로 묶이므로 최소 반사/흡수 접점을 함께 구현했다. 반환 운동·피해 출처·포화·풀의 상세 검사는 P2가 소유하며 위 23건으로 그 동작까지 합격 처리하지 않는다. 콘텐츠 opt-in 미적용. 사용자 입력/피드백 인수 미수행.

다음: P2 스냅샷·귀속·충돌/수명 경계 PlayMode. 임시 오브젝트는 테스트 finally에서 정리. 기존 미커밋 에셋을 저장하지 않았다. [전투 위키](../../wiki/combat.md).
