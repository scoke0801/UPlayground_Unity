# 툰 안개 통합 계약

[전달 설계](../../../../../docs/전달용/unity_toon_fog/unity_toon_fog_design.html)와 [작업 상태](../../../../../docs/work-status/toon-fog/TaskStatus.md)를 연결한다.

PC Renderer에 기능을 등록하고 월드 단위로 활성화한다. 기본 합성은 카메라 깊이와 대상 컬러 attachment를 사용한다. 불투명·컷아웃·깊이 기록 외곽선은 이 경로를 공유한다. 수역 광학이 처리하는 카메라는 기존 Resolve 안에서 안개를 평가해 공기와 물의 순서를 보존한다. 투명 재질은 표면의 월드 위치로 같은 함수를 호출한다.

지역 프로필의 선택 영역과 실제 밀도 부피는 개별 컴포넌트다. 프로필과 품질·전투 가시성 수치는 데이터 에셋에서 관리한다. 거리와 높이의 단위는 미터다.
