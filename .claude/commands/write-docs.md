# 시스템 가이드 문서 작성

사용자가 제공한 인자(`$ARGUMENTS`)를 파싱하여 `Assets/docs/` 폴더에 시스템 가이드 문서를 작성하고, `ProjectReadme.md` 인덱스를 갱신한다.

## 인자 파싱

`$ARGUMENTS` 형식: `<SystemName> [<SourcePath>]`

- `SystemName` — 필수. 문서화할 시스템 이름 (예: `"Actor ID System"`, `Combat`, `Save`).
  - 공백 포함 시 따옴표 사용 가능 (예: `"Item Drop System"`).
- `SourcePath` — 선택. 분석할 소스 최상위 경로 (예: `Assets/02.Scripts/Manager/Actor`).
  - 없으면 SystemName 키워드로 Glob/Grep하여 자동 탐색.

## 실행 단계

### 1단계: 출력 파일명 결정

`SystemName`에서 출력 파일명을 유도한다:

- 공백 → `_`, 소문자 → 대문자, 특수문자 제거.
- 접미사 `_GUIDE` 추가.
- 예: `"Actor ID System"` → `ACTOR_ID_SYSTEM_GUIDE.md`

### 2단계: 기존 문서 스타일 파악

`Assets/docs/` 내 기존 문서 한 개를 Read 툴로 읽어 제목 형식, 섹션 구조, 표/코드블록 컨벤션을 파악한다.

### 3단계: 소스 파일 탐색 및 분석

아래 순서로 관련 소스를 수집한다.

1. `SourcePath`가 주어진 경우 — 해당 경로 아래 모든 `.cs` 파일을 Glob으로 수집.
2. `SourcePath`가 없는 경우 — `SystemName`의 주요 단어로 Grep하여 관련 파일 탐색.
3. 수집된 파일 중 **핵심 클래스**(베이스 클래스, 매니저, 주요 SO, 에디터 창)를 Read 툴로 읽어 분석:
   - 퍼블릭 API (메서드 시그니처, 프로퍼티)
   - 직렬화 필드 (`[SerializeField]`)
   - 클래스 계층 구조 (상속 관계)
   - 매니저 등록 여부 (`GameManager.cs` 확인)
   - 에디터 메뉴 경로 (`[MenuItem]` 어트리뷰트)
4. 파일이 너무 많으면 각 파일의 첫 60줄만 읽고 필요한 부분을 추가로 읽는다.

### 4단계: 문서 작성

아래 구조를 기반으로 `Assets/docs/<FILENAME>.md`를 Write 툴로 생성한다.
시스템에 따라 불필요한 섹션은 생략하고, 필요한 섹션은 추가한다.

---

```markdown
# <SystemName> 가이드

## 개요

<시스템이 해결하는 문제, 핵심 특징 3~5개를 bullet로>

---

## 아키텍처

<클래스 관계를 ASCII 다이어그램으로 표현>

### 파일 구조

<관련 파일 트리>

---

## 핵심 클래스

<각 클래스별: 역할 1~2문장 + 주요 필드 표 + 주요 API 코드블록>

---

## 셋업 방법

<번호 목록으로 단계별 셋업 절차. Inspector 설정, 에셋 생성, 씬 배치 등 포함>

---

## 사용 예시

<실제 코드 예시. 기본 사용, 고급 사용 케이스를 코드블록으로>

---

## 에디터 도구 (해당 시)

<커스텀 에디터 창이 있으면: 메뉴 경로, 기능 표, 사용법>

---

## 주의 사항

<자주 실수하는 포인트, 타이밍 이슈, 제약 조건>

---

## 확장 포인트

<오버라이드, SO 필드 추가, 이벤트 연동 등 커스터마이징 방법>
```

---

**작성 원칙:**

- 소스 코드에서 직접 확인한 실제 클래스명·메서드명·필드명만 사용한다. 추측하여 작성하지 않는다.
- 코드 예시는 이 프로젝트의 네임스페이스(`UPlayGround.*`)와 패턴을 따른다.
- 표는 필드/API를 나열할 때 사용하고, 관계는 ASCII 다이어그램으로 표현한다.
- 한국어로 작성한다.

### 5단계: ProjectReadme.md 인덱스 갱신

`Assets/docs/ProjectReadme.md`를 Read 툴로 읽고, `### 시스템별 상세 가이드 문서` 표에 새 항목을 추가한다.

```markdown
| [<FILENAME>.md](<FILENAME>.md) | <SystemName> — <한 줄 설명> |
```

표가 없으면 `## 📖 주요 시스템 가이드` 섹션 아래에 표를 새로 만든다.

### 6단계: 완료 메시지 출력

```
문서 생성 완료:
- Assets/docs/<FILENAME>.md

ProjectReadme.md 인덱스 갱신 완료.

주요 섹션: <작성된 H2 섹션 목록>
```
