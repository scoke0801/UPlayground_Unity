# Edit 모드 애니메이션 프리뷰 가이드

Unity Edit 모드(플레이하지 않은 상태)에서 애니메이션을 미리 볼 수 있는 기능입니다.

## 🎯 주요 기능

### 1. **실시간 애니메이션 재생**
- Play 버튼 없이 에디터에서 바로 애니메이션 확인
- Scene 뷰에서 실시간으로 캐릭터 동작 확인
- 재생 속도 조절 가능 (0.1x ~ 3x)

### 2. **정밀한 프레임 제어**
- 타임라인 슬라이더로 특정 시점 이동
- 프레임 단위로 포즈 확인
- 키 프레임 분석 가능

### 3. **비파괴적 미리보기**
- 씬 수정 없이 애니메이션만 확인
- Animation Mode 사용으로 안전한 프리뷰
- 프리뷰 종료 시 원래 상태로 복원

## 📖 사용 방법

### Step 1: 에디터 열기

1. Unity 메뉴: **Tools > Animancer 캐릭터 에디터**
2. 에디터 윈도우 열림

### Step 2: 캐릭터 선택

1. Hierarchy에서 AnimancerComponent가 있는 캐릭터 선택
2. 에디터의 "타겟 캐릭터" 필드에 할당

### Step 3: Edit 모드 프리뷰 실행

#### 방법 1: 클립 관리 탭에서
```
1. "클립 관리" 탭 선택
2. 클립 목록에서 "👁 미리보기" 버튼 클릭
3. Scene 뷰에서 애니메이션 확인
```

#### 방법 2: 프리뷰 탭에서
```
1. "프리뷰" 탭 선택
2. "프리뷰 클립" 필드에 클립 할당
3. "▶ 재생" 버튼 클릭
4. Scene 뷰에서 애니메이션 확인
```

## 🎮 컨트롤

### 재생 컨트롤
- **▶ 재생**: 애니메이션 재생 시작
- **⏸ 정지**: 재생 중지
- **⏮ 처음**: 타임라인 0초로 이동

### 타임라인
- **슬라이더**: 특정 시간으로 이동
- **실시간 표시**: 현재 시간/전체 시간/진행률 표시

### 재생 속도
- **슬라이더**: 0.1x ~ 3x 범위 조절
- **1x**: 정상 속도
- **0.5x**: 슬로우 모션
- **2x**: 빠른 재생

## 💡 활용 팁

### 1. 애니메이션 품질 확인
```
✅ 포즈 확인: 타임라인 슬라이더로 각 프레임 점검
✅ 루프 확인: 재생 속도 낮춰서 시작/끝 프레임 확인
✅ 타이밍 확인: 슬로우 모션으로 세밀한 동작 분석
```

### 2. 애니메이션 디버깅
```
- 특정 프레임에서 멈춰서 본 구조 확인
- 타임라인으로 문제 구간 찾기
- 느린 속도로 부자연스러운 동작 발견
```

### 3. 작업 효율성 향상
```
✓ Play 버튼 없이 바로 확인
✓ 여러 클립 빠르게 비교
✓ 씬 수정 없이 안전하게 테스트
```

## ⚠️ 주의사항

### Edit 모드 제한사항

1. **Animancer 레이어 기능 미지원**
   - Edit 모드에서는 단일 클립만 재생 가능
   - 레이어 블렌딩은 Play 모드에서 테스트

2. **트랜지션 미지원**
   - Edit 모드에서는 클립 간 전환 불가
   - 트랜지션은 Play 모드에서 확인

3. **이벤트 미실행**
   - 애니메이션 이벤트는 발생하지 않음
   - 이벤트 테스트는 Play 모드에서 진행

### 프리뷰 종료

```
⚠️ 프리뷰 재생 중일 때 다음 작업 시 자동 종료됩니다:
- 타겟 캐릭터 변경
- 에디터 윈도우 닫기
- Play 모드 진입
```

## 🔄 Edit 모드 vs Play 모드 비교

| 기능 | Edit 모드 | Play 모드 |
|------|-----------|-----------|
| **기본 재생** | ✅ 가능 | ✅ 가능 |
| **재생 속도 조절** | ✅ 가능 | ✅ 가능 |
| **타임라인 제어** | ✅ 가능 | ✅ 가능 |
| **레이어 블렌딩** | ❌ 불가 | ✅ 가능 |
| **트랜지션** | ❌ 불가 | ✅ 가능 |
| **이벤트 실행** | ❌ 불가 | ✅ 가능 |
| **씬 수정 필요** | ❌ 불필요 | ✅ 필요 |

## 🎨 Scene 뷰 활용

### 카메라 조작
```
- 마우스 휠: 줌 인/아웃
- Alt + 마우스 드래그: 회전
- 마우스 중간 버튼: 팬
```

### 최적 뷰 설정
```
1. Scene 뷰에서 캐릭터 선택
2. F 키 누르기 (Focus)
3. 애니메이션 재생하며 각도 조정
```

## 🛠️ 문제 해결

### 애니메이션이 재생되지 않음

**원인 1**: 타겟이 설정되지 않음
```
해결: "타겟 캐릭터" 필드에 캐릭터 할당
```

**원인 2**: 클립이 없음
```
해결: "프리뷰 클립" 필드에 AnimationClip 할당
```

**원인 3**: Animation Mode 충돌
```
해결: 
1. 프리뷰 정지
2. Window > Animation > Animation 탭 닫기
3. 다시 시도
```

### Scene 뷰가 업데이트되지 않음

**해결방법**:
```
1. Scene 뷰 클릭하여 포커스
2. 에디터 윈도우 재시작
3. Unity 재시작 (마지막 수단)
```

### 캐릭터가 이상한 포즈로 멈춤

**원인**: 프리뷰 종료 시 Animation Mode가 정상 종료되지 않음

**해결**:
```
1. "⏸ 정지" 버튼 클릭
2. 또는 Window > Animation Mode > Stop Animation Mode
```

## 📊 성능 최적화

### Edit 모드 프리뷰 성능 팁

1. **복잡한 캐릭터**
   - 프리뷰는 한 번에 하나만
   - 불필요한 Scene 뷰 닫기

2. **긴 애니메이션**
   - 필요한 구간만 확인
   - 재생 속도 높여서 빠르게 확인

3. **메모리 관리**
   - 사용 후 반드시 정지
   - 여러 클립 테스트 시 중간중간 정지

## 🎯 실전 활용 예제

### 예제 1: 걷기 애니메이션 루프 확인
```
1. Walk 클립 선택
2. Edit 모드 프리뷰 시작
3. 재생 속도 0.5x로 설정
4. 시작과 끝 프레임 비교
5. 타임라인으로 중간 프레임 확인
```

### 예제 2: 공격 애니메이션 타이밍 조정
```
1. Attack 클립 선택
2. 타임라인 슬라이더로 히트 포인트 찾기
3. 해당 시간 기록 (예: 0.35초)
4. 애니메이션 이벤트 추가 시 활용
```

### 예제 3: 여러 클립 빠르게 비교
```
1. "클립 관리" 탭 활용
2. 각 클립의 "👁 미리보기" 버튼 클릭
3. Scene 뷰에서 즉시 확인
4. 빠른 의사결정
```

## 📝 단축키 (향후 추가 예정)

현재 버전에서는 단축키가 없지만, 다음 기능이 계획되어 있습니다:

```
Space: 재생/정지
← →: 프레임 이동
Home: 처음으로
[ ]: 재생 속도 조절
```
