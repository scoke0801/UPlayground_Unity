# 생명의 호수 시작과 영입 및 퀘스트 제작 명세

버전 1.1 / 상태 초안 / 2026-10-10. 상위 요구는 [00](00_MASTER_PLAN.md), 배치는 [02](02_WORLD_AND_PLACEMENT.md), 전투는 [04](04_ENCOUNTERS_AND_EXPLORATION.md)를 따른다. S·Q·E 번호는 제작용 추적 키이며 기존 저장 ID를 대체하지 않는다.

장면 S00~S10의 행동·구도·소리·조작권·취소/스킵 복구는 [08 연출 지침](08_PRESENTATION_DIRECTION.md)을 적용한다. NPC 대사는 실제 모델과 일러스트를 확인한 Voice Profile로 작성하고 기존 플로우의 어투도 대조한다.

## 1 언어 경계

플레이어에게는 사람·신전·보물·천·짐·자국·길처럼 눈앞의 상황을 말한다. 제작 문서의 '구역', '영입 커밋', '게이트', 'Variant', '상태'를 목표·대사에 노출하지 않는다. 새 NPC 이름은 03의 가칭과 실제 npcId를 별도로 관리한다. 제작 편의를 위한 역할명으로 인물을 부르지 않는다.

현재 v3.1의 관계 어투를 유지한다. 주인공은 초면 주민과 묘령에게 해요체, 화린·리안에게는 말을 놓기로 한 이후 반말이다. 짧다는 이유만으로 군대식 어투를 쓰지 않는다. 아래 대사는 장면 의도용 최소 예시이며 외형과 실제 동작을 확인한 뒤 최종 원고에 반영한다.

## 2 주제와 시작 계약

주제는 낯선 사람과 함께 위험을 지나며 서로를 기다리게 되는 변화다. 목적지인 신전과 구체적인 사람의 사정이 같은 방향으로 이어져야 한다.

| 항목 | 기본안 |
|---|---|
| 시작 선택 | Bokusein 계열과 Arin 중 1명 선택 |
| 실제 식별 | Bokusei 저장 이름 → Raon=1, Arin=13. 사용자 표기로 enum 신규 생성 금지 |
| 최초 보유·출전 | 선택한 인물 1명 |
| 최초 시점 | 선택 인물을 StoryProtagonistType에 보존 |
| 화린 합류 후 | 보유·출전 2명 |
| 리안 합류 후 | 보유·출전 3명 |
| 묘령 합류 후 | 보유·출전 4명 |
| 선택하지 않은 시작 인물 | 자동 지급하거나 영입 이벤트 없이 출현시키지 않음. 후속 영입은 별도 기획 |
| 주인공별 전투 | 현재 카탈로그의 실제 능력을 기준으로 조율. Arin을 근거 없이 마법사로 재설계하지 않음 |
| 분신·대사 | 현재 ActiveCharacter가 아니라 StoryProtagonistType을 사용 |

시작 방식에 답이 없을 때는 현행 선택 데이터와 일치하는 위 기본안으로 기획한다. 두 명 동시 시작으로 변경되면 처음부터 두 명이 함께 온 이유·비활성 인물의 대화 등장 규칙을 저작하고 2→3→4→5명의 Roster 성장을 적용한다. 4인 BattleOrder 상한은 유지하며 다섯 번째 영입은 대기로 처리한다. 해금 성공과 출전 자동 편입 성공을 혼동하지 않는다. 이 분기에서는 교체 안내를 첫 전투 뒤로 앞당기고 '혼자 왔다' 문구를 모두 검수한다.

## 3 세계와 저장 규칙

| 사실의 수준 | 내용 |
|---|---|
| 유지할 사실 | 보물 소문, 숲의 위협, 화린과 리안의 기존 관계, 묘령의 공격자 목격 증언, 신전의 닮은 상대 |
| 인물의 판단 | 흔적이 신전 쪽으로 이어진다는 관찰, 묘령의 오인, 주민의 걱정 |
| 확정하지 않음 | 보물의 작동 원리·주인공의 구체적 소원·닮은 존재의 생성 시점과 본질 |
| 지속 | 정상 종료 대화, 영입, 퀘스트 진행, 이미 지급된 보상, 장 완료 |
| 재진입 시 복구 | 전투 중이면 정의된 안전 시작점, 대화 중단이면 완료되지 않은 대화 단계 |
| 새 게임에서 초기화 | 해당 플레이의 지역·퀘스트·영입 진행. 기존 계정 공용 정책이 있으면 별도로 보존 |
| 일반 적 재출현 | 현재 리스폰 서비스 계약 사용. 스토리 일회성 조우와 분리 |

시점 인물과 동료가 임시 대역으로 나오는 장면은 종료·스킵·취소·씬 이탈 시 모두 정리한다. 필드에 지속적으로 따라오는 동료 AI를 이 기획의 전제로 추가하지 않는다.

## 4 인과 사슬

1. 주인공은 보물 소문을 직접 확인하려고 찾아온다. 도착길에서 사람이 생활하는 곳을 발견하여 길을 묻는다.
2. 주민이 위험을 알리지만 주인공은 직접 가겠다고 결정한다. 그래서 물자와 사람의 흔적이 남은 숲길로 나간다.
3. 그 길에서 싸우는 화린을 돕는다. 화린의 친구가 근처에서 헤어졌으므로 함께 찾는다.
4. 천과 소리를 따라 리안에게 도달한다. 서로를 찾은 두 사람은 자신들을 도운 주인공이 위험한 길을 혼자 가게 두지 않는다.
5. 길의 큰 자국을 따라가던 일행이 묘령과 만난다. 같은 얼굴에게 공격받았다는 경험 때문에 묘령이 방어적으로 반응한다.
6. 충돌이 멎고 주인공이 추격하지 않는 행동을 보자 묘령은 확신을 보류한다. 함께 목격 장소를 확인한다.
7. 신전으로 가는 길의 수호자를 넘어 큰 흔적의 물리적인 주인을 확인한다. 닮은 사람의 문제는 아직 남는다.
8. 신전에서 실제 같은 얼굴을 마주한다. 함께 온 동료들은 이제 주인공 곁에 선다.
9. 승리 후 귀로에서 일행이 서로를 기다린다. 마을에서는 도움받은 사람만 각자의 생활 변화로 반응한다.

## 5 장면별 실행 명세

### S00 새 게임과 도착

진입: 타이틀에서 새 게임 확정. 출구: 선택한 인물로 Z00의 안전한 지면에서 조작 가능.

제작 순서: 선택 정의·모델·초상/삽화 매핑 검증 → 저장 초기화 → 시점 확정 → 짧은 오프닝 → 씬 준비 완료 → 조작 반환. 로딩 중 이야기 완료를 먼저 기록하지 않는다.

보물 소문은 한 번만 제시한다. I01 배경 삽화 뒤 실제 도착 화면으로 이어지며 스킵 시 같은 안전 위치와 목표를 갖는다. 최초 조작까지 목표 30초 이내. P04 도입은 현행 2개 노출 노드(소문 4.3초 → 선택 주인공 삽화와 지역명 2.7초), 합계 7초를 유지한다. 기존 8~12초 제안과 3개 노드·9.6초 테스트 기대는 소문을 반복하는 독백을 복원하지 않도록 이 계약으로 대체한다. 상위 요약은 신전이라는 방문 목적, 첫 목표는 안내인과 대화라는 즉시 행동을 맡는다. 로딩 시간과 연출 시간을 별도로 측정하며 실제 최초 조작 시간은 아직 미검증이다.

배치: 주인공 정면에 길의 곡선과 마을 지붕이 보이고 가까운 전투는 없다. 조작을 설명하는 주민 대사는 없다. 이동·시점 안내는 기존 입력 가이드로 순차 표시한다.

실패: 선택 모델이 없으면 다른 주인공으로 조용히 시작하지 않는다. 두 경로의 누락을 출하 전 검사에서 막는다. 현재 런타임 폴백 동작을 정상 출시 흐름으로 인정하지 않는다.

### S01 마을에서 방향을 정한다

진입: Z01. 필수 만남은 안내인 1명뿐이다. 주인공이 먼저 방문 이유를 말한 뒤 안내인이 반응한다.

행동: 안내인은 손에 든 짐을 내려놓고 방문자를 본다. 위험 고지 후 주인공이 가겠다고 하면 숲 출구 쪽으로 몸을 돌린다. 시선과 실제 길이 일치해야 한다.

예시: 주인공 '보물 얘기를 듣고 왔어요.' / 안내인 '신전으로 가시려고요? 숲에 괴물이 내려왔어요.' 이후 방문 의사와 길 안내만 짧게 교환한다. 현재 원고의 필요한 관계 표현을 유지하며 모든 주민에게 같은 대화를 복사하지 않는다.

출구: 안내인 대화 정상 종료로 Q01 완료, Q02 자동 인계. 대화를 취소하면 완료되지 않으며 재대화 가능. 조안·상인·미아·헤이즐은 선택 접근이다.

선행 방문: 안내 전에 숲에 들어가도 수색·전투에서 얻은 사실은 버리지 않는다. Quest 공개 순서와 도메인 진행 기록을 분리한다. 자동 추적 목표는 지금 가능한 단계로 맞춘다.

### S02 경계 밖 첫 전투와 표식

진입: 마을 생활권을 벗어나 굽은 길 통과. E00 기본 적 1체가 먼저 읽힌다. 첫 입력 학습은 기본 공격·회피 두 행동으로 한정한다.

전투 후 천 표식은 가지에 묶인 매듭·끊긴 끝·발자국으로 읽힌다. 붉은 수목 배경에 빨간 천만 두지 않고 밝은 천 가장자리, 인공적인 매듭 형태, 접근 조명을 함께 쓴다. 색각에 의존하지 않는다.

표식 조사 → 멀리서 화린의 전투음 → 시야가 열리는 순서다. 조사를 건너뛰고 화린에게 닿으면 조우를 허용하고 목표의 관찰 부분을 발견 사실에 맞게 정리한다. 삽화로 화면을 덮지 않는다.

### S03 화린과 공동 전투

진입: Z02 조우 활성 범위. 최초 시야 전에 참가자를 준비하되 마을 입구에서 전투가 계속 진행되지는 않는다. E01은 주인공이 화린의 전투에 끼어드는 형태다.

전투 공간: 화린은 출구를 등지고 2체와 싸우며, 주인공 진입 방향은 30~60도 측면이다. 아군 락온·아군 피해가 없고 전투 종료에 플레이어의 마지막 타격을 강제하지 않는다. 임시 아군의 실패·회복은 기존 조우 계약을 따른다.

전투 후: 화린은 숲 안쪽을 먼저 확인한다. 부상 확인 → 리안 수색 부탁 → 동의 → 이름과 말 놓기 순으로 짧게 끝낸다. 말 놓기 전 주인공은 해요체다. 예시: '다친 데는 없어요?' / 화린 '응. 그런데 같이 있던 애가 안 보여.'

출구: 필수 대화 정상 종료 후 영입을 확정한다. 별도의 두 번째 합류 대화를 요구하지 않는다. 해금 알림은 감정 장면이 끝난 뒤 한 번만. 5~10m 앞 안전 공간에서 교체를 안내한다. 교체 성공을 메인 진행 필수 조건으로 삼지 않는다.

### S04 리안을 찾고 재회한다

진입: Q03 공개, Z03. 경로에는 천 2개 이하와 끊긴 짐 흔적을 둔다. 단서마다 화면을 멈추지 않는다.

E02는 화린 조우의 복제가 아니다. 리안은 넘어진 수레의 열린 쪽을 지키며 근접 2체·원거리 1체에 대응한다. 플레이어는 원거리 적의 측면으로 접근하거나 수레를 엄폐물로 쓴다. 방어 대상의 제한 시간이나 별도 호위 UI는 추가하지 않는다.

종료 직후 먼저 화린과 리안의 안부를 교환한다. 주인공에게 감사하는 동안 새 자국 설명을 끼우지 않는다. 5~8초 무언 행동 또는 짧은 이동의 여백을 준다. 리안의 초면 해요체와 동행 뒤 말 놓기를 구분한다.

리안은 자신을 도와준 사람을 혼자 보내지 않겠다는 의사로 동행한다. '내 전문 기술이 없으면 길을 못 간다'는 신규 능력 잠금을 만들지 않는다. 합류 후 큰 자국은 다음 이동 중 발견한다.

출구: 정상 종료 후 리안 영입. 자국을 미리 확인했으면 다시 클릭시키지 않고 Q04의 현재 단계에 반영한다.

### S05 묘령의 오인과 충돌

진입: Z04. 정면에서 얼굴을 확인할 수 있는 거리와 후퇴 공간을 먼저 확보한다. 부상을 감싸는 기존 모션·3~5개 발화·짧은 충돌을 사용한다.

묘령은 공격당한 기억 때문에 경계한다. 대화에서 평화 선택을 받아 놓고 무시하는 연출을 만들지 않는다. 최초 연출 공격으로 회피 불가능 피해를 주지 않으며, 조작 반환 뒤 예고가 있는 공격부터 시작한다.

기존 구현 기록의 12초 충돌·정지 경로를 기준으로 실제 런타임을 재확인한다. HP 0이나 패배를 오해 해소의 증거로 쓰지 않는다. 일행은 추격을 멈추고 거리를 내주며 묘령은 목격을 다시 확인하러 동행한다.

예시: 주인공 '더 가까이 안 갈게요.' / 묘령 '…그 사람은 멈추지 않았어.' 말의 내용보다 공격 중단·거리 확보가 먼저 보인다.

출구: 화해 정상 종료 후 묘령 영입, 신전 목표를 다시 메인 추적으로 올린다. 선택 의뢰가 이를 가리지 않는다. 스킵 시에도 같은 영입·목표 결과를 적용한다. 경고 취소·전투 저장·화해 취소를 별도 복구한다.

### S06 호수 조망과 마지막 준비

진입: Z05. 숲이 열리며 호수와 신전 방향의 지형을 확인한다. 카메라는 강제 180도 회전을 하지 않고 2~3초 이내의 가벼운 유도만 검토한다. 락온 중이나 전투 중에는 조망 연출을 시작하지 않는다.

이곳에서 파티 편성·기존 휴식을 이용할 수 있다. 장비·제작·속성·궁극기를 동시에 강의하지 않는다. 휴식 이용은 선택이며, 이후 보스 패배 시 되돌아올 수 있는 안전 공간을 둔다.

호수 섬으로 내려가는 길은 탐험 가능하다. 신전 사건은 진행 상태로 복구 가능하게 제어한다. 동료가 없는데 있다고 가정한 대화는 재생하지 않는다.

### S07 수호자와 신전 접근

진입: Z06, E04. 큰 발자국과 쓰러진 나무의 크기를 수호자 모델과 맞춘다. 수호자는 신전 이상에 반응한 위협이며 보물의 원흉으로 단정하지 않는다.

전투: 넓은 공터, 진입 측 안전 공간, 회피 경로 2개 이상. 전투 중 천장·문기둥 카메라 압박 없음. 처치 뒤 회복과 탐색의 여유를 주고 즉시 다음 보스를 연속 호출하지 않는다.

출구: 수호자 처치 기록 후 신전 접근. 북쪽 우회로로 먼저 도달한 플레이어에게도 '수호자와 싸웠다'는 대사를 거짓으로 재생하지 않는다. 관문 조건과 돌아갈 현재 목표를 현장에서 안내한다. 제단의 필수 장면은 조건 충족 후 상호작용으로 시작한다.

### S08 신전 공개와 닮은 상대

진입: 필수 영입·수호자·신전 단계 충족. 제단 조사 전 실루엣으로 얼굴을 여러 번 스포일러하지 않는다.

공개: 기존 실시간 얼굴 클로즈업을 우선한다. 활성 캐릭터를 바꾸었어도 원래 시점 인물의 얼굴·목소리·분신을 사용한다. 장면용 시점 전환이 있으면 기존 presentation lease의 복구 경계를 유지한다.

준비 → 얼굴 공개 정상 완료 → 적대 전투 해제의 순서를 지킨다. 공개 취소는 전투를 시작하지 않으며 재접근 시 공개부터 재개한다. 잘못된 Arin/SeolA 외형 폴백을 허용하지 않는다. 기존 BossAlternateSelfNenmir ID는 저장 호환 이름이며 현재 외형은 연결 자산으로 판정한다.

E05 승리 후 닮은 상대의 정체를 세계관 강의로 해명하지 않는다. 묘령은 오인이었음을 행동으로 받아들이고 일행은 주인공 곁에서 기다린다.

### S09 귀로와 장 완료

진입: alternate_self_defeated가 참. 임의 전투 종료 위치에서 장거리 걷기 연출을 하지 않는다. 검증된 신전 앞 귀로 지점으로 플레이어가 직접 돌아오게 한다.

귀로의 일행은 안전한 바닥에 대기하고, 주인공이 다가오면 앞서 몇 걸음 걸으며 속도를 맞춘다. 장면 이동은 NavMesh·KCC·충돌을 확인한 짧은 구간만 쓴다.

정상 종료 또는 명시적 스킵에서만 chapter1_completed와 최종 Quest 완료를 확정한다. 취소는 다시 접근할 수 있게 한다. 이미 장 완료된 기존 세이브에 새 귀로 의무를 추가하지 않는다.

### S10 마을 후일담

장 완료의 필수 조건이 아닌 선택 귀환이다. '전원에게 보고하기'를 만들지 않는다. 준 구출 시 미아와 준이 같은 곳에 있고, 약초 전달 시 헤이즐이 약을 챙긴다. 돕지 않은 사건을 해결된 모습으로 바꾸지 않는다.

마을 전체의 괴물 위협이 영구 소멸했다고 선언하지 않는다. 신전 사건과 각 주민의 실제 진행만 반영한다. 새 동료는 영구 필드 AI를 만들지 않고 정해진 대화 연출 또는 편성 화면으로 확인한다.

## 7 퀘스트 및 영입 연결

| 기획 키 | 기존 Quest ID | 표시 목표의 순차 흐름 | 완료 권위 |
|---|---|---|---|
| Q01 | quest_sub_lake_missing_villagers | 신전으로 가는 길 묻기 | 안내 대화 정상 종료 |
| Q02 | quest_sub_lake_rescue_hwarin | 천이 묶인 곳 살펴보기 → 싸우는 사람 돕기 | 화린 영입 커밋 |
| Q03 | quest_sub_lake_rescue_lian | 화린과 리안 찾기 → 함께 길 정리하기 | 리안 영입 커밋 |
| Q04 | quest_sub_lake_follow_tracks | 큰 자국 따라가기 → 앞에 있는 사람 만나기 | 묘령 영입 커밋 |
| Q05 | quest_main_lake_shrine | 신전으로 가기 → 앞을 막은 상대와 싸우기 → 안으로 들어가기 → 돌아가는 길로 나가기 | 종료 연출 정상 완료 |

기존 Objective·StoryEvent·Flow ID는 실제 에셋에서 추출해 이동 대상과 함께 대조한다. 이름을 예쁘게 바꾸려고 저장 ID를 교체하지 않는다. 중간 Quest 제목·알림은 기존 하나의 큰 이야기 표현을 유지하되 실제 목표가 갱신됨을 확인한다.

선택 의뢰: 미아·준은 남겨진 짐보다 사람을 선택하는 귀환, 헤이즐은 약초 3개와 약 준비, 페니는 등불 3곳의 상태 조사, 모건은 수레와 사람이 이동한 흔적 확인이다. 네 의뢰 모두 메인 선행 조건에서 제외한다. 정확한 ID는 P00의 QuestDatabase 추출표를 권위로 삼으며 오래된 문서의 별칭을 새 ID로 생성하지 않는다.

## 8 역순 진행과 복구 표

| 상황 | 필요한 처리 |
|---|---|
| 안내인보다 화린을 먼저 만남 | 전투 사실을 보존. 안내 대화가 합류를 초기화하지 않음 |
| 화린보다 리안을 먼저 발견 | 고립 상태의 짧은 반응 또는 조우 대기. 화린 대역을 임의 생성하지 않음. 메인에서 현재 가능한 만남 안내 |
| 이전 전투를 미리 처리 | 처치 기록을 조회하여 완료 신호 누락 때문에 대기하지 않음 |
| 묘령·신전 먼저 접근 | 안전한 접근 가능, 아직 없는 동료의 대화와 최종 전투는 보류. 현재 할 일 안내 |
| 로드 시 이미 볼륨 내부 | Enter 이벤트만 기다리지 않고 현재 위치·저장 단계로 재평가 |
| 영입 대화 취소 | CombatResolved 유지, RecruitmentCommitted 미설정, 대화 재시도 |
| 영입 저장 직후 알림 전 종료 | Roster 확인으로 중복 해금·보상 방지, 알림은 필요 시 재표시만 |
| Roster에 이미 해당 동료 있음 | 출전 편입 bool이 false여도 실패로 보지 않음. 도메인 영입 결과와 보유 상태 확인 |
| 준·등불·약초를 수락 전에 발견 | 의미 있는 획득·사실은 보존하거나 재상호작용 가능. 영구 소진으로 진행 막지 않음 |
| 퀘스트 재료를 소비·판매 | 기존 보호 정책 적용. 없으면 비소모 조사 목표 또는 재획득처를 설계하고 검증 |
| 보스 전투 중 저장 | 이미 완료된 앞 단계 유지, 해당 전투 안전 시작점에서 복구 |
| 최종 보스 뒤 저장·취소 | 보스는 부활하지 않고 귀로 대화·종료만 재개 |
| 마을 귀환 후 로드 | 완료한 선택 의뢰만 NPC 위치·소품 변화 복원 |

## 9 인물과 다음 단계 경계

주요 인물의 자리·충돌·이동·기억은 03에 정의한다. 퀘스트 영입을 죽은 적의 자동 해금과 섞지 않는다. BossAssist도 별도 경로다. 본편의 새로운 영입을 추가할 때는 만남→함께 한 행동→개인적 합류 결정→정상 종료 커밋→다음 플레이에서 사용할 이유를 모두 채운다.

제2장 미스터리의 답은 이번 제작 범위 밖이다. 외곽의 선택 적을 처치했다는 이유만으로 이름 있는 동료가 지급되는 콘텐츠는 본편 배치에서 제거하고, 해당 인물의 후속 영입 사건이 만들어질 때 연결한다.

## 10 구현 완료 조건

S00~S10을 두 시작 경로로 확인한다. 파티 교체 후에도 시점·화자·분신이 맞아야 한다. 장면별 정상·스킵·취소·저장·재진입을 구분하고, 대화 성공을 액터의 실제 이동 성공이나 전투 감각 합격으로 대체하지 않는다. 장면 책임자는 07의 T01~T18에 결과와 증거 경로를 남긴다.
