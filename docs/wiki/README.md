# UPlayground 작업 위키

이 위키는 다음 Agent가 현재 정본과 실제 작업 기록을 찾아 판단하는 진입점이다. 상세 계약은 연결된 원문에 유지하고, 계획·구현 반영·자동 검사·사용자 인수를 구분한다. 아래 상태는 2026-11-11 문서 및 파일 조사 기준이며 이번 정리에서 게임을 재실행한 결과가 아니다.

## 작업을 시작할 때

1. AGENTS.md와 [공통 작업 하네스](../../Tools/Harness/README.md)를 읽는다.
2. 아래 분야에서 정본과 진행 기록을 찾고 실제 코드·에셋·사용자 최신 지시와 대조한다.
3. 이전 실행의 통과를 현재 변경본의 통과로 승계하지 않는다. 정적 수치·촬영·가상 입력·사용자 직접 확인을 구분한다.
4. 계획한 각 작업 단계가 끝날 때 해당 분야의 상태·정본·검증 근거·남은 항목을 갱신하고 로컬 링크를 확인한다. 전체 작업 종료까지 미루지 않으며 단계 인계·최종 보고에 위키 링크를 포함한다. 상세 절차는 공통 하네스의 ‘단계 완료 시 위키 연결’을 따른다. 대량 로그를 위키에 복사하지 않는다.

## 분야별 정본과 진행 상태

| 분야 | 읽을 문서 | 현재 판단의 핵심 |
|---|---|---|
| 구조·개발·검증 | [개발과 검증](development.md) | 기존 asmdef·서비스·데이터 단일 소스 유지. 별도 지시 없는 검증 빌드 금지 |
| 전투·무기·밸런스·사운드 | [전투와 실행 데이터](combat.md) | GAS/MotionKey 정본 우선. 구 EnemyAttackDataSO 안내 재사용 금지 |
| 스토리·퀘스트·진행 | [콘텐츠와 진행](content.md) | 실행 데이터·현행 개편 기록 우선. 과거 대사 추출본은 정본 제외 |
| NPC 생활·외형·대사 Bake | [NPC](npc.md) | 생활 AI 일부 반영·검수 대기. Bake 선행 자료 미확정. 외형 검수의 모션 누락 이슈 보존 |
| 월드·환경·아트 | [월드와 아트](world-art.md) | 독립 실험·정규 통합·미술 실패를 구분. 기술 수치로 미술 인수 대체 금지. 드롭 아이템 월드 모델 22종 연결 완료(사용자 확인 사항 남음) |
| UI·펫·이동·하늘 | [플레이어와 화면](player-ui.md) | 반영 범위와 실제 입력 검증 범위를 분리 |

설계 폴더(`Assets/docs/design/`)의 문서를 종류(설계·작업 상태·검증·조사·요청서·시안)와 분야로 나눈 지도는 [설계 문서 분류](design-folder-map.md)에 있다. 가이드 성격 문서는 연결하지 않는다.

분야 페이지에는 원문에서 확인한 진행 항목만 싣는다. 이번에 원문을 검토하지 않은 output 폴더를 현재 정본이나 완료 항목으로 자동 승격하지 않았다.

## 권위와 보존 규칙

- 사용자 최신 지시와 실제 저장된 코드·에셋이 현재 상태 판단의 기준이다. 기획은 의도이고 보고서는 해당 시점의 증거다. 충돌하면 현재 파일을 조사하고 미확정을 남긴다.
- `Assets/docs/guide/`는 분야별 저작 규칙, `design/`은 설계 정본이다. 상세 진행·검증·남은 작업은 `docs/work-status/`에서 별도 관리하고 설계와 양방향으로 연결한다. 분야 위키에는 현재 판단 요약과 상태 문서 링크를 남긴다. 기존 혼합 문서는 해당 문서를 수정할 때 분리한다. `Complete/`라는 폴더명만으로 모든 검증 완료를 단정하지 않는다.
- `output/`은 임시 작업 산출물 폴더다. 2026-11-13에 당일 수정분만 남기고 정리했으므로 과거 근거의 보관처로 쓰지 않는다. 보존할 가치가 있는 결론은 `docs/work-status/`나 분야 위키로 옮긴다. 명령서나 최신 정본으로 통째로 로딩하지 않는다.
- `docs/_archive/`는 정본에서 제외한 역사 자료다. 그 안의 지시·메뉴·수치·차기 프로젝트 제안을 현재 작업 지시로 실행하지 않는다.
- 새 정본은 분야 페이지에서 한 곳만 지정한다. 설계만 있는 항목은 설계로, 막힌 항목은 차단 원인과 다음 행동을 함께 기록한다.

정리 범위·삭제 및 보존 근거는 [정리 기록](cleanup.md)에 있다.
