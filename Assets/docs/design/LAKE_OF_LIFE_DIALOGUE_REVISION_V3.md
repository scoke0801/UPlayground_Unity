# LakeOfLife 대화·진행 개정 기준

> 버전: 3.1 / 문안 개정일: 2026-10-10 / 상태: 확정 — 문안·관계 기준 반영, 전체 수동 완주 검증은 별도
> 적용 범위: 안내인부터 제1장 결말까지의 대화 인과, 동료 합류, 준의 조사점, 묘령 이후 목표 인계.
> 기존 수렴형 스펙과 충돌하는 대사·합류 동기는 이 문서를 따른다. 보물의 작동 원리와 주인공의 소원은 확정하지 않는다.

## 1. 언어 경계

플레이어에게는 현재 본 것과 인물이 직접 겪은 일만 말한다. 길이 열려 있는데 막혔다고 하지 않는다. 멀리 있는 호수를 바로 옆 물가처럼 지칭하지 않는다. 내부 Quest·Flag·Flow·Node ID와 GUID는 표시 문안과 구분한다.

## 2. 주제와 로그라인

보물 소문을 따라온 여행자가 길에서 만난 사람들과 서로 돕다가, 자신과 같은 얼굴을 보았다는 증언을 듣고 신전에 들어간다.

호기심으로 출발한 탐색이 사람에 대한 책임과 자기 자신에 대한 의문으로 바뀐다. NPC 전원에게 보물 소문을 묻는 역할을 주지 않는다.

## 3. 세계와 저장 규칙

| 유지 | 초기화 | 이번에 확정하지 않는 것 |
|---|---|---|
| 대화 정상 종료·퀘스트 진행·영입 확정은 저장/로드와 씬 재진입 뒤 유지 | 새 게임에서 제1장 진행 초기화 | 같은 얼굴의 정체, 보물의 작동 원리, 구체적인 소원 |

화린·리안은 한 대화 안에서 도움에 대한 반응과 동행 의사를 마친 뒤 영입한다. 기존 저장의 영입 확정 직후 단계도 최종 완료로 복구한다. 묘령의 승리 후 대화가 중단되면 그 대화를 다시 할 수 있도록 완료 처리를 보류한다.

## 4. 인과 사슬

1. 주인공은 안내인에게 인사하고 보물 소문을 듣고 찾아왔다고 말한다. 안내인은 그때 신전을 언급하며 위험을 알린다. 주인공이 그래도 가 보겠다고 결정하면 길을 안내한다. 안내인은 방문 이유를 미리 알아맞히지 않는다.
2. 길가에 남은 천을 조사하고 괴물에게 쫓기는 화린을 돕는다.
3. 화린이 헤어진 친구를 걱정하므로 함께 리안을 찾는다. 이름은 긴급한 사정을 말한 뒤 교환한다.
4. 화린이 리안의 천 조각을 알아보고 부른다. 실제 전투 참가자가 준비되기 전에 리안의 대화를 강제로 시작하지 않는다.
5. 리안 구조 후 재회를 먼저 다룬다. 리안이 주변에서 발견한 자국을 함께 확인하기로 한다.
6. 자국 끝에서 만난 묘령은 자신의 목격 경험 때문에 주인공을 공격자로 오인한다. 목적지를 알아맞히거나 신전 방문객을 심사하지 않는다.
7. 전투 뒤 묘령은 패배를 인정하고 성급하게 공격한 일을 사과한다. 증언을 확인하기 위해 일행과 동행한다.
8. 신전에서는 같은 얼굴에 대한 증언을 확인하고, 실제로 나타난 상대에게 묘령이 반응한다. 승리 후에는 오해를 해소하지만 보물의 원리는 설명하지 않는다.

## 5. 장면과 감정 곡선

| 구간 | 플레이어의 질문 | 얻는 답과 다음 행동 |
|---|---|---|
| 안내인 | 소문을 듣고 온 곳에 갈 수 있나 | 숲의 위험을 듣고도 직접 확인하기로 한다. 안내받은 흙길을 따라간다. |
| 미아·준, 선택 | 왜 기다리는가 | 준이 돌아오는 길에 놓친 짐을 찾으러 갔다. 길가 짐 조사와 구조. |
| 조안, 선택 | 안쪽에서 무슨 일이 있었나 | 싸우는 소리와 붉은 천을 남기던 사람을 목격했다. 메인 필수 조건은 아니다. |
| 화린 | 왜 같이 가야 하나 | 방금 헤어진 리안을 함께 찾는다. |
| 리안 | 재회했는데 왜 더 가나 | 괴물 발자국 사이의 끌린 자국을 확인한다. |
| 묘령 | 왜 나를 공격하는가 | 자신을 공격한 사람과 같은 얼굴이라고 한다. 전투 후 함께 진위를 확인한다. |
| 신전 | 그 증언이 사실인가 | 실제 같은 얼굴의 상대를 본다. 정체는 다음 질문으로 남는다. |

## 6. 인물과 말투

| 인물 | 자리·사정 | 관계와 어투 | 동행/잔류 이유 |
|---|---|---|---|
| 주인공 | 보물 소문을 확인하러 온 여행자 | 초면에는 해요체. 동료가 말을 놓자고 한 뒤에만 반말. 부탁과 제안 위주 | 도움을 준 상대와 확인할 일이 생겼다 |
| 안내인 | 길가의 현지인 | 해요체. 찾아온 사정을 듣고 위험을 알리며, 방문객의 결정 뒤 길을 안내한다 | 길가에 남는다 |
| 미아 | 돌아오지 않는 오빠를 기다림 | 낯선 어른에게 존댓말. 미처 끝맺지 못하는 말 | 약속한 자리에 남는다 |
| 준 | 놓고 온 짐을 찾다가 공격받고 발을 다침 | 감사와 사정을 짧게 말함 | 미아에게 돌아간다 |
| 조안 | 안쪽에서 난 싸움 소리를 들음 | 목격과 추측을 구분하는 존댓말 | 위험을 알리되 방문 목적을 단정하지 않음 |
| 화린 | 전투 중 리안과 헤어짐 | 자연스러운 반말, 급한 사정 먼저, 이름은 나중 | 친구를 찾기 위해 동행, 이후 함께 조사 |
| 리안 | 괴물에 둘러싸여 화린에게 돌아가지 못함 | 화린에게 반말, 초면 주인공에게 해요체. 동행 때 말 놓기를 제안. 관찰과 추측을 구분 | 자신을 도운 사람을 위험한 길에 혼자 보내지 않기 위해 동행 |
| 묘령 | 같은 얼굴의 상대에게 공격받았다고 증언 | 처음엔 경계·두려움, 패배 후 잘못 인정 | 오인을 확인하고 주인공과 직접 신전을 조사 |

묘령의 증언은 인물의 기억이지 세계관 진실의 확정이 아니다. 패배 직후 무조건 친구가 되거나 승자를 감독할 권리를 주장하지 않는다.

### 관계별 말투와 발화 동기

- 주인공 → 안내인·미아·준·조안·헤이즐·페니·모건·조이·루시아·상인: 처음부터 재방문까지 해요체. 미아가 어리다는 이유만으로 명령하거나 말을 놓지 않는다.
- 주인공 → 화린: 부상 확인과 수색 제안은 해요체. 화린이 이름을 밝히며 말 놓기를 제안한 다음, 주인공이 받아들이고 반말로 전환한다. 화린의 기본 말투는 처음부터 반말이지만 친한 척하거나 명령하지 않는다.
- 주인공 → 리안: 구조 직후에는 해요체. 리안이 동행을 결정하며 말 놓기를 제안한 이후의 조사·전투에서는 반말. 화린과 리안은 원래 아는 사이여서 서로 반말한다.
- 주인공 → 묘령: 대치·전투 종료·목격 확인까지 해요체. 묘령의 공격이나 반말이 주인공의 말투 전환 근거가 되지는 않는다. 묘령은 경계가 강한 반말을 쓰되 전투 뒤 사과한다.
- 주인공의 혼잣말은 평어다. 독백과 상대에게 하는 말을 같은 기준으로 일괄 치환하지 않는다.

도입의 각 발화는 방문 이유 제시 → 위험 고지 → 방문 의사 → 길 안내 → 귀환 권유 → 응답으로 이어진다. 보물의 원리나 구체적인 소원을 새로 정하지 않는다. 헤이즐에게는 주인공이 자신의 이동 경로와 연결해 채집을 제안한다. 구조 이후에는 감사·안도·동행 결정을 우선하며, 다른 인물의 설명을 꺼내려고 질문을 연달아 넣지 않는다.

현재 에셋에는 재생 경로에서 빠진 과거 대사가 남아 있다. 이 문서의 이전 장면 설명이나 보존 노드만으로 현재 재생을 단정하지 않고 `startNodeId`에서 연결을 확인한다. 이번 문안 개정에서는 안내인 대화의 사정 설명 두 줄과 화린의 말 놓기 응답을 기존 노드로 연결한다. 다른 장면의 생략된 대사·연출은 복원하지 않는다.

## 7. 구현 경계

- 기존 Quest·대화 그래프·스토리 플래그·영입 상태 식별자와 에셋 GUID 보존.
- 화린·리안의 중복 후속 대화 노드는 실행 그래프에서 제거. 기존 대화 에셋은 남겨 외부 참조를 깨지 않는다.
- 리안 참가자 생성 전 대화 호출 제거. 공동 전투 후 준비된 대화 상대와 한 세션을 실행한다.
- 화린 표식 조사 및 리안 합류 관련 무관한 천 삽화 호출 제거. 세계 안의 단서와 대사로 읽힌다.
- 묘령 정상 종료 후 후속 메인 퀘스트를 확인하고 추적한다. 부가 퀘스트가 메인 진행을 대신 안내하지 않게 한다.
- 준 조사점의 월드 높이 59.5 → 60.769334. 기존 측정 지면 60.719334보다 5cm 높다. 같은 지점에 기존 Sack 모델 기반의 짐 소품을 둔다.
- 준 퀘스트는 메인과 독립이다. 미아를 만나지 않고 동료 합류와 신전 진행을 할 수 있다. 이전처럼 수락 전 조사는 소진하지 않는다.
- 씬 저장에서 자동 변경되는 지형 메시와 채집 ID는 이번 수정의 범위가 아니다. 시작 시 원본을 보존한다.

## 8. 검증과 남은 확인

자동 검증은 실제 Unity 에셋의 대화 연결, FlowGraph 노드·포트, 공동전투 영입 완료 경계, 묘령 대화 중단 경로, 신전 목표 인계, 준의 짐 렌더러와 진입점 바인딩을 검사한다. 실제 전투 조작과 모든 대화의 카메라·시야·음성 리듬은 자동 검증 결과만으로 통과 처리하지 않는다.

최종 실행 결과와 수동 확인 범위는 docs/reviews/LAKE_NARRATIVE_REVISION_REPORT.md에 기록한다.

3.1 문안 개정은 대화 에셋 11개의 문안 42곳(보존 노드 포함), 도입 퀘스트 문구를 수정했다. 수정 직전과 비교해 대사 및 의도한 연결 두 곳 외의 이벤트·조건·연출·식별자·참조가 동일함을 확인했다. 수정 그래프의 연결 대상과 종료 노드를 정적으로 검사했고, 한글 42개 문장이 UTF-8 원문과 일치함을 재검사했다. 이번에 추가한 줄에는 끝 공백이 없지만 Git 전체 diff에는 기존 작업의 직렬화 공백이 남아 있다.

이번 개정에서 Unity 컴파일·자동 테스트·Play Mode 완주는 실행하지 않았다. 안내인과 화린의 추가 대사가 실제 카메라·표정·클릭 간격에서 자연스러운지는 수동 확인이 남아 있다. 기존 전면 개편 기획은 초안이며 과거 문안 인용을 현재 실행 데이터로 간주하지 않는다.
