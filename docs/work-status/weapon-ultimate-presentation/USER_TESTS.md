# 궁극기 연출 사용자 테스트

대상: 이번 작업의 Editor 저장 상태. Player/Addressables 빌드는 만들지 않았다. 기존 저장 슬롯은 덮어쓰지 말고, 평소 전투 테스트용 씬/슬롯과 Raon·Hwarin의 궁극기 발동 경로를 사용한다. 실제 입력은 패드와 키보드를 각각 확인한다. 궁극기 에셋이 없는 캐릭터는 테스트 대상에서 제외한다.

결과 회신: `항목 ID / 통과·실패·미수행 / 실제 결과 / 필요 시 화면·영상·Console 로그`. 실패 시 사용 캐릭터·입력 장치·해상도·시작 씬·발동 직전 행동을 알려준다.

| ID | 절차 | 기대 결과/실패 기준 |
|---|---|---|
| U01 외형 | Raon/Hwarin 궁극기를 각각 발동, 얼굴의 헤어·눈·장신구·의상 확인 | 현재 모델과 맞고 2종의 선·조명·채색이 일관됨. Hwarin은 밝은 피부·흑발·붉은 끝머리 계통. 최종 미술 승인은 사용자 판단 |
| U02 배치 | 1920×1080과 2560×1080(또는 보유한16:9/21:9)에서 반복 | 왼쪽 약20% 폭/높이45~65% 부근의 짧은 반투명 패널. 얼굴이 패널 위아래로 자연스럽게 넘치고 눈/뿔/머리/턱이 부자연스럽게 잘리지 않음. 중앙 적HP·데미지·전투 시야를 가리면 실패 |
| U03 시간 | Raon 기존0.2배속 구간과 정상 속도에서 패널 관찰 | UI 등장/유지/퇴장은 실시간으로 부드럽고 얼굴이 약간 늦게 따라옴. 유지 끝 직전 속성색 플래시. 전투 타격/기존 슬로모션 시점은 변경 전과 같음 |
| U04 HUD/T2 | Raon hideHud, Hwarin Stage가 활성인 궁극기 발동 | HUD가 숨겨져도 얼굴은 표시. Stage 카메라 전환 중 패널이 사라지거나 세계 좌표로 이동하지 않음 |
| U05 교체 | 가능한 빠르게 캐릭터 교체/어시스트/연속 궁극기 발동 | 패널은 항상 하나. 이전 시퀀스 종료가 최신 얼굴을 갑자기 지우지 않음 |
| U06 정리 | 표시 중 pause 열기/닫기, 시전자 사망, 씬 전환을 각각 재현 | pause 진입 때 얼굴만 닫힘. 재개 후 다시 나타나지 않음. 사망/중단/씬 전환 뒤 패널과 트윈 잔존 없음. 궁극기 외 전투 동작을 임의로 중단하지 않음 |
| U07 입력 | 표시 중 이동/카메라 입력이 허용된 상태 확인, pause에서 패드 Navigate/Cancel | 표시 패널은 포커스·마우스·패드 입력을 가져가지 않음. 기존 궁극기 입력 잠금 정책 유지, pause 탈출 정상 |
| U08 무게감 | Raon Katana/Hwarin DoubleAxe의 피니시를 반복 | Katana는 짧고 절제된 여운, DoubleAxe는 더 무거운 흔들림. 멀미·불필요한 대기·반복 피로가 있으면 조정 요청 |
| U09 카메라 | 구도 실패 화면과 같은 장소·캐릭터로 궁극기 재발동 | 자동 생성 Snapshot은 실행하지 않고 기존 모션/Stage 카메라를 사용. 상체가 위로 잘리거나 카메라가 발·바닥으로 접히지 않음. 얼굴/타격/슬로모션 유지. [복구 기록](CAMERA_FRAMING_FIX.md) 참고 |
| U10 모션 후보 | [P4 후보표](MOTION_REUSE_REVIEW.md)의 클립을 실제 대상 모델/무기로 재생 | GreatSword 차지/슬램, Katana 칼집 접촉·수납·정지, Staff 영창 유지, Bow 활시위/화살, Whip 무기 본 궤적을 확인. 불가능한 조합만 신규 제작으로 확정 |

Sword/GreatSword 및 나머지 보유하지 않은 궁극기의 프로필 생성 검사와 실제 플레이 체감은 구분한다. 스킬·궁극기 에셋 없는 캐릭터의 플레이를 확인했다고 보고하지 않는다. 새 얼굴10종은 스타일 승인 전 생성하지 않는다. Whip 접촉 속박/던지기(T3)는 사용자 채택 결정 전 구현하지 않는다.
