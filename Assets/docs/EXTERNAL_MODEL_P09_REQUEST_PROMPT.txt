[제작 요구]
1. 외부 모델은 리깅·토폴로지·UV·표정의 제작 기반이다. 원본 얼굴에 옷만 바꿔 새 캐릭터라고 제출하지 마.
2. ImageGen으로 필요한 얼굴 참고·피부·눈 텍스처를 만들고, Blender에서 눈·눈썹·코·입·볼·턱선을 실제로 새로 조형해. 생성 이미지를 게임 적용 결과로 대체하지 마.
3. 기본은 새 얼굴 + P09 바디·스켈레톤 + P09 헤어·의상이다. 원본 바디 유지가 필요한 경우에는 별도 피팅·재웨이트 범위를 먼저 설명하고 진행해.
4. 실제 선택한 P09 베이스의 좌표·본 순서·bindpose·목 경계를 확인해. 다온의 배율·본 개수·재질 슬롯을 다른 모델에 그대로 복사하지 마.
5. 두피 관통, 목 틈, 눈꺼풀 닫힘, 입안, 노멀·탄젠트, 표정 델타와 컬링을 검수해. 두피를 늘려 헤어 틈을 메우지 말고 헤어 부착 위치·폭을 먼저 맞춰. 수정 전 실제 대상 캐릭터·프리셋·얼굴 프로필을 확인하고, Lili의 피팅 수치를 다른 얼굴에 그대로 복사하지 마. 머리·의상·표정은 실제 Unity 렌더로 확인해.
6. P09FaceMeshProfileSO와 CharacterBuildConfig.FaceMeshProfile을 사용해 P09 빌더에서 헤어·의상을 바꿔도 새 얼굴이 유지되도록 연결해. 프로파일은 자동 리타게터가 아니므로 입력 메시를 먼저 맞춰.
7. 기본 구성과 대체 헤어·의상 조합을 검사하고, 미검증 투구·긴 머리·물리 조합을 명시해. Player/Enemy 요청이면 무기·GAS·모션·충돌도 별도 통합·검증해.

[정규 반영 요구]
8. 기존 프리팹 GUID와 외형 외 fileID, ActorDefinition·NpcData·대화·모션·SceneEntityId·위치·회전을 보존해. 정규 캐릭터를 삭제 후 재생성하지 마.
9. 같은 프리팹을 공유하는 다른 NPC·Variant·중첩 프리팹·농장 작업자·스폰 참조를 조사하고, 대상이 아닌 인물의 외형을 보존해.
10. 파일별 백업과 체크섬을 검증한 뒤 정규 프리팹의 외형만 적용하고, 정규 BuildPreset·월드 배치·필요한 초상화를 같은 결과로 맞춰. 씬 override를 일괄 초기화하거나 오래된 제작표 ID로 중복 배치하지 마.
11. 검수본에서 멈추지 말고 정규 반영과 저장 후 재로드 확인까지 진행해. 사용자 수정과 열린 미저장 씬을 보존하고, 별도 요청 없이 커밋하지 마.
