# RiverBasin4km 동부 사막과 발자국

[4km 공간 설계](RIVER_BASIN_WORLD_REBUILD_DESIGN.md#동부-사암-사막) · [제작·검증 상태](../../../../../docs/work-status/river-basin-sand-footprints.md)

## 지형과 동선

- 확장 권역은 동쪽 협곡 아래의 모래 평원, 서쪽 진입 사면, 동쪽 협곡 바닥으로 이어진다. 서쪽 초원은 자갈과 사암을 거쳐 모래로 바뀌며, 북동쪽 급경사에는 기존 절개면이 드러나게 한다. 기존 분지와 돌 아치는 넓어진 권역의 중앙 표지로 활용한다.

- 채석 요새 동쪽의 사암 능선을 조망 기준으로 삼고, 남동쪽 X 3730~3950 / Z 1700~1900의 완만한 분지에서 모래를 처음 밟게 한다. 경사가 급한 북쪽 사면은 사암으로 남기고 그 아래에서 사암이 모래로 풀리게 한다.
- 분지 안쪽에 1~3m 사구와 얕은 바람길을 교차시켜 걸어서 돌아올 수 있게 한다. 서쪽 가장자리는 돌 아치가 진입 방향을 보여 주고, 북동쪽은 사암 절개와 암반으로 시선을 받는다. 안쪽 모래 주행선은 X 3796 / Z 1773에서 X 3830 / Z 1811까지 이어진다. 외곽은 기존 지형 높이로 연속적으로 돌아가고, 요새 부지와 기존 수로 및 타일 경계를 보존한다.
- 모래 레이어는 기존 모래 알베도를 사용한다. 분지 안에서는 경사와 바람길에 따라 모래 비중을 늘리고 사암이 드러나는 사면과 외곽으로 천천히 줄인다.

## 접촉과 렌더링

- 최종 애니메이션 포즈에서 플레이어의 좌우 발마다 마지막 접지 위치를 추적한다. 걷기와 달리기에서는 보폭으로 다음 디딤 후보를 찾고, 출발·정지·공격 전환에서는 발이 들리거나 새 위치로 옮겨졌다가 멎는 순간을 잡는다. 같은 접지 위치에서 발생하는 작은 움직임은 누적 발자국으로 만들지 않는다. 디딤 후보는 실제 지면 조회와 수신 마스크를 통과해야 한다. 다른 액터는 MotionSet 접촉 힌트를 사용한다. 양발 착지는 모터의 접지 전이를 0.23초 보관해 최종 발바닥이 실제 지면에 닿을 때 발자국을 남긴다.
- 등록된 TerrainCollider에 직접 닿고 베이크된 모래 가중치가 0.5 이상인 곳에서만 기록한다. 동일한 마스크를 셰이더에서 사용해 테두리가 사암에 걸친 부분을 감쇠한다.
- 기본은 8m 격자의 3×3 타일, 타일 내부 1024²와 2픽셀 여유를 둔다. Low는 512², Extended는 1024² 5×5다. 눌림 및 테두리는 RG16F에 보관하고, 타일 갱신에는 별도 작업 표면을 사용한다. 20초 반감기의 시간은 게임 시간으로 진행한다. 지형 패스는 가상 높이의 기울기로 기존 노멀을 보정한다.
- 기본 카메라가 타일 갱신을 소유한다. 다른 게임 카메라는 현재 캐시를 읽는다. 원점 이동은 수신면 위치를 기준으로 반대 오프셋을 더해 동일한 논리 타일을 찾는다.
