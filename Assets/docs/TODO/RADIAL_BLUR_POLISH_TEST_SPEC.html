활공 가속 Radial Blur 개선 검증

상태: 사용자 테스트 대기. AI 컴파일·규칙 테스트와 실제 플레이 화면의 속도감 판정을 구분한다.

대상과 준비

Unity 6000.3.21f1 이상, URP PC 렌더러. 평소처럼 Boot에서 플레이를 시작하고 LakeVillageWorld의 평지와 경사로에서 확인한다. 글라이더가 사용 가능한 캐릭터, 충분한 스태미나, 키보드 또는 게임패드를 사용한다. 저장 데이터 변경이나 초기화는 필요 없다. Inspector에서 Assets/10.Datas/Camera/CameraSettings.asset의 ‘활공 가속 가장자리 블러’를 확인한다.

실행 절차와 판정

ID조작기대 결과·실패 기준
RB01나무·집·울타리가 보이는 평지에서 일반 달리기 후 최고 질주를 2초 이상 유지한다.일반 달리기와 최고 질주 모두 Radial Blur가 없어야 한다. 지상에서 블러가 생기면 실패.
RB02비슷한 방향의 경사로를 오르내리며 질주를 유지한다.평지·경사로 모두 지상 질주에는 Radial Blur가 없어야 한다.
RB03글라이더 일반 활공 → 가속 유지 → 가속 해제를 반복한다.가속 중간부터 블러가 올라오고 최고속도에서 주변 풍경의 늘어짐이 분명하다. 착지 지점과 캐릭터가 있는 중앙은 선명하며 바람 궤적은 블러와 함께 과해지지 않게 옅어진다. 속도 차이가 안 읽히거나 착지 판단이 어려우면 실패.
RB04질주 중 정지·벽 접촉, 활공 해제·착지를 각각 확인한다.일반 활공으로 감속하면 빠르게 복귀하고, 활공 해제·착지 시 즉시 정상 화면으로 복귀한다. 벽에 막힌 정지 상태에서 블러가 지속되면 실패.
RB05활공 가속 중 메뉴를 열고 닫거나 대화·카메라 연출로 전환한다.플레이 화면의 블러가 해제되고 메뉴·대화·HUD가 흐려지지 않는다. 복귀 시 이전 최고 강도가 갑자기 남아 있으면 실패.
RB06Inspector에서 enableSpeedRadialBlur를 꺼 비교한 뒤 원래대로 켠다.꺼짐/켜짐의 가장자리 차이가 분명하고 중앙의 시야 손실은 작다. 최종 값은 켜짐으로 복구한다. 멀미나 시야 방해는 별도로 기록한다.
RB07RB01·RB03 실행 중 프레임과 Unity Console을 확인한다.새 예외·렌더 오류가 없어야 한다. 샘플 수가 8→16으로 늘었으므로 효과 활성 시 프레임 저하가 체감되는지도 기록한다. 성능 판정은 아직 미검증이다.

알려진 수정과 미검증 범위

지상 빨리 달리기는 적용 대상에서 제외했다. Radial Blur는 공중 글라이더 가속에만 적용한다. 속도 진입·복귀 기준을 분리하고 지연 경계를 넘는 프레임의 보간 시간을 바로잡았다. 강도·범위·중간 가속 반응을 강화했다. 실제 플레이 시각 품질, 입력 장치별 체감, GPU 비용은 사용자 확인 전까지 검증 완료로 표시하지 않는다. Player·Addressables 빌드는 실행하지 않는다.

결과 회신

항목 ID / 통과·실패·미수행 / 실제 결과 / 첨부 또는 로그 형식으로 남긴다. 실패 시 지상·활공 여부, 평지·경사로 여부, 입력 장치, 가능하면 효과 켜짐·꺼짐 비교 영상과 Console 오류를 함께 전달한다.

웹 조사 기반 방향성 개선

NVIDIA GPU Gems 3의 Motion Blur as a Post-Processing Effect는 화면 속도 방향을 따라 색상을 누적하는 원리를 설명한다. CRYENGINE의 Radial Blur Node는 중심·강도·영역을 분리해서 제어한다. Unity 6.3 Motion Blur 문서는 최대 궤적 제한과 샘플 품질의 비용을 설명한다. 이를 바탕으로 현재 효과에는 카메라 기준 이동 방향, FOV·화면비 보정, 최대 궤적 길이 제한, 원본 쪽 가중 샘플을 적용했다. 픽셀별 깊이·개별 오브젝트 속도를 복원하는 물리 모션 블러가 아닌, 활공 속도감을 위한 화면 흐름 근사다. 지상 질주 제외와 중앙·HUD 보호는 유지한다.

  • CRYENGINE Radial Blur Node
  • Unity 6.3 Motion Blur

RB08: 가속 활공을 유지한 채 카메라를 정면→측면→후면으로 회전한다. 정면은 방사형, 측면은 횡방향, 후면은 반대 방향의 흐름이 나타나야 한다. 모든 방향에서 중앙 캐릭터와 HUD는 선명해야 한다. 측면에서도 계속 중앙 방사형이면 실패다.

RB09: 16:9와 21:9 또는 서로 다른 창 크기에서 같은 활공을 비교한다. 화면비가 달라도 흐름 방향과 체감 궤적 길이가 급변하지 않아야 한다. 가장자리 잔상이 화면을 가로질러 늘어나거나 멈춘 화면처럼 보이면 실패다. GPU 비용은 별도 확인 대기다.
