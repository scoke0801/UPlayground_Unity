# 실시간 통신 모니터 검증

기존 LayaWorker에 /monitor HTML과 /monitor/state 읽기 경로를 추가했다. 기존 v1 계약과 모델 설정·선택 로직은 유지했다. 새 서버·중계·Unity 수정 없음.

전체 자동 테스트 36개 통과. 추가 검사는 인증·원문/토큰 미수집·캐시/409 계측·추론 중 모니터 조회/503 처리를 확인한다. 실제 오프라인 모델 HTTP로 골렘/엔트 각 1건, 캐시 1건, 충돌 1건을 확인했다. 이들은 monitor-local-synthetic-smoke 세션의 합성 검증 기록이며 Windows 통신으로 주장하지 않는다. 원시 검증은 http-checks.json에 보존했다.

실제 브라우저에서 서버 연결 표시, 누적 4건/성공 3건/오류 1건, 행 상세 후보별 확률·usage, 오류 필터와 전체 복귀를 확인했다. JavaScript가 브라우저에서 정상 실행됐다. node 실행기가 설치되어 있지 않아 node --check는 미수행이며 browser 실행 검사로 검증했다.

현재 서버 PID 10968, loopback 8765. 로그 server.log, PID server.pid. 기존 SSH 터널은 재사용 가능하다. 기존 프로세스 9919만 확인 후 재시작했다. 모니터 기록과 기존 중복 캐시는 재시작 때 초기화된다.

응답 준비 단계 계측이며 클라이언트 수신 보장은 아니다. 원시 관측은 수집하지 않고 최근 200개만 메모리에 저장한다. 기본은 무파일 계측이며 사용자가 화면에서 JSON을 내려받을 수 있다. Windows 실제 요청과 Unity 전투는 이번 모니터 검증에서 미수행이다.

Git 전달용 사본이다. monitor-saved.html은 저장 시점의 합성 검증 기록 4건을 포함하는 독립 HTML이며 자동 갱신하지 않는다. 실시간 모니터는 실행 중인 서버의 /monitor를 사용한다. PID·실행 상태는 검증 시점 기록이다.
