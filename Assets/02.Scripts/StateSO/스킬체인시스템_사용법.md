# 스킬 체인 시스템 사용 가이드

## 📌 개요

입력 키에 따라 다른 스킬로 분기되는 트리 구조의 스킬 체인 시스템입니다.

```
시작 스킬 (2001)
├─ X 입력 → 스킬 2002
│  ├─ X 입력 → 스킬 2003 (종료)
│  └─ Y 입력 → 스킬 2011 → X 입력 → 스킬 2014 (종료)
└─ Y 입력 → 스킬 2010
   ├─ X 입력 → 스킬 2012 (종료)
   └─ Y 입력 → 스킬 2013 (종료)
```

## 🎮 특징

- **다양한 분기**: X, Y 키 입력에 따라 다른 스킬로 연계
- **입력 윈도우**: 특정 타이밍 내에서만 입력 감지
- **자유로운 조합**: X→X→X, X→Y→X, Y→Y→X 등 무한 조합
- **Json 기반 관리**: 코드 수정 없이 데이터만으로 스킬 트리 구성

## 📝 1. Json 데이터 작성

### 파일 위치
`Assets/10.Datas/Json/SkillChainData.json`

### 기본 구조
```json
{
  "chains": [
    {
      "currentSkillID": 2001,
      "branches": [
        {
          "inputKey": "X",
          "nextSkillID": 2002,
          "description": "연속 공격"
        },
        {
          "inputKey": "Y",
          "nextSkillID": 2010,
          "description": "상승 공격"
        }
      ],
      "inputWindowStart": 0.5,
      "inputWindowEnd": 0.9
    }
  ]
}
```

### 필드 설명

#### SkillChainData
- **currentSkillID**: 현재 스킬 ID
- **branches**: 가능한 분기 목록 (빈 배열이면 체인 종료)
- **inputWindowStart**: 입력 받기 시작 시점 (0~1, 애니메이션 진행률)
- **inputWindowEnd**: 입력 받기 종료 시점 (0~1)

#### SkillChainBranch
- **inputKey**: 입력 키 ("X", "Y", "A", "B" 등)
- **nextSkillID**: 다음에 실행될 스킬 ID
- **description**: 설명 (디버그/UI용, 옵션)

### 체인 종료 표시
```json
{
  "currentSkillID": 2003,
  "branches": [],  // 빈 배열 = 체인 종료
  "inputWindowStart": 0.5,
  "inputWindowEnd": 0.9
}
```

## 🗺️ 2. 스킬 트리 설계 예시

### 예시 1: 기본 검 콤보
```
2001 (기본 베기)
├─ X → 2002 (2타)
│  ├─ X → 2003 (3타, 종료)
│  └─ Y → 2011 (회전 베기)
│     └─ X → 2014 (강타 마무리, 종료)
└─ Y → 2010 (상승 베기)
   ├─ X → 2012 (낙하 공격, 종료)
   └─ Y → 2013 (공중 연타, 종료)
```

### 예시 2: 창 콤보
```
3001 (찌르기)
└─ Y → 3002 (연속 찌르기)
   ├─ X → 3003 (강타 찌르기, 종료)
   └─ Y → 3004 (난타, 종료)
```

## 📦 3. 필요한 설정

### 3-1. Addressable 설정
1. `SkillChainData.json` 파일을 Addressable 그룹에 추가
2. Address를 `SkillChainDataTable`로 설정

### 3-2. SkillJsonData 설정
각 스킬은 기존 SkillJsonData에 정의되어 있어야 합니다.

```json
{
  "skills": [
    {
      "skillID": 2001,
      "skillName": "Basic Slash",
      "actionAnimKey": "Attack1",
      "cooldownTime": 0,
      ...
    },
    {
      "skillID": 2002,
      "skillName": "Slash Combo 2",
      "actionAnimKey": "Attack2",
      "cooldownTime": 0,
      ...
    }
  ]
}
```

### 3-3. InputAction 설정
SkillActionStateSO에 InputAction을 연결합니다.

**인스펙터 설정:**
1. `SkillActionStateSO` 에셋 선택
2. **Attack X Action**에 X키 InputAction 연결
3. **Attack Y Action**에 Y키 InputAction 연결

## 💻 4. 코드에서 사용

### PlayerBrain에서 스킬 체인 시작
```csharp
using Game.FSM;
using UnityEngine;

public class PlayerBrain : CharacterBrain
{
    [SerializeField] private SkillActionStateSO skillChainState;
    
    void Update()
    {
        // X키로 스킬 체인 시작
        if (Input.GetKeyDown(KeyCode.X))
        {
            // 시작 스킬 ID 설정
            SetData("CurrentSkillID", 2001);
            ChangeState(skillChainState);
        }
        
        // Y키로 다른 체인 시작
        if (Input.GetKeyDown(KeyCode.Y))
        {
            SetData("CurrentSkillID", 3001);
            ChangeState(skillChainState);
        }
    }
}
```

### InputSystem 사용 시
```csharp
using UnityEngine.InputSystem;

public class PlayerBrain : CharacterBrain
{
    [SerializeField] private SkillActionStateSO skillChainState;
    [SerializeField] private InputActionReference attackXInput;
    [SerializeField] private InputActionReference attackYInput;
    
    void OnEnable()
    {
        attackXInput.action.performed += OnAttackX;
        attackYInput.action.performed += OnAttackY;
    }
    
    void OnDisable()
    {
        attackXInput.action.performed -= OnAttackX;
        attackYInput.action.performed -= OnAttackY;
    }
    
    void OnAttackX(InputAction.CallbackContext context)
    {
        // 대기 상태일 때만 체인 시작
        if (CurrentState == defaultState)
        {
            SetData("CurrentSkillID", 2001);
            ChangeState(skillChainState);
        }
    }
    
    void OnAttackY(InputAction.CallbackContext context)
    {
        if (CurrentState == defaultState)
        {
            SetData("CurrentSkillID", 3001);
            ChangeState(skillChainState);
        }
    }
}
```

## 🔄 5. 체인 진행 과정

### 단계별 흐름
1. **시작**: `SetData("CurrentSkillID", 2001)` + `ChangeState(skillChainState)`
2. **첫 스킬 실행**: 스킬 2001 애니메이션 재생
3. **입력 윈도우 활성화**: 애니메이션 50% 지점 (inputWindowStart)
4. **사용자 입력 감지**: X 또는 Y 입력 대기
5. **다음 스킬 결정**: 
   - X 입력 → 2002로 연계
   - Y 입력 → 2010으로 연계
   - 입력 없음 → 체인 종료
6. **체인 계속**: 2~5 반복

### 블랙보드 데이터
```csharp
// 현재 실행 중인 스킬 ID
int currentSkillID = brain.GetData<int>("CurrentSkillID", 0);

// 입력이 감지되었는지
bool hasInput = brain.GetData<bool>("ChainInputReceived", false);

// 다음에 실행할 스킬 ID
int nextSkillID = brain.GetData<int>("NextSkillID", 0);
```

## 🎯 6. 입력 윈도우 타이밍

### 권장 설정
```json
{
  "inputWindowStart": 0.5,  // 애니메이션 50%부터
  "inputWindowEnd": 0.9     // 애니메이션 90%까지
}
```

### 타이밍 조절 팁
- **빠른 콤보**: 0.3 ~ 0.8 (이른 입력 허용)
- **정확한 타이밍**: 0.6 ~ 0.85 (늦은 입력만 허용)
- **느긋한 연계**: 0.4 ~ 0.95 (긴 입력 윈도우)

### 체인 데이터 확인
```csharp
void Start()
{
    StartCoroutine(CheckChainData());
}

IEnumerator CheckChainData()
{
    yield return new WaitUntil(() => 
        JsonDataManager.Instance.IsDataLoaded<SkillChainData>());
    
    var allChains = JsonDataManager.Instance.GetAllData<SkillChainData>();
    Debug.Log($"로드된 체인 개수: {allChains.Count}");
    
    foreach (var chain in allChains)
    {
        Debug.Log($"스킬 {chain.CurrentSkillID}: {chain.Branches.Length}개 분기");
        foreach (var branch in chain.Branches)
        {
            Debug.Log($"  - {branch.inputKey} → {branch.nextSkillID}");
        }
    }
}
```

## ⚠️ 8. 주의사항

1. **skillID는 고유해야 함**
   - SkillJsonData와 SkillChainData의 ID가 일치해야 합니다

2. **순환 참조 방지**
   - 2001 → 2002 → 2001 같은 무한 루프는 피하세요
   - 최대 체인 길이를 고려하세요

3. **inputKey는 대소문자 구분**
   - "X"와 "x"는 다른 키입니다
   - 통일된 규칙 사용 권장

4. **입력 윈도우 타이밍**
   - 너무 짧으면 입력이 어렵습니다
   - 최소 0.2 이상 권장 (inputWindowEnd - inputWindowStart >= 0.2)

5. **애니메이션 길이 고려**
   - 짧은 애니메이션에 긴 입력 윈도우는 비효율적입니다
   - 애니메이션 길이에 맞춰 윈도우 조정

## 📈 11. 성능 최적화

### 데이터 캐싱
```csharp
private Dictionary<int, SkillChainData> chainCache = new();

SkillChainData GetChainDataCached(int skillID)
{
    if (!chainCache.ContainsKey(skillID))
    {
        chainCache[skillID] = 
            JsonDataManager.Instance.GetData<SkillChainData>(skillID);
    }
    return chainCache[skillID];
}
```

### 입력 최적화
- InputSystem의 performed 콜백 활용
- 불필요한 Update 반복 최소화
- 입력 윈도우 밖에서는 입력 체크 안 함

이제 X→X→X, X→Y→X 같은 자유로운 스킬 체인이 가능합니다!
