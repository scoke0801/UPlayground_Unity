# C 두 주민 교류

## 재개 후 현재 반영

- 나무 충돌체 안에 있던 초기 후보를 폐기하고 두 자리를 XZ `(982,420.5)`/`(983.5,420.5)`로 옮겼다. 같은 pointId를 유지했다. 두 자리·각 접근 경로·생활 복귀의 정적 캡슐 검사를 통과했다.
- 제안 순서와 무관하게 참여자 배열의 저작된 자리/경로를 유지한다. 현재 참여자는 두 생성 주민 GUID이며 동시 제안은 작은 stable ID 쪽만 진행한다.
- 기존 4초 세션이 응답 Think 5.333초를 자르는 결함을 고쳤다. 현재 양쪽은 짧은 Npc_Greet(각 2.5초)를 교대한다. 응답 시작은 첫 MotionSet 전체 길이 뒤, 종료는 프로필 최소 체류와 양쪽 전체 길이 합 중 큰 값(현재 5초)이다.
- 부분 예약/상태 진입 실패·진행자 소실·도착 기한·진행자 단독 시간·과거 취소·전체 모션 보장 회귀를 포함해 관련 EditMode 58/58 통과했다.
- 장소 준비 게이트는 false를 유지한다. 자동 승인 검토가 검수 전 활성화/씬 저장을 거절했으며, STATUS의 한 장소/두 주민에 대한 승인 후 LIFE03을 실행한다. 사용자 시각 검수는 미수행이다.

아래 최초 기록의 이전 장소·Think 모션·추가 검사 대기는 위 현재 반영으로 대체된다.

`NpcSocialPoint`는 저작된 소수 참여자와 두 자리/접근 Step을 소유한다. stable ID가 작은 쪽만 제안한다. 두 참여 동의와 양쪽 예약/상태 진입 중 하나라도 실패하면 전부 취소한다. 진행자 한 명의 Routine 틱만 시간을 갱신하며 먼저 도착한 주민은 자기 자리에서 대기한다. 양쪽 도착 후 인사→짧은 반응을 교대하고 각자 일과를 재선택한다.

장소 비활성·접근 제한시간·진행자/상대 소실·대화/위험·시뮬레이션 중단은 양쪽 취소로 수렴한다. 취소된 세션의 중복 Cancel은 새 예약을 건드리지 않는다. 전체 주민 쌍 비교 대신 장소의 고정 후보만 확인하며 쌍별 대기는 씬 수명의 제한된 사전에 둔다. 강제 카메라·대사·관계 저장은 없다.

대표 장소는 `NpcLifeAI_Review/Social_FarmEdge`, 자리 후보 XZ `(980,415)`와 `(981.5,415)`, 방향 90/270도다. 높이는 실제 Terrain 충돌면에서 구한다. 참여자는 A의 두 생성 주민 GUID다. Npc_Greet와 Npc_Gesture_Think MotionSet을 연결했다. 자리의 준비 게이트는 false이며 보행·시선·모션 적합성 승인 전 자동 교류를 켜지 않는다.

기존 신규 검사 10개 중 취소/이전 세션 재취소/준비 전 진입 거부를 확인했다. 부분 예약/상태 진입 실패·단독 시간 갱신·접근 기한·진행자 소실 회귀 5개도 추가했다. 첫 실행에서 테스트 몸의 Collider 누락을 발견해 fixture와 선행 준비 assert를 수정했다. **수정 후 추가 5개 재실행과 동시 제안의 실제 상태 전이 검증은 남아 있다.** 단순 예약/취소 테스트를 전체 교류 검증으로 표시하지 않는다. LIFE03은 사용자 테스트 대기이며 현재 장소 승인 선행 작업도 남아 있다.
