# LakeVillageWorld 동물 행동 사용자 검수 명세

대상은 Animal Pack Deluxe 17종 77개체다. Unity 6000.3.21f1 URP에서 기존 Boot 진입 절차로 LakeVillageWorld를 실행한다. 씬 경로는 `Assets/01.Scenes/Scenario/OpenWorld/LakeVillageWorld.unity`, Hierarchy는 `탐험 콘텐츠/야생동물/FieldWildlife/APD_*`다. 직접 씬 Play로 서비스·플레이어가 준비되지 않으면 Boot 경로를 사용한다. 기존 저장 슬롯 초기화는 필요 없다. 키보드·마우스 또는 평소 게임패드를 사용하고 장치를 결과에 적는다. 편집 씬의 Transform을 바꾸지 않고 Play Mode에서 검사한다.

이 명세의 모든 항목은 **사용자 테스트 대기**다. EditMode의 13개 통과나 에셋 연결 검사로 실제 발 접지·전환 품질까지 확인했다고 간주하지 않는다. 감지 거리는 야생 생물의 실측값이 아니라 현재 게임 프로필 값이다.

WO08에서 미끄러짐이 확인되면 해당 종 프로필의 WalkCycleSpeed 또는 RunCycleSpeed를 조정한다. 기준값은 클립 1배속에 맞는 월드 속도이며 MoveSpeed와 역할이 다르다. 먼저 직선 정속 구간을 맞춘 뒤 가감속·회전·CrossFade를 조정한다. 돼지·쥐·달팽이는 별도 달리기가 없으므로 속도를 올려 해결하지 않는다. 한 발자국 중 도약·정지 구간을 포함하는 토끼·개구리는 평균 재생률만으로 해결되지 않을 수 있다.

## 결과 회신

`WO 항목 ID / 통과·실패·미수행 / 실제 결과 / 입력 장치 / 영상 또는 Console 첫 오류`

화면 품질 실패는 동물 ID, 관찰 위치, 접근 방향, 재현 횟수와 10~20초 영상을 남긴다. 진행 성공과 Console 오류 유무는 따로 기록한다. 이미 알려진 한계는 수영·흡밀·등반·반추·밤낮 스케줄·전투 반응 미구현이며, 이를 검증 통과로 바꾸어 보고하지 않는다. Player·Addressables 빌드는 실행하지 않는다.
