# 몬스터 구역·회피 사용자 테스트

상태: **사용자 테스트 대기**. 자동 검사 63/63은 아래 체감 합격을 대신하지 않는다. [구현·수치](P2A_TERRITORY_EVASION.md) · [상태](STATUS.md).

MCP 재검증: 정상 컴파일 뒤 관련 43/43, E01의 60초 반경 유지·구르기 0회·복귀 재교전은 확인했다. E02 실제 공격은 명중했으나 구르기가 발생하지 않아 회피 뒤 공격 기회는 미검증이다. **E03 알려진 실패:** `(1132.452,48.795,389.405)`의 급경사에서 귀속점까지 NavMesh가 `PathPartial`로 끊겨 복귀 정지. 해당 위치의 통행 가능성·NavMesh 연결을 해결한 뒤 재검증해야 한다. [전체 MCP 기록](MCP_VALIDATION.md).

## 준비

- 씬: `Assets/01.Scenes/Scenario/OpenWorld/LakeVillageWorld.unity`, 현재 변경본의 Editor Play Mode. Player/Addressables 빌드는 필요 없다. 테스트를 위해 씬/저장 데이터를 덮어쓸 필요는 없다.
- 먼저 기존 `MonsterActor_Skeleton_Bow_EncounterTest` 중 월드 좌표 약 `(969.00, 68.25, 539.00)`의 궁수로 확인한다. [실제 로드 씬 조사](P2A_SCENE_ARCHERS.txt)와 [ActorDefinition·프리팹·BT 목록](P2A_ARCHER_INVENTORY.txt)을 참조한다. 다른 동일 이름 궁수도 있으므로 좌표로 구분한다.
- Humanoid 궁수는 `Enemy_Random_F_Bow_001`을 기존 전투 테스트 배치에서 확인한다. 임의 새 씬/프리팹을 저장하지 않는다. 차지 견제 규칙은 이 궁수 계열 BT에만 추가했다.
- 적용 설정: 반경 18m, 재교전 해제선 15m, 귀속 도착 허용 1.25m, 연속 구르기 1회, 종료 후 연속 예산 회복 4s, 무적 초안 0.18s, 모션 종료 뒤 회복 0.65s. SO를 바꿔 테스트했다면 실제 값을 함께 기록한다.
- 입력 장치(키보드/마우스 또는 게임패드), 사용 무기와 확인한 몬스터를 결과에 적는다. 귀속점은 최초 활성화/풀 재스폰 위치이며 구르기 종료 위치가 아니다. 외부 넉백 이탈과 자발적 이동 이탈을 구분한다.

## 실행과 판정

| ID | 실행 | 기대 결과 / 실패 기준 |
|---|---|---|
| E01 | 궁수에게 공격 없이 계속 접근하고 60초간 압박한다 | 접근만으로 구르기를 반복하지 않는다. 후퇴·원이동도 귀속 반경 밖으로 계속 밀려나지 않는다. 자발적 이탈 허용 오차는 KCC 충돌 보정 관찰용 0.2m. 지속 초과는 실패 |
| E02 | 가까이서 공격을 유도한 뒤 구르는 궁수를 따라가 기본 공격한다. 5회 반복한다 | 실제 위협에는 회피할 수 있으나 즉시 재구르기/후퇴로 공략 시간을 계속 지우지 않는다. 이동 초반 뒤 무적이 풀리고, 모션 종료 뒤 0.65s 회복 중 공격이 닿을 기회가 있다. 단순히 멈춰 맞는 적이 되어도 체감 실패로 기록 |
| E03 | 벽·좁은 통로·절벽·귀속 경계 쪽으로 압박하며 공격한다 | 유효한 접선/안쪽 회피만 한다. 막힌 방향/발밑이 없는 방향은 다른 행동을 선택한다. 벽 관통·추락·모션과 이동 방향의 큰 불일치·지속 정지는 실패 |
| E04 | 타겟인 플레이어가 귀속점에서 18m 밖으로 나갔다가 17m, 15m 안으로 돌아온다. 5회 반복한다 | 추적을 멈추고 귀속으로 복귀한다. 복귀가 시작됐으면 17m 왕복만으로 추적/복귀가 진동하지 않고, 몸과 타겟의 해제 조건이 충족되어야 재교전한다. 체력 초기화·귀환 무적 추가가 없어야 함 |
| E05 | 넉백으로 궁수를 반경 밖에 밀어낸다 | 피격/넉백이 우선하며 순간이동하지 않는다. 강제 상태가 끝나면 유효 경로로 복귀하고 다시 정상 교전한다. 돌아오다 벽에 계속 걸리거나 교전으로 복구하지 못하면 실패 |
| E06 | 기존 풀링/리스폰 경로로 다른 위치에 재스폰시킨 뒤 접근한다 | 새 스폰 위치가 귀속점이다. 이전 전투 위치로 돌아가거나 이전 회피 잠금이 남으면 실패. 단순 감지기/AI 일시 정지·재개만 했을 때는 귀속이 바뀌면 안 됨 |
| E07 | 근접 몬스터와 그리핀을 각각 유인해 경계를 넘고 재진입한다 | 근접의 접근·공격·피격과 비행의 지상/공중/착지 루프가 정상으로 복구된다. 비행의 복잡한 장애물 우회는 미지원이므로 지속 정지를 발견하면 실패와 위치를 기록 |
| E08 | 기존 몬스터 공개/대화 연출을 끝낸 뒤 교전한다 | 연출 이동을 구역 제약이 가로막지 않고, 전투 재배치를 확정한 위치를 기준으로 싸운다. 예전 연출 시작점으로 돌아가거나 멈추면 실패 |
| R01 | Humanoid 궁수 앞에서 강공격을 차지한다 | 시야·사거리·슬롯·행동 딜레이가 허용할 때 기본 사격으로 견제한다. 차지를 이미 발사한 뒤에도 계속 차지 중으로 읽으면 실패 |
| R02 | 기존 3마리 그룹에서 공격한다 | 슬롯 조회만으로 점유/해제가 발생하지 않는다. 기존 동시 공격 제한과 피격/사망 처리가 유지된다. 그룹 역할 개선(P5)은 아직 적용되지 않음 |

실패할 경우 항목 ID, 좌표, 실제 행동, 입력 장치, 무기, 적용 SO 수치를 남긴다. 필요할 때 이미 촬영한 영상/Console 로그 위치를 덧붙인다. 특히 E03/E05/E07의 지속 정지는 경로가 없을 때의 안전 정지와 구분해 원인을 조사할 수 있도록 위치를 적는다.

회신 형식: `E02 / 통과·실패·미수행 / 해골 궁수·대검·게임패드 / 실제 결과 / 영상 또는 로그 위치`.
