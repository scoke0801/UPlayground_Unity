11월 9일의 초기 자동 검사 기록을 보존했다. 최신 구현과 검증 결과는 마지막 “상황 고도화 추가 검수” 절을 기준으로 한다.

현재 확인 결과

  • 대사 ID·정확 중복·길이·행동/시간 조건, Resources 설정, 프리팹 참조, Missing Script 검사 통과. 최대 대사 길이 27자(공백·문장부호 포함). 실제 프리팹 TMP 폰트로 1,024개 문구의 preferred height를 측정했으며 최대 62.45px / 본문 영역 77px, 높이 넘침 0건이었다. 이는 시각 품질 승인과 다르다.

  • 미리보기용 독립 Canvas의 오프스크린 촬영은 정상 UI를 얻지 못해 폐기했다. 해당 임시 촬영 정리에서 Camera.targetTexture가 연결된 RT를 해제했다는 에디터 로그 2개가 발생했다. 제품 런타임의 렌더 텍스처 사용 코드는 추가하지 않았다. UI 시각 품질 통과 근거로 사용하지 않는다.

준비

기존 Boot 초기화 경로로 Editor Play Mode에 진입하고 NPC가 있는 맵으로 이동한다. 현재 열려 있던 씬은 Assets/01.Scenes/Ingame/Worlds/RiverBasinWorld.unity였다. 이 씬을 자동 변경하거나 저장하지 않았다. 평상시 검증은 NPC가 여럿 보이는 지점, 구조 전후 검증은 기존 미아·준 시나리오를 사용한다. 저장 진행을 시험할 때는 별도 테스트 슬롯을 사용하고 기존 슬롯을 덮어쓰지 않는다. 키보드와 실제 게임패드를 각각 확인한다.

튜닝 설정: Assets/10.Datas/NpcAmbientSpeech/Resources/Config/NpcAmbientSpeech.asset. 원본 문구와 연결은 같은 상위 폴더의 NpcAmbientLines.json, NpcAmbientBindings.json이다. 동기화는 UPlaygroundToolCatalog.TryExecute("npc.ambient-speech.apply", out error), 검사만 하려면 npc.ambient-speech.validate를 사용한다. 이 도구는 런처에 추가하지 않았다. 현재 SO에서 표시 간격만 조정하면 대사를 다시 동기화해도 유지된다.

범위와 남은 위험

이번 기능은 NPC별 간헐 발화다. 플레이어 대답이나 두 NPC의 교대 대사를 생성하지 않는다. 시간·실제 행동·상점 데이터·저작된 플래그/퀘스트 상태를 확인한다. 미저작 퀘스트의 감정 상태를 자동 추론하지 않는다. 새 상황은 Binding.rules에 조건과 대사 묶음을 연결하고, 침묵이 필요한 구간은 requiredFlag로 보호한다. 말풍선 이력은 현재 UI 수명 동안만 유지하며 세이브 진행도에는 저장하지 않는다. 실제 화면과 어투의 최종 승인, 긴 Play Mode 경로는 사용자 테스트 대기다.

정지 NPC 반응·개별 말투·짧은 표시 수정

사용자 관찰: 정지한 NPC가 밀쳐진 뒤 “지나갈게요”라고 말하며, 일부 말풍선이 읽기 전에 사라진다. 공용 반응에서 자신의 이동·길 양보 요청을 전제한 문구를 교체했다. 안내인 3개 데이터에 같은 고유 말투와 밀침 반응을 연결하고 상인·미아·준·헤이즐·모건·페니도 NPC 참조 기반 반응을 연결했다. 준의 발 통증 반응은 구조 이후·재회 이전 플래그에만 허용한다. 기존 퀘스트 단계 규칙과 ID는 보존한다.

표시 시간 4~8초 자체는 유지한다. 대기↔보행 전환만으로 읽던 문장을 끊지 않는다. 작업·시간·퀘스트 조건이 달라지거나 정식 대화·위험 반응·메뉴가 시작되면 중단한다. 가림·화면 가장자리·거리 판정 실패에는 즉시 숨기되 0.4초 동안 기존 문장을 보존한다. 그 안에 돌아오면 가려졌던 읽기 시간을 보충한다. 계속 가려진 화자는 풀에 반환한다. 가린 상태에서도 트윈이 글자를 벽 너머에 다시 표시하지 않도록 표시 여부와 트윈 알파를 분리했다. 새 밀침 문구를 고르지 못했을 때 읽던 반응을 먼저 지우지 않는다.
