# 실제 맵 기반 세계관과 생명의 호수 지도

> 버전: 0.2 / 작성일: 2026-10-21 / 상태: 초안  
> 이 문서는 현재 맵의 조사와 지역 해석 자료다. 바깥으로 넓히는 월드 콘셉트·신규 지역·제작 순서는 [월드 확장 콘셉트](WORLD_EXPANSION_CONCEPT.md)를 따른다.  
> 기준: [붉은 나무의 축복 정규 스토리](LAKE_OF_LIFE_RED_TREE_STORY_PLAN.md)  
> 공간 근거: 기존 미니맵 이미지, 맵 등록 데이터, 현재 디스크에 저장된 씬의 Transform·프리팹 배치. 실시간 Editor 화면과 실제 보행은 이번에 확인하지 못했다.  
> 이전 ‘여울땅’ 대륙 지도와 네 신규 권역은 이번 설계에서 제외한다. 실제 맵을 확인하지 않은 0.1안은 [보관본](../../../output/worldbuilding/archive-world-atlas-v01.md)으로만 남긴다.

**큰 바위 지형과 숲 사이에 사람들이 길을 내고 살아가는 땅. 생명의 호수에서는 아름다운 물가와 가까운 이웃의 피해가 한 생활권 안에서 맞닿는다.**

실제 보유한 ‘생명의 호수’, ‘풍요의 대지’, ‘잊혀진 회랑’을 조사했다. 저장 자산만으로는 세 지역 사이의 세계 지도상 방위·거리가 확정되지 않는다. 별도 확장안에서는 이들을 출발점으로 새 상대 배치와 바깥 지역을 제안한다. 현재 본편의 구체적인 공간 설계는 기본 시작 맵인 `LakeOfLifeScenario`에 맞춘다.

## 1. 확인한 맵과 언어 경계

| 맵 | 확인한 사실 | 사용 범위 |
|---|---|---|
| `LakeOfLifeScenario` | 맵 DB의 기본 시작 맵. 미니맵 범위 X 680~1280, Z 300~1150. 동쪽의 긴 호수, 여러 섬과 연결길, 남쪽 마을, 서쪽 숲길이 보인다. | 본편의 위치와 지역 콘셉트 기준 |
| 원본 `LakeOfLife` | 별도 등록 씬. 미니맵에 큰 암봉, 중앙 호수와 붉은 나무 섬, 남쪽 강줄기가 보인다. | 원본 환경의 조형적 정체성과 확장 참고 |
| `HarvestOfPlain` | 표시 이름은 ‘풍요의 대지’. 미니맵에 길게 이어진 골짜기, 밭, 가옥, 교량 형태가 보인다. | 농경 생활권의 세계관 후보 |
| `ForgottenWatchpost` | 표시 이름은 ‘잊혀진 회랑’. 미니맵에 석조 방과 통로, 단차, 분리된 발판이 보인다. | 실내·폐허 탐험 공간의 세계관 후보 |

원본 호수와 시나리오 호수는 서로 다른 지형이다. 시나리오를 원본 지도의 단순 확대나 잘라낸 영역으로 표시하지 않는다. 원본의 남쪽 강을 시나리오 호수의 실제 유출로라고 설명하지도 않는다.

‘확인’은 저장 자산에서 읽거나 이미지에서 본 사실, ‘제안’은 앞으로 부여할 이야기와 연출이다. 코드 이름과 좌표는 내부 위치 추적용이며 플레이어용 지명으로 사용하지 않는다. 대사와 퀘스트 표시 문구는 별도 저작한다.

## 2. 주제와 콘셉트

**주제:** 내가 편히 사는 곳의 풍요가 어디에서 오는지 돌아본다.

**확정 로그라인:** 피난민 구조를 돕던 여행자가 호수 마을의 풍요가 주변 땅의 물과 양분을 빼앗아 유지된다는 사실을 알아내고, 동료들과 루시아를 막아 축복 없이 살아갈 길을 연다.

남쪽 마을에서는 가까운 사람의 생활을 보고, 서쪽 숲길에서는 시야 밖의 일을 의심하며, 호수의 연결길에서는 그동안 보아 온 나무에 직접 다가간다. 같은 나무를 처음에는 길을 찾는 기준으로, 나중에는 풍요의 원인으로 보게 한다.

현재 자산에서 읽히는 출발점은 **마을과 경작지, 오래된 석조 공간이 길로 이어지는 생활권**이다. 바깥의 고개·숲·고원·해안으로 확장하는 제안은 별도 월드 확장안에 담는다. 현재 구현된 지형과 신규 구상을 구분하며, 확장 지역이 기존 자산에 없다는 이유만으로 콘셉트 범위를 제한하지 않는다.

## 3. 세계의 규칙과 생활

| 항목 | 기준 |
|---|---|
| 붉은 나무와 기원 표식 | 나무는 주변 땅의 물과 양분을 끌어온다. 구호품과 함께 설치된 표식이 뿌리 확장을 돕는다. 표식을 끊으면 흡수가 줄어든다. |
| 피해와 회복 | 피해는 호수 주변 생활권에 집중한다. 물이 돌아와도 사망자·잃은 수확·무너진 생활이 즉시 복구되지는 않는다. |
| 몬스터 | 서식지를 잃은 몬스터와 붉은 뿌리 주변의 식물형 적을 구분한다. 모든 적이 신의 부하는 아니다. |
| 마지막 대결 | 루시아의 선택과 책임이 중심이다. 관계없는 최종 적을 추가하지 않는다. |
| 남는 것 | 진실 공개·표식 중단·마지막 대결과 관계의 변화는 일어난 사건으로 남는다. 기존 저장 계약을 따른다. |
| 반복되는 것 | 적·채집물의 재등장은 기존 게임 규칙이다. 서사가 되돌아갔다고 해석하지 않는다. |
| 미확정 | 신의 기원·우주적 위계, 루시아의 전투 후 생사와 처우는 열어둔다. |

마을의 기존 빵집·우물·숙소·풍차를 식사, 물 사용, 거처, 물자 준비라는 생활로 읽게 한다. 풍차가 있다는 이유로 곡물 수출국을 만들거나, 호수라는 이유로 항구 문화를 붙이지 않는다.

‘풍요의 대지’에서 곡식이 온다는 관계는 실제 경작지에 맞는 **후속 제안**이다. 채택하더라도 그 지역 전체가 붉은 나무 때문에 망했다고 연결하지 않는다. 호수 마을이 축복을 끝낸 뒤에도 거래와 노동으로 살아갈 기반을 남긴다.

## 4. 실제 지형에서 이어지는 인과

1. 남쪽 마을에서 환대받기 때문에 주민을 도우려는 이유가 생긴다.
2. 가까운 북서쪽 생활 터전으로 구조하러 가기 때문에 마른 우물과 남겨진 살림을 본다.
3. 우물과 밭을 조사하기 때문에 그 북쪽의 마른 개울과 뿌리를 살핀다.
4. 기록과 물자 경로를 대조하기 때문에 자연재해처럼 보였던 피해에 사람의 선택이 있었음을 안다.
5. 축복을 끊으면 호수 마을도 풍요를 잃기 때문에 식량·물·대피 준비가 필요하다.
6. 중앙 섬에서 흡수를 멈춘 뒤에도 피해가 남기 때문에 남쪽 마을로 돌아와 주변을 돕는 생활로 마무리한다.

현재 뿌리 조사점 X 948, Z 524와 중앙 나무 X 1074.53, Z 845.72의 평면 직선거리는 약 346m다. 실제 보행 거리나 연속된 개울의 길이가 아니다. 이 사이에 어떤 단서와 조망이 있는지 확인하기 전에는 한 물길을 따라 호수까지 조사한다고 확정하지 않는다.

## 5. 지도와 장소별 콘셉트

[실제 맵 기반 지도 크게 보기](../../../output/worldbuilding/actual-world-atlas-v02.svg)

![실제 맵 기반 지도](../../../output/worldbuilding/actual-world-atlas-v02.png)

큰 지도는 기본 시작 맵의 기존 미니맵이다. 번호는 저장된 씬 또는 지역 데이터의 좌표를 같은 X/Z 범위에 올렸다. 오른쪽 세 이미지는 별도 보유 맵이며 서로 이어 붙인 대륙 지도가 아니다. 배경에 최근 추가 소품이 빠져 있어도 번호가 가리키는 좌표와 구분해서 읽는다.

### 기본 시작 맵의 현재 배치

| 지도 | 실제 근거와 X/Z 좌표 | 장소의 의미와 제안 |
|---|---|---|
| 1 호수 마을 | `Village_Well` 1043.87 / 407.99, 빵집 1028 / 392, 숙소 1064 / 440 | 남쪽 숲 아래의 생활 중심. 첫 식사와 마지막 구호품 준비를 같은 작업 공간에서 보여준다. |
| 2 피해 마을 | `R04_DryWell` 958 / 461, 집 조사점 950 / 457, 밭 조사점 947 / 478 | **호수 남서쪽, 생활 마을 북서쪽**이다. 가까운 이웃의 피해로 느끼게 한다. ‘마른들’이라는 새 이름은 사용하지 않는다. |
| 3 마른 개울과 뿌리 | `R04_Pool` 950 / 506, `R04_roots` 948 / 524, 진실 확인점 950 / 530 | 우물·밭 다음으로 가까운 범위에서 변화를 읽는다. 남은 물, 드러난 흙, 뿌리 방향을 함께 단서로 쓴다. |
| 4 중앙 섬의 신사와 붉은 나무 | `Heart_BaseShrine` 1094.95 / 831.54, `Heart_AncientTree` 1074.53 / 845.72 | 정규 이야기의 중심. 여러 섬과 육상 연결길을 유지한다. 서쪽 단일 다리로만 진입하는 섬으로 바꾸지 않는다. |
| 5 북쪽 사당 | `Shrine_Sanctuary` 1083.96 / 976.49 | 중앙 신사와 다른 장소다. 조용한 방문·선택 탐험 역할을 검토한다. 새 신이나 최종 목적지를 붙이지 않는다. |
| 6 북서쪽 큰 신전 | `Temple_Main` 812 / 1100 | 중앙 신사로 오인시키지 않는다. 선택 탐험 또는 지나간 생활의 흔적으로 역할을 재검토한다. 철거·이전은 제안하지 않는다. |
| 7 서쪽 숲길 | `RegionInfo`의 ‘서쪽 숲길’ 765 / 630 | 시야가 닫히는 숲과 외곽 경로의 선택 탐험권. 같은 구조 임무를 반복하는 필수 왕복 구간으로 늘리지 않는다. |

좌표는 건물 중심·조사점·포털 지점을 구분해 읽는다. 모두 보행 가능한 바닥 좌표라는 뜻은 아니다. 프리팹 좌표의 상위 Transform은 위치 0, 회전 항등, 배율 1임을 확인했다.

### 섬과 연결길

현재 씬에는 남쪽·서쪽·동쪽 진입, 북쪽 귀로, 섬 사이 연결길 이름이 존재한다. 미니맵에서도 여러 진입 방향과 순환이 보인다. 이 연결을 유지하면서 섬마다 경험을 다르게 만든다.

남쪽 섬은 물가에 다가가는 감각과 휴식, 중앙 섬은 신앙과 사건의 중심, 동쪽 섬은 시야가 제한된 선택 조우, 북쪽 사당은 돌아갈 방향을 살피는 조망을 제안한다. 모든 섬에 적과 보물상자를 같은 비율로 놓지 않는다.

길이 존재한다는 것과 현재 KCC·NavMesh로 안전하게 통행된다는 것은 별개다. 수영·비행·갈고리 이동을 전제하지 않으며, 길 제거와 진행 잠금도 이 문서만으로 적용하지 않는다.

### 실제 보유 지역을 살리는 세계관

| 지역 | 확인한 공간 | 세계관 제안과 탐험 경험 |
|---|---|---|
| 원본 생명의 호수 | 큰 암봉, 중앙 호수, 붉은 나무 섬, 남쪽 강줄기 | 숲과 물 주변에 생활 터전이 분산된 지역. 능선을 넘어 같은 나무를 다른 방향에서 보며 접근을 선택한다. |
| 풍요의 대지 | 골짜기 주변의 밭·가옥·길 | 수확과 운송, 겨울 준비가 중요한 농경 생활권. 식량을 지킬 구체적인 사정을 만든다. 원경의 넓은 갈색 지형을 확인 없이 강물로 그리지 않는다. |
| 잊혀진 회랑 | 석조 방·통로·단차·주변 발판 | 사람들이 쓰다 떠난 장소. 옛 보관소나 피난처라는 해석을 검토하되 원래 용도는 미확정이다. 통로 뒤에서 열린 공간을 만나는 긴장과 이완을 만든다. |

원본 `LakeOfLife`의 지역 데이터에는 X 962.35, Z 150.49에 `ForgottenWatchpost`를 목적지로 하는 포털 선언이 있다. **원본 맵의 직렬화된 연결 근거**이며 현재 시나리오에서 동작한다는 확인은 아니다. 시나리오 지역 데이터의 네 포털 목적지는 모두 같은 시나리오다. 풍요의 대지와의 연결 방위·진입점은 미정이다.

### 시각과 소리

실제 자산의 초록 숲, 황금빛·주황빛 잎, 푸른 물, 목재와 바위에서 색을 가져온다. 생활 마을은 작업 소리와 사람의 움직임, 피해 마을은 물이 닿지 않는 두레박과 멈춘 일, 중앙 섬은 물과 나무의 소리로 구분한다.

기존 개울 작업 캡처에서는 마른 바닥·남은 물·굵은 뿌리가 보이지만 주변 잔디와 작물은 푸르게 보인다. **피해를 읽게 하는 대비가 약할 수 있다.** 후속 연출에서는 피해 구간의 작물과 물 사용 흔적부터 바꾸고 작은 범위에서 의미가 전달되는지 확인한다. 저장 캡처에 대한 평가이며 현재 플레이 화면의 최종 품질 판정은 아니다.

## 6. 감정 곡선

| 구간 | 플레이어의 질문 | 경험과 다음 행동 |
|---|---|---|
| 남쪽 마을 | 여기서 쉬어도 될까? | 식사·거처·돌봄을 보고 구조에 참여한다. |
| 가까운 피해 마을 | 가까운 이웃은 왜 이렇게 살까? | 우물과 밭, 남아 있는 사람을 보고 물이 사라진 원인을 살핀다. |
| 개울·기록·물자 조사 | 풍요와 피해는 연결되어 있을까? | 환경과 기록이 같은 사실을 가리킨다. 중단 준비를 함께 한다. |
| 중앙 섬 | 풍요를 끝내도 살아갈 수 있을까? | 마련한 식량과 물, 동료들의 행동이 답이 된다. 루시아와 대치한다. |
| 남쪽 마을 귀환 | 우리가 바꾼 것이 남아 있을까? | 처음 받았던 식사가 바깥에 보낼 짐으로 싸인다. 회복의 시작을 본다. |

## 7. 퀘스트 범위

기존 구조·조사·물자 준비·신사 접근·귀환의 인과를 지킨다. 다른 맵 방문을 호수 이야기의 필수 전제나 후속 세계 구원 예고로 추가하지 않는다. 퀘스트 ID·완료 조건·대사·저장 규칙은 변경하지 않는다.

## 8. 인물 역할

설아의 물길 조사, 리안과 묘묘의 물자 경로 확인, 릴리의 피해 마을 구조, 유라의 길 확보는 정규 스토리를 따른다. 배치가 있다는 이유로 장면과 영입의 작동까지 확인했다고 보고하지 않는다.

루시아는 마을을 돕는 관리자이자 피해를 알면서 은폐한 당사자다. 중앙 신사에서의 대치는 이 책임을 해결한다. 기존 인물의 출신지·가족관계를 다른 맵에 임의로 배정하지 않는다.

## 9. 우선 개선할 지점

1. **지도 일치:** 마을·피해 마을·뿌리·중앙 신사를 현재 좌표로 읽고, 북쪽 사당과 북서 신전을 구분한다.
2. **피해의 가독성:** 우물·밭·개울을 가까운 생활 변화로 묶는다. 주변의 푸른 환경 때문에 피해가 묻히는지 실제 시점에서 확인한다.
3. **조사의 연속성:** 뿌리 조사점과 호수 사이 약 346m의 평면 간격에 어떤 단서와 조망이 있는지 확인한다. 연속된 물길을 있다고 가정하지 않는다.
4. **반복 이동 감소:** 이미 존재하는 연결길 중 안전한 귀환로를 활용한다. 먼저 길을 막거나 새 다리를 만드는 방식으로 해결하지 않는다.

위 항목은 후속 씬 작업의 판단 순서다. 이번 작업에서는 지도와 세계관 문서만 고쳤다.
