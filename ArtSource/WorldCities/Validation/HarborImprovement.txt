동쪽 부두 낚시 → 물고기 획득 → 태수에게 판매 → 고은에게 보급품 구매.
물고기는 기존 아이템 100008이며 판매가는 기존 상점과 같은 20골드.
낚시 3회 후 소진, 게임 시간 180분 후 재생성. 1회 보상 1~2마리.
서쪽 물가 쉼터는 기존 파티 회복·성장 화면으로 연결.
상점 ID를 각각 merchant_saltwind_supplies / merchant_saltwind_catch로 분리.
매입 전용 태수 상점은 빈 구매 목록 대신 판매 탭부터 열린다.
낚시·쉼터 저장 ID: saltwind.fishing.eastpier / saltwind.rest.westquay.
NPC는 별도 ID·데이터·프리팹을 쓰고 기존 인물 외형·동작만 재사용한다.
기존 호수 인물의 대화·스토리를 연결하지 않았으며 신규 대사·퀘스트는 없다.
일과 위치는 저장 진행이 아니며 재진입 시 기존 일과 스케줄로 시작한다.
낚시 소진·상점 재고는 기존 저장 정책을 사용한다. 실제 저장 복원은 플레이 테스트 대기.

사용자 테스트 명세 — 현재 모두 미수행
준비: Unity 6000.3.21f1 이상. 기존 Boot 시작 경로와 별도 테스트 저장 슬롯 사용.
입력 장치를 기록하고, 다른 작업의 씬은 각 작업자가 저장한 후 플레이한다.
H01 / 진입로에서 시장까지 걷기 / 길·노점·상인을 구분하고 카메라가 건물에 과도하게 가려지지 않는다.
H02 / 시장 → 창고 앞 → 두 부두 → 등대 왕복 / 끼임·낙하·막힌 난간·소품 관통 없음.
H03 / 호수·돌등성 출구 왕복 / 기존 목적지로 이동하고 도착 즉시 재이동하지 않는다.
H04 / 시장·항구 여러 각도와 미니맵 관찰 / 검은 천·분홍 재질·다른 씬의 겹침 없고 배치와 지도 일치.
H05 / 고은에게 물품 구매 / 구매 탭부터 시작, 가격·소지금·수량·재고가 맞게 변한다.
H06 / 동쪽 부두에서 3회 낚시 후 태수에게 판매 / 물고기 획득, 태수 판매 탭에서 20골드에 매입, 3회 후 낚시 소진.
H07 / 낚시 소진·상점 구매 뒤 저장·로드 및 항구 재진입 / 진행과 재고가 기존 정책대로 유지되고 복제·영구 진행 불능 없음. 게임 시간 180분 뒤 낚시 재개 가능.
H08 / 서쪽 쉼터 사용 / 파티 회복·성장 화면 열기와 닫기 정상, 종료 후 이동 입력 복귀.
H09 / 낮 동안 동진 왕복과 저녁 휴식 관찰 / 화물·난간에 걸리지 않고 작업점 도달. 민수·유나 동작이 가구와 크게 겹치지 않는다.
H10 / 게임패드로 양 상점 조작 / 초기 포커스, 품목·수량 이동, 숄더 탭 전환, Cancel 종료 정상. 빈 판매 목록도 빠져나올 수 있다.
