리소스 제작은 기존 Unity 메시/TrailRenderer와 URP material을 조합했다. 구매 원본 변경 없음. [Unity 로드·의존 GUID 원자료](p3-audit.txt), [적용 실행 기록](content-execution.txt). 초기 동시 세션의 컴파일/테스트 중 실행은 거절됐고, Editor 유휴 상태에서 최종 적용 성공을 기록했다. 한 차례 설정 비저장 상태를 확인해 Audit가 SupportsReflection도 확인하도록 보완하고 재적용했다.

검증: 관련 확장 EditMode **109/110 통과**, [원본](p3-broad-editmode.json). 두 실제 액터의 GAS→자기 Motion→SpawnProjectile→Definition→형태/음향 연결, 지원 조합 검사, 궁수 높이, 기존 Staff/진영 검사가 포함된다. 실패1은 변경하지 않은 WoodlandWolf의 등급 반응 정책 누락(`CombatDefaultReactionPolicyTests`,69행)이다. 이를 제외한 전체 프로젝트 통과로 기록하지 않는다.

발견·수정: 표시 구성 호출이 reflectable 플래그 확정보다 빨라 첫 비행 표시/음향이 꺼질 수 있던 순서를 수정했다. 최종 컴파일과 실제 표시 재대여 검사는 P4에서 재실행한다. SO 자동 재직렬화는 이번에 새로 추가된 무관한 기본 필드를 정리하며 기존 Staff 작업 필드는 보존한다.

실제 입력/사운드/형상 미술/난이도 인수는 [PP01~PP10](USER_TEST.md) 사용자 테스트 대기다. [전투 위키](../../wiki/combat.md).
