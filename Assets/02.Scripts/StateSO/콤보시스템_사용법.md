# 콤보 시스템 사용 가이드

## 📌 개요

콤보 공격 데이터를 Json 파일로 관리하여, SkillActionStateSO에서 외부 데이터를 기반으로 콤보를 실행합니다.

## 🔧 구조

```
ComboData.json (Addressable)
    ↓
JsonDataManager (로드 및 캐싱)
    ↓
SkillActionStateSO (ComboID로 참조)
    ↓
실행 (AnimationKey, HitTiming 등 모두 Json에서 로드)
```

## 📝 1. Json 데이터 작성

### 파일 위치
`Assets/10.Datas/Json/ComboData.json`

### 예시 구조
```json
{
  "combos": [
    {
      "comboID": 1001,
      "comboName": "Basic Sword Combo",
      "animationKeys": ["Attack1", "Attack2", "Attack3"],
      "hitStarts": [0.3, 0.35, 0.4],
      "hitEnds": [0.6, 0.65, 0.7],
      "comboResetTime": 2.0,
      "useHitBox": true
    }
  ]
}
```

### 필드 설명
- **comboID**: 고유 식별자 (1001부터 시작 권장)
- **comboName**: 콤보 이름 (디버그용)
- **animationKeys**: 애니메이션 키 배열 (순서대로 재생)
- **hitStarts**: 각 공격의 히트 판정 시작 시점 (0~1)
- **hitEnds**: 각 공격의 히트 판정 종료 시점 (0~1)
- **comboResetTime**: 콤보 리셋 시간 (초)
- **useHitBox**: 히트박스 활성화 여부

## 📦 2. Addressable 설정

1. `ComboData.json` 파일을 Addressable 그룹에 추가
2. Address를 `ComboDataTable`로 설정
3. 빌드 후 로드 가능

## 🎮 3. SkillActionStateSO 설정

### 인스펙터 설정
1. `SkillActionStateSO` 에셋 생성
2. **ComboID** 필드에 Json의 comboID 입력 (예: 1001)
3. 나머지 설정은 Json에서 자동 로드됨

### 기존 방식과의 차이
```csharp
// ❌ 기존: AnimationKey를 SO에 직접 저장
[SerializeField] private string[] ComboAnimationKeys;

// ✅ 변경: ComboID만 저장, 데이터는 Json에서 로드
[SerializeField] private int ComboID = 1001;
```

## 💻 4. 코드에서 사용

### PlayerBrain에서 콤보 공격 실행
```csharp
public class PlayerBrain : CharacterBrain
{
    [SerializeField] private SkillActionStateSO comboActionState;
    
    void Update()
    {
        // 마우스 좌클릭으로 콤보 공격
        if (Input.GetMouseButtonDown(0))
        {
            // ComboID는 이미 SO에 설정되어 있음
            ChangeState(comboActionState);
        }
    }
}
```

### 런타임에서 콤보 데이터 조회
```csharp
// 특정 콤보 데이터 가져오기
ComboJsonData comboData = JsonDataManager.Instance.GetData<ComboJsonData>(1001);

if (comboData != null)
{
    Debug.Log($"콤보 이름: {comboData.ComboName}");
    Debug.Log($"콤보 단계: {comboData.AnimationKeys.Length}");
}
```

## 🔄 5. 콤보 리셋 시스템

콤보는 다음 조건에서 리셋됩니다:

1. **시간 초과**: `comboResetTime` 이내에 다음 입력이 없을 때
2. **콤보 완료**: 마지막 공격까지 실행 후
3. **피격/회피**: 다른 상태로 전환 시

### 블랙보드 데이터
```csharp
// 현재 콤보 인덱스 (0부터 시작)
int comboIndex = brain.GetData<int>("ComboIndex", 0);

// 마지막 공격 시간
float lastAttackTime = brain.GetData<float>("LastAttackTime", 0f);
```

## 📊 6. 여러 콤보 사용하기

### 무기별 콤보 설정
```csharp
[SerializeField] private SkillActionStateSO swordComboState;  // ComboID: 1001
[SerializeField] private SkillActionStateSO axeComboState;    // ComboID: 1002
[SerializeField] private SkillActionStateSO dualComboState;   // ComboID: 1003

void EquipWeapon(WeaponType type)
{
    switch(type)
    {
        case WeaponType.Sword:
            currentComboState = swordComboState;
            break;
        case WeaponType.Axe:
            currentComboState = axeComboState;
            break;
        case WeaponType.Dual:
            currentComboState = dualComboState;
            break;
    }
}

void Update()
{
    if (Input.GetMouseButtonDown(0))
    {
        ChangeState(currentComboState);
    }
}
```

## 🎯 7. 디버깅 팁

### 콤보 데이터 로드 확인
```csharp
void Start()
{
    // JsonDataManager가 초기화될 때까지 대기
    StartCoroutine(CheckComboData());
}

IEnumerator CheckComboData()
{
    yield return new WaitUntil(() => JsonDataManager.Instance.IsDataLoaded<ComboJsonData>());
    
    var allCombos = JsonDataManager.Instance.GetAllData<ComboJsonData>();
    Debug.Log($"로드된 콤보 개수: {allCombos.Count}");
    
    foreach (var combo in allCombos)
    {
        Debug.Log($"- {combo.ComboName} (ID: {combo.ComboID})");
    }
}
```

### 콤보 진행 상황 확인
```csharp
void OnEnter(CharacterBrain brain)
{
    int comboIndex = brain.GetData<int>("ComboIndex", 0);
    ComboJsonData comboData = JsonDataManager.Instance.GetData<ComboJsonData>(ComboID);
    
    Debug.Log($"현재 콤보: {comboData.ComboName}, 단계: {comboIndex + 1}/{comboData.AnimationKeys.Length}");
}
```

## ⚠️ 주의사항

1. **Json 파일은 반드시 Addressable로 설정**해야 합니다
2. **animationKeys, hitStarts, hitEnds 배열 길이**는 동일해야 합니다
3. **ComboID는 고유**해야 합니다 (중복 시 경고 발생)
4. **애니메이션 키**는 AnimationData에 등록된 키여야 합니다

## 💡 확장 아이디어

### 콤보 데이터에 추가 가능한 필드
```json
{
  "comboID": 1001,
  "comboName": "Basic Sword Combo",
  "animationKeys": ["Attack1", "Attack2", "Attack3"],
  "damages": [10, 15, 25],              // 각 공격의 데미지
  "knockbackForces": [5, 8, 15],        // 각 공격의 넉백 강도
  "particleEffects": ["Slash1", "Slash2", "Slash3"],  // 이펙트
  "soundEffects": ["Swing1", "Swing2", "Swing3"],     // 사운드
  "cameraShakes": [0.1, 0.2, 0.3]       // 카메라 흔들림
}
```

이렇게 확장하면 콤보의 모든 정보를 Json으로 관리할 수 있습니다.
