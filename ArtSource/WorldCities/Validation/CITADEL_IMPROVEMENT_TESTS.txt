돌등성 개선 — 사용자 플레이 검수

대상: Assets/01.Scenes/Scenario/StonegateCitadel.unity.
기존 Boot/Title 경로에서 호수 마을 서쪽 출구(X1005/Z430)로 방문한다.
기존 저장을 덮어쓰지 않고 빈 슬롯을 사용한다. 키보드와 게임패드의 기존 상호작용 입력을 사용한다.
이번 변경은 씬·NPC·상점 데이터다. 종전 WorldCities Player 빌드에는 이번 변경이 들어 있지 않다.

S01 거리와 분위기
성문 → 장터 → 분수 → 본성 앞 → 오른쪽 공방을 걷고 회피한다.
기대: 본성이 방향 기준으로 보이고, 길 옆 가로수·차양이 시야를 완전히 가리지 않는다.
가로수 줄기, 시장 기둥, 주택 모서리에서 끼임·카메라 관통·지면 침투가 없을 것.

S02 주민 배치
장터 5명, 성문 2명, 공방 3명, 광장 2명을 확인한다.
기대: 12명의 외형이 구분되고 손님 3명은 짧게 배회하며 나머지는 자기 자리에서 대기하거나 작업한다.
T 포즈, 잘못된 본 연결, 소품 관통, 이동 중 멈춤은 실패.
기존 역할별 경량 모델의 외형을 재사용했으며 이번 검수로 원본 외형 승인까지 대신하지 않는다.

S03 보급 상점
왼쪽 첫 좌판의 하루(X169/Z148)에게 접근해 거래한다.
기대: '하루의 여행용품'에 기존 가격의 회복 물품과 재료 매입 목록이 표시된다.
구매·판매 후 소지품/골드/한정 재고가 정확히 변하며 Cancel로 닫은 뒤 이동 가능하다.
돈·재료 부족 거래가 성립하거나 재고가 다른 마을 상점과 공유되면 실패.

S04 공방 매입
오른쪽 안쪽 공방의 담(X218/Z215)에게 거래한다.
기대: '담의 재료 매입'에서 네 종류 재료를 기존 매입가로 팔 수 있다.
판매할 물건이 없다면 매입 목록이 비어 있을 수 있다. 물건 지급이나 무료 골드 생성은 없다.
이번 공방은 재료 매입처이며 제작 메뉴를 여는 기능은 추가하지 않았다.

S05 쉼터
파티의 체력을 일부 소모한 뒤 분수 뒤 벤치(X171/Z206)를 이용한다.
기대: 기존 휴식 기능대로 파티 체력이 회복되고 성장 화면을 닫은 뒤 조작이 돌아온다.
여러 번 사용 가능하며 본편 진행·퀘스트 수락을 요구하지 않는다.

S06 저장·역순·왕복
공방→쉼터→장터의 역순으로 이용하고, 거래 후 빈 슬롯에 저장·불러온다.
호수 또는 항구로 나갔다 다시 들어온다.
기대: 상점 한정 재고·골드·소지품은 기존 저장 계약대로 유지된다. 주민은 배치 위치부터 일상을 재개한다.
기존 출구/도착 ID와 본편 퀘스트는 바뀌지 않으며 재진입·대화/거래 취소로 진행이 막히지 않는다.

S07 게임패드와 성능
실제 게임패드로 두 상점과 휴식 화면을 열고 이동/선택/Cancel을 확인한다.
광장과 장터에서 NPC 12명이 있을 때 프레임, 카메라 반응, 장비 관통을 확인한다.
Editor 정적 검사와 캡처는 이 실제 입력·성능 검증을 대신하지 않는다.

결과 회신: 항목 ID / 통과·실패·미수행 / 실제 결과 / 입력 장치 / 실패 시 로그 또는 화면.
현재 S01~S07은 사용자 테스트 대기. 진행 성공과 런타임 예외 유무를 별도로 기록한다.
