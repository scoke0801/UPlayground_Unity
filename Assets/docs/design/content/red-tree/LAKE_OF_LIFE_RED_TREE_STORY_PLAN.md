# 생명의 호수 정규 스토리 기획안 붉은 나무의 축복

> 버전: 1.0 / 확정일: 2026-10-17 / 상태: 확정
> 확정 근거: 사용자가 마지막으로 제시된 ‘주변 마을을 피폐하게 만드는 축복, 호수의 신사와 붉은 나무, 신을 추앙하는 루시아’ 기획을 정규 기획안으로 승인했다.
> 적용 범위: 생명의 호수 전체 이야기의 콘셉트·세계 규칙·인물 역할·합류·결말. 문서 확정이며 씬·대화·퀘스트·전투 데이터 구현 완료를 뜻하지 않는다.

## 1. 기준과 범위

이 문서가 생명의 호수 스토리의 최상위 기준이다. 기존 보물 소문, 같은 얼굴의 적, 세 동료만 합류하는 제1장 구성과 충돌하면 이 문서를 따른다. 기존 문서의 구현 기록·ID·GUID·저장 계약은 이력과 기술 근거로 보존한다. 치료와 고통 이전, 주민 감금만을 중심으로 한 이전 제안은 채택하지 않는다.

전체 서사는 호수 마을과 피해를 입은 가까운 마을들의 삶을 구하는 데서 끝난다. 세계 구원이나 더 큰 적을 예고하는 결말로 확대하지 않는다. 기존 캐릭터 이름·외형·전투 정체성을 유지하고 이야기 속 역할과 관계를 재구성한다. 일반 NPC는 추가할 수 있으나 플레이어블을 새로 만들지 않는다. 파티 합류 대상은 플레이어블뿐이다.

G26~27 조사에서 참고한 구성은 일상과 관계 형성, 사건을 통한 의심의 누적, 인물의 실체 공개, 동료 합류, 최종 대결 이후의 생활 변화다. 특정 원작의 인물·설정·대사를 복사하지 않는다.

## 2. 로그라인과 주제

호수 마을에서 피난민 구조를 돕던 여행자가 마을의 풍요가 주변 마을을 말려 죽인다는 사실을 알아내고, 동료들과 함께 신을 맹신하는 관리자 루시아를 막아 축복 없이 살아갈 길을 연다.

마을을 사랑한다는 이유로 다른 사람의 삶을 빼앗을 수는 없다. 결말에서 호수 마을은 주변으로부터 받던 물자와 생명을 돌려주는 쪽으로 변한다.

## 3. 세계의 규칙

| 항목 | 확정 규칙 |
|---|---|
| 중심 장소 | 중앙 호수의 신사와 붉은 나무가 신앙과 사건의 중심이다. 기존 씬의 실제 배치와 확정 구도의 차이는 맵 재배치 작업에서 해결한다. |
| 축복 | 붉은 나무는 생명을 새로 만들지 않고 주변 땅의 물과 양분을 끌어와 호숫가에 모은다. |
| 피해 | 주변 우물과 개울이 마르고 작물이 죽는다. 서식지를 잃은 몬스터가 생활권으로 밀려들어 피해가 커진다. |
| 기원 표식 | 구호품과 함께 설치한 표식은 붉은 나무가 뿌리를 뻗도록 돕는다. 단순한 장식이 아니다. |
| 중단 | 표식을 끊으면 바깥에서 끌어오는 힘이 줄고 붉은 나무의 꽃이 떨어진다. 마을은 풍요를 잃지만 이를 즉사나 세계 멸망으로 바꾸지 않는다. |
| 회복 | 흡수가 멎으면 물이 돌아오기 시작한다. 사망자·소실된 수확·무너진 생활은 즉시 복구되지 않는다. |
| 최종 적 | 루시아가 스스로 신의 힘을 받아들여 일행과 싸운다. 관계없는 괴물이 뒤늦게 나타나 그녀의 책임을 대신하지 않는다. |

신의 고유명·기원·우주적 위계는 이번 확정 범위가 아니다. 이를 설명하기 위한 후반 설정 강의나 세계 규모의 사건을 추가하지 않는다.

## 4. 루시아

과거 마을이 굶주림과 몬스터 습격으로 무너질 때 루시아는 신사에 도움을 청했다. 신이 응답하고 붉은 나무가 꽃을 피운 뒤 물과 땅이 살아났다. 그녀는 마을 관리자이자 신사를 돌보는 신앙의 중심이 되었다.

루시아는 주민의 부탁을 기억하고 피난민에게 잠자리와 일을 마련한다. 도움은 전부 연기가 아니다. 그러나 고향으로 돌아가겠다는 사람에게는 이미 망가진 곳으로 돌아갈 필요가 없다며 정착을 권한다. 자신이 망가뜨린 마을의 주민을 받아주는 것까지 신의 자비로 해석한다.

처음에는 축복의 대가를 몰랐지만 현재는 안다. 축복을 끊으면 마을이 다시 무너지고 자신도 신에게 버림받을 것이라고 두려워한다. 그녀의 승리 조건은 축복을 유지하고 주민들이 자신과 신에게 의지하며 사는 것이다.

내부 콘셉트인 ‘멘헤라’는 진단명이나 플레이어 노출 호칭으로 쓰지 않는다. 응답이 없으면 신사를 떠나지 못하고, 시든 잎을 보고 자신의 잘못부터 찾고, 신을 의심하는 사람에게 웃다가 적대하는 행동으로 불안·의존·집착을 표현한다. 불안 자체가 악행의 원인은 아니다. 피해를 안 뒤에도 은폐하고 봉헌을 늘린 선택에 책임이 있다.

## 5. 전체 인과와 감정 곡선

| 구간 | 사건과 플레이 목표 | 새로 알게 되는 사실 |
|---|---|---|
| 도입과 환대 | 운송 의뢰로 온 주인공이 풍족한 마을에서 환대받고 피난민 구조를 돕는다. 조이는 식사, 헤이즐은 돌봄, 루시아는 거처와 일을 마련한다. | 루시아는 실제로 사람을 돕는 유능한 관리자다. |
| 바깥의 피해 | 피난민을 호위하고 몬스터를 물리치며 가까운 피해 마을 한 곳을 구체적으로 본다. | 호숫가의 풍요와 바깥의 황폐함이 동시에 커지고 있다. |
| 첫 공개 | 마른 개울을 따라 붉은 뿌리와 식물·엔트를 조사한다. 물길이 호수로 이어진다. | 축복이 주변의 물과 양분을 빼앗는다. 루시아는 몰랐던 일이라며 조사를 돕겠다고 한다. |
| 은폐 발견 | 전달되지 않은 경고와 중단된 조사 기록을 찾는다. 동료와 주민의 의견이 갈린다. | 루시아는 이미 피해를 알았고 더 많은 봉헌을 해왔다. |
| 실체 확인 | 구호품 운송 경로를 추적해 피해 마을의 기원 표식을 조사하고 생존자를 구조한다. | 구호와 함께 설치한 표식이 피해를 확대했다. 루시아는 신의 뜻을 직접 실행했다. |
| 공동 대응 | 동료들이 합류해 표식을 끊고 축복 없이 버틸 식량과 물자를 마련한다. 주민의 대피와 생활 유지가 전투의 목적이다. | 축복을 끝낼 대안이 사람들의 협력으로 마련된다. |
| 마지막 대결 | 꽃이 떨어지자 루시아는 버림받는다고 느끼고 신의 그릇이 된다. 일행은 신사에서 루시아와 싸워 흡수를 멈춘다. | 신앙을 유지하려는 그녀의 선택이 주민의 생존과 직접 충돌한다. |
| 귀환과 결말 | 물이 돌아오기 시작한다. 호수 마을은 주변에 물자와 노동을 보낸다. 처음 환대받은 마을에서 달라진 일상을 본다. | 구원은 모든 피해의 삭제가 아니라 빼앗던 삶을 끝내고 회복을 책임지는 일이다. |

실체 공개는 축복의 대가 → 사전 인지와 은폐 → 표식 설치의 책임 순서다. 묘령 한 사람의 설명으로 진실을 해결하지 않고 각 사건에서 증거를 먼저 경험하게 한다.

## 6. 전체 플레이어블 등장과 합류

현행 `CharacterActorType`의 사용 대상 12명을 본편에 등장시킨다. `H09`는 코드에 미사용으로 표시되어 제외한다. 라온·아린 중 선택한 인물이 혼자 시작하며, 선택하지 않은 인물은 별도 사건에서 만난다. 전원 최종 구간 전에 합류하고 합류 뒤에도 마을 구원에 기여한다. 상시 전원 추종 AI를 전제하지 않으며 현행 교체 중심 파티와 장면 대역을 기준으로 한다.

| 인물 | 등장과 합류의 이유 | 합류 후 기여 |
|---|---|---|
| 선택한 라온 또는 아린 | 운송 의뢰로 마을에 도착하고 구조를 통해 사건에 관여한다. | 주민의 생존을 우선하며 조사와 축복 중단을 연결한다. |
| 화린 | 피난민을 호위하며 몬스터가 밀려오는 원인을 추적한다. | 구조로와 대피로를 확보한다. |
| 리안 | 구호품 운송과 기원 표식 설치가 같은 경로를 따른다는 사실을 발견한다. | 경로와 기록을 대조해 피해의 연결을 밝힌다. |
| 묘묘 | 선의로 전달한 물건이 피해를 키웠음을 알게 된다. | 전달했던 물건과 표식의 위치를 찾아 회수를 돕는다. |
| 릴리 | 호수 마을에 받아들여졌지만 고향에 남은 사람을 포기할 수 없다. | 피해 마을 생존자 구조를 이끈다. |
| 설아 | 말라가는 물길에서 호수로 향하는 붉은 뿌리를 발견한다. | 흡수 경로와 중단 후 변화를 확인한다. |
| 연화 | 신사의 봉헌을 돕다가 축복의 대가를 확인하고 루시아와 갈라선다. | 표식과 신사에 접근하는 데 협력한다. |
| 세라 | 축복 덕분에 살아남아 중단에 반대하지만 바깥의 피해를 직접 겪는다. | 축복 없이 살 대안을 마련하며 주민의 불안을 대변한다. |
| 유라 | 폐쇄된 길 너머의 생존자들을 오가며 구조한다. | 우회로를 연결하고 고립자를 데려온다. |
| 레이네 | 마을을 지키려고 신사 접근을 막다가 피해 은폐 명령을 거부한다. | 주민 보호와 관리자의 명령을 구분해 행동한다. |
| 묘령 | 루시아가 신에게 의지하기 전부터 알던 인물이다. | 과거의 관계로 현재 행동의 변화를 짚고 최종 대치에 참여한다. |
| 선택하지 않은 라온 또는 아린 | 바깥에서 생존자를 보호하다 일행과 구조로를 연결한다. | 외곽 구조와 공동 대응에 합류한다. |

세부 등장 순서·장면별 참여 인원·대사는 후속 저작에서 정한다. 기존 이름·모델·무기·능력을 임의로 바꾸지 않는다. 같은 구조 보상으로 영입을 반복하지 않고 조사, 책임 인정, 의견 충돌과 입장 변화로 합류를 구별한다.

## 7. 기존 NPC와 추가 변형

기존 배치 NPC인 안내인, 조안, 미아, 준, 헤이즐, 페니, 모건, 조이, 루시아, 상인, 연목, 소담, 다온을 활용한다. 루시아를 관리자이자 최종 대립자로 설정한다. 조이의 식사, 헤이즐의 돌봄을 비롯한 생활 역할은 피해 주민 수용과 이후 회복에 연결한다. 나머지 NPC의 세부 대사와 새 관계는 외형·기존 데이터 확인 후 저작한다.

추가 NPC는 다음처럼 서로 다른 삶과 입장을 갖도록 만든다. 아직 새 이름이나 정확한 인원·모델을 확정한 것은 아니다.

- 고향으로 돌아가 재건하려는 피난민.
- 돌아갈 의사가 없고 호수 마을에 정착하려는 피난민.
- 피해를 알면서도 가족의 생계를 위해 축복을 지지하는 기존 주민.
- 구호를 믿고 표식 설치를 도왔다가 배신당한 피해 마을 주민.
- 축복 중단에 동의하지만 당장 먹을 식량을 걱정하는 주민.
- 외부에 물자와 노동을 돌려주는 데 먼저 나서는 주민.

피해자들끼리도 원하는 결말이 다르다. 일반 NPC를 파티 동료로 영입하지 않으며, 전원이 관리자에게 반대하거나 같은 정보를 반복하는 구성은 피한다.

## 8. 맵과 몬스터

기존 호수·섬·숲길·마을·사원 기물을 바탕으로 중앙 호수의 신사와 붉은 나무 구도를 구현한다. 필요한 오브젝트 추가·재배치·테레인 수정을 허용한다. 기존 배치와 지형을 확정 콘셉트에 맞게 조정할 수 있으나 확인하지 않은 공간을 이미 구현된 것으로 기록하지 않는다.

외곽에는 마른 개울, 버려진 경작지, 피난민 거처, 붉은 뿌리에 잠식된 길을 둔다. 가까운 피해 마을 한 곳을 구체적으로 보여주고 다른 주변 마을의 상황은 피난민과 운송 흔적으로 전달해 지역 규모를 유지한다.

기존 식물 몬스터와 엔트는 붉은 뿌리 주변에서 조우한다. 기존 거미류 등은 서식지를 잃어 이동한 위협으로 쓸 수 있으며 모든 몬스터를 신의 부하로 설정하지 않는다. 신규 몬스터 종을 전제로 하지 않는다.

최종전은 기존 골렘 기물에 붉은 뿌리와 신사 장식을 적용하는 방향이다. 루시아가 받아들인 신의 힘을 전투 형태로 표현하며 목소리와 행동의 주체는 루시아다. 단순 골렘 경비병을 쓰러뜨리고 끝내지 않는다. 사용할 골렘 변형, 모델 연결, 애니메이션·연출 범위는 실제 자산 검토와 전투 명세에서 확정한다.

## 9. 확정과 후속 구현 경계

이번 확정은 전체 콘셉트, 지역 구원 규모, 루시아의 신앙·은폐·최종 대립, 세 단계 공개, 전원 플레이어블 등장·합류, 다양한 주민 입장, 기존 몬스터 활용, 맵 수정 허용, 회복을 시작하는 결말을 포함한다.

후속 작업은 장면·퀘스트 분해, NPC 배역과 외형 대응, 자연스러운 대사, 신사와 붉은 나무의 배치, 최종전 연출, 세부 영입 순서다. 루시아의 전투 후 생사와 처우는 이번 승인 내용에 없으므로 임의로 확정하지 않는다.

구현 시 기존 ID·GUID와 사용자 변경을 보존한다. 기존 저장의 진행을 새 전체 서사에 대응시키는 정책은 콘텐츠 구현 전에 별도로 정의한다. 대화·퀘스트·씬·전투 데이터는 문서 확정만으로 변경되거나 검증된 것이 아니다.

## 10. 문서 검수 기준

- 각 구간에서 구조, 조사, 물자 확보, 표식 중단 등 당장의 목표를 설명할 수 있다.
- 루시아의 도움과 집착이 모두 행동으로 드러나고, 피해 은폐에 책임이 남는다.
- 세 단계 진실 공개에 앞서 환경과 기록의 단서를 배치한다.
- 모든 사용 대상 플레이어블에게 등장·합류·합류 후 기여가 있다.
- 일반 NPC의 관점과 생활이 다양하며 파티 영입과 구분된다.
- 마지막 전투는 루시아와의 관계 및 선택의 충돌을 해결한다.
- 축복 중단이 피해를 즉시 지우지 않고, 마을의 달라진 일상으로 끝난다.
