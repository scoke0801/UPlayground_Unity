원거리 나무 마젠타 수정 및 검증

원인: Polyart/Utilities/Impostor의 RenderPipeline 태그가 UniversalRenderPipeline이었다.
현재 URP의 태그는 UniversalPipeline이다. 설치된 Core 패키지의
Editor/ShaderStripping/ShaderPreprocessor.cs는 태그가 다르면 변형을 모두 제거한다.
기존 Editor.log의 해당 셰이더: After scriptable stripping 0, total internal programs 0.
LakeVillageWorld를 Unity에서 로드해 이 셰이더 사용 렌더러 4,579개를 확인했다.

수정: M_Impostor.shader의 태그만 교정. GUID와 머티리얼 연결은 보존한다.
ExternalAssets는 Git 제외 경로이므로 원본 수정은 일반 diff에 나오지 않는다.
외부 에셋 재설치 또는 다른 체크아웃에 적용할 때 프로젝트 루트에서 실행:
git apply --check Tools/Rendering/PolyartImpostorUrpTag.patch
git apply Tools/Rendering/PolyartImpostorUrpTag.patch
이미 적용했으면 --check가 실패하므로 중복 적용하지 않는다.
ImpostorShaderBuildTests는 직렬화된 SubShader 태그와 빌드 파이프라인 태그를 비교한다.
