돌등성 고밀도 성 제작 원본

최신 산성 레퍼런스 반영 버전은 FORTRESS_REFERENCE.txt를 따른다.
아래는 이전 확대·폐쇄 버전 기록이다.

현재 본성: 확대·폐쇄 버전
- 몸체 46×26m, 상층 36×20m, 층 간 높이 9m.
- 처마 포함 폭 51.84m, 기단 포함 높이 31.42m.
- LOD0/1/2: 1727860 / 337856 / 15564 삼각형, 각 LOD Renderer 9개.
- 본성 정문·네 방향 벽은 닫혀 있으며 실내 진입 기능은 없다.
- 근접 삼각형이 이전 906036에서 증가했다. 실제 성능은 미측정이다.
- build_castle_highpoly.py의 Blender 스크립트 인자 -- keep으로 본성만 생성 가능.
- 본성만 생성하면 StonegateHighPoly_keep.blend / castle_mesh_validation_keep.json에 기록한다.
- 현재 본성 최신 원본은 StonegateHighPoly_keep.blend다. 전체 생성은 인자 없이 실행한다.
- apply_castle_highpoly.csx는 재적용 시 설정의 배치 좌표도 기존 인스턴스에 반영한다.
- 이번 적용은 첫 번째 건물 생성 루프를 Keep으로 제한하여 성문·망루 파일을 보존했다.
- 생성 중 메시 벽체 검사 168건/LOD, Unity 충돌 검사 168건, 기존 경로 재검사 통과.
- 현재 비교·검증: output/StonegateEnclosed/REVIEW.html 및 TESTS.txt.

아래 수치·접근 설명은 이전 열린 장대형 기록이다.

자료·조형 방향: KOREAN_CASTLE_REFERENCES.txt
치수·재료·칸별 입면: castle_highpoly.json
생성: Blender 5.2 background에서 build_castle_highpoly.py 실행.
열린 Blender 씬은 변경하지 않는다. StonegateHighPoly.blend 및 9개 FBX를 만든다.
FBX는 별도 폴더에서 전부 생성·검증한 뒤 Assets/08.Models/WorldCities/StonegateHighPoly에 복사한다.
기존 .meta를 보존한다. CASTLE_BUILD_COMPLETE를 확인한 뒤 Unity에서 적용한다.

적용: 돌등성 Edit Mode에서 apply_castle_highpoly.csx.
전용 재질과 Keep/Gate/Watch 프리팹을 동일 경로에 저장한다.
최초 적용은 기존 성 건물만 비활성화하고 HighPolyCastle 그룹을 만든다.
재적용은 기존 인스턴스의 프리팹을 갱신하며 새 그룹을 중복 생성하지 않는다.

충돌과 표시
- 본성 2층, 문루 2층, 망루 1층. 본성 처마 폭 38.64m, 기단 포함 높이 26.02m.
- 본성 LOD0/1/2: 906036 / 176820 / 15000 삼각형.
- 성문: 498144 / 101196 / 13820. 망루 한 곳: 137768 / 30444 / 6016.
- 재질별 합친 Renderer: 본성·성문 각 LOD 9개, 망루 7개.
- 기와는 메시, 물리는 별도 BoxCollider. 하층의 빈 기둥 사이는 막지 않는다.
- 본성 하층 접근은 NavMesh 검사 통과. 상층 이동용 내부 계단은 제작하지 않았다.
- NPC·도착점·포털 진행 계약, Terrain 높이, 기존 주택을 유지한다.
- 실제 보행·카메라·LOD 전환·성능은 Play Mode 직접 검증 대기다.

검증과 촬영
- ../validate_citadel.csx로 기존 Navigation.asset GUID를 보존해 재베이크한다.
- validate_castle_highpoly.csx의 output 경로를 작업 폴더로 지정해 Before/contracts.txt와 비교한다.
- CityEnvironment는 현재 씬 루트에서 찾는다. 다른 도시의 동일 이름 루트를 사용하지 않는다.
- capture_korean_castle.csx는 다른 깨끗한 도시 씬을 잠시 닫고 촬영 후 복원한다.
  씬 culling mask를 바꾸면 GPU Resident Drawer 일부 배치가 촬영에서 사라져 기존 마스크를 유지한다.
  최종 캡처는 기존 GPU Resident Drawer 설정으로 수행했다.
- output/StonegateKorean/REVIEW.html: 8개 시점 전후 비교.
- output/StonegateKorean/TESTS.txt: 검사 결과 및 사용자 직접 테스트 절차.
