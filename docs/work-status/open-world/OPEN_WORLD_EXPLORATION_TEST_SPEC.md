# 다섯 탐험 지역 사용자 테스트

회신: `U5-ID / 통과·실패·미수행 / 실제 결과 / 입력 장치·주야·날씨·슬롯 상태 / 화면 또는 로그`. 진행 성공과 Console 오류는 별도로 판정한다. 최초 길찾기는 위 좌표표를 보지 않고 수행한 뒤 실패 위치를 대조한다.

그늘숲 후속 검수는 [Iteration04 그늘숲 테스트](../../../output/OpenWorld/Exploration/Iteration04/RESULT.md)의 **F4-01~05**다. 빠른 시작은 **1700/740**에서 서쪽을 보는 상태다. 낮은 목재 흔적을 따라 1640/750 → 수로 1605/805로 들어가 마른 나무를 벌목하고, 장작 1개·나무 소진을 확인한 뒤 1650/855 → 빈터 1750/870으로 복귀한다. 본길 직진·역순·취소·파일 저장/재시작·전투 카메라는 각각 따로 판정한다. 자동 검사와 모션 실행 API 통과는 실제 입력 인수의 합격 근거가 아니다.

현재 그늘숲은 recipe 기반 **증분 적용** 상태이며 최종 Unity 전체 재생성은 미수행이다. 상세 상태 정책·동일 시점 화면·미검증 항목은 위 결과 문서를 따른다. 툴 런처의 현재 진입점은 **호수·여울마을 도보 연결**이다.

회랑 후속 변경은 [Iteration03의 C3-01~04](../../../output/OpenWorld/Exploration/Iteration03/RESULT.md)를 따른다. 첫 시작 위치는 650/478 → 뜰 650/532이며 서쪽 하단 책장 628/536에서 상층 서고로 이어지는 발견·복귀를 확인한다. 이번 배치에서 직접 입력·전투·파일 저장 재시작은 대기다.

최신 후속 변경은 [Iteration02의 T2-01~04](../../../output/OpenWorld/Exploration/Iteration02/RESULT.md)를 먼저 확인한다. 새 쉼터의 좌표는 수레 844/192, 보상 846/184다. Unity 재생성 완료를 확인한 뒤 테스트한다. 현재 코드의 런처 명칭은 **호수·여울마을 도보 연결**이다. 아래는 기존 전체 회귀 명세다.

대상: Unity 6000.3.21f1, `Assets/01.Scenes/Scenario/OpenWorld/LakeVillageWorld.unity`. 최종 생성·검사 시각과 알려진 실패는 [이번 결과](../../../output/OpenWorld/Exploration/RESULT.md)를 기준으로 한다. 아래 실제 입력 항목은 사용자 테스트 대기다. 과거 Expansion 검수는 재사용하지 않는다.

## 준비

툴 런처의 **호수·여울마을·돌등성·항구 도보 연결**로 시작한다. 기존 저장은 복사 슬롯에서 검사하고 원본 슬롯을 덮어쓰지 않는다. 새 게임 상태와 획득 전/후 복사 슬롯을 구분한다. 키보드·마우스와 게임패드를 각각 기록한다. 위치 확인은 [전체 위치도](../../../output/OpenWorld/Exploration/layout.svg)를 사용하되 첫 탐험의 방향 판단은 풍경으로 한다. 좌표는 월드 X/Z(m)이며 Y는 현재 지면을 따른다.

## 회신

`항목 ID / 통과·실패·미수행 / 실제 결과 / 시작 상태·슬롯 종류·입력 장치 / 좌표·진행 방향 / 화면 또는 Console 로그`

Editor 정지 촬영은 실제 Play Mode 화면과 구분한다. 기존 미니맵 배경은 확장 길을 반영하지 않으므로 길찾기 합격 근거로 사용하지 않는다. 커밋·Player·Addressables 빌드는 이번 검증에 포함하지 않는다.
