## 연결

1. P01의 B 또는 C `WorldPreview.unity`를 단독으로 연다. 기존 게임 월드에는 이 도구를 연결하지 않는다.
2. 툴 런처의 **월드 / 맵 → WorldBuilder 지형 저작**을 연다.
3. **현재 미리보기의 저작 정의 만들기/연결**을 누른다. `Assets/10.Datas/WorldBuilder/<worldGuid>_Authoring.asset`가 생성된다. 이미 있으면 GUID·원본 규격을 검사해 재사용한다.
4. 이후에는 같은 저작 정의를 창에 지정한다. 정의가 연결한 씬 GUID를 찾지 못하면 씬을 직접 열어야 한다. 다른 이름의 씬으로 자동 대체하지 않는다.

Base RAW와 P01 Source는 불변이다. 높이 편집은 명령·패치로, TerrainData는 재생성 가능한 결과로 저장한다. C는 2,048m/2049²/originY0/700m, B는 −80/480m를 유지한다.

## 명령 편집

- **표본 영역 X/Z/너비/높이**는 전역 격자의 반개방 영역이다. 높이는 2049² 표본, Hole은 2048² 셀이다. +X는 동, +Z는 북이다.
- **높이 더하기**는 m 단위 delta, **목표 고도 고정/평탄화**는 고정된 월드 고도를 사용한다. 매번 영역 평균을 다시 구하지 않는다.
- **Falloff**는 명령에 저장하는 마스크다. 0이면 전 영역, 양수면 사각 영역 가장자리에서 안쪽으로 부드럽게 증가한다.
- **Smooth**는 반경1~8, 반복1~16을 허용한다. 입력과 출력 버퍼를 분리하고 타일 경계를 넘는 이웃 표본을 읽는다.
- **HoleCut**은 true=표면인 셀에서 구멍을 낸다. 여러 cut은 합집합이다. 하나를 삭제해도 다른 cut은 유지된다. 기존 cut을 Sculpt로 덮어 복원하지 말고 소유 명령을 삭제한다.
- **자동 높이·Hole 연산 보호**는 자동 연산만 막는다. 수동 명령은 적용되며, 고도 범위 등 최종 안전 검사를 우회하지 않는다.
- 목록에서 명령을 활성/비활성하거나 삭제한다. Undo/Redo는 저작 명령을 되돌리고 지형을 재평가한다. TerrainData 네이티브 Undo만으로 복구했다고 가정하지 않는다.

영역 변경 시 이전/새 영역을 합쳐 Dirty로 기록한다. 변경 지형은 지역 평가하며, 누적 Smooth 반경을 읽기 halo로 포함한다. Height/Holes에서 재질·수계·배치·내비게이션·프록시로 Dirty를 전파하지만 P02가 그 후속 시스템을 구현한 것은 아니다.

## Sculpt

1. **Sculpt 시작**을 누른다. 현재 Final, sourceRevision, operationStackHash를 기록한다.
2. Unity 기본 Terrain 브러시로 수정한다. 원본 Base와 비교하는 것이 아니라 시작 시점 Final과의 차이를 캡처한다.
3. **Sculpt/미캡처 수정 캡처**를 누른다. 변경된 영역의 delta patch와 새 HoleCut이 저장되고, 네 타일 공유 모서리도 같은 전역 표본으로 동기화된다.
4. **명령에서 재생성** 후 수정이 유지되는지 확인한다. 기존 제약 위에 수정이 한 번만 적용돼야 한다.

편집 도중 원본·프로필·명령 스택이 바뀌면 충돌로 중단한다. 서로 다른 타일에서 같은 경계 표본을 다른 값으로 편집한 경우도 충돌이다. 미시작 수정은 마지막 정상 적용의 검증된 캐시에서 명시적으로 캡처할 수 있다. 캐시가 없거나 손상됐으면 자동 추정하지 않는다.

미캡처 지형 변경이 있으면 재생성과 Bake 입력 검사를 막는다. **미캡처 수정·세션 버리기**는 명시적으로 선택했을 때만 기록된 명령 결과로 복원한다. 이 버튼은 현재 미캡처 수정을 버린다.

## 외부 RAW 왕복

1. **세션 기준 RAW 내보내기**로 새 파일을 만든다. 동일 이름의 기존 파일을 덮어쓰지 않는다.
2. `.raw`와 옆의 `.raw.json`을 함께 보존한다. JSON에는 월드·원본 버전·스택·세션·export hash·규격이 있다.
3. 외부 편집기에서 **unsigned R16 little-endian, 첫 행 남쪽, 헤더 없음, 같은 해상도**를 유지한다. PNG·북쪽 첫 행 참조 RAW·컨셉 이미지는 입력으로 사용하지 않는다.
4. 같은 세션에서 **편집 RAW 가져오기**를 실행한다. JSON이 다른 월드·이전 세션·다른 규약이면 거절한다. 경로를 바꿨다면 같은 이름의 JSON도 함께 옮겨야 한다.
5. 기본은 내보낸 파일과의 Delta다. **RAW 변경 부분을 절대 높이로 캡처**를 켜면 달라진 표본만 Absolute patch로 저장한다. Final을 새 Base로 교체하지 않는다.

세션과 패치는 `Assets/WorldBuilder/Worlds/<worldGuid>/Authoring/`의 버전 있는 바이너리 자산이다. undo가 참조할 수 있으므로 사용 중인 패치를 지우지 않는다. 마지막 정상 적용의 물리 스냅샷은 `Library/WorldBuilder/<worldGuid>/Applied/`의 재생성 가능한 캐시다. 전체 적용 상태별 캐시가 커질 수 있으며 P02에서 대형 월드 편집 성능을 판정하지 않았다.

P02의 **Bake 입력 준비 검사**는 미캡처/원본/명령 입력만 검사한다. 실제 Bake·Published 전환·Nav·수계·런타임 준비 완료 판정은 P07 이후 범위다.
