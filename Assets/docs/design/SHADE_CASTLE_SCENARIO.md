# 그늘성 시나리오 — 다시 오가는 길

> 버전: 0.1 / 작성일: 2026-10-31 / 상태: **초안 — 신규 지역·인물·사건 제안, 구현 전**  
> 근거: [월드 확장 콘셉트](WORLD_EXPANSION_CONCEPT.md)의 그늘숲과 동양풍 툰 미술 기준.  
> 저작 기준: [플롯](../guide/STORY_PLOT_AUTHORING_GUIDE.md), [대사](game_dialogue_natural_korean_guide.md), [연출](ScenarioGameplay/08_PRESENTATION_DIRECTION.md), [콘텐츠](../guide/CONTENT_SYSTEM_AUTHORING_GUIDE.md), [전투](../guide/COMBAT_SYSTEM_AUTHORING_GUIDE.md).  
> 연결된 구현 명세: 없음. 씬·모델·텍스처·퀘스트 데이터는 이번 문서에서 생성하지 않는다.

그늘성은 **그늘숲 안에 제안하는 별개의 작은 산성**이다. 기존 돌등성(`StonegateCitadel`)의 개명이나 확장이 아니다. 그늘숲에 성이 있었다는 설정은 기존 문서의 확정 사실이 아니라 이번 제안이다. 신규 인물 이름과 과거사도 가칭이며 기존 플레이어블의 가족·출신 설정을 변경하지 않는다.

## 1. 언어 경계

플레이어에게 보이는 원고는 아래 퀘스트 표의 ‘표시 제목’과 ‘표시 목표’다. 나머지는 제작 설명이다. 장면 번호와 상태 이름은 개발용이며 화면에 표시하지 않는다.

| 내부 설명 | 플레이어에게 쓰는 말 |
|---|---|
| 지역 동선 복구 | 수레가 다닐 길을 연다 |
| 생태 통로 확보 | 짐승이 다닐 길을 비워 둔다 |
| 보스 조우 | 뒤뜰에 몰린 큰 짐승 |
| 수로 상태 전환 | 목재 수로를 다시 잇는다 |
| 귀환 지름길 해금 | 성 안쪽 문을 연다 |

NPC 외형은 아직 확인·선정하지 않았다. **이 문서에는 실행 대사를 싣지 않는다.** 모델·일러스트를 직접 확인하고 관계와 발화 동기가 포함된 `Voice Profile`을 작성한 뒤 별도로 대사를 저작한다.

## 2. 주제와 로그라인

**주제:** 지킨다는 것은 모든 길을 막는 일이 아니라, 서로 지나갈 자리를 남기는 일이다.

**로그라인:** 그늘숲으로 짐을 찾으러 간 여행자는 막힌 옛길 때문에 짐승들이 주민의 일터로 몰린 사실을 발견하고, 성을 다시 닫으려는 사람과 함께 다른 운송로를 열어 사람과 짐승이 서로를 덜 해치는 경계를 만든다.

### 공간과 경험의 제안

- **규모:** 도시 전체가 아닌 성문·아래 마당·수로 작업장·상부 망루·뒤뜰이 있는 산성 하나. 주 경로 약 40~55분, 선택 탐험 포함 약 60~75분을 목표로 검수한다. 실제 소요 시간은 미측정이다.
- **분위기:** 아래 마당은 주민이 창고와 수선장으로 사용하고, 위쪽 성벽과 뒤뜰은 오래 비어 있다. 전면 폐허도 번성한 왕성도 아니다.
- **용도:** 생활 거점에서 출발해 숲과 성의 안팎을 오가는 탐험·전투 지역. 상점·영입·공성전·성 경영을 필수 기능으로 요구하지 않는다.
- **대표 풍경:** 나뭇가지에 반쯤 가린 목조 망루 아래로, 성벽을 가로지르는 낡은 목재 수로가 보인다. 귀환 때는 같은 수로 옆에서 주민이 짐을 옮긴다.

## 3. 세계의 규칙

### 공간과 사건의 규칙

| 규칙 | 먼저 보이는 증거 | 끝까지 유지할 한계 |
|---|---|---|
| 그늘성은 옛 운송길을 지키던 산성이다 | 군사 공간을 고쳐 쓴 창고, 수선한 성문, 비어 있는 상부 | 사라진 제국·신앙의 중심지로 확대하지 않는다 |
| 새 벌목장과 적치 목재가 낮은 숲길을 막았다 | 새 그루터기, 목재 더미 앞에서 꺾이는 발자국 | 짐승을 조종하는 흑막이나 숲의 저주로 뒤집지 않는다 |
| 짐승은 남은 마른 길인 작업장 쪽으로 우회한다 | 같은 크기의 발자국이 숲길과 작업장에 이어진다 | 성문을 닫아도 성 바깥 일터의 위험은 사라지지 않는다 |
| 높은 옛 운송길을 쓰면 낮은 길을 비울 수 있다 | 망루에서 이어지는 성벽길과 낡은 운반 흔적 | 대형 짐은 수선 뒤 주민이 나른다. 플레이어에게 운반 시뮬레이션을 요구하지 않는다 |
| 수로와 통로는 사람의 작업으로 회복한다 | 먼저 놓인 받침과 수선 도구, 이후 이어진 수로 | 승리 순간 무너진 성벽과 베인 숲이 모두 복구되지 않는다 |

### 진행의 보존과 초기화 제안

그늘성은 호수 본편 이후의 지역 사건으로 제안한다. 지역 시간 회귀를 추가하지 않는다. 아래는 신규 진행 계약의 제안이며 실제 저장 지원을 확인한 기록이 아니다.

| 대상 | 사망·이탈·저장/로드·재방문 | 새 게임 |
|---|---|---|
| 발견한 흔적과 조사 사실 | 확정된 조사 유지, 재조사 가능 | 초기화 |
| 열린 안쪽 문과 수선 완료 | 완료 사실 유지, 길과 충돌 상태 재구성 | 초기화 |
| 필수 조우의 승리 | 유지, 미완료 후속 작업부터 재개 | 초기화 |
| 낮은 길을 비운 사실 | 유지, 적치물과 주민 배치도 동일 사실로 복원 | 초기화 |
| 지역 결말과 일회성 보상 | 유지, 중복 지급 금지 | 초기화 |
| 선택 탐험 보상 | 기존 아이템·상자 저장 정책에 연결 | 기존 정책 |
| 진행 중 전투·조작·카메라·임시 대역 | 완료 처리하지 않고 해제, 안전한 위치에서 재시도 | 초기화 |
| 일반 숲 적·채취물 | 기존 재등장 정책 적용, 퀘스트 결과는 되돌리지 않음 | 기존 정책 |

별도 회차 기능이 이 지역을 다루게 된다면 저장 경계를 먼저 확정한다. 기존 사이클 문서의 리셋 예시를 그대로 적용하지 않는다.

## 4. 인과 사슬

1. 숲 작업장의 운송이 끊겨 주문한 짐이 도착하지 않는다. 그래서 여행자가 그늘성 아래 마당으로 찾아간다.
2. 작업장으로 향하던 수레가 짐승에게 막혔다. 그래서 가까운 일터의 위험을 정리하고 바퀴 자국을 따라간다.
3. 짐승의 발자국은 새 벌목장 앞에서 돌아 나와 수레길로 겹친다. 그래서 단순히 성문을 닫자는 방안으로는 바깥 일터를 지킬 수 없다는 사실을 확인한다.
4. 낮은 길을 막은 목재를 치우면 당장 겨울 땔감과 운송 짐을 둘 곳이 없다. 그래서 망루에서 보였던 높은 옛 운송길을 살핀다.
5. 높은 길은 성 안쪽 문으로 아래 마당에 이어지지만 끊어진 수로 받침과 방치된 위험 때문에 쓸 수 없다. 그래서 문을 먼저 열고 수선할 작업 공간을 확보한다.
6. 짐을 옮길 다른 길이 생기므로 주민이 목재 이동을 시작한다. 하지만 뒤뜰의 큰 짐승이 통로 가까이에 남아 있어 마지막 구간에 접근하지 못한다.
7. 여행자가 뒤뜰의 큰 짐승을 쓰러뜨리고 작업 구역의 안전을 확인한다. 그래서 주민이 남은 목재를 높은 길로 옮기고 낮은 숲길을 비운다.
8. 짐승의 이동 흔적이 낮은 길로 돌아가고 수레는 높은 길로 다닌다. 그래서 처음의 마당은 문을 굳게 닫는 곳에서 서로 다른 길을 내주는 곳으로 바뀐다.

큰 짐승을 쓰러뜨리는 일은 마지막 작업을 가능하게 할 뿐이다. 적치물을 옮기지 않으면 처음 문제가 해결되지 않는다는 인과를 결말에서 반드시 보여준다.

## 5. 전체 플롯

### S01. 문 아래에서 멈춘 수레 — 도입 / 5~7분

성문 앞에는 들어오지 못한 수레가 서 있고 아래 마당에서는 남은 목재를 작은 묶음으로 나누고 있다. 길을 닫자고 주장하는 **도윤**도 쉬지 않고 짐을 옮긴다. 두려움 때문에 일을 남에게 떠넘기는 사람으로 소개하지 않는다.

여행자는 가까운 작업장의 위험을 정리한다. 첫 조우는 넓은 공터에서 기존 소형 적 소수와 맞붙는 구성으로 제안한다. 싸움이 끝난 뒤 수레 아래의 발자국이 숲 쪽 길로 이어지는 것을 발견한다. 새 정보는 ‘짐승이 일터로 들어오는 길이 있다’ 하나다.

### S02. 발자국이 돌아온 자리 — 전환 / 7~10분

수로를 손보던 **나래**의 작업 흔적을 따라 새 벌목장으로 간다. 목재 더미 앞에서 발자국이 꺾이고, 닫힌 짐승길 옆에 수레길이 보인다. 나래는 버려진 짐을 가지런히 묶어 사람이 다시 쓸 수 있게 둔다. 숲을 위해 주민의 생계를 포기하라고 요구하는 인물로 만들지 않는다.

낮은 길을 비워야 한다는 필요와 옮길 자리가 없다는 제약을 같은 시야에서 보여준다. 돌아가는 길에 수관 사이로 높은 성벽길이 드러나 다음 탐험의 목적지가 된다.

### S03. 쓰지 않던 성벽길 — 확인 / 10~13분

수로 옆의 마른 보행로로 상부에 오른다. 수영·벽타기·갈고리 없이 이동할 수 있어야 한다. 두 번째 조우는 근접 적과 거리를 벌리는 적의 조합으로, 수로 받침을 엄폐·우회에 쓰게 한다. 좁은 성벽 위에서 다수전을 시키지 않는다.

망루에서 출발한 마당과 낮은 숲길을 함께 본다. 옛 운송길은 막다른 장식이 아니라 성 안쪽 문으로 실제 연결된다. 플레이어가 문을 열면 아래 마당까지의 귀환이 짧아진다. 같은 길을 전투로 채워 두 번 걷게 하지 않는다.

### S04. 옮길 자리가 생기다 — 전복 / 5~7분

주민은 열린 길로 도구와 빈 짐틀을 가져온다. 도윤은 자신이 박아 둔 폐쇄용 가로대를 빼서 수로 받침에 쓴다. 의견이 바뀌는 이유를 긴 사과 대신 실제 작업으로 보여준다.

수선은 안전한 작업장 상호작용 후 준비된 전후 배치로 표현한다. 무의미한 재료 수집을 끼우지 않는다. 높은 길이 이어지자 뒤뜰의 큰 짐승과 막힌 마지막 작업 구간이 보인다. 첫 구간의 발자국과 긁힌 목재가 이 짐승의 크기를 미리 예고해야 한다.

### S05. 뒤뜰의 큰 짐승 — 절정 / 8~10분

넓은 뒤뜰에서 단일 큰 적과 전투한다. 종과 실제 에셋은 미선정이며, 대응 모션과 GAS 연결이 정상인 기존 지상 적을 우선 검토한다. 정체를 감추던 성의 주인이나 저주받은 수호자로 만들지 않는다.

핵심은 앞서 배운 옆으로 비키기와 거리 조절이다. 몸을 낮춘 준비 자세 → 직선 돌진 → 빗나간 뒤 멈춤, 넓은 휘두르기 → 사거리 밖으로 빠짐 → 빈틈의 대비를 제안한다. 실제 모션이 없으면 이 패턴을 구현 완료로 간주하거나 임의 판정으로 대신하지 않는다.

전투 중 수문 조작·NPC 호위·시간제한·잡몹 증원을 동시에 요구하지 않는다. 쓰러뜨린 뒤에도 낮은 길을 막은 목재는 그대로 남아 있어 마지막 할 일이 명확해야 한다.

### S06. 같은 성문, 다른 길 — 결말 / 5~8분

안전을 확인한 뒤 주민이 마지막 목재를 옮긴다. 낮은 길의 적치물이 사라지고 높은 길 옆에는 운송 짐이 놓인다. 이동 작업 전후는 사전 배치로 전환할 수 있으며, 실시간 대규모 운반 AI는 요구하지 않는다.

처음 멈춰 있던 수레가 마당으로 들어온다. 도윤은 남은 가로대를 다시 문에 끼우지 않고 작업장에 내려놓는다. 나래는 사람이 쓰는 높은 길 쪽에만 새 안내 천을 묶는다. 짐승길에는 사람을 부르는 안내를 두지 않는다.

낮은 길의 먼 발자국과 움직임은 생활권 밖 배경 표현으로 끝낸다. 결말 촬영을 위해 중립 짐승 AI를 새로 요구하지 않는다. 숲의 위험이 사라졌다고 선언하지 않고, 수레와 짐승의 길이 달라졌음을 보여준다. 마지막 장소는 첫 수레를 보았던 성문이다.

## 7. 퀘스트 라인

| 번호 | 표시 제목 | 표시 목표 | 내부 완료 기준 |
|---|---|---|---|
| Q01 | 멈춰 선 수레 | 작업장으로 가는 길을 살핀다 | 작업장 도달과 필수 첫 조우 해결. 선행 승리 인정 |
| Q02 | 돌아온 발자국 | 발자국이 이어진 곳을 찾는다 | 목재 더미와 우회 흔적의 조사 완료. 임의 처치 수 요구 없음 |
| Q03 | 성 위의 옛길 | 성 안쪽 문을 연다 | 상부 경로 확인과 실제 문 개방. 열린 문 상태 저장 |
| Q04 | 짐을 옮길 자리 | 수로를 고칠 자리를 마련한다 | 작업 구역 안전과 수선 상호작용 완료. 재료 소모 없음 |
| Q05 | 비워 둘 길 | 뒤뜰에 몰린 큰 짐승을 쓰러뜨린다 | 실제 전투 승리. 연출 스킵으로 승리 처리 금지 |
| Q06 | 다시 오가는 길 | 도윤과 함께 옮긴 짐을 확인한다 | 목재 이전·통로 상태 반영 후 마무리 장면 정상 종료. 명시적 스킵은 동일 결과 적용 |

보상은 **연결된 안쪽 문과 안전해진 작업 동선**을 먼저 체감하게 한다. 수치 보상은 현재 소비처가 있는 기존 재화·재료에서 선정한다. 전용 화폐와 소비처 없는 증표는 추가하지 않는다. 지급은 지역 완료의 단일 경로가 소유하며 재입장·재대화에서 반복하지 않는다.

선택 탐험은 두 곳으로 제한해 시작한다. 망루 옆 창고는 위험을 감수한 짧은 우회의 기존 보상, 수로 아래 옛 쉼터는 성의 생활 흔적과 조용한 조망을 제공한다. 선택 보상을 얻지 않아도 본 이야기가 닫힌다.

## 8. 인물 역할

| 인물 | 왜 여기 있는가 | 왜 여행자와 부딪히는가 | 왜 남거나 떠나는가 | 다음에 기억하는 것 |
|---|---|---|---|---|
| 도윤 — 가칭, 운송 작업 책임자 | 겨울 전에 목재와 맡은 짐을 내보내야 한다 | 성문을 닫으면 안의 사람은 지킬 수 있다고 믿고, 상부 수선에 사람을 빼는 일을 꺼린다 | 다른 운송길이 열린 뒤 자기 짐부터 옮기며 현장에 남는다 | 여행자가 일터의 위험을 줄이고 운송을 실제로 이어 준 사실 |
| 나래 — 가칭, 수로 수선공 | 막힌 낮은 길과 끊어진 수로를 함께 살펴 왔다 | 낮은 길을 비워야 한다고 주장하지만 목재를 둘 현실적인 자리를 아직 제시하지 못한다 | 높은 길 수선을 맡고, 숲 안쪽에는 사람용 안내를 걷는다 | 자신의 관찰이 실제 길 수선에 쓰였다는 경험 |
| 여행자 — 기존 서사 주인공 | 도착하지 않은 짐을 찾으러 왔다. 배달·주문 연결은 후속 확정 | 당장 짐만 받아 나가려 해도 같은 길의 위험을 피할 수 없다 | 운송이 재개되면 떠날 수 있고, 짧아진 길로 재방문할 수 있다 | 위험의 원인과 눈앞의 적을 구분한 경험 |

도윤의 만족 조건은 사람이 다치지 않고 겨울 물자를 내보내는 것이다. 나래의 만족 조건은 낮은 길을 비우면서 주민의 일을 이어 가는 것이다. 둘은 같은 결과에 서로 다른 이유로 동의한다. 사람 간 충돌은 처치해야 하는 적대 세력으로 확대하지 않는다.

큰 짐승의 생태적 동기는 막힌 길을 우회해 마른 공간을 확보하는 것이다. 사람처럼 교섭·기억하는 인격을 부여하지 않는다. 새 동료 영입이나 기존 플레이어블의 고정 대사를 사건 성립 조건으로 두지 않는다.

## 9. 이번 단계와 다음 단계

### 이번 문서가 정하는 것

그늘숲과 성의 관계, 생활과 폐허의 비율, 여섯 구간의 사건 인과, 두 주민의 사정, 퀘스트 표시 문구, 진행 보존 원칙을 제안한다. 원본 월드 콘셉트의 확정 상태를 승격하지 않는다.

### 공간 제작 방향

주 경로는 **숲 진입 → 성문·아래 마당 → 낮은 벌목길 → 수로 옆 오르막 → 망루 → 안쪽 문 → 수선장 → 뒤뜰 → 아래 마당**이다. 망루에서 앞서 지난 길을 내려다보고, 안쪽 문으로 원래 장소에 돌아오는 순환을 우선한다.

| 영역 | 제작 기준 |
|---|---|
| 건축 | 낮은 석축, 짙은 목재, 소박한 기와·널 지붕. 호수의 동양풍 툰 문법 유지 |
| 돌등성과 구별 | 도시·본성의 거대한 위용 대신 수관에 묻힌 작은 망루, 덧댄 작업장과 목재 수로 강조 |
| 빛과 색 | 짙은 녹색 그늘, 젖은 회청 석재, 햇빛 드는 작업 빈터. 사실풍 노이즈로 면을 채우지 않음 |
| 모듈 후보 | 직선·경사 석축, 성문, 소형 망루, 목조 작업장, 수로 직선·굽이·받침, 작업 발판, 목재 더미 |
| 기존 자산 우선 | 바위·식생·수레·도구·주택 몸체는 실제 재고 조사 후 재사용. 조사 전 신규 제작량 확정 금지 |
| 전투 공간 | 뒤뜰은 큰 적 전신과 회피 방향이 보이는 육상 공터. 식생과 기둥이 예고 동작을 가리지 않음 |

씬 내부 후보명은 `ShadeCastleScenario`다. 아직 생성·등록하지 않았으며, 그늘숲 전체를 같은 씬에 담을지는 기존 월드 연결과 실제 보행·성능 조사 후 정한다. 지명과 씬 ID를 혼동하지 않는다.

### 다음 제작 순서

1. 기존 월드·씬·자산 재고와 두 NPC 외형 후보를 조사하고, 연결 위치와 구현 명세를 작성한다.
2. 아래 마당 → 수로 오르막 → 안쪽 문까지 회색 상자 배치로 만든다. 돌아왔을 때 지름길을 이해하는지 먼저 확인한다.
3. 첫 조우와 문 개방을 진행·저장·취소까지 완성한 뒤 뒤뜰 전투를 확장한다.
4. 실제 모델·일러스트에 맞춘 말투와 장면 카드를 작성한다. 필요한 모델·텍스처는 조달 수단을 확인한 뒤 제작한다.
5. 전후 환경 상태와 재방문을 붙이고, 직접 플레이에서 가독성·전투 감각·진행 복구를 확인한다.

Blender 연결과 이미지 생성은 아트 제작 단계의 의존성이다. 현재 연결·도구 사용 가능 여부는 이 문서에서 확인한 것으로 기록하지 않는다.

## 10. 구현 경계와 검수

### 시스템 소유와 장면 복구

퀘스트는 목표, `FlowGraph`는 사건 순서와 결과 적용, `DialogueGraph`는 대화, 공용 진행 사실은 기존 저장 계약이 소유한다. 같은 결과를 트리거와 흐름 그래프 양쪽에서 중복 실행하지 않는다. 기존 ID·GUID를 보존한다.

상부 문 개방·조사·승리·수선·목재 이전·마무리를 각각 독립된 사실로 제안한다. 앞 단계 안내를 못 봤더라도 이미 발생한 사실을 인정한다. 단, 수선은 실제 접근 가능한 작업장과 안전 조건, 목재 이전은 운송로 수선과 뒤뜰 승리를 요구한다. 큰 짐승을 먼저 쓰러뜨렸다면 후속 공개 시 전투를 반복시키지 않는다.

| 상황 | 처리 계약 |
|---|---|
| 장면 정상 종료·명시적 스킵 | 해당 장면 결과만 1회 확정. 미발생 전투·미수선 작업 대신 완료 금지 |
| 취소·피격·사망·씬 이탈 | 미완료 장면은 재시도. 임시 입력 잠금·카메라·대역·소품 해제 |
| 문 개방 직후 로드 | 열린 문과 통행 가능 충돌 상태 일치 |
| 승리 후 작업 전 로드 | 큰 적 재전투 없이 목재 이전부터 재개 |
| 목재 이전 중 종료 | 이전 완료 사실을 기준으로 전후 배치 중 하나로 복원. 반쯤 막힌 통로 방치 금지 |
| 결말 후 재방문 | 수레길·비운 낮은 길·주민 작업 위치 유지. 필수 전투와 보상 재실행 금지 |

카메라는 탐험 중 강제 회전하지 않는다. 망루 조망은 플레이어가 직접 발견할 수 있는 구도로 시작한다. 짧은 결말 장면은 안전 확보 후 실행하며 취소와 스킵에서도 기존 플레이 카메라·입력으로 돌아온다. 장면별 실제 좌표·모션·음원·ID·GUID는 구현 명세에서 기록한다.

전투 판단은 `BT`, 피해·비용·공격 구성은 `GAS`, 예고·타격·캔슬 시점은 `MotionSet`에 둔다. 기존 공격의 실제 모션을 확인하기 전 예고 길이와 피해 수치를 확정하지 않는다. 히트스톱 중복 누적·선입력 유실·카메라 흔들림 감소 시 가독성을 함께 검수한다.

### 문서 검토와 구현 후 합격 기준

문서 단계에서 인과, 기존 그늘숲 주제와의 일치, 플레이어 표시 문구, 미확정 설정 구분을 검토한다. 아래 플레이 항목은 **구현 후 사용자 테스트 대기**이며 지금 실행할 수 있는 테스트가 아니다.

| 항목 | 실행할 확인 | 합격 기준 |
|---|---|---|
| V01 목표 이해 | 각 구간 끝에서 다음 행동을 말한다 | 설정 용어 없이 목적과 갈 곳을 설명 가능 |
| V02 동선 | 망루에서 아래 마당으로 돌아온다 | 같은 장소를 알아보고 열린 문이 이동을 줄였음을 체감 |
| V03 역순 | 흔적 선행 조사·안쪽 문 선행 개방·큰 적 선행 처치 후 진행 | 사실 누락·재전투·진행 불능 없음 |
| V04 저장 | 문 개방, 승리, 목재 이전 전후, 결말 후 각각 저장/로드 | 공간·진행 일치, 보상 중복 없음 |
| V05 중단 | 수선·마무리 장면의 취소·스킵·이탈 | 입력·카메라 복원, 안전한 재시도, 미완료 사실 보존 |
| V06 전투 | 패드와 키보드로 뒤뜰 전투, 흔들림 감소 상태 확인 | 전신·공격 예고·퇴로 식별, 회피·가드·캔슬 반응 확인 |
| V07 결과 | 결말 직후와 재방문 때 성문·양쪽 길 비교 | 무엇을 옮겼고 무엇을 비웠는지 화면만으로 파악 |

직접 테스트 준비물은 신규 씬과 진입 경로, 별도 테스트 저장 슬롯, 키보드·마우스와 게임패드다. 구현 시 실제 씬·시작점·저장 준비 절차를 명세에 채운다. 결과는 `항목 ID / 통과·실패·미수행 / 실제 결과 / 화면·로그`로 기록한다. 런타임 오류와 플레이 경험은 따로 판정한다.

**현재 검증 범위:** 문서 내용·상대 링크·변경 내역의 정적 확인. Unity 컴파일·EditMode·Play Mode·Player 빌드와 아트 실물 검수는 미수행이며, 문서 작성으로 구현 완료를 선언하지 않는다.
