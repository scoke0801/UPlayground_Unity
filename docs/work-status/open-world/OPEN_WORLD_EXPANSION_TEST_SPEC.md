# 세계관 지도 기반 확장 월드 검수

대상은 `Assets/01.Scenes/Scenario/OpenWorld/LakeVillageWorld.unity`다. **아래 플레이 항목은 사용자 테스트 대기**다. 이전 재설계의 905m 입력 이동 결과는 이번 확장 지형의 검증 결과가 아니다.

## 준비

Unity 6000.3.21f1의 툴 런처에서 **호수·여울마을·돌등성·항구 도보 연결**로 시작한다. 기존 저장은 복사 슬롯에서만 검사하고 원본 슬롯을 덮어쓰지 않는다. 키보드/마우스와 게임패드를 각각 기록한다. [배치도](../../../output/OpenWorld/Expansion/layout.svg)는 진행자가 좌표를 찾는 용도로만 사용하고, 첫 탐험에서는 지도를 계속 보지 않는다.

이번 배치에서 성채 중심은 약 `(580,62,100)`, 항구 중심은 약 `(1920,50,-280)`이다. 기존 호수·여울마을 생활권은 유지했다. 성채는 서쪽, 항구는 남동쪽으로 떨어져 있다. 성채·항구의 논리 지역과 콘텐츠 ID는 그대로이며, 생성 월드에 적용하는 좌표 변환만 바뀌었다.

## 실행 항목

| ID | 동선·조작 | 기대 결과 / 실패 기준 |
|---|---|---|

| EXP-02 | `(740,68,300)`에서 북서쪽 갈림길 → 돌등 고개 `(450,130,760)` → 고원 `(1040,190,1410)` | 산기슭에서 고원으로 올라가는 고도감과 조망 변화가 있다. 대시·점프 후 접지, 카메라 가림과 급격한 도로 턱을 확인한다. |

| EXP-06 | 길가의 수레·작업 흔적·갈대 둔치를 자유롭게 살펴본 뒤 길로 복귀 | 길 밖을 잠깐 탐색하고 스스로 돌아올 수 있다. 불필요한 막다른 지형, 의미 없는 소품 반복, 방향 상실 구간은 위치와 함께 기록한다. |

## 알려진 제한

- 돌등 고개 `(740,68,300)` → `(800,180,1230)`의 장거리 NavMesh 조회가 부분 경로다. 연속 선분 83개는 연결되지만 이 장거리 AI 이동은 미해결이다.
- 미니맵 배경은 기존 지역 이미지다. 확장 길의 안내에 사용하면 맞지 않는다. 이번 결과의 별도 배치도·조감도와 구분한다.
- 2.4 × 2.8km는 산지·해수면까지 포함한 Terrain 범위다. 전 영역이 완성된 탐험 콘텐츠라는 뜻이 아니다.
- 호수 원형과 기존 진행을 보존했다. 새 퀘스트·NPC 마을·던전·채집 보상은 추가하지 않았다.
- Editor 고정 화면과 NavMesh/지형 표본은 실제 플레이 인수를 대신하지 않는다. 커밋과 Player/Addressables 빌드는 별도 지시 없이 수행하지 않는다.

회신 형식: `EXP-ID / 통과·실패·미수행 / 실제 결과 / 시작 상태·입력 장치 / 좌표 또는 화면·로그`. 실패 시에는 발생한 방향, 시간대, 저장 슬롯 종류까지 적는다.
