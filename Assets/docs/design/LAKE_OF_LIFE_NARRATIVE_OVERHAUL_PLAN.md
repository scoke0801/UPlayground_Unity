# 생명의 호수 스토리 모드 대화와 진행 전면 개편 기획

## 0 문서 상태와 현재 진단

버전 0.1 / 작성일 2026-10-09 / 상태 **초안** / 대상 생명의 호수 제1장과 연결된 지역 대화.

**개편의 중심은 인물이 말하는 이유를 다시 만드는 것이다.** 현재 문장은 이전보다 구어체에 가까워졌지만, 장면의 상당 부분은 여전히 정보를 확인하고 다음 목적지를 지시하는 데 쓰인다. 동료를 만날수록 대화의 인원은 늘어나는데 관계가 깊어졌다는 경험은 부족하다. 어미를 바꾸는 작업으로는 해결되지 않는다.

이 기획은 현재 실행 데이터의 문제 진단과 후속 제작안을 구분한다. 아래 개작 대사와 장면은 모두 제안이며 세계관 확정이나 에셋 적용을 뜻하지 않는다. 분석 범위는 실제 확인한 제1장이다. 제2장 이후와 전체 게임 서사를 분석했다고 간주하지 않는다.

- `MapConfigDatabase`에는 `LakeOfLife`와 `LakeOfLifeScenario`가 함께 있으며 기본 시작 맵은 `LakeOfLife`다. 작업 중인 시나리오 맵의 지형과 기존 맵의 길 안내를 같다고 가정하지 않는다.
- 상위 가이드가 연결한 `Assets/docs/cycle/CYCLE_STORY_PLOT.md`는 현재 경로에 없다. 레거시 사이클 설정을 제1장에 임의로 복원하지 않는다.

분석은 문서·직렬화 데이터·그래프 연결을 읽은 결과다. 이번 작업에서 Unity 수동 완주, 실제 음성 리듬, 카메라 시야, 이동 시간은 검증하지 않았다. 이전 [검증 기록](../../../docs/reviews/LAKE_NARRATIVE_REVISION_REPORT.md)의 자동 테스트 성공도 서사 체감의 합격을 뜻하지 않는다.

### 0.2 현재 진행과 플레이 경험

| 현재 순서 | 데이터상 진행 | 서사적 평가 |
|---|---|---|
| 오프닝과 안내인 | 보물 소문 → 신전 길 질문 → 숲길 진입 | 목적지는 알지만 원하는 것이 계속 추상적으로만 제시된다 |
| 붉은 천과 화린 | 천 조사 → 공동 전투 → 헤어진 리안 수색과 합류 | 구체적인 사람이 목표가 되어 처음으로 감정이 붙는 구간 |
| 리안 | 천 조각 확인 → 전투 → 재회 → 끌린 자국 조사 | 재회의 여운이 끝나기도 전에 다음 단서 설명으로 전환된다 |
| 묘령 | 흔적 조사 → 같은 얼굴이라는 오인 → 전투 → 사과와 합류 | 해명 시간이 충분한데도 싸워야 하는 이유가 약하다 |
| 신전 | 도착 대화 → 수호자 → 내부 진입 → 발자국 → 같은 얼굴의 상대 | 단서가 같은 사실을 여러 번 예고해 마지막 공개의 여지가 줄어든다 |
| 결말 | 상대의 마지막 말 → 일행의 반응 → 제1장 종료 | 확인한 사실보다 모른다는 말이 앞서며, 관계의 변화가 약하게 닫힌다 |
| 선택 곁가지 | 미아·준, 약초, 등불, 수레, 주민 대화 | 생활 이야기가 가능하지만 상당수가 같은 위험의 증언으로 수렴한다 |

### 0.3 실제 문안에 근거한 문제

인용 뒤 괄호는 해당 대화 에셋의 `nodeId`다. 문장이 존재하는 것과 플레이 중 호출되는 것은 구분한다.

| 문제 | 현행 근거 | 고쳐야 할 장면 기능 |
|---|---|---|
| 재회가 설명의 발판이 됨 | 리안: “쉬기 전에 이것 좀 봐 줘. 괴물 발자국 사이에 길게 파인 자국이 있어.” (`DLG_Test_LianRescue`, `dlg_test_lian_rescue_06`) | 방금 찾은 친구보다 흔적을 먼저 설명하게 만드는 배치를 바꾼다. 재회와 조사 사이에 실제 이동과 정리 시간을 둔다 |
| 다음 행동을 여러 사람이 승인함 | “앞에 사람이 있어.” → “지나가는 걸 봤을지도 몰라.” → “물어보자.” (`DLG_Lake_DragTracks`, `_03`~`_05`) | 사람을 보고 접근하는 단순 행동을 세 번의 대사 진행으로 나누지 않는다 |
| 질문이 다음 문장의 재생 버튼임 | “이 발자국 좀 봐.” → “왜?” → “네 신발 자국이랑 같아.” (`DLG_Lake_ShrineTreasure`, `_04`~`_06`) | 먼저 발자국을 보여주고 인물이 확인하게 한다. 의미 없는 질문은 삭제한다 |
| 갈등을 대사로 진정시킨 뒤 전투를 강제함 | “알겠어. 여기서 얘기하자.” 이후 “움직이지 말랬지!” (`DLG_Test_MyoRyeongConfrontation`, `_11`, `_16`) | 플레이어가 공격을 피할 태도를 보였는데 왜 싸움이 나는지 행동 원인이 필요하다 |
| 패배가 오해 해소의 증거처럼 작동함 | “내가 졌어. 칼 내릴게.” → 사과 (`DLG_Test_MyoRyeongJoined`, `_01`~`_03`) | 힘의 우열과 인물의 동일성은 별개다. 주인공의 행동에서 다른 사람일 근거를 얻어야 한다 |
| 가장 큰 사건을 관찰 보고로 닫음 | “자국도 여기서 끊겼어. 더는 안 보여.”, “왜 나랑 같은 모습이었을까.”, “나도 모르겠어.” (`DLG_Lake_AlternateSelfVictory`, `_04`, `_06`, `_07`) | 추적 결과와 미해결 질문의 낭독을 줄이고, 공격받던 주인공을 동료들이 어떻게 대하는지 보여준다 |
| 주민과의 관계에 따라 높임말이 일관되지 않음 | 안내인에게 “길 좀 물어봐도 될까요?”, 헤이즐에게 “어디가 안 좋은데?”, 조안 재방문에서 “나랑 똑같이 생긴 사람이 있었어.” | 초면 주민에게 존댓말을 기본으로 하고, 반말 전환에는 관계 근거를 둔다. 화린의 반말을 전 주민에게 복제하지 않는다 |
| 조사자가 근거보다 강한 결론을 말함 | “짐승들은 수레보다 호수에서 도망치는 데 급했던 것 같아.” (`DLG_Npc_Morgan`, `morgan_report_04`) | 현장에서 확인한 것과 추측을 나눈다. 짐과 발자국만으로 도주 원인을 확정하지 않는다 |

묘령 대치 그래프에는 시작점에서 도달하는 `Talk` 노드가 16개다. 중간 `_13`, `_17`은 `Event` 노드이며 `eventActions`와 모션 ID가 비어 있다. 대화 에셋 자체에서는 급격한 행동 전환을 뒷받침하는 연출이 확인되지 않는다. 외부 연출 유무와 실제 화면은 별도 검증 대상이다.

반대로 삭제할 이유가 없는 부분도 있다. 화린의 “난 괜찮아. 그런데 같이 오던 친구가 안 보여.”는 지금 말을 꺼낼 사정이 있다. 준이 짐을 포기하고 돌아가기로 하는 선택은 생활의 무게를 만들 수 있다. 안내인에게 주인공이 먼저 길을 묻는 순서, 합류를 한 대화에서 마치는 v3 개선도 유지한다.

## 1 언어 경계와 개작 원칙

플레이어 노출 대사·목표에는 이름, 사람, 길, 천, 짐, 신전처럼 상황을 가리키는 말을 쓴다. `Flow`, `Flag`, `Variant`, `영입 단계`는 제작 설명에서만 사용한다. `다른 가능성의 자신`은 내부 가칭이며 등장인물이 아는 정체가 아니다.

어미 일괄 치환은 하지 않는다. “왜?”, “괜찮아?”, “가자”도 실제 의도가 있으면 필요하다. 문제는 질문이나 짧은 말 자체가 아니라, 상대에게 영향을 주지 않고 설명만 이어 주는 사용이다.

원고는 각 발화를 **부탁한다, 거절한다, 안심시킨다, 시간을 번다, 확인한다** 중 어떤 행동인지 설명할 수 있어야 한다. 아무 기능도 없는 맞장구를 삭제하되, 망설임이나 사과를 받아들이는 응답까지 없애지 않는다. 모든 인물이 짧고 무뚝뚝하게 말하는 또 다른 획일화를 피한다.

필드에서 보이는 사실은 이동을 유지하며 처리한다. 대화 화면으로 멈추는 이유는 동행 결정, 충돌, 관계 변화처럼 인물에게 집중해야 할 때로 한정한다. 단서가 작거나 카메라 밖이라면 먼저 시인성을 고친다. 보이지 않는 단서를 대사 삭제만으로 전달하려 하지 않는다.

## 2 주제와 로그라인

**주제:** 낯선 사람을 믿게 되는 순간은 함께 위험을 지나온 뒤의 작은 행동에 있다.

**로그라인:** 보물을 찾아 호수에 온 여행자가 헤어진 두 사람의 재회를 돕고, 자신을 공격자로 기억하는 사람과 함께 신전에 들어가 같은 얼굴의 상대를 마주한다.

제1장의 감정 목표는 “보물의 원리를 알았다”가 아니라 “처음에는 혼자였는데, 마지막에는 내 편이 생겼다”다. 보물과 같은 얼굴의 존재는 이 관계가 필요한 위기를 만든다. 주인공의 구체적인 소원은 공개하지 않되, 원한다는 선언을 여러 번 반복하지 않는다.

## 3 세계의 규칙과 정보 공개

| 구분 | 유지할 규칙 |
|---|---|
| 저장하고 다시 시작할 때 | 완료된 대화·동료 합류·퀘스트 진행을 유지한다 |
| 새 게임 | 제1장 진행을 초기화한다 |
| 대화 중단 | 정상 종료 이전의 완료·합류를 임의 확정하지 않고 안전한 단계로 복구한다 |
| 사실 | 보물 소문이 있다. 묘령은 같은 얼굴의 공격자를 보았다고 말한다. 신전에서 닮은 상대를 마주한다 |
| 증언과 추측 | 묘령의 기억, 흔적의 주인, 소문이 사실인지에 대한 판단은 사실과 분리한다 |
| 미확정 | 보물의 작동 원리, 상대의 본질, 주인공의 소원, 이상이 시작된 최종 원인 |
| 새로 넣지 않을 설명 | 기억상실, 새로운 평행세계 규칙, 감시자, 주인공을 평가하는 시험 |

묘령이 “닮은 공격자”를 먼저 만났다는 현행 설정은 주인공의 신전 진입 이전에 그 존재가 활동할 수 있음을 요구한다. **보물에 처음 다가간 순간에만 그 존재가 탄생한다는 이전 설명과 동시에 사용할 수 없다.** 후속 원고에서는 생성 시점을 말하지 않고 목격과 재출현만 보여준다. 내부 세계관에서는 이 시간 관계를 반드시 정리한다.

발자국이 같은 신발임을 확신시키려면 실제 모델·바닥 자국에 비교 근거가 있어야 한다. 구현되지 않으면 그 대사는 폐기한다. 모든 발자국이 같은 그림인데 대사만 정확한 감식을 주장해서는 안 된다.

## 4 개편할 인과 사슬

1. 주인공은 보물 소문을 확인하려고 신전으로 향한다. 첫 안내는 길과 당장의 위험만 전달한다.
2. 길 위 전투에 개입해 화린과 함께 살아남는다. 화린이 찾는 사람이 근처에 있어, 주인공은 수색을 돕기로 한다.
3. 천과 소리를 따라 리안에게 닿는다. 재회가 첫 번째 분명한 보상이 된다.
4. 리안이 위험이 온 방향을 확인하고, 주인공의 목적지가 그쪽임을 알게 된다. 두 사람은 도움을 받은 상대를 혼자 보내지 않기로 선택한다. 이 동행 이유는 이번 개편 제안이다.
5. 묘령은 같은 얼굴을 보고 즉각 방어적으로 반응한다. 긴 해명 뒤 억지로 공격하는 순서를 없앤다.
6. 짧은 충돌 뒤 주인공이 공격을 멈추고 거리를 내준다. 묘령은 그 행동을 보고 자신의 확신을 보류한다. 신전에 함께 가서 목격을 확인한다.
7. 수호자를 넘어 신전 내부에 닿는다. 거대한 흔적은 여기서 구체적인 움직임과 회수하고, 닮은 상대의 문제와 구분한다.
8. 같은 얼굴을 마주할 때 동료들은 주인공을 의심해 시간을 끌지 않고 함께 대응한다. 앞의 관계 축적이 전투의 감정적 의미가 된다.
9. 승리 뒤 주인공을 기다려 주는 행동으로 동행의 변화를 닫는다. 보물의 정체는 남겨도 오인과 고립이라는 제1장의 문제는 해결한다.

## 5 장면별 개편과 대표 대본

아래 행동·소품·연출은 신규 제작 요구를 포함한다. 현재 구현되어 있다는 설명이 아니다. 대사만 먼저 넣고 행동은 빠뜨리는 방식으로 적용하지 않는다.

### 5.1 도입은 소문 한 번과 길 안내 한 번으로 끝낸다

오프닝은 보물 소문 한 문장과 신전 방향의 풍경으로 구성한다. “이루고 싶은 게 있다”와 “돌아갈 수 없어”를 겹쳐 추상적인 절박함을 만들지 않는다. 구체적인 소원을 숨겨야 한다면 과장 없이 직접 찾아온 행동을 믿는다.

관계는 초면 주민과 여행자. 발화 목적은 길 확인과 위험 고지다.

> 주인공: 신전으로 가려면 이쪽이 맞아요?
>
> 안내인: 네. 이 흙길 따라가세요. 아직 좀 걸어야 해요.
>
> 안내인: 숲에 괴물이 내려왔으니 조심하시고요.
>
> 주인공: 고맙습니다.

길 안내는 최종 채택 맵에서 확인한 지형과 맞춘다. 보이지 않는 호수나 붉은 나무를 눈앞의 이정표처럼 말하지 않는다. 마을 NPC 전원을 방문해야 출발할 수 있게 만들지 않는다.

### 5.2 화린은 구조 설명보다 수색 요청을 먼저 한다

공동 전투 중 화린의 도움을 한 번 명확히 보여준다. 주인공이 일방적으로 캐릭터를 구해 받는 인상을 줄인다. 새 전투 능력 제작보다 기존 이동·공격과 상대 배치를 활용한다.

전투 직후 화린은 숨을 고르면서도 길 안쪽을 본다. 관계는 방금 함께 싸운 초면. 발화 목적은 다친 상태 확인, 친구 수색 요청, 동행 결정이다.

> 주인공: 괜찮아?
>
> 화린: 응. 같이 있던 애가 안 보여. 리안이라고 하는데.
>
> 주인공: 같이 찾아보자. 어디서 헤어졌어?
>
> 화린: 저쪽. 돌아오면 날 찾으라고 천을 묶어 뒀어.

화린이 먼저 방향을 잡는다. 걷기 시작한 뒤 이름을 교환한다.

> 화린: 난 화린이야. 도와줘서 고마워.

주인공의 이름 표시는 기존 선택 주인공 계약을 따른다. 여기서 신전 설정, 인물의 과거, 수색 방법을 한꺼번에 설명하지 않는다. 천 조사와 합류 확정의 기존 이벤트는 보존한다.

### 5.3 리안 재회에는 조사하지 않는 시간을 준다

두 번째 전투는 첫 구조와 체감이 달라야 한다. 화린은 재회를 서두르고 리안은 남은 적 때문에 접근을 말리는 기존 상황을 살린다. 방어선 유지나 협력 구도를 기존 조우 안에서 만들고, 새 호위 시스템을 전제로 잡지 않는다.

전투 후 화린은 리안의 상태를 확인한다. 둘은 친구이며, 주인공에게는 아직 처음 만난 사람이다.

> 화린: 리안, 다친 데 없어?
>
> 리안: 응. 넌?
>
> 화린: 나도 괜찮아.

리안이 화린 뒤의 주인공을 본다.

> 화린: 같이 찾으러 와 줬어.
>
> 리안: 고마워. 돌아가려는데 자꾸 몰려와서.

“응. 넌?”은 삭제 대상인 기계적 맞장구가 아니다. 서로의 안부가 이 장면의 목적이므로 남긴다. 여기서 바닥의 흔적 설명을 시작하지 않는다.

짧은 이동 뒤, 리안이 괴물들이 온 방향을 확인한다. 동행 결정은 다음처럼 따로 힘을 준다.

> 리안: 괴물들이 저쪽에서 왔어. 너도 그쪽으로 가?
>
> 주인공: 신전에 가 보려고.
>
> 화린: 그럼 우리도 같이 가자. 여기까지 도와줬는데.
>
> 리안: 응. 나도 갈게.

이는 도움에 대한 보답으로 시작하는 임시 동행이다. 갑자기 평생의 동료처럼 말하지 않는다. 주인공이 이들을 지휘하는 대장으로 자동 승격하지도 않는다.

### 5.4 흔적은 다음 사람을 만나기 위한 문답이 아니다

현재 “앞에 사람이 있어—봤을지도 몰라—물어보자”는 접근 행동으로 통합한다. 흔적 관찰은 크기와 방향을 실제로 보여주고 리안의 필요한 한마디만 남긴다. 파인 자국의 정체를 아직 모르면 “끌고 간 물건”까지 확정하지 않는다.

천은 헤어진 친구를 찾는 단서, 거대한 자국은 물리적 위협의 예고, 사람의 발자국은 신전 안의 방문 흔적으로 역할을 나눈다. 모두 “신전 쪽이 이상하다”는 같은 결론을 세 번 말하지 않게 한다.

### 5.5 묘령은 긴 해명 뒤 싸우지 않는다

**권고안은 짧은 방어적 충돌을 유지하되, 패배로 개심시키는 구조를 없애는 것이다.** 같은 얼굴에 대한 오인은 유지한다. 현행 16개 대사를 공격 직전 3~5개 발화로 압축하고, 자세와 거리 변화로 긴장을 만든다. 수치는 시연용 분량 목표이며 획일적인 대사 제한이 아니다.

묘령은 주인공의 얼굴을 본 순간 물러서며 무기를 든다. 상처를 보호하는 자세 등 이미 공격받았다는 시각적 근거가 필요하다.

> 묘령: 또 왔어?
>
> 주인공: 누구랑 착각한 것 같은데.
>
> 묘령: 다가오지 마!

묘령의 짧은 선제 동작과 주인공의 방어가 충돌의 시작이다. 플레이어가 평화적인 선택을 고르게 해 놓고 이를 무시하는 선택지는 넣지 않는다. 연출 공격으로 피할 수 없는 체력 손실을 주지 않고, 조작권을 돌려준 뒤 공격 예고를 읽을 수 있게 한다.

전투 끝은 상대를 쓰러뜨리고 훈계하는 컷으로 닫지 않는다. 묘령의 공격이 멎으면 주인공이 먼저 추격을 멈추고 거리를 내준다. 묘령은 말과 행동을 보고 확신을 거둔다.

> 주인공: 그만할게. 너도 멈춰.
>
> 묘령: ……그 사람은 멈추지 않았어.
>
> 화린: 우리랑 같이 왔어. 신전에는 아직 안 갔고.
>
> 묘령: 내가 잘못 봤나 봐. 미안해.
>
> 주인공: 어디서 만났어?
>
> 묘령: 신전 앞. 같이 가 줄래? 나도 확인해야겠어.

단순히 주인공이 착하니 다른 사람이라고 확정하지 않는다. 묘령이 자신의 판단을 유보할 근거를 얻는 장면이다. 완전한 확인은 마지막 대면에서 한다.

이 장면을 위한 제압·정지 연출이 성립하지 않으면, 차선안은 묘령과의 필수 대결을 공동 위협에 대응하는 조우로 교체하는 것이다. 단, 퀘스트 완료 이벤트와 기존 영입 저장 단계의 호환 설계가 추가로 필요하다. 둘을 동시에 제작하지 않고 짧은 시연으로 하나를 선택한다.

### 5.6 신전에서는 같은 얼굴을 세 번 설명하지 않는다

묘령의 증언이 이미 질문을 열었다. 신전 도착에서 다시 증언을 문답으로 확인하고, 발자국으로 정답을 거의 말하고, 등장 후 또 “똑같이 생겼다”고 설명하면 공개가 약해진다.

- 도착: 묘령이 자신이 서 있던 위치를 확인한다. 새로운 정보가 없으면 대화 화면을 열지 않는다.
- 수호자: 거대한 자국과 대응하는 이동·발 구조를 보여준다. 대응하지 않는다면 흔적의 외형 또는 기존 “끌고 간” 목표 문구를 먼저 고친다.
- 격파 후: 짧게 숨 돌리고 직접 내부로 이동한다. 바로 다음 대형 전투를 연속 재생하지 않는다.
- 제단: 보물은 보이게 한다. 동일 신발 자국이라는 대사는 삭제를 기본안으로 한다. 재현 가능한 비교 단서가 확정될 때만 복원한다.
- 상대 등장: 얼굴과 몸짓을 알아볼 시간을 주고 묘령의 “저 사람이야.”로 앞선 증언을 회수한다. 화린의 외형 해설은 뺀다.

상대의 “이루고 싶은 게 있잖아”는 개편 기본안에서 삭제한다. 아직 구체적으로 다루지 않은 욕망을 상대가 아는 듯 말해 미스터리만 부풀리기 때문이다. 침묵과 익숙한 무기 동작으로 충분한지 먼저 검증한다. 주인공의 사적인 소원이 후속 장에서 확정된 뒤 이 발화를 다시 판단한다.

선택 주인공별로 외형과 기술에서 동일성을 읽을 수 있어야 한다. 기존 `Raon` 및 `Arin → Nenmir` 캐스팅은 유지하되, 특히 아린 경로에서 “같은 얼굴”이라는 말이 실제 화면과 맞는지 반드시 따로 본다. 제작상 매핑이 존재하는 것만으로 서사적 동일성이 성립하지 않는다.

### 5.7 결말은 동료가 기다려 주는 행동으로 닫는다

정체를 설명하지 않는 것과 아무것도 끝내지 않는 것은 다르다. 제1장은 친구의 재회, 묘령의 오인 해소, 주인공에게 동료가 생긴 변화까지 닫을 수 있다.

상대의 “아직 아니야”는 후속 원고에 **무엇이 아직인지에 대한 작가의 답과 회수 장면**을 적을 수 있을 때만 유지한다. 현재 개편 기본안은 삭제다. 이유 없는 수수께끼를 또 다른 멋있는 문장으로 교체하지 않는다.

전투 후 상대가 사라지고 주인공은 잠시 제단 앞에 남는다. 일행은 출구로 움직이다가 주인공이 오지 않은 것을 알아차린다.

> 화린: 같이 나가자.

묘령은 앞서 길을 막던 위치에서 이번에는 비켜서 기다린다. 이 행동이 반복 사과보다 중요한 변화다. 주인공이 합류하면 이동을 시작한다.

필수 종료 연출은 시작 길을 다시 볼 수 있는 안전한 장소에서 짧게 닫는다. 처음 혼자 지나온 길을 이제 함께 나온다. 새 장소와 대규모 컷신을 추가하지 않고 같은 장소의 의미를 바꾼다. 종료 카드는 이 장면 뒤에 둔다.

마을 복귀 대화는 선택이다. 준을 도왔다면 미아와 준이 함께 있는 모습을, 돕지 않았다면 그 상태에 맞는 마을을 보여준다. 선택 의뢰를 하지 않았다고 결말을 막거나 미완료 사건을 자동 해결하지 않는다. 다음 장의 구체적인 행선지가 미확정이면 존재하지 않는 목표를 표시하지 않는다.

## 6 감정 곡선과 플레이 리듬

| 구간 | 플레이어의 질문 | 얻는 답 | 다음 행동의 동력 | 권장 전달 방식 |
|---|---|---|---|---|
| 출발 | 신전은 어디지 | 길과 가까운 위험 | 직접 소문을 확인 | 짧은 대화 후 조작 |
| 화린 | 저 사람은 혼자인가 | 친구와 헤어졌다 | 함께 싸운 사람을 도움 | 공동 전투 후 동행 결정 |
| 리안 | 둘 다 무사할까 | 재회한다 | 도움을 주고받은 관계 | 안부 확인과 짧은 휴식 |
| 묘령 | 왜 나를 공격하지 | 닮은 사람을 보았다 | 내 일로 바뀐 의문 | 짧은 충돌 후 증언 |
| 수호자 | 큰 자국은 무엇이었나 | 눈앞의 위협과 연결 | 신전 안으로 갈 수 있음 | 환경과 전투로 회수 |
| 같은 얼굴 | 묘령이 정말 잘못 본 걸까 | 닮은 상대가 실재한다 | 함께 살아 나감 | 공개와 협력 전투 |
| 귀로 | 그래서 무엇이 달라졌나 | 나를 기다리는 사람이 생김 | 남은 의문을 함께 마주할 기대 | 행동 중심의 짧은 종료 |

기존 문서의 30~40분은 현재 측정치가 아닌 제작 목표다. 이번 개편도 대사를 늘려 시간을 채우지 않는다. 시연에서 전투 후 안부 장면과 다음 조사가 붙어 있는지, 묘령·수호자·최종 상대의 연속 전투가 서로의 절정을 깎는지 확인한다.

이동 대사는 발화 사이에 실제 걷고 살피는 시간을 둔다. 동료가 멀거나 전투 중이면 중요한 말을 시작하지 않는다. 다시 들어야 할 핵심 정보는 대화 전체 강제 재생 대신 목표 문구와 현장 단서로 복구한다. 구체적인 재생 정책은 기존 대화 시스템 지원 범위를 조사한 뒤 확정한다.

## 7 퀘스트와 지역 곁가지 개편

### 7.1 메인 목표

메인 표시 제목 `신전의 보물`과 현재 자동 후속 연결은 유지한다. 아래는 목표 문구 제안이다. 화린 에셋 파일명과 내부 ID가 다르므로 실제 `questId`를 기준으로 한다.

| 내부 Quest ID | 제안 표시 목표 | 내부 완료 기준 |
|---|---|---|
| `quest_sub_lake_missing_villagers` | 신전으로 가는 길을 묻는다 | 기존 안내인 정상 종료 이벤트 |
| `quest_sub_lake_rescue_honoka` | 붉은 천이 묶인 곳을 살펴본다 → 싸우는 사람을 돕는다 | 기존 조사와 화린 조우·합류 완료 |
| `quest_sub_lake_rescue_lian` | 화린과 함께 리안을 찾는다 | 기존 천 조사·전투·리안 합류 완료를 유지하고 순차 안내 |
| `quest_sub_lake_follow_tracks` | 큰 자국을 따라간다 → 앞에 있는 사람에게 다가간다 | 기존 조사와 묘령 조우·정상 대화 종료 |
| `quest_main_lake_shrine` | 신전으로 간다 → 앞을 막은 상대를 쓰러뜨린다 → 안으로 들어간다 | 기존 도착·수호자·진입·제단·최종 전투 이벤트와 종료 연출 완료 |

최종 상대의 존재는 등장 전에 목표로 노출하지 않는다. 목표를 합쳐 보여도 저장용 `Objective ID`를 삭제하거나 다른 사건에 재사용하지 않는다.

### 7.2 곁가지의 역할을 서로 다르게 만든다

| 인물 | 유지할 플레이 | 개편할 감정과 결과 |
|---|---|---|
| 미아·준 | 짐 조사, 준 구조, 귀환 확인 | 메인과 다른 가족의 재회. “짐을 두고 사람에게 돌아온다”는 선택을 살린다 |
| 헤이즐 | 약초 세 뿌리 | 식물 현상 강의보다 다친 사람에게 쓸 약이 모자란 상황. 완료 후 약을 챙기는 행동이 보상 |
| 페니 | 등불 세 곳 조사 | 신전 원인 추리보다 밤길을 쓸 수 있는지 결정하는 일. 결과에 따라 고치거나 접근을 말리는 반응 |
| 모건 | 수레 주변 전투와 조사 | 발자국으로 생사를 확정하지 않고 마지막 이동 방향을 전달. 실제 안전 확인 전 “무사했다”를 성급히 회수하지 않음 |
| 조안·루시아·조이·상인 | 선택 대화·거래 | 전원에게 불길한 증언을 맡기지 않는다. 실제 관찰, 생활 준비, 거래 중 각자의 관심사를 남김 |

헤이즐 개작 예시. 초면이며 부탁을 받아들이는 상황이다.

> 헤이즐: 약으로 쓸 게 모자라요. 물가에서 뜯어 온 건 못 쓰겠고요.
>
> 주인공: 숲 안쪽에서 구하면 될까요?
>
> 헤이즐: 네. 향이 진한 걸로 세 뿌리만 부탁드릴게요.

약초의 이상은 현물 조사에서 보여준다. NPC 대화에서 전부 설명한 뒤 현장에서 같은 결론을 다시 읽히지 않는다. 조사가 필요한 정보는 삭제하지 말고 전달 장소를 옮긴다.

준 귀환은 긴 경위 설명보다 미아가 다친 발을 보고 곁으로 붙는 행동을 쓴다. 신규 개작에서 그물 이야기를 다시 도입하지 않는다. 현행 `DLG_Npc_Jun`에는 “그물은 다시 짜면 돼요”가 남아 있으므로 짐 사건과의 연속성을 확인해 함께 정리한다. 현재 참조 여부를 확인하기 전 실행 중 오류라고 단정하지 않는다.

## 8 인물별 말투와 관계

아래는 이 장에 필요한 연기 지침 제안이다. 성격 전체와 평생의 소원을 새로 확정하는 설정집이 아니다.

| 인물 | 말하는 습관 | 초면과 가까워진 뒤 | 피할 것 |
|---|---|---|---|
| 주인공 | 필요한 것을 먼저 묻고, 할 수 있는 일을 제안한다 | 주민에게 존댓말. 함께 싸운 동료에게 담백한 반말. 선택 주인공의 고유 성격을 덮지 않음 | 모든 정보를 요약하는 대장, 만나는 사람마다 심문하는 탐정 |
| 화린 | 사람의 상태와 당장 할 일에 관심이 먼저 간다 | 초면에는 도움을 부탁한다. 리안에게는 안부를 되묻고 생략이 자연스러움 | 걱정을 장황하게 선언, 남의 갈등에 훈계, 모든 상황에 “가자” |
| 리안 | 필요한 근거 하나를 짚고, 확실하지 않은 것은 멈춘다 | 화린 앞에서는 관찰보다 안부가 먼저다. 새 동료에게는 확인을 부탁함 | 매 장면 발자국 보고, 격언처럼 말하는 추적 교관 |
| 묘령 | 초반엔 상대의 움직임에 반응하고, 진정된 뒤 자신이 본 것을 말한다 | 확신 → 판단 유보 → 행동으로 신뢰. 합류 즉시 친근해지지 않음 | 심사관, 감독자, 패배 뒤 곧바로 세계관 설명자 |
| 미아 | 자신이 기다리는 사람과 약속한 장소를 구체적으로 말한다 | 낯선 주인공에게 존댓말, 준에게 일상적인 반말 | 어린아이를 통해 주제를 완성된 교훈 문장으로 말하기 |
| 준 | 설명을 짧게 하고 실제로 귀환을 택한다 | 도움에는 공손하게 감사, 미아에게는 변명보다 상태를 말함 | 계속 남아서 다른 단서를 주는 의뢰 장치 |
| 안내인과 주민 | 자기 눈으로 본 일과 생활에 필요한 일만 말한다 | 처음에는 공손함을 유지. 재방문 때 앞선 행동을 기억함 | 주인공의 목적을 알아맞히기, 근거 없는 친근함 |
| 닮은 상대 | 외형·자세·기술이 먼저 말한다 | 관계와 지식 범위가 미확정이므로 대사를 최소화 | 근거 없는 예언, 무엇이든 아는 듯한 수수께끼 |

인물의 다음 만남에는 지금의 행동 하나가 남아야 한다. 화린과 리안은 수색을 도운 일을, 묘령은 싸움을 멈춰 준 일을, 미아와 준은 귀환을 도운 일을 기억한다. 이 기억을 감사 대사 반복이 아니라 먼저 다가오거나 기다리는 행동으로 바꾼다. 안내인과 주민은 생활할 자리가 있으므로 남고, 전투 동료는 함께 확인할 일이 있어서 움직인다.

## 9 제작 순서와 이번 단계 범위

### 우선순위 1 묘령부터 결말까지의 짧은 시연

현재 가장 큰 인과 문제인 오인 전투와 가장 중요한 보상인 결말을 먼저 붙인다. 묘령 대치 축약, 공격·정지의 행동 근거, 신전의 중복 설명 삭제, 귀로의 종료 장면을 하나로 본다. 여기서 설득력이 없으면 전 대사 교정에 들어가지 않는다.

산출물은 장면별 행동 대본, 대사 연결표, 기존 상태와 신규 연출의 복구 표다. 짧은 충돌과 공동 위협 대체안 중 하나를 시연 결과로 선택한다.

### 우선순위 2 화린과 리안의 합류

구조 두 번의 체감을 다르게 만들고 재회와 조사를 분리한다. 합류 UI와 조작 설명은 감정 장면이 끝난 다음에 나온다. 이미 없앤 필수 후속 대화 창을 되살리지 않는다. 이동 대사를 지원하지 않는다면 한 세션 안에 행동의 여백을 두되, 더 긴 설명문으로 대체하지 않는다.

### 우선순위 3 시작과 지역 생활

안내인 질문 축약, 주민 높임말 정렬, 선택 퀘스트 역할 분리, 준 후일담 연속성, 기존 미연결 문안 정리를 진행한다. 오래된 추출본을 새 원고로 덮어쓰지 않고 실제 실행 그래프를 기준으로 새 대사 목록을 만든다.

### 우선순위 4 전체 경험 검증

처음 보는 플레이어에게 목표와 인물 동기를 자기 말로 설명하게 한다. 답을 유도하는 설문 대신 “왜 묘령과 싸웠다고 생각했는가”, “리안은 왜 계속 함께 갔는가”, “끝나고 무엇이 달라졌는가”를 묻는다. 의도와 다르면 원고 또는 연출을 다시 고친다.

이번 작업은 분석과 기획서 작성까지다. 실행 데이터, 코드, 씬, 기존 확정 문서, 저장 형식은 수정하지 않는다. 후속 제작에서 보물의 진실·제2장 목적지·주인공의 소원을 결정해야 할 때는 미확정 설정으로 따로 다룬다.

## 10 구현 경계와 완료 기준

### 10.1 적용 대상

| 대상 | 후속 변경 | 지켜야 할 경계 |
|---|---|---|
| `Dialogue/Story/Dialogue`와 `Dialogue/Test` | 문안·화자·장면 연결 정리 | 그래프·노드 참조를 확인하고 기존 ID와 GUID 보존 |
| 화린·리안 영입 `Flow` | 재회와 동행의 연출 시점 조정 | 전투 완료와 영입 완료를 분리하고 정상 대화 종료 계약 유지 |
| 묘령 영입 `Flow` | 충돌 시작·멈춤의 행동 연결 | 합류 확정 및 기존 저장 복원 보존. 단순 HP 패배를 인격 변화의 이유로 쓰지 않음 |
| `FLOW_LakeShrineChapter1` | 제단 공개, 최종 상대, 귀로 종료 연결 | 현재 `play_victory → mark_chapter_completed → complete_shrine_quest`의 정상 종료 경계 보존 |
| 메인·지역 `Quest` | 목표와 요약 문안 | 기존 `Objective ID` 의미·완료 시점·선행 달성 누적 보존 |
| 최종 채택 맵 | 시선, 흔적, 이동 경로, 안전한 종료 장소 | 기존 맵과 시나리오 맵을 혼동하지 않고 높이·가시성·내비게이션 확인 |
| 보존용 대화 | 호출 여부와 잔존 문안 목록화 | `PostRescue` 등의 파일 존재만으로 재생 중이라고 판단하거나 무단 삭제하지 않음 |

대사는 `DialogueGraph`, 장면 전환은 `FlowGraph`, 플레이어 목표는 `Quest`가 소유한다. 문안 교체 과정에서 완료 이벤트를 함께 지우지 않는다. 귀로를 필수 종료 연출로 추가하면 중간 저장·이탈 후 다시 최종 보스를 잡게 만들지 않도록 별도 재개 지점을 설계한다. 전투 동작 변경은 전투 저작 가이드와 BT/GAS/MotionSet 책임 경계를 따른다.

### 10.2 개편 합격 기준

- [ ] 첫 안내 후 세계관 용어 없이 목적지와 현재 할 일을 말할 수 있다.
- [ ] 화린과 리안의 합류 이유를 “구해 줘서 캐릭터를 받았다” 이상으로 설명할 수 있다.
- [ ] 리안 재회 장면에서 흔적 설명이 안부보다 먼저 나오지 않는다.
- [ ] 묘령이 공격한 이유와 멈춘 이유가 서로 다른 근거로 이해된다.
- [ ] 제단에서 이미 아는 사실을 네 인물이 돌아가며 설명하지 않는다.
- [ ] 선택 주인공 두 경로 모두 외형·기술과 “같은 얼굴” 설정이 납득된다.
- [ ] 결말에 주인공과 동료의 관계 변화가 행동으로 보인다.
- [ ] 대사에서 답하지 않은 수수께끼는 작가용 회수 계획이 있거나 삭제되어 있다.
- [ ] 등장인물 없이 문장만 읽어도 화린·리안·묘령의 관심사 차이가 드러난다.
- [ ] 초면·동료·가족의 높임말과 친밀도가 일관된다.
- [ ] 화면에 없는 행동이나 근거를 대사로 있다고 주장하지 않는다.
- [ ] 곁가지를 하나도 하지 않아도 메인을 이해하고 끝낼 수 있다.
- [ ] 모든 단계의 중단·저장/로드·역순 접근·재진입·스킵을 확인한다.

### 10.3 검증 방식

원고 검수에서는 발화 동기, 관계, 말의 길이, 질문의 필요성을 가이드에 따라 소리 내어 읽듯 확인한다. 낭독으로 부자연스러운 문장을 찾되 낭독만으로 플레이 리듬을 합격 처리하지 않는다.

구현 후에는 대화·콘텐츠·진행 관련 기존 자동 테스트와 변경한 복구 경로 검사를 실행한다. Unity Play Mode에서 시작부터 종료까지 게임패드로 직접 진행하고, 묘령·신전·결말은 주인공 두 경로를 확인한다. 대사 클릭 수, 연속 조작 제한 시간, 길찾기 정체, 대사 중단 위치를 기록해 개편 전후를 비교한다. 현재 측정되지 않은 시간을 수치 성과로 보고하지 않는다.

새 대사를 넣는 것으로 완료하지 않는다. **플레이어가 사람을 만났다고 느끼고, 다음 행동을 납득하며, 끝났을 때 함께한 시간이 남는지**를 최종 완료 기준으로 삼는다.
