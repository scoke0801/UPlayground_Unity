Reine P09 r02 사용자 확인 명세

준비: Unity 6000.3.21f1 이상, 현재 작업 씬을 원하는 방식으로 보존한 뒤
Assets/01.Scenes/Tests/Equipment/Reine_P09_Review.unity를 연다.
이 씬은 외형 검수용이며 기존 저장 파일이나 Reine 플레이어를 교체하지 않는다.

R01 / 코의 검은 삼각형·볼 점·코끝 얼룩이 없는지 먼저 확인한다. 기본 Hair11 단발과 대체 Hair03의 바뀐 얼굴 비율을 확인한다.
기본·대체 모델의 정면·35도·측면·후면·근접 시점 확인.
기대: 눈 크기가 과하지 않고 원치 않는 감김·안구 돌출·헤어 관통·분홍 재질이 없다.
실패 시 대상 모델 이름과 각도를 적는다. 두피·목의 약한 색 경계는 사용자 미술 확인 대상이다.

R02 / BodyOnly 모델에서 목·턱 아래·정수리 확인.
기대: Face02/Chest/Leg만 보이며 열린 구멍·목 틈이 없다. 의상 프리팹에는 가시성 변경이 적용되지 않는다.

R03 / P09 빌더에서 Reine_P09_BuildPreset 불러오기 → Hair03/11, 의상03/05 변경 → 다시 불러오기.
기대: Reine_P09_Face와 Reine_P09_ToonLook 연결 유지, 눈과 피부색이 이전 P09 얼굴로 돌아가지 않는다.
전체 헤어·투구·MagicaCloth 조합은 이번 검사 범위가 아니다.

R04 / Review 씬 Play 후 카메라를 가까이/멀리 이동하고 씬뷰로 돌아와 상태 확인.
기대: 부품 소멸·검은 스키닝·헤어 지연·Console 오류가 없다. 이 단계도 실제 게임 통합 검사를 대신하지 않는다.

R05 / 정규 NPC 또는 Player 교체를 별도로 진행할 때만 수행.
해당 등장 경로, 대화, 표정/립싱크, 목 시선 추종, 이동, 재진입, 저장/로드와 무기·GAS·모션 연결을 검사한다.
현재 독립 모델에는 NPC 데이터·ActorDefinition·플레이어 컴포넌트가 없으므로 본 항목은 미수행이다.

회신: ID / 모델·프리셋 / 통과·실패·미수행 / 실제 결과 / 화면·Console 로그.
사용자 외형 승인과 Play Mode 통과는 아직 대기 상태다.
