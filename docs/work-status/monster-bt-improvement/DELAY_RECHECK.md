# 지연 행동 조건 재검사 구현

설계: [행동 개선 §6](../../../Assets/docs/design/combat/monster/MONSTER_BT_BEHAVIOR_IMPROVEMENT_DESIGN.md#6-추가-행동-패턴-상세-설계-2026-11-14-조사) · [전투 위키](../../wiki/combat.md) · [전체 상태](STATUS.md)

## 반영

- Rules importer는 `do`의 Wait 이후 다음 행동 전에 그룹 및 규칙 조건을 다시 생성·평가한다. 대기 중 조건이 바뀌면 Failure로 종료해 상위 선택으로 돌아간다. WeightedRandom 재추첨이나 실행 중 Ability 취소 정책은 변경하지 않는다.
- RequestAction의 지상 Attack/Punish 및 ExecuteAttack은 현재 사선을 슬롯 예약 전에 검사한다. 기존 타깃·거리·Ability·슬롯 검사는 유지한다. 이미 발동된 공격을 사선 상실로 취소하지 않는다.
- 신규 Intent·노드·Blackboard 키·밸런스 값은 추가하지 않았다. 기존 사용자 미커밋 변경을 보존했다.
- Wait를 쓰는 BT 10개만 기존 importer로 재생성했다. [import 경로·GUID 보존](DELAY_RECHECK_IMPORT.txt), [생성 그래프 재검사 연결·Missing 0](DELAY_RECHECK_GRAPH.txt). 그래프는 객체 연결 검사이며 화면 시각 검토와 구분한다.

## 검증과 남은 항목

- 신규 회귀 3건: 대기 중 규칙 조건 상실, 그룹 조건 상실, 조건 유지 후 정상 진행. 해당 fixture 14/14 통과. 초기 11건 실행은 구 어셈블리였으므로 이번 변경 증거에서 제외했다.
- 최초 테스트 키 오류는 실제 registry 키로 수정했고 정상 컴파일의 새 6인자 importer 로딩과 scriptCompilationFailed=false를 확인했다. Edit Mode·allowlist 밖 변경이므로 Hot Reload 대신 정상 컴파일했다.
- 추가 관련 검사 결과는 [원본](DELAY_RECHECK_TEST_RESULTS.json)에 기록한다.
- Player/Addressables 빌드·실제 플레이·화면 체감 검증은 미수행이다. P3 원형 분화, P4, P5 및 기존 P2a 선행 사용자 검수는 남아 있다. 이번 변경은 §6.3의 공통 실행 전제 개선이다.

## 사용자 직접 테스트

기존 USER_TESTS.md의 동일 씬·궁수·장비를 사용한다. 저장 데이터 변경 없이 독립 항목으로 실행한다.

| ID | 조작 | 기대·실패 기준 |
|---|---|---|
| D01 | 궁수 지연 사격 유도 후 대기 중 엄폐물 뒤로 이동 | 엄폐 전 관찰로 공격하지 않고 다음 유효 행동 선택. 벽을 향해 발동하면 실패 |
| D02 | 대기 중 사거리 밖 이동 또는 타깃 상실 유도 | 무효 후속 공격 거절. 제자리 영구 대기·쿨다운만 소모하면 실패 |
| D03 | 사선·사거리 유지 상태에서 지연 사격 유도 | 정상 사격. 조건 유지에도 모든 지연 사격이 소멸하면 실패 |
| D04 | 대검·근접 대표와 평지/좁은 문 교전 | 공격과 추적 유지. 사선 검사 때문에 경계에서 공격 없이 멈추면 실패 |

각 항목의 씬·액터·설정·입력 장치·관찰 시간을 기록하고 `ID / 통과·실패·미수행 / 실제 결과 / 영상 또는 로그`로 전달한다. 체감 합격은 사용자 테스트 대기다.

## 부산물

하네스 준비표 `output/harness/20261114-135853-1f974459`와 import/그래프/테스트 근거는 재개를 위해 보존한다. 임시 코드·테스트 에셋은 생성하지 않았다. 커밋하지 않았다.
- 최종 관련 EditMode: 74/74 통과(신규 3건 포함), 정상 컴파일 실패 false. 생성 그래프 10개/재검사 지점 11개/Missing 0. 이 결과는 실제 엄폐 전투 검증을 대체하지 않는다.
