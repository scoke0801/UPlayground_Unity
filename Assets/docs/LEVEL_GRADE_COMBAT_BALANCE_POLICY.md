# 레벨 / 등급 기반 전투 시간 밸런스 정책

## 개요

이 문서는 `Balance Designer`로 몬스터 전투 시간을 검증할 때 사용할 레벨 차이와 몬스터 등급별 기준을 정의한다.

핵심 기준은 다음 두 값이다.

| 지표 | 의미 |
|------|------|
| 플레이어 생존 예상 시간 | 몬스터 공격을 평균적으로 받았을 때 플레이어가 버티는 시간 |
| 몬스터 처치 예상 시간 | 현재 플레이어 공격력과 공격 루프 기준으로 몬스터를 처치하는 시간 |

전투가 성립한다고 판단하려면 두 값이 모두 목표 시간 범위 안에 들어와야 한다. 한쪽만 만족하면 실제 플레이에서는 너무 쉽거나, 너무 치명적이거나, 공격 기회가 부족한 전투가 된다.

---

## 레벨 차이 정의

플레이어 레벨과 몬스터 레벨의 차이는 아래처럼 해석한다.

```text
레벨 차이 = 몬스터 레벨 - 플레이어 레벨
```

| 구분 | 레벨 차이 | 설계 의도 |
|------|-----------|-----------|
| 저레벨 Normal | -3 ~ -1 | 이미 성장한 플레이어가 빠르게 처리하는 일반 적 |
| 동레벨 Normal | 0 | 기본 필드 전투 기준점 |
| 고레벨 Normal | +1 ~ +3 | 같은 타입이라도 조심해야 하는 일반 적 |
| Elite | 0 ~ +3 | 일반 적보다 긴 교전과 패턴 대응 요구 |
| Boss | 0 이상 | 전투의 중심 콘텐츠. 패턴 학습과 페이즈 전환을 전제로 함 |

`Balance Designer`에서는 몬스터 레벨을 `ActorDefinitionSO.level` 또는 `BalanceScenarioAsset.overrideMonsterLevel`로 지정하고, 플레이어 레벨은 `BalanceScenarioAsset.playerLevel`에 기록한다.

## 목표 전투 시간

아래 시간은 1:1 전투 기준의 1차 목표값이다. 다수전, 지형 제약, 회복 아이템, 파티 교체가 들어가는 경우 별도 보정한다.

| 전투 유형 | 목표 시간 | 허용 범위 | 판정 의도 |
|-----------|-----------|-----------|-----------|
| 저레벨 Normal | 6초 | 4 ~ 10초 | 플레이어가 우위에 있어 빠르게 정리 가능 |
| 동레벨 Normal | 18초 | 12 ~ 25초 | 기본 전투. 1~3회 공격 교환이 발생 |
| 고레벨 Normal | 28초 | 20 ~ 40초 | 일반 적이지만 회피/가드 실패 시 압박 |
| 동레벨 Elite | 45초 | 35 ~ 60초 | 패턴 대응과 브레이크/기회 창 활용 필요 |
| 고레벨 Elite | 60초 | 45 ~ 80초 | 무리해서 싸우면 위험하지만 처치 가능 |
| Boss | 120초 | 90 ~ 180초 | 페이즈, 특수 공격, 회복/자원 운영을 포함 |

`N초 전투` 기준은 목표 시간의 중앙값을 사용한다. 예를 들어 동레벨 Normal은 `targetDuration = 18`, Boss는 `targetDuration = 120`을 기본으로 둔다.

## 상태 판정 기준

### Stable

다음 조건을 모두 만족하면 기준 전투로 본다.

| 조건 | 설명 |
|------|------|
| 몬스터 처치 예상 시간이 허용 범위 안에 있음 | 플레이어 공격력이 목표 구간에 맞음 |
| 플레이어 생존 예상 시간이 목표 시간 이상 | 몬스터가 너무 치명적이지 않음 |
| 몬스터 공격 기회가 기준 이상 | 몬스터가 실제로 공격할 수 있음 |
| 사용 가능한 공격이 1개 이상 | 레벨/거리 조건으로 공격이 잠기지 않음 |

### TooEasy

몬스터 처치 예상 시간이 허용 범위 하한보다 짧으면 `TooEasy`로 본다.

예시:

| 유형 | 하한 | TooEasy 조건 |
|------|------|--------------|
| 저레벨 Normal | 4초 | 4초 미만에 사망 |
| 동레벨 Normal | 12초 | 12초 미만에 사망 |
| Boss | 90초 | 90초 미만에 사망 |

조정 후보는 몬스터 HP, Defense, Poise, 위험 패턴 사용 빈도다. 단순히 HP만 올리면 전투가 늘어질 수 있으므로 공격 기회와 브레이크 주기를 같이 확인한다.

### TooLethal

플레이어 생존 예상 시간이 목표 시간보다 짧으면 `TooLethal`로 본다.

예시:

| 유형 | 목표 시간 | TooLethal 조건 |
|------|-----------|----------------|
| 동레벨 Normal | 18초 | 플레이어가 18초 전에 사망 |
| Elite | 45초 | 플레이어가 45초 전에 사망 |
| Boss | 120초 | 플레이어가 120초 전에 사망 |

조정 후보는 몬스터 공격 피해량, 쿨다운, selectionWeight, 방어 가능 여부, 회피 가능한 텔레그래프 시간이다.

### Stalled

양쪽 모두 잘 죽지 않지만 공격 기회가 부족하면 `Stalled`로 본다.

대표 원인:

| 원인 | 확인 항목 |
|------|-----------|
| 기준 거리에서 공격 없음 | `EnemyAttackInfo.minRange`, `maxRange` |
| 레벨 조건으로 공격 잠김 | `EnemyAttackInfo.requiredLevel` |
| 쿨다운 과다 | `cooldown`, `globalCooldown` |
| BT가 공격 Intent로 진입하지 않음 | `BehaviorTreeAsset`, Intent 로그 |
| 몬스터 HP만 높음 | `MaxHealth`, `Defense`, 플레이어 DPS |

## 등급별 세부 기준

### 저레벨 Normal

플레이어보다 낮은 레벨의 Normal 몬스터는 성장 체감과 필드 진행 속도를 담당한다.

| 항목 | 기준 |
|------|------|
| 목표 시간 | 6초 |
| 허용 범위 | 4 ~ 10초 |
| 플레이어 생존 | 목표 시간의 2배 이상 권장 |
| 공격 기회 | 0.5 ~ 1.5회 |
| 주요 위험 | 과도한 경직, 예고 없는 고피해 공격 |

권장 상태:

- 플레이어가 실수하지 않으면 거의 맞지 않고 처치 가능
- 한 번 맞아도 즉시 위험 상태가 되지 않음
- 공격 패턴은 튜토리얼 또는 리듬 유지용으로 사용

### 동레벨 Normal

동레벨 Normal은 가장 중요한 기준점이다. 모든 일반 몬스터 튜닝은 이 구간에서 먼저 맞춘다.

| 항목 | 기준 |
|------|------|
| 목표 시간 | 18초 |
| 허용 범위 | 12 ~ 25초 |
| 플레이어 생존 | 18초 이상 |
| 공격 기회 | 2 ~ 4회 |
| 주요 위험 | 특정 공격 하나가 전체 위험도를 독점하는 경우 |

권장 상태:

- 플레이어가 기본 공격 루프를 수행하면 15~20초 전후로 처치
- 몬스터는 최소 2회 이상 공격을 시도
- 가드/회피/패리를 몰라도 처치 가능하지만, 무시하면 HP 손실이 누적

### 고레벨 Normal

고레벨 Normal은 같은 몬스터라도 레벨 차이로 긴장감을 만드는 구간이다.

| 항목 | 기준 |
|------|------|
| 목표 시간 | 28초 |
| 허용 범위 | 20 ~ 40초 |
| 플레이어 생존 | 28초 이상, 실수 보정 낮게 |
| 공격 기회 | 3 ~ 6회 |
| 주요 위험 | 일반 몬스터가 Elite처럼 오래 버티는 경우 |

권장 상태:

- 플레이어가 낮은 레벨 장비/스탯으로 싸우면 체감 난도가 상승
- 처치 가능하지만 회피/가드 실패가 누적되면 위험
- 공격 해금 레벨이 있다면 고레벨에서 1개 정도 추가 패턴 허용

### Elite

Elite는 필드 전투의 중간 목표다. 일반 몬스터보다 전투 시간이 길어야 하지만, Boss처럼 페이즈 학습을 강제하지 않는다.

| 항목 | 기준 |
|------|------|
| 목표 시간 | 45초 |
| 허용 범위 | 35 ~ 60초 |
| 플레이어 생존 | 45초 이상 |
| 공격 기회 | 5 ~ 9회 |
| 주요 위험 | HP만 높은 몬스터가 되는 경우 |

권장 상태:

- 브레이크, 강인도, 특수공격 대응이 의미를 가져야 함
- 공격 카테고리가 Basic에만 치우치지 않도록 Heavy/Skill 비중 확인
- 플레이어가 패턴을 읽으면 전투 시간이 줄어드는 구조가 좋음

### Boss

Boss는 전투 시간 자체보다 페이즈 구성과 위험 분포가 중요하다.

| 항목 | 기준 |
|------|------|
| 목표 시간 | 120초 |
| 허용 범위 | 90 ~ 180초 |
| 플레이어 생존 | 120초 이상. 회복/자원 운영 포함 시 별도 측정 |
| 공격 기회 | 12회 이상 |
| 주요 위험 | 특정 공격 1개가 즉사급으로 압축되는 경우 |

권장 상태:

- 페이즈별 공격 풀과 위험도가 다르게 느껴져야 함
- 전체 피해 기여도가 한 공격에 35% 이상 몰리면 재검토
- 처치 시간은 길지만 반복 대기 시간이 길어지면 안 됨
- 패턴 학습 후 재도전 시 목표 시간보다 20~30% 빠르게 처치되는 것은 허용

## Balance Designer 설정값

### 기본 프리셋

`BalanceScenarioAsset`은 아래 기준으로 만들면 된다.

| 프리셋 | targetDuration | playerLevel | overrideMonsterLevel | useActorDefinitionLevel | 설명 |
|--------|----------------|-------------|----------------------|-------------------------|------|
| Normal_LowLevel | 6 | 기준 레벨 | 플레이어 레벨 - 1 ~ -3 | false | 저레벨 Normal 검증 |
| Normal_SameLevel | 18 | 기준 레벨 | 플레이어 레벨 | false | 동레벨 Normal 검증 |
| Normal_HighLevel | 28 | 기준 레벨 | 플레이어 레벨 + 1 ~ +3 | false | 고레벨 Normal 검증 |
| Elite_SameLevel | 45 | 기준 레벨 | 플레이어 레벨 | false | Elite 기준 검증 |
| Boss_Standard | 120 | 보스 권장 레벨 | 보스 레벨 | false 또는 true | Boss 기준 검증 |

### 플레이어 공격력 입력

플레이어 쪽 계산은 다음 순서로 사용한다.

| 입력 | 우선순위 |
|------|----------|
| `playerStatData.AttackPower` | 1순위 |
| `manualPlayerAttackPower` | `playerStatData`가 없을 때 |
| `playerAttackData` | 공격 1회 평균 피해량 계산 |
| `manualPlayerDps` | `playerAttackData`가 없을 때 기준 DPS |
| `playerAttackInterval` | `playerAttackData` 평균 피해량을 DPS로 바꿀 때 사용 |

최종 계산식:

```text
플레이어 최종 DPS = 플레이어 공격 루프 기준 DPS * 플레이어 AttackPower * (1 - 몬스터 Defense)
몬스터 처치 예상 시간 = 몬스터 MaxHealth / 플레이어 최종 DPS
```

### 몬스터 공격 입력

몬스터 쪽 계산은 다음 값을 사용한다.

| 입력 | 사용 |
|------|------|
| `EnemyAttackInfo.requiredLevel` | 현재 몬스터 레벨에서 해금 여부 |
| `EnemyAttackInfo.minRange/maxRange` | 기준 거리에서 사용 가능 여부 |
| `EnemyAttackInfo.selectionWeight` | 공격 선택 확률 |
| `EnemyAttackInfo.cooldown` | 공격 빈도 |
| `HitPhaseData.damage` | 공격 1회 피해량 |
| `ActorStatSO.AttackPower` | 몬스터 공격력 배율 |

## 조정 우선순위

### 몬스터 처치 시간이 너무 짧을 때

1. `MaxHealth`를 목표 시간 대비 부족한 비율만큼 보정
2. `Defense`는 0.05 단위 이하로 소폭 보정
3. `Poise`를 올려 브레이크 빈도 조정
4. 공격 기회가 너무 낮으면 BT/쿨다운을 먼저 조정

예시:

```text
목표 18초, 실제 처치 9초
필요 보정 배율 = 18 / 9 = 2.0
HP를 바로 2배로 올리기 전에 공격 기회, 브레이크, 방어율을 함께 확인
```

### 몬스터 처치 시간이 너무 길 때

1. HP 또는 Defense를 낮춘다.
2. 플레이어 공격 데이터가 실제 콤보 루프보다 낮게 잡혔는지 확인한다.
3. 무적/가드/후퇴 BT가 전투 시간을 과하게 늘리는지 확인한다.
4. Boss가 아닌데 허용 범위를 넘으면 먼저 HP를 조정한다.

### 플레이어 생존 시간이 너무 짧을 때

1. 가장 높은 DPS 기여 공격을 확인한다.
2. 해당 공격의 `damage`, `selectionWeight`, `cooldown` 중 하나를 조정한다.
3. `AttackDefenseType`이 회피/가드/패리 가능한 의도와 맞는지 확인한다.
4. 텔레그래프가 있는 공격은 실제 회피 가능 시간을 Play Mode에서 확인한다.

## 검증 체크리스트

밸런스 통과 전 최소 확인 항목:

- 저레벨 Normal, 동레벨 Normal, 보스 기준 `BalanceScenarioAsset`을 각각 실행했다.
- `몬스터 처치` 시간이 목표 허용 범위 안에 있다.
- `플레이어 생존` 시간이 목표 시간 이상이다.
- 기준 거리에서 사용 가능한 공격이 1개 이상 있다.
- 몬스터 공격 기회가 유형별 기준 이상이다.
- `TooEasy`, `TooLethal`, `Stalled`, `InvalidData`가 나오면 원인을 문서화했다.
- Motion 기반 생성 공격의 `HitPhaseData` 개수가 `BeginCollisionEvent` 의도와 맞다.
- Boss는 공격별 DPS 기여도가 한 공격에 과도하게 몰리지 않는다.

## 초기 권장값

현재 프로젝트의 초기 기본값은 아래처럼 시작한다.

| 구분 | targetDuration | minAttackOpportunities | assumedDistance |
|------|----------------|------------------------|-----------------|
| 저레벨 Normal | 6 | 0.5 | 2.5 |
| 동레벨 Normal | 18 | 2 | 2.5 |
| 고레벨 Normal | 28 | 3 | 2.5 |
| Elite | 45 | 5 | 2.5 |
| Boss | 120 | 12 | 3.0 |

이 값은 고정 규칙이 아니라 첫 패스 기준이다. 실제 플레이 로그와 `EncounterReplay`가 쌓이면 몬스터 타입, 무기 타입, 파티 구성별로 분리한다.
