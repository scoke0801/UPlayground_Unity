Siuha P09 r01 사용자 확인 명세

준비: 열린 사용자 씬을 원하는 방식으로 보존하고 Siuha_P09_Review.unity를 연다.
Unity 6000.3.21f1+, URP. 이 씬은 외형 검수용이며 NPC 서비스·대화·전투가 연결되어 있지 않다.
기존 저장 게임은 사용하지 않는다. Unity 버전과 입력 장치를 결과에 기록한다.

V01 / 정면·35도·측면에서 눈의 크기와 인상을 확인한다.
      눈이 과도하게 크거나 작지 않고 양쪽 시선과 눈매가 자연스러워야 한다.
V02 / P09 빌더에서 Siuha_P09_BuildPreset을 불러온 뒤 Hair03/11, Armor03/05를 변경한다.
      FaceMeshProfile 유지, 분홍 재질·Missing Script·두피 돌출·얼굴 소멸이 없어야 한다.
V03 / 검수 모델의 활성 Female_Face_02에서 Eye_Blink, Mouth_Smile, Lip_aa/ii/uu/ee/oo를 조정한다.
      눈이 닫히고 입안이 유지되어야 한다. 중립으로 되돌릴 때 잔여 변형이 없어야 한다.
V04 / Idle/Walk 샘플 및 고개 좌우 회전에서 턱 아래·목·두피를 확인한다.
      목이 갈라지거나 헤어가 피부를 뚫고 나오지 않아야 한다.
V05 / Play Mode에서 카메라 거리·시야를 바꾸고 되돌아온다.
      얼굴·헤어·의상이 사라지지 않아야 한다. 실제 게임 등장·시선·립싱크는 향후 액터 연결 후 별도 확인한다.

전체 투구·긴 머리·망토·물리 조합은 미검증이다. 해당 조합 사용 시 추가 검수가 필요하다.
Player 빌드·군중 성능·Player/Enemy 무기·GAS·모션 통합은 이번 모델 제작에 포함하지 않았다.
회신: 항목 ID / 통과·실패·미수행 / 실제 증상 / 각도·표정·헤어·의상 / 화면 또는 Console 로그.
