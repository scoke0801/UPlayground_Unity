두 도시 직접 플레이 확인 — 2026-10-24

Player 빌드: Builds/WorldCities_20261024/UPlayground.exe (Development, 2026-10-24, 오류 0 / 경고 541).
에디터에서 확인할 때는 기존 Boot 씬을 사용한다. 배치 시작 로그 검증은 완료했으나 아래 직접 검수는 미수행이다.

대상: SaltwindHarbor, StonegateCitadel, 기존 LakeOfLifeScenario의 새 길 표식.
준비: 평소 사용하던 Boot/Title 경로로 새 게임 또는 기존 저장을 연다.
기존 저장을 덮어쓰지 않고 별도 빈 슬롯에서 저장/로드를 확인한다.
도시 씬만 직접 Play한 결과와 정상 Boot/Title에서 방문한 결과는 구분한다.
키보드와 게임패드의 현재 상호작용 바인딩을 각각 사용한다.

C01 호수 → 항구 → 호수
호수 마을 남동쪽 X1125/Z380의 '소금바람항으로 가는 길' 표식에 접근해 상호작용.
기대: 로딩 뒤 항구 접근길에 도착하고 캐릭터·카메라·조작이 복원된다.
항구 X176/Z40의 호수행 표식으로 귀환. 즉시 재이동하거나 지면 아래로 떨어지면 실패.

C02 호수 → 성 도시 → 호수
호수 마을 서쪽 X1005/Z430의 '돌등성으로 가는 길' 표식으로 이동.
성문 안으로 걸어 광장과 본성 앞마당에 도착하고, 접근길 X176/Z40에서 호수로 귀환.
기대: 성문과 거리에서 막히지 않고 캐릭터·장비·파티가 유지된다.

C03 항구 ↔ 성 도시
항구 서쪽 X122/Z133과 성 도시 바깥 장터 X220/Z102의 길 표식으로 왕복.
기대: 올바른 도착점에 나타나고 호수행 출구도 계속 이용 가능하다.

C04 도시 내부 보행과 시야
항구 시장 → 두 부두 → 서쪽 방파제 등대 앞을 걷는다.
성문 → 광장 → 본성 앞 → 양쪽 생활 거리를 걷는다.
기대: 계단 없는 주요 동선에서 KCC 걸림·지면 침투·난간 이탈이 없고 카메라가 벽에 갇히지 않는다.
NavMesh 연결 검사만으로 실제 KCC·회피·카메라 품질을 통과한 것은 아니다.

C05 지도와 저장/로드
두 도시에서 지도 범위·방향·플레이어 표시를 확인한다.
각 도시의 안전한 길 위에서 빈 슬롯에 저장 후 Title로 나와 다시 불러온다.
기대: 해당 도시·위치·활성 캐릭터가 복원되고 어느 출구로든 다시 이동할 수 있다.

C06 역순 방문
도시 의뢰나 본편 완료를 전제로 하지 않고 두 도시를 다른 순서로 방문한다.
기대: 새 퀘스트·영입·본편 완료가 임의로 기록되지 않고 귀환도 잠기지 않는다.

회신: 항목 ID / 통과·실패·미수행 / 입력 장치 / 실제 결과 / 필요 시 화면·로그.
현재 위 직접 입력·왕복·저장 검수는 사용자 테스트 대기다.
신규 NPC·상점 거래·건물 내부·도시 퀘스트는 이번 제작 범위가 아니다.
