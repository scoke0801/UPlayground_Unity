# 플레이어 궁극기 모션 재설계

적용·검증 상태: [손·무기 결합과 FX 후속 수정](../../../../../docs/work-status/weapon-signature/GRIP_FX_REVISION.md). 자동 검사와 미술 인수는 구분한다.

2026-11-15 사용자 피드백: 카메라·FX 조율 후에도 동작이 궁극기로 읽히지 않는다. 기존 결과는 미술 인수 실패로 취급한다. 이 문서는 **새 동작의 제작 기준**이며 신규 클립 적용 완료 문서가 아니다.

조사·출처·검증 제한: [Sol 조사와 리드 재구성](../../../../../docs/work-status/weapon-signature/REFERENCE_REDESIGN.md). 실행 계약은 [시그니처 설계](WEAPON_SIGNATURE_SKILL_CLIP_DESIGN.md)를 따르되, 그 문서의 고정 프레임표와 기존 클립만 쓰는 연출 제한을 새 동작의 품질 기준보다 우선하지 않는다.

## 1. 이전 접근에서 바꿀 것

- 현재 1.5~3.9초 공격에 컷인·줌·이펙트를 덧붙이는 순서를 중단한다. 검수되지 않은 클립을 타이밍 표에 억지로 압축하지 않는다.
- 준비 자세, 힘을 싣는 방향, 발동의 결정적 행동, 마무리 자세를 먼저 저작한다. 머리·흉곽·골반·발·무기의 순차 가속이 있어야 한다. 팔만 목표점으로 움직이는 IK 보정으로 투척 완성을 판정하지 않는다.
- 반복 공격은 처음부터 끝까지 같은 강도가 아니어야 한다. 단, 화린은 회전 도중 정지하는 방식으로 강약을 만들지 않는다.
- 궁극기 길이는 동작 검수 뒤 확정한다. 길게 늘이는 것 자체가 해법은 아니다. 피해량·게이지 비용·쿨다운·대상 정책은 이번 연출 설계로 임의 증감하지 않는다.
- 아래는 레퍼런스를 참고한 **이 프로젝트의 신규 제안**이다. 특정 게임의 실제 궁극기를 그대로 묘사하거나 복제한 표가 아니다.

## 3. 얼굴·카메라·FX·소리의 역할

얼굴 패널은 준비 동작의 의지를 전달한다. 손·무기 해제 장면을 가리는 구도나 타이밍이면 위치·길이를 재저작한다. 현재 1.45~1.74초 값은 새 모션의 확정값이 아니다.

카메라는 축적 자세의 몸과 무기, 발동 방향, 명중 결과를 읽히게 한다. 모든 무기를 동일한 줌/각도 상한으로 다시 일괄 조절하지 않는다. 전신 무표정 렌더에서 포즈가 성립한 뒤 캐릭터별로 저작한다. 전투 카메라에서 보이지 않는 동작을 얼굴 클로즈업으로 감추지 않는다.

효과음은 준비의 마찰/긴장, 발동의 공격부, 결과의 잔향을 분리한다. 지속 회전·빔에 큰 타격음을 매 틱 반복하지 않는다. 이펙트는 실제 무기 궤적과 판정이 바뀌는 순간을 따라간다. 화면 전체 섬광·대형 문양·색 변경은 동작 부재의 대체물이 아니다.

## 4. 제작·검수 순서

1. 화린/레이네/세라를 먼저 만든다. 각각 지속 운동·투사체 해제·중량 타격의 대표이며 이 세 가지가 실패하면 나머지를 양산하지 않는다.
2. 기존 구매 클립은 재료로 사용한다. 후보 포즈/구간을 실제 장비 상태에서 비교하고 부족한 전신 동작을 Blender에서 저작한다. 원본·현행 실행본을 보존한 파생 자산으로 만든다.
3. 3/4 고정 카메라, 실제 장비, FX/컷인/흔들림 없이 시작부터 복귀까지 연속 재생한다. 준비와 힘의 전달·해제·마무리를 확인한 다음 MotionSet 이벤트를 맞춘다. 정지 포즈 네 장만으로 통과시키지 않는다.
4. 한 동작의 실제 해제/접촉을 확정한 뒤 판정·투사체·숨김·발/루트·카메라·음향을 붙인다. 타이밍 변경에 따라 캔슬·피격 중단·게이지 소비 후 결과도 재검토한다.
5. 대표 세 무기 다음 라온/아린, 설아, 연화/묘묘, 유라, 리안, 묘령, 릴리 순으로 전개한다. 공유 무기는 기존 MotionKey를 유지하되 모델별 PlayerActorAnimationMotionSet과 무기 ActorAnimationMotionSet 파생 매핑으로 분리한다. Ability/Payload를 불필요하게 복제하거나 캐릭터 이름 런타임 분기를 만들지 않는다.
6. 최종 확인은 실제 전투에서 적 한 명/다수·무타깃·벽·경사·교대·피격 중단을 포함한다. 기존 자동 검사 통과를 새 동작의 미술 승인으로 승계하지 않는다.

## 5. 유지할 계약

GAS 수치/비용/쿨다운과 기존 ID·GUID를 보존한다. 모션 변경에 맞춘 판정 시점 조정은 가능하나 피해 범위·횟수 변경은 명시한다. 관통 대시·적 속박·추가 무적·전체 적 정지·턴제 전용 무대는 이번 조사만으로 승인됐다고 보지 않는다. 일반 공격형 실행을 유지하고 시퀀스 경로 복원을 새 동작의 선행 조건으로 삼지 않는다.
