Hichi P09 r01 — 사용자 테스트 대기

준비: 열린 작업 씬을 원하는 방식으로 보존한 뒤
Assets/01.Scenes/Tests/Equipment/P09_Hichi_Review.unity를 연다.
Unity 6000.3.21f1. 검수 씬은 정적 비교용이며 자체 NPC 행동을 실행하지 않는다.

H01 / 기본·대체 모델을 정면·측면·후면에서 관찰한다.
기대: 얼굴·목·피부·머리의 뚜렷한 틈/관통/재질 소실 없음.
얼굴 방향 및 의상 실루엣의 미술 승인 여부를 별도로 남긴다.

H02 / 통합 툴 런처의 P09 빌더에서 Hichi_P09_BuildPreset을 불러온다.
Hair_01↔13, Armor_003↔011을 바꾼 뒤 프리셋을 다시 읽는다.
기대: Hichi 얼굴 유지, 별도 외부 모델 없이 P09 바디·장비 표시.
미검증 투구·긴 머리·물리 조합의 관통은 해당 조합 이름과 함께 기록한다.

H03 / 얼굴 Eye_Blink, Eye_Smile, Mouth_Smile, Lip_aa를 0/50/100으로 관찰한다.
기대: 눈꺼풀 닫힘, 입안 유지, 목 연결면 벌어짐 없음.
AI Editor 표본은 통과했으나 감정 표현의 자연스러움은 사용자 판단 대기다.

H04 / 적용할 정규 NPC와 등장 씬을 확정한 뒤 별도 테스트 저장 슬롯으로 Play Mode 실행.
대화·시선·립싱크·걷기·야간·카메라 거리 변화·씬 재진입을 확인한다.
기대: 동일 외형 유지와 기존 행동 정상, 서비스 경고·예외 없음.
현재 모델 전용 프리팹에는 NPC 행동/대화/월드 연결이 없어 이 항목은 미수행 상태다.

H05 / 실제 목표 지역의 동시 표시 인원으로 성능 비교.
하드웨어·인원·카메라·프레임 시간·메모리를 기록한다. 이번 제작에서는 미수행.

회신: 항목 ID / 통과·실패·미수행 / 실제 결과 / 화면 또는 Console 로그.
외형 결함에는 모델 조합·표정 수치·각도·동작을 함께 적는다.
