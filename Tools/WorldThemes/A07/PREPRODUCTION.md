# A07 구름등 고원 · 실제 현황과 독립 제작 입력

현재 상태는 파일 조사·입력 준비다. Editor는 A00 lease이므로 Unity 호출·씬 전환·임포트·저장을 하지 않았다. 이 폴더 밖의 파일도 수정하지 않았다.

## 현재 범위와 분산 소유

현재 디스크에서 X800~1630/Z1230~1500 검색 범위에 프리팹 인스턴스741개가 있다. 이 사각형은 편집 권한이 아니다. 후속 배치는 11개 부모 루트에 흩어져 있으며 북부 벌목 취락과 혼합림183개, 빈 공간 고원 쉼터182개, 북서 고원 혼합림168개, 북동 바위숲96개, 북부 옛 성채49개 등이 포함된다. 저장된 위치 override를 집계한 값이며 실제 bounds·접지·보행·렌더 검증은 아니다.

검색 범위에 걸린 옛 성채 하위 프리팹 인스턴스49개는 A10 소유로 분리한다. 성채 전체 수량이나 건물49채라는 뜻은 아니다. A07은 고원 지면·외부 조망·기존 길과의 연결만 담당한다. `호수와 사당`이나 `그늘숲` 부모 아래 있어도 고원 경로를 안내하는 분산 표식이 있으므로 계층 이름만으로 제외하지 않는다.

## 기존에 구현한 탐험 계약

Iteration05는 남향 탐색→낮은 어깨에서 호수 발견→전망→본길 오르막 귀환을 구현했다. 기존 본길이나 역방향 진입·생략을 잠그지 않으며 새 보상·퀘스트·저장 플래그가 없다. 옛 순환로 도색 잔존과 떠 있던 나무·바위는 당시 수정된 범위다. 새 근거 없이 일회성 apply-upland-discovery나 전체 재생성을 다시 실행하지 않는다.

보존 경로는 `upland-study.json`에 기재했다. 이는 현재 이동을 다시 통과했다고 주장하는 자료가 아니다. 실제 양방향 경로·낙하·회피·저장 복구는 새 기준선과 사용자 U5-01~05로 확인해야 한다.

## 현재 사진의 한계와 첫 조사 후보

Iteration05의 shelf/view/choice 사진을 직접 보았다. 낮은 풀 위로 호수와 생활권이 열리는 방향과 빈 조망 중심이 핵심이다. 사진은 안개off·FOV65의 과거 Editor 렌더로, 현재 룩·풀이 보이는지·실제 TPS의 합격 증거가 아니다.

현재 낮은 어깨(1225,1265) 주변에는 후속 나무(1238.53,168.4042,1252.27), (1255,169.7572,1267.23), (1217.96,170.1831,1248.2) 등이 추가되어 있다. 이 나무들이 현재 조망을 가리는지는 아직 실제 화면으로 확인하지 않았으므로 결함으로 단정하거나 삭제하지 않는다.

첫 짧은 core 후보는 X1200~1260/Z1250~1300이다. A00가 실제 나무/암반 footprint·길·활동 공간·호수 시선과 겹치는 범위를 확인해야 한다. `maskAuthorized=false`, `corridorsLiveConfirmed=false`로 잠갔다.

## 제작 방향과 자원

기존 Detail6종과 InstanceCountMode·80m 거리·맵을 유지한 동일 조건 기준 렌더가 먼저다. 풀 미렌더는 이미 영구 수정·재로드 검증이 끝난 문제이므로 다시 셰이더/산포 모드를 고치지 않는다. 짧은 풀의 실제 키·중경 연속성·색 띠가 부족한지 본 뒤 필요한 core 전용 변형만 제안한다.

낮은 채도의 초지·마른 풀·바위턱을 기존 능선/안부에 연결하고, 중경의 표면 반복을 군락 경계와 재료 전이로 줄인다. 나무 추가나 풀 밀도 수치 증가를 목표로 삼지 않는다. 절벽 후보는 보조이며 기존 낮은 풀과 노출 암반의 비율을 먼저 비교한다. 기존 TerrainLayer0/3/4/2의 정확 경로·GUID·파일 hash를 입력에 기록했다. 외형·URP·충돌·LOD·성능은 실제 검토 전이다.

독립 씬은 전체 전용 TerrainData와 수정용 레이어/재질을 사용하며, 원본 전체 hash·맵 내용 불변·core 밖 변경0을 확인해야 한다. 레이어 재연결로 alpha가 초기화되는 함정은 전체 맵 복원과 전수 비교로 막는다. 기존 바람·표시거리·산포 모드와 영역 밖 Detail을 보존한다.

고원의 원경 조망에는 멀리 있는 호수 수면이 필요하다. 로컬 reference만 복제해 수면이 사라진 화면을 만들지 않고 원경 `LakeWater`의 native renderer/mesh를 ReferenceOnly로만 포함한다. 발소리·진행·전역 작성자는 복제하지 않으며 A02 WaterV2를 승인된 공용 물재질로 연결하지 않는다.

입구·대표·활동·출구·양쪽 경계의 구도 후보는 JSON에 있다. 실제 촬영 전 눈높이·수관/지면 관통을 확인하고 자기 검수 씬의 실효 하늘 두께1·채도15/대비2/Bloom0.08·안개ON을 기록/assert한다. 현재 카메라 후보는 미촬영이다.

새 모델/텍스처 생성은 하지 않았다. 실제 기존 후보의 화면 결손이 확인될 때만 A11에 규격과 비교 증거를 넘긴다. 사용자 미술·긴 플레이 인수, Player/Addressables 빌드·본편 통합은 미수행이다.
