01

전체 그림

카메라는 누가 지휘하나(Manager) → 어떤 모드인가(Director·Behavior) → 포즈를 어떻게 만드나(Modifier) → 어디에 반영하나(Resolver) 순서로 나뉜다. 위에서 아래로 읽으면 한 프레임의 책임 순서와 같다.

핵심은 Behavior가 포즈 계산 방식을 갖고, Modifier가 계산의 작은 단계를 갖는다는 점이다. Modifier는 자신이 언제 켜질지 판단하지 않는다. 상태 판단은 Director와 Behavior 몫이다 (ICameraModifier.cs).

02

한 프레임의 흐름

입력은 OnUpdate에서, 포즈 계산과 적용은 OnLateUpdate에서 처리한다 (CameraManager.cs:333, :380). 플레이어와 카메라 대상이 움직인 뒤에 포즈를 계산하려고 LateUpdate에서 한다.

포즈를 평가할 수 없는 프레임(대상 없음 등)에는 가려진 오브젝트가 복귀하도록 가림 페이드만 진행하고 끝낸다.

03

Modifier 파이프라인

CameraBehaviorBase.EvaluatePose는 시드 포즈를 만든 뒤 등록된 Modifier를 Priority 오름차순으로 실행해 포즈를 누적한다 (CameraBehaviorBase.cs:59). 단계는 CameraFrame(상태·이펙트·포즈)만 읽고 쓰므로 서로의 내부 값을 몰라도 된다.

순서에는 의미가 있다. 추적(700)이 피벗을 정한 뒤 프레이밍(730~740)이 거리 상한을 정하고, 마지막에 충돌(800)이 그 상한 안에서 암을 접는다. 보간 상태(SmoothDamp 속도 등)는 Modifier 인스턴스가 필드로 들고 있어서 프레임 사이에 이어진다.

04

카메라 모드

CameraDirector는 모드를 등록해 두고 전환한다. PushMode/PopMode로 이전 모드를 스택에 쌓아 복귀하고, 스택이 비면 InGame으로 돌아간다 (CameraDirector.cs:54-90).

어떤 모드를 등록할지는 CameraSettings.enabledModes가 정하고, 팩토리는 5종만 만든다 (CameraManager.cs:619). CameraModeType.Cinematic은 열거형에만 있다.

05

이식 경계

Camera 모듈은 게임 시스템을 직접 부르지 않고 ICameraRuntimeAdapter 포트로만 접근한다 (CameraRuntimeServices.cs). 다른 프로젝트로 옮길 때는 이 인터페이스만 새로 구현하면 된다. 이식 절차는 카메라 모듈 이식 가이드를 따른다.

예외로, Actor에서 CameraManager.Instance를 쓰는 기존 경로는 의도된 asmdef 예외다. 새 기능은 먼저 기존 계약이나 어댑터로 표현할 수 있는지 본다.

06

용어

용어뜻
Behavior카메라 모드 하나의 동작. 입력 처리와 포즈 계산을 맡는다.
Modifier포즈 계산의 한 단계. 추적·락온·충돌처럼 하나의 책임만 가진다.
CameraPose한 프레임의 결과값. 피벗·카메라 위치·회전·FOV.
CameraEffectState흔들림·줌 같은 이펙트가 더하는 델타 묶음(yaw·pitch·거리·오프셋·FOV·위치).
PriorityModifier 실행 순서. 숫자가 작을수록 먼저 실행된다.
07

확인한 것과 남은 것

  • 코드 대조 결과: 위 구조는 이번에 Assets/02.Scripts/Camera/의 코드와 대조했다. Modifier 14개의 역할 설명은 클래스 이름과 주석에서 요약한 것이라 내부 로직을 모두 검증한 것은 아니다.
  • 마이그레이션 문서와 코드가 어긋난다: 마이그레이션 계획은 Stage 5를 ‘미착수’로 적었지만, 코드에는 CameraResolver가 있고 OnLateUpdate가 쓰며, 죽은 코드로 지목된 UpdateCameraPosition·ComputeCapsuleClearance는 검색되지 않는다. 다만 CameraManager.cs는 아직 1495줄이라 슬림화가 끝났다고 볼 수 없다. 계획 문서 갱신이 필요하다.
  • 미검증: Stage 5 게이트로 이월된 대화 카메라, 대화 녹화·재생, 스냅샷 시퀀스의 플레이 검증과 위키가 적은 카메라 Phase 7 스모크는 이번에 실행하지 않았다. 이 문서는 게임을 실행한 결과가 아니다.
  • 관련 문서: 프레임워크 설계, 카메라 가림, 락온.
