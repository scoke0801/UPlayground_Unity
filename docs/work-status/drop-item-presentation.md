# 드롭 모델 조사와 이름표 연결선 개선

최신 후속: [모델 제작·연결 확장](drop-item-world-model-expansion.md)에서 최종 컴파일·EditMode8/8과 모델74종 연결/표시 검사를 확인했다. 아래 실패·미확인 기록은 당시 조사 이력이며, 실제 플레이/최종 미술은 계속 사용자 테스트 대기다.

## 조사 단계 — 2026-11-13

정본: [월드 모델 저작](../../Assets/docs/guide/DROP_ITEM_WORLD_MODEL_AUTHORING_GUIDE.md), [UI 저작](../../Assets/docs/guide/UI_UX_AUTHORING_GUIDE.md).

Unity AssetDatabase에서 `Assets/10.Datas`의 ItemSO 113종을 조회했다. `worldPrefab` 연결 22종, 장착 프리팹만 있는 장비 27종, 양쪽 모델이 없는 항목 64종이다. 마지막 그룹은 방어구 58종, 쌍도끼·쌍검·창·채찍 4종, 당근·호박이다. 신규 모델 제작은 이번 범위에 포함하지 않는다.

- 첨부 화면의 소검_1: 장착용 `Sword_001.prefab`이 있지만 드롭 경로가 `worldPrefab`만 읽어 메달로 대체했다.
- 몬스터 정수: `WorldItem_MonsterEnergy.prefab` 연결이 존재한다. [제작 원본 프리뷰](../../ArtSource/DropItems/MonsterEnergy/MonsterEnergy_preview.png)를 직접 확인했으며 첨부 화면의 보라색 번개와 같은 형상이다. 모델 누락이 아니다. 프리뷰 확인은 현재 게임의 미술 인수를 뜻하지 않는다.
- 이름표: 알파 0.85의 수직 Image를 매번 그렸으며 모델 부유를 반영하지 않는 고정 높이를 가리켰다. 선은 이름표 자식이라 다른 이름표 위를 지날 수 있었다.

기존 미커밋 변경을 확인했다. 이 작업의 런타임 대상 4개 파일에는 기존 diff가 없었다. 기존 위키의 다른 작업 기록을 보존한다.

## 구현·검증 단계

소스 반영. 장착 프리팹 재사용(명시 worldPrefab 우선, CharacterBuiltIn은 메달 유지), 얇아지고 흐려지는 연결선, 모델 부유 추종, 모든 이름표 뒤 렌더링, 양 끝 여백, 짧거나 역방향인 선 숨김, 이름표와 동기화한 페이드·비활성을 반영했다. 기존 폭 설정은 유지하고 시작 불투명도를 `GroundDropSettingsSO.labelTailOpacity`(기본0.32)로 조절한다. 원래 선 알파는0.85였다.

장착 프리팹27종의 MeshFilter 조사에서 활4종·화살3종은 일반 메시가 없었다. 실제 YAML은 SkinnedMeshRenderer와 메시 참조를 가지고 있으므로 메시 바운드 계산을 함께 지원했다. 신규 모델·재질·ItemSO 연결 에셋을 제작하거나 변경하지 않았다.

Hot Reload allowlist 밖 변경이며 시작 당시 Editor가 Edit Mode이므로 정상 컴파일을 요청했다. 연결선 클래스 로드와 중간 컴파일 종료는 확인했으나 **SkinnedMeshRenderer 보완을 포함한 최종 소스 컴파일은 미확인**이다.

### 자동 검사와 제한

- `git diff --check`: 통과. 신규 테스트는 모델 우선순위·고유무기 메달·일반/스킨 메시 크기·연결선 방향/숨김/페이드/메시를 다루는8케이스다.
- EditMode job `894f834d950e4277a41855aea4f2df9b`: **초기화 실패, 실행0건**. `Test job failed to initialize (tests did not start within timeout)`를 반환했다. Console에는 Play Mode에서 Editor 씬 API를 사용할 수 없다는 Test Runner 예외4건이 있었다. 테스트 assertion 실패나 통과로 집계하지 않는다.
- 이 과정에서 MCP 연결이 끊겼다가 동일 인스턴스 `UPlayground@fddd0702`로 복귀했다. 이후 상태는 LakeVillageWorld Play 전환 중/stale이며 후속 코드 실행도 연결 종료로 실패했다. 전환을 누가 시작했는지는 확인하지 못했다. Play 종료 제한을 우회하거나 Editor를 재시작하지 않는다.
- 모델 정규화·획득·포커스/클릭·겹침·최종 화면은 **사용자 테스트 대기**다. 최종 컴파일 확인 및8케이스 재실행이 먼저 필요하다. 자동 검사 통과나 화면 인수 완료로 보고하지 않는다.

### 사용자 확인 명세

본편의 기존 드롭 재현 경로를 사용한다. 저장 데이터 변경을 위해 새 게임이나 저장 초기화를 할 필요는 없다. 플레이 종료 후 Unity 자동 컴파일 오류가 없는 상태에서 Test Runner의 `GroundDropPresentationTests`를 실행한다.

| ID | 절차 | 기대 결과·실패 기준 |
|---|---|---|
| DI01 | 소검·활·화살을 드롭하고 회전·착지를 관찰 | 메달 대신 무기 표시. 모델이 안 보이거나 크기·피벗이 어긋나면 실패 |
| DI02 | 몬스터 정수와 모델 없는 장비를 드롭 | 정수는 기존 번개 모델, 모델 없는 장비는 메달. 이름·아이콘·획득 대상 일치 |
| DI03 | 여러 아이템을 겹쳐 드롭하고 카메라 이동 | 이름표 뒤의 가는 선이 모델 부유를 따라가며 끝으로 갈수록 흐려짐. 선이 이름을 덮거나 모델을 관통하면 실패 |
| DI04 | 커서로 이름표 획득, 패드 포커스/획득, 팝업 열기/닫기·거리 이탈 | 기존 획득·포커스 유지, 비활성 이름표의 선이 남지 않음. 예외는 별도 실패 |

결과는 `DI번호 / 통과·실패·미수행 / 실제 결과 / 입력 장치·화면`으로 남긴다. 근거리/8m·풀밭·낮/밤의 선 가독성과 모델 품질은 사용자 판단으로 확정한다.
