# 시그니처 궁극기 직접 테스트

[설계와 SG01~SG16 전체 명세](../../../Assets/docs/design/combat/player/WEAPON_SIGNATURE_SKILL_CLIP_DESIGN.md#10-사용자-테스트-항목) · [현재 적용·자동 검사 상태](STATUS.md)

아래 항목은 모두 **사용자 테스트 대기**다. 자동 검사는 입력감·미술·멀미를 대신하지 않는다.

## 준비

- 이 작업의 코드·데이터가 적용된 Unity Editor에서 CombatTestMap을 연다. Player/Addressables 빌드는 별도 생성하지 않았다.
- 기존 저장 슬롯을 덮어쓰지 않는 테스트 상태를 사용하고 궁극기 게이지를 채운다. 사용 입력 장치(키보드/마우스 또는 게임패드)를 기록한다.
- 정규 플레이어 12명(H09 제외), 적 한 마리·일렬 세 마리·다섯 마리, 벽·기둥·경사면을 준비한다. 같은 무기 공유 캐릭터도 각각 확인한다.

## 동작·복구

| ID | 조작 | 기대·실패 기준 |
|---|---|---|
| SG01 | 라온·아린 각각 대상 있음/없음에서 발동 | 둘 다 실행. 대상 앞 정지/허공 대시, 지나온 직선만 피격. 칼·칼집이 손을 벗어나거나 이동이 멈추면 실패 |
| SG02 | 설아 락온/비락온, 움직이는 적 | 락온 위치 또는 전방 12m 지면에 반경 4m 화살비. 낙하와 피해 시점 일치, 대상당 최대 6회. 발사 뒤 회피 가능 |
| SG03 | 레이네 평지·경사·벽 앞 | 2.5~3m 도약, 투척 뒤 0.3초에 지면 폭발 1회. 창 궤적·착탄 균열/파편·복귀 손 섬광 확인. 비행 접촉 추가 피해·공중 정지·창 미복구는 실패 |
| SG04 | 화린 회전 중 이동·카메라 조작·피격 | 2.5초 회전 동안 느린 이동, 회전 5회+마무리. 적 AI·리액션이 계속 동작. 피격 중단 뒤 이동 잠금이 남으면 실패 |
| SG05 | 유라 장판 생성 후 회피·교대·사망 | 3초 동안 반경 3.5m 안에만 최대 12틱. 교대 후 유지, 사망·씬 이탈 시 정리 |
| SG06 | 연화·묘묘, 일직선/벽 뒤 적 | 18m 빔 전체가 보이며 벽 뒤에도 같은 판정. 빔 밖 피격·벽에서 잘린 FX는 실패 |
| SG07 | 세라·릴리 정면·측면, 공격 속도 다른 상태 | 거대 검 디졸브 출현·접지/본타 일치·잔류 후 분해 확인. 형상보다 넓은 본타, 속도 변경에 따른 접지 시차는 실패 |
| SG08 | 리안 원형 공격, 회전 3무기 번갈아 | 몸보다 채찍 원이 읽힘. 채찍 몸/무기 클립이 분리되거나 회전 3종의 실루엣을 구분하기 어려우면 실패 |
| SG09 | 묘령 투척 중 가드·패리·피격, 착지 뒤 회피 | 방패 없는 동안 방어·반격 불가, 보호 효과 체감. 하강 중 방패 확대·문양/트레일, 반경4.5m 착탄 예고·착탄1회·방패 복귀 섬광. 예고는 사망·장면 이탈 후 남지 않아야 함. 피격 중단 뒤 보호 효과는 최대 1.83초 내 끝남 |
| SG11 | 라온·화린 궁극기, 도중 피격·교대·사망 | 얼굴은 한 번만 짧게 표시. 적이 계속 움직이고 반응함. 시퀀스 스테이지/전구간 무적·적 정지 없음. 종료 뒤 카메라·시간 복귀 |
| IV-1/6 | 창·방패 숨김 중 피격·교대·사망·씬 이탈 | 무기·얼굴·입력·중력·카메라·슬로가 복구. 이전 얼굴 종료가 새 얼굴을 닫으면 실패 |

## 화면·연속 사용

| ID | 조작 | 기대·실패 기준 |
|---|---|---|
| SG10/14 | 9무기 각 10회, 이동 중 카메라 조작 | 무게감 차이와 명중 정보가 읽힘. 반복 섬광·흔들림·슬로가 피로하거나 조작을 막으면 실패 |
| SG12/13 | 락온/비락온, 큰 적·다수·벽·기둥·경사 | 시전자·무기·판정 위치를 볼 수 있음. 카메라 튐·가림·각도 잔류·착탄점 이탈은 실패 |
| SG15 | 12명 각각 컷인 확인 | 각자 이미지, 공유 무기도 자기 얼굴. 유라 포함. 늘어짐·다른 얼굴·중복 표시·오류는 실패 |
| SG16 | 짧은 컷인·히트스톱·슬로·일시정지 | 대표 임팩트 전에 퇴장, 실시간 진행·정지 시 정리. 패널이 임팩트를 가리거나 남으면 실패 |

기존 U01~U09는 이번 일반 공격형 경로로 재인수한다. U03의 기존 긴 0.2배속, U04의 전용 스테이지/HUD 처리, U07의 전구간 입력·적 잠금은 이번 기대 결과가 아니다. U08 무게감·U09 카메라는 SG10~14로, 기존 얼굴 CR/F/M은 SG15~16으로, 라온 일반·교대·특수 FX 회귀 KFX03은 별도로 확인한다.

회신: `ID / 통과·실패·미수행 / 캐릭터·입력 장치·시작 상태 / 실제 증상 / 영상 또는 Console 오류`.
