P09 실제 프리팹 시각 검수 자료 재생성

열람: output/NpcAppearanceReview/index.html
검수 보고: output/NpcAppearanceReview/REVIEW_REPORT.md
사용자 동작 테스트: output/NpcAppearanceReview/PLAY_MODE_TEST.md

1. 열린 Unity에서 Edit Mode와 URP를 확인한다. 같은 프로젝트를 두 번째로 열지 않는다.
2. MCP execute_code로 다음을 실행한다.
   UPlayGround.EditorTools.UPlaygroundToolCatalog.TryExecute("p09.npc-appearance.capture", out string error)
   또는 UPlayGround.Editor.P09Builder.NpcAppearanceReview.CaptureAll();
3. output/NpcAppearanceReview/progress.txt가 288/288인지 확인한다.
   capture-error.txt가 있으면 내용을 확인한다. 이전 실행 실패 파일인지도 구분한다.
   이번 실행은 오류 파일을 생성하지 않았다.
4. 프로젝트 루트 PowerShell에서 실행한다.
   powershell -NoProfile -ExecutionPolicy Bypass -File Tools/NpcAppearances/BuildReviewSheets.ps1
5. 자기 검사:
   powershell -NoProfile -ExecutionPolicy Bypass -File Tools/NpcAppearances/ValidateReview.ps1

BuildReviewSheets는 라벨 없는 Unity 촬영 PNG를 입력으로 받는다.
라벨을 붙인 뒤 다시 실행하면 규격 검사에서 거부한다. 재실행 전 Unity 촬영을 먼저 완료한다.
변형별 해상도/장수/빈 배경 검사는 생성 오류를 찾는 보조 수단이며 시각적 적합성 통과가 아니다.
이미지 제목과 파일명 모두 원본 프리셋 ID를 사용한다. M=남성, F=여성, 순번은 01~12다.

기존 프리팹 및 데이터는 읽기만 한다. 원본에 AppearanceApplier를 재적용하지 않는다.
촬영은 저장된 T 포즈이며 대기/이동 애니메이션의 대체 검증이 아니다.
전용 Preview Scene과 인스턴스/텍스처를 finally에서 정리하고 씬을 저장하지 않는다.
촬영 도구는 Editor 전용이고 UPlaygroundTool 속성만 붙였다. 런처에는 등록하지 않았다.

참고: 생성기 EditMode 테스트 본문 11개는 통과했지만 Test Framework 종료 PerformUndoTask에
네이티브 Assert가 발생했다. Console 무오류나 안전한 정리 완료로 확대 해석하지 않는다.
사용자 Undo 이력을 지우거나 완료된 P09 빌드의 구조 Undo를 되감지 않는다.
대기/이동 MotionSet 누락 288개는 이번 조사에서 발견한 미해결 오류다.
허용 목록 및 생성물 변경, 프리팹 재빌드, Player/Addressables 빌드는 수행하지 않았다.
