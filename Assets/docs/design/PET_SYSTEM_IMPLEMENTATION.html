펫 시스템 1차 구현 및 테스트

원본 설계의 기본 동행·회수 수직 구현이다. 코드와 에셋을 연결했으며 실제 Unity Editor Play Mode의 조작·연출·장시간 동행은 사용자 테스트 대기다. 설계 전체의 완료를 뜻하지 않는다.

반영 범위

  • 파티 세션 소유 PetManager, PetCatalog/Definition/Follow/Loot 데이터, ActorDatabase 등록, Pet.Monkey 액터, KCC 이동과 NavMesh 완전 경로, 저주기 Brain/회수 판단.
  • 원숭이 외형 Monkey.00~09, 기존 sharedMaterial 재사용, IdleA/Walk/Run MotionSet. 기본 신규 게임에서 원숭이를 지급·동행한다. 파티 슬롯과 캐릭터 enum은 사용하지 않는다.
  • 캐릭터 교체 시 같은 PlayerActor 루트 추종, 씬 변경 시 액터 회수, 사망·대화·상위 입력·일시정지 중 행동 정지, 비접지 시 숨김, 안전 지상·경로 확인 후 합류. Pet 레이어는 지형과만 충돌한다.
  • 몬스터·채집·낚시·야생동물 아이템 보상을 선지급에서 실제 바닥 드롭으로 변경. 퀘스트·상점 직접 지급과 경험치·골드·바이탈오브는 기존 계약을 유지한다.
  • 드롭의 PendingSpawn/Available/Committing/Collected 상태, 만료 가능한 펫 예약, 클릭 우선 획득, 전체 장비 옵션 보존, 인벤토리 삽입 성공 후 획득 알림·퀘스트/제작 카운트 확정. 지급 실패 시 잔류하며, 확정 중 저장은 거절한다.
  • 바닥 아이콘과 클릭 가능한 이름, 거리·지형 시야 재검사, 겹침 위치 조정, 패드 근접 이름 초기 포커스·방향 선택·상호작용 즉시 획득. 아이템 클릭/패드 선택은 공격·퀵슬롯 선입력 전 소비한다.
  • 기존 메뉴 하단의 동행 펫 버튼과 UI_Scene_PetMenu. 동행/해제와 외형 선택, 초기 포커스, 외형 조작에서 Cancel 시 동행 버튼 복귀, 다음 Cancel로 닫기. 기존 UI 리소스와 unscaled 기본 전환 사용.
  • 저장 버전 3.5의 선택적 pet과 독립 groundDrops 영역. 구버전 펫 미보유는 그대로 유지하며 신규 게임의 초기 지급과 구분한다. 미확인 콘텐츠 ID와 친밀도 값은 보존하고 경로·Transform·예약은 저장하지 않는다.

후속 단계와 아직 검증하지 않은 계약

교감·관심 지점·Dig·친밀도 획득/해금·버프·장난 말풍선·공격 지원은 미구현이다. 친밀도는 저장만 준비했으며 자동 증가하지 않는다. 버프/공격의 GAS 쿨다운·Effect 스냅샷 계약은 해당 단계에서 먼저 확인한다. 외형 메뉴의 실제 모델 미리보기와 최종 시각 마감도 남아 있다.

현재 작업 트리에서 실제 회차 전환 매니저/진입점을 찾지 못했다. 따라서 회차 귀속 드롭 정리·사전 안내는 연결하지 않았으며, 회차 완료 기준으로 보고하지 않는다. 보유·외형·선택은 명시적 새 게임 초기화 전까지 유지한다. 새 게임은 모든 드롭과 펫 상태를 초기화한다.

현재 열린 월드에는 NavMesh가 있지만, 원숭이 agent·캡슐·보폭·좁은 경로의 조합은 실제 플레이로 판정해야 한다. 유효 경로가 없으면 숨김 상태를 유지하며 벽 통과 직선 추종으로 대체하지 않는다. 화면 밖 복귀 후보를 우선하지만 항상 화면 밖 합류를 보장하지는 않는다. 다량 드롭의 표시 예산·프로파일링과 지역 경계에서의 표시도 검수 대상이다.

검증 기록

Unity 6000.3.21f1에서 신규 타입 컴파일과 실제 에셋 로드를 확인했다. ActorDatabase의 Pet.Monkey 등록, 외형 10개 몸체 lilToon·얼굴 머티리얼 참조, 신규 프리팹 4개의 Missing Script 0건, Pet 레이어의 플레이어/적 비충돌·지형 충돌, PetCatalog/GroundDropSettings Addressables 키 및 Fast Mode 설정을 확인했다.

최초 신규 규칙 11개 통과. 관련 Item/Content/Input EditMode 회귀 256개 중 254개 통과, 2개 실패: 저장 버전 기대값 3.4는 3.5로 갱신했고, 미수정 대검 시험 몬스터가 테스트의 공용 AbilitySet 대신 AbilitySet_GreatSword_Normal을 참조하는 불일치는 범위 밖으로 남겼다. 최종 선별 재검사 결과는 Tools/PetMonkey/ImplementationValidation.json을 참조한다.

Play Mode 사용자 입력·화면·보폭·안전 복귀·저장/로드의 통합 시나리오는 미수행이다. 저장 API를 호출해 사용자의 슬롯을 변경하지 않았다. 프로젝트 검증 지침에 따라 Player/Addressables 빌드는 실행하지 않았다.

사용자 테스트 준비

Z는 아이템 줍기 전용 입력이며 가까운 획득 가능 아이템 한 개를 즉시 줍는다. 대상이 없으면 아무 동작도 하지 않는다. 수동 질주 입력과 일정 시간 이동 후 자동 질주 전환은 제거했다. 원숭이 표시 크기는 기존의 25%이며 Pet_Monkey → PetPresentation → Model Scale에서 조절한다. 충돌 캡슐도 축소했다. Z 연속 입력의 단일 지급과 표시 크기의 최종 화면 비교는 사용자 테스트 대기다.

  1. Unity 6000.3.21f1에서 Boot부터 시작하고 새 테스트 게임을 만든다. 기존 슬롯을 덮어쓰지 않고 별도의 테스트 슬롯 두 개를 사용한다. 이전 버전 게임에서는 새 3.5 저장을 읽을 수 없으므로 원본 슬롯을 유지한다.
  2. NavMesh와 Ground 레이어 지형이 준비된 기존 월드에서 진행한다. 키보드/마우스와 게임패드를 각각 준비하고 Console 오류를 확인한다. 메뉴의 동행 펫에서 원숭이를 쉬게 하면 수동 획득을 독립적으로 검사할 수 있다.
  3. 마우스 클릭 검사는 기존 커서 표시 입력으로 커서를 보인 뒤 수행한다. 패드는 아이템 근처에서 이름 포커스를 확인하고 기존 방향키와 상호작용 입력을 사용한다. 조작 키는 현재 사용자 바인딩을 따른다.

L05바닥 드롭을 남긴 상태를 슬롯 A에 저장한다. 장비를 획득하고 강화/옵션을 기록한다. A를 로드해 재획득하고 비교한다. 획득 후는 슬롯 B에 저장하고 로드한다.A에서 같은 드롭과 옵션 복원, B에서 재생성 없음. 인벤토리 수용 실패 시 바닥에 잔류. 씬 왕복 뒤에도 누락·재추첨·복제 없음.
L06이름 밀집·벽 뒤·화면 밖·범위 밖을 확인하고 패드 방향 선택과 상호작용으로 줍는다. 상위 메뉴 중에도 시도한다.가림·거리·상위 UI 정책 적용. 선택한 항목 하나만 획득. 패드 이름 탐색이 퀵슬롯을 사용하거나 클릭이 공격으로 전달되면 실패.

각 항목은 진행 성공과 Console 오류 여부를 따로 기록한다. 실패 회신 형식: 항목 ID / 통과·실패·미수행 / 외형 번호 / 씬·시작 상태·슬롯 / 입력 장치 / 실제 증상 / Console 로그 또는 화면.

재적용과 변경 보존

ExternalAssets와 Addressables 설정은 기존 Git 제외 정책을 유지했다. 새 환경 또는 외부 패키지 갱신 뒤에는 Edit Mode에서 UPlaygroundToolCatalog.TryExecute("PetSystem.CreateFirstCompanion", out string error)를 실행한다. 이 제작 진입점은 툴 런처에 노출하지 않았다. 프로젝트용 프리팹·SO·GUID와 전용 Pet 레이어 설정은 저장소에 남긴다.

기존 메뉴의 Unity 재직렬화는 자동 승인 검토에서 차단되어 원복했다. 수정된 제작 도구는 기존 189개 오브젝트의 값·순서를 보존하고 새 버튼과 참조 두 곳만 추가한다. 기존 이동·NPC 말풍선 등 사용자 변경은 보존했다. 커밋과 검증용 빌드는 만들지 않았다.
