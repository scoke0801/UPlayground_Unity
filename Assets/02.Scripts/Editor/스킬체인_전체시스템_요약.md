## 🎮 사용 워크플로우

### 개발 단계
```
1. Unity Editor
   └─ Tools → Skill Chain Editor
   
2. 노드 추가 및 연결
   └─ 드래그 앤 드롭으로 체인 구성
   
3. Json 저장
   └─ SkillChainData.json 생성
   
4. Addressable 설정
   └─ Json 파일 등록
```

### 런타임 단계
```
1. 게임 시작
   └─ JsonDataManager.Init()
   
2. Json 로드
   └─ Addressable에서 데이터 로드
   
3. 플레이어 입력
   └─ X키: SetData("CurrentSkillID", 2001)
   
4. 스킬 체인 실행
   └─ SkillActionStateSO.OnEnter()
   
5. 입력 윈도우 감지
   └─ OnUpdate()에서 입력 체크
   
6. 다음 스킬 분기
   └─ X/Y 입력에 따라 nextSkillID 결정
   
7. 체인 계속 또는 종료
   └─ 분기 있으면 계속, 없으면 종료
```

## 🎮 실제 사용 예시

### 게임 코드
```csharp
public class PlayerBrain : CharacterBrain
{
    [SerializeField] private SkillActionStateSO skillChainState;
    
    void Update()
    {
        // X키로 검 체인 시작
        if (Input.GetKeyDown(KeyCode.X))
        {
            SetData("CurrentSkillID", 2001);
            ChangeState(skillChainState);
        }
        
        // Y키로 창 체인 시작
        if (Input.GetKeyDown(KeyCode.Y))
        {
            SetData("CurrentSkillID", 3001);
            ChangeState(skillChainState);
        }
    }
}
```

### 체인 진행 로그
```
[사용자] X 키 입력
[System] 스킬 2001 실행
[System] 입력 윈도우 활성화 (50%)
[사용자] X 키 입력
[System] 다음 스킬: 2002
[System] 입력 윈도우 활성화 (50%)
[사용자] Y 키 입력
[System] 다음 스킬: 2011
[System] 체인 완료
```
