정규 다온 사용자 테스트 명세

상태: 아래 Play Mode 항목은 사용자 테스트 대기. Editor 렌더와 참조 검사는 별도 통과했다.
준비: 현재 작업본, 기존 정상 게임 진입 경로, 생명의 호수의 다온 배치(1006, 62.56, 439).
기존 저장 슬롯은 덮어쓰지 말고 별도 검증 슬롯을 사용한다. 키보드/마우스 또는 게임패드 종류를 기록한다.
씬 단독 실행으로 서비스 초기화를 생략하지 않는다. 검사 후 임시 설정과 게임 시간을 복구한다.

D01 등장: 정상 진입 후 다온에게 접근한다. 새 얼굴, 갈색 Hair_03, 보라색 목도리와 방어구 05가 보여야 한다.
실패: 옛 얼굴, 머리/옷 누락, 분홍 재질, 중복 다온, 기존 위치에서 비정상 이탈.
D02 대화: 다온과 대화를 시작하고 진행·종료한다. 기존 대화가 이어지고 새 초상화가 표시되어야 한다.
실패: 다른 화자 초상화, 대화 진행 불능, 카메라 근접에서 눈/입/목의 틈, 시선·립싱크 파손.
D03 움직임: 생활 동작과 보행을 관찰하고 카메라를 정면·측면·후면으로 이동한다.
실패: 머리카락 이탈, 두피 관통, 목 벌어짐, 갑옷의 심한 관통, 발 접지 파손, 거리에 따른 얼굴 소실.
D04 야간: 게임의 정상 시간 진행 또는 기존 시간 조절 도구로 야간을 확인한다.
실패: 얼굴만 발광하거나 검게 소실됨, 눈 하이라이트/피부가 조명과 어긋남, 초상화 가독성 저하.
D05 재진입: 대화를 끝낸 뒤 다른 지역으로 이동하고 돌아온다. 검증 슬롯 저장/로드도 확인한다.
실패: 다온 중복·소실, 기존 대화/생활 진행 초기화, 옛 외형으로 복귀.
D06 공유 인물: 항구의 보라·유나와 FarmWorker_0 사용처를 확인한다.
실패: 다온의 새 얼굴/헤어로 바뀜, 각 인물의 데이터·동선·외형 누락.

D07 중립 시선: D01 상태에서 얼굴 정면을 확인한 뒤 대화를 시작하고 좌우에서 접근한다. 중립 상태의 동공이 한쪽으로 함께 쏠리지 않고, 눈 감기 뒤에도 같은 위치로 돌아와야 한다.
실패: 평상시 옆눈질 고정, 양쪽 눈이 서로 다른 방향을 봄, 눈꺼풀을 뚫는 동공/하이라이트, 대화 종료 뒤 시선 고정.
D08 피부색: 같은 화면에서 얼굴·목·노출된 허벅지를 비교하고 낮과 야간에 반복한다. 표면 방향에 따른 명암은 허용하되 얼굴만 주황색이거나 다른 피부로 붙인 듯한 경계가 없어야 한다.
실패: 얼굴만 과도하게 붉음/회색/발광, 조명 전환 때 얼굴과 몸의 밝기가 서로 반대로 변함.
수정 후 Editor 참고 화면: output/DaonGazeSkinFix/After/World_Lake_Daon.png. 이 캡처는 D07/D08 Play Mode 통과를 대신하지 않는다.

각 항목에서 화면 판정과 Console 예외 유무를 따로 기록한다.
회신: 항목 ID / 통과·실패·미수행 / 실제 결과 / 입력 장치 / 화면 또는 Console 로그.
Player 실행·군중 성능과 미검증 헤어·투구 조합은 위 검사 통과와 별개다.
