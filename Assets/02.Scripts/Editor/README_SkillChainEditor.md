# Skill Chain Editor

Unity에서 스킬 체인 트리를 시각적으로 편집하는 노드 기반 에디터입니다.

## ✨ 주요 기능

### 📦 노드 기반 편집
- 드래그 앤 드롭으로 노드 배치
- 시각적 연결선으로 스킬 체인 구성
- 실시간 미리보기

### 🎨 직관적 UI
- 색상으로 구분되는 입력 키 (X=빨강, Y=노랑)
- 입/출력 포인트 명확히 표시
- 그리드 배경으로 정렬 용이

### 💾 Json 통합
- Json 파일로 저장/불러오기
- 게임과 완벽 호환
- Addressable 지원

### ⚙️ 상세 설정
- 스킬 ID 커스터마이징
- 입력 윈도우 타임라인 조정
- 분기별 설명 추가

## 🚀 빠른 시작

### 에디터 열기
```
Tools → Skill Chain Editor
```

### 기본 워크플로우
```
1. 노드 추가 (Add Node)
2. 노드 연결 (빨간점 → 녹색점)
3. 분기 키 선택 (X, Y, A, B)
4. ID 설정 (우클릭 → Edit Node)
5. 저장 (Save JSON)
```

## 🎮 사용 예시

### 기본 3단 콤보
```
[2001] X→ [2002] X→ [2003]
```

## ⌨️ 조작법

### 마우스
```
좌클릭:        노드 선택/드래그
좌클릭+드래그: 노드 이동
우클릭:        컨텍스트 메뉴
출력점 클릭:   연결 시작
입력점 클릭:   연결 완료
```

### 컨텍스트 메뉴
```
노드에서 우클릭:
  - Edit Node    (노드 편집)
  - Delete Node  (노드 삭제)

빈 공간에서 우클릭:
  - Add Node     (노드 추가)
```

## 📋 워크플로우 예시

### 새 스킬 체인 만들기
```
1. Tools → Skill Chain Editor 열기
2. Add Node로 시작 노드 생성
3. 시작 노드 우클릭 → Edit Node
   - Skill ID: 2001 설정
4. Add Node로 다음 노드들 생성
5. 빨간점 → 녹색점으로 연결
6. 각 연결마다 입력 키 선택
7. Save JSON으로 저장
```

### 기존 체인 수정하기
```
1. Load JSON으로 불러오기
2. 노드 추가/삭제/이동
3. 연결 추가/제거
4. Save JSON으로 덮어쓰기
```

## 💡 모범 사례

### ID 네이밍 규칙
```
2000번대: 검 스킬
3000번대: 창 스킬
4000번대: 활 스킬
5000번대: 마법 스킬

예시:
2001 - 검 기본 공격
2002 - 검 2단 공격
2003 - 검 3단 공격
```

### 노드 배치
```
✅ 좋은 예:
[시작] → [중간1] → [중간2] → [종료]

❌ 나쁜 예:
  [중간2]
      ↑
[시작] → [중간1] → [종료]
(교차된 선은 가독성 저하)
```

### 입력 윈도우 설정
```
빠른 체인:  0.3 - 0.8  (넓음, 쉬움)
보통 체인:  0.5 - 0.9  (중간)
어려운 체인: 0.6 - 0.85 (좁음, 어려움)
```

## ⚠️ 주의사항

### 필수 확인사항
- [ ] 스킬 ID는 고유해야 함
- [ ] 순환 참조 방지 (A → B → A)
- [ ] 입력 윈도우는 0~1 범위
- [ ] 분기 키는 노드당 중복 불가

### 흔한 실수
```
❌ 녹색점 → 빨간점 (역방향)
✅ 빨간점 → 녹색점 (정방향)

❌ 같은 노드에 X 분기 2개
✅ 노드당 X 분기 1개만

❌ 존재하지 않는 스킬 ID 참조
✅ SkillJsonData에 있는 ID만 사용
```

## 🐛 문제 해결

### 연결선이 안 그려져요
```
원인: 반대 방향으로 드래그
해결: 출력(빨강) → 입력(녹색) 순서로
```

### 노드가 선택되지 않아요
```
원인: 다른 노드에 가려짐
해결: 노드 이동 후 다시 시도
```

### Json 저장이 안 돼요
```
원인: 폴더가 없거나 권한 부족
해결: 폴더 생성 후 다시 시도
```

## 📊 성능 팁

### 권장 노드 개수
```
소규모: ~10개 노드
중규모: 10~30개 노드
대규모: 30~50개 노드
초대규모: 50개+ (여러 파일로 분리 권장)
```

### 메모리 관리
```
- 불필요한 노드 정기적으로 삭제
- 사용하지 않는 체인은 별도 파일로
- 복잡한 트리는 섹션별로 분리
```
