# 호수 폭포 뒤 숨은 동굴

## 경험

넓은 폭포를 보다가 측면의 틈·젖은 바닥과 희미한 따뜻한 빛을 알아차리고, 물줄기 뒤로 들어가 보물을 찾는다. 별도 퀘스트나 지도 마커 없이 먼저 발견해도 획득할 수 있다. 안전한 귀로가 있어야 한다.

## 구성

- 기존 약18.6m 폭은 유지한다. 낙수의 잘못된 4차 곡선 대신 유입 접선과 이어지는 중력 낙하 궤적을 사용하고, 얇은 양면 판의 측면 실루엣을 보완한다.
- 폭포 뒤 넓게 열린 암반 공간: 내부 약9m 너비·9m 깊이·4m 높이, 전면은 더 넓게 벌린다. 별도 입구 테두리나 사각 외벽을 만들지 않는다.
- 호수77m에서 내부 바닥 자체가 마른 공간으로 이어진다. 인공 진입로를 별도 배치하지 않으며 빈 틈이나 급경사 없이 돌아 나올 수 있게 한다.
- 기존 지형을 파생한 전용 Terrain에 국소 구멍을 만들고, 동굴 내벽·바닥·천장·상부 하상 덮개를 MeshCollider와 함께 구성한다. 상류 지면과 물길은 유지한다.
- 내부 중심선에 보물상자1개를 접지한다. 기존 DropItemActor·DungeonTreasure 상호작용·SceneEntityId 저장 계약 재사용. 보상은 기존 희귀 회복약3개이며 새 아이템이나 경제 시스템을 추가하지 않는다.
- 보상은 일반 지역 재진입·저장/로드에서 소비 상태 유지, 새 게임에서 초기화한다. 중복 획득 방지는 기존 배치 드롭 계약이 소유한다.

## 확인

정면·측면·동굴 내부·상류 화면, 입구 왕복 캡슐 공간·바닥/천장·물가 연결, 보상 참조·ID 중복·소비 복원·기존 ID 보존과 NavMesh를 확인한다. 실제 조작·발견의 즐거움·카메라·미술 인수는 사용자 확인으로 구분한다.
