## 2026-11-27 2차 — 사용자 결정 반영

| 결정 | 반영 |
|---|---|
| 안개 속 아이콘은 숨긴다. 안개에선 포탈이 활성화될 수 없다 | 마을·포탈·고정 NPC·커스텀·데이터 포탈·NPC·채집·적 아이콘은 탐험한 곳에서만 표시한다. 숨은 포탈은 지도에서 클릭 이동도 할 수 없다. 퀘스트·사용자 마커와 플레이어 아이콘은 항상 표시한다 |
| HUD 미니맵은 레거시 | 1차에 넣은 미니맵 HUD 안개를 제거했다(`UI_HUD_Minimap.cs` 변경 없음) |
| 지역 목록 표시는 레거시. RiverBasin4km 오픈월드 지도 한 장만 사용 | 지역 미리보기와 다른 지도는 확인 대상에서 뺐다. 기존 코드는 삭제하지 않았다 |

### 이전 저장·바로 활성인 포탈의 한계

- 3.6 이하 저장은 포탈 활성화 플래그는 남지만 탐험 기록이 없다. 이미 활성화한 포탈도 **다시 근처에 갈 때까지 지도에서 숨는다.** 기록을 채워 주는 변환은 만들지 않았다.
- `startsActivated`·`requiresActivation=false` 포탈은 월드에서는 방문 전에도 활성 상태다. 지도에서는 탐험 전까지 숨고 클릭할 수 없다. RiverBasin4km 씬에는 `requiresActivation=false` 포탈이 3개 있다.
- RiverBasin4km 씬 파일에는 배치된 `MinimapMarkerRegistrar`가 없고(GUID 검색), 시작 지점의 Play Mode 조회에서도 정적 마커·데이터 포탈이 0개였다. 코드상 런타임 설치 경로(`WorldBuilderRuntimeBridge`의 POI, NPC 퀘스트·영입 마커)는 있으므로 콘텐츠가 연결되면 같은 숨김 규칙을 따른다.

## 2026-11-27 3차 — 치트: 현재 지도 전부 밝히기 (Editor·Development 빌드)

- 위치: 치트 패널 → **지역 이동** 탭 맨 위 `현재 지도 전부 밝히기 (저장에 남음)`.
- 지금 있는 지도의 촬영 범위를 탐험한 것으로 기록한다. 안개가 걷히고 숨은 아이콘도 보인다. 실행 결과·실패 사유는 치트 로그에 남는다.
- **저장하면 유지되며 되돌리는 치트는 없다.** 안개를 시험할 슬롯에서는 저장하지 않거나 새 게임을 쓴다.
- `CheatManager.Map.cs`와 매니저의 `TryRevealCurrentMap`은 `UNITY_EDITOR || DEVELOPMENT_BUILD`에서만 컴파일한다.

## 사용자 테스트 (대상: RiverBasin4km, 새 게임 또는 별도 저장 슬롯)

기존 저장을 덮어쓰면 3.7이 되어 이전 코드에서는 열 수 없으므로 별도 슬롯을 쓴다.

| ID | 절차 | 기대 결과 / 실패 기준 |
|---|---|---|
| MF01 | 진입 직후 지도를 연다 | 시작 지점 주변만 보이고 나머지는 안개. 전부 보이거나 전부 가려지면 실패 |
| MF02 | 한 방향으로 200m쯤 걷고 지도를 연다 | 걸은 길이 끊김 없이 드러나고 플레이어 아이콘이 밝은 영역 안에 있다 |
| MF03 | 지도 줌 최소↔최대, 마우스·패드로 이동 | 안개가 지형에 붙어 움직인다. 밀리거나 패널 밖으로 새면 실패 |
| MF04 | Ctrl+좌클릭(개발용 이동) 또는 빠른 이동으로 먼 곳에 간 뒤 지도 확인 | 도착 주변만 밝아진다. 두 지점 사이가 이어지면 실패 |
| MF05 | 저장 → 타이틀 → 불러오기 | 드러난 영역이 같다. 로드 직후 엉뚱한 곳이 밝으면 실패 |
| MF06 | 이어서 타이틀 → 새 게임 | 이전 기록 없이 안개로 시작 |
| MF07 | 안개 속에 퀘스트 목표가 있는 상태, 사용자 마커 배치 | 두 마커가 보인다 |
| MF08 | 지도에 표시되는 마을·포탈 마커가 생긴 뒤, 먼 마커를 방문 전후로 확인 | 방문 전에는 아이콘이 없고 클릭·패드 선택도 안 된다. 근처에 다녀온 뒤에는 보이고 이용할 수 있다. 현재 마커가 없으면 `미수행` |
| MF09 | 체감 확인 | 밝힘 반경(90m), 안개 진하기·색, 경계 모양 |
| MF10 | (별도 슬롯) 치트 패널 → 지역 이동 → `현재 지도 전부 밝히기`, 지도 열기. 이어서 저장 → 불러오기. 가능하면 Development 빌드에서도 확인 | 지도 가장자리까지 안개가 없고 치트 로그에 성공이 남는다. 불러온 뒤에도 밝다. 안개가 남거나 로그가 실패면 실패 |

회신 형식: `ID / 통과·실패·미수행 / 실제 결과 / 첨부 또는 로그`
