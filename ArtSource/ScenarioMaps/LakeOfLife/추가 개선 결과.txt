1. 동굴
거미 동굴과 여왕 동굴 2곳을 추가했습니다. 기존 Farmlands의 속 빈 CaveTunnel 메시를 사용합니다.
별도 충돌로 입구를 막지 않으며, 실제 터널 메시의 최고 LOD에만 콜라이더를 붙입니다.
동서 입구를 연결하고 내부에는 거미 계열과 채광 대상을 배치했습니다.
거미 동굴 중심: X 805 / Z 605. 여왕 동굴 중심: X 790 / Z 865.

2. 포탈
서쪽 숲길 ↔ 옛 야영지, 무너진 회랑 입구 ↔ 폐허 내부의 두 쌍, 총 4개입니다.
기존 PortalActor의 InMapTeleport를 사용하며 활성화 ID와 지도 도착 ID를 명시했습니다.
현장 상호작용으로 해금하고, 폐허의 귀환 포탈은 처음부터 이용할 수 있습니다.
도착점은 포탈 트리거 밖에 두어 왕복 재전송을 피합니다. RegionInfo와 SceneArrivalPoint도 연결했습니다.
숲길: X 765 / Z 630. 야영지: X 765 / Z 915.
회랑 입구: X 833 / Z 884. 폐허 귀환: X 765 / Z 1057.

3. 던전 이동
새로운 로딩 씬이 아니라 같은 씬 안의 분리된 폐허 던전 구역입니다.
여왕 동굴 바깥 포탈로 들어가고, 내부 포탈로 돌아옵니다. 북쪽 탐험로를 통한 도보 접근도 가능합니다.
석벽은 Fantastic Dungeon Pack 모듈을 사용하며 내부에는 Lich 두 변형과 채광 지점을 분리 배치했습니다.
기존 퀘스트의 필수 진입 조건이나 완료 플래그는 변경하지 않았습니다.

4. 다양한 상호작용
신규 10곳: 휴식 2, 낚시 2, 채광 3, 약초 2, 목재 1.
기존 채집 9곳과 NPC·퀘스트 조사 대상을 보존하고 포탈 활성화 4곳을 추가했습니다.
휴식은 기존 RestPointActor의 회복·성장 화면 경로를 사용합니다.
낚시는 기존 FishingZone 보상 데이터와 3회 고갈 정책을 사용합니다.
고갈된 낚시터는 외형이 남고 상호작용만 잠깁니다. 다른 채집물은 소모 후 비활성화됩니다.
낚시의 고갈 전 횟수는 런타임 값이며 고갈 여부부터 월드 저장 상태에 기록됩니다.
고정 SceneEntityId를 사용하고 기존 시간 기반 월드 리스폰 정책을 따릅니다.
신규 아이템이나 임의의 회차 리셋 정책은 만들지 않았습니다.

5. 모든 사용 가능한 몬스터
Assets/03.Prefabs/Actor/Monster의 후보 48개를 검사했습니다.
활성 AI, BT, AbilitySet, 자기 MotionSet의 AI 공격 Key 매핑, HitPhase, Missing Script 검사 통과 프리팹 40개를 각각 배치했습니다.
ActorDefinition이 없는 프리팹은 기존 EnemyCombat/AI의 직렬화 실행 데이터를 확인했습니다. 비행 AI도 따로 검사했습니다.
기존 15마리는 보존했고 새 배치 40마리를 30개 서식·도전 구역에 나눴습니다.

그룹당 동시 공격 상한은 근접 1 / 원거리 1, 휴식 시간 2.5초, 경보 반경 18m로 인스턴스에 설정했습니다.
공용 BT·GAS·MotionSet·프리팹 원본은 변경하지 않았습니다.

정적 검사 통과는 모든 공격의 체감·연출까지 검증했다는 의미는 아닙니다.
