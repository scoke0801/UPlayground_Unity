1. Unity 프로젝트에 설치

네이티브 DLL 복사GamepadCore.dll을 Unity 프로젝트의 Assets/Plugins/x86_64/에 넣습니다.
C# 래퍼 복사GamepadCoreApi.cs를 Assets/02.Scripts/Input/GamepadCore/에 넣습니다.
Plugin Import Settings 확인Unity Inspector에서 DLL의 플랫폼을 Editor와 Standalone / Windows / x86_64로 설정합니다.
자동 드라이버 추가빈 GameObject에 GamepadCoreBehaviour 컴포넌트를 추가합니다.
중요: Unity Editor와 빌드 타깃이 모두 64비트여야 합니다. DLL 이름은 바꾸지 말고 GamepadCore.dll로 유지하세요.

제공 파일

Release GamepadCore.dll

GamepadCoreApi.cs

권장 Unity 구조

Assets/
├─ Plugins/x86_64/GamepadCore.dll
└─ 02.Scripts/Input/GamepadCore/GamepadCoreApi.cs

2. 초기화와 매 프레임 업데이트

GamepadCoreBehaviour를 사용하면 초기화, 프레임 업데이트, 종료가 자동 처리됩니다. 프로젝트에 드라이버가 하나만 존재하도록 하세요.

권장 — 자동 수명주기
// 빈 GameObject에 GamepadCoreBehaviour 컴포넌트를 추가하면 끝입니다.
// Awake      → GamepadCoreApi.Initialize()
// Update     → GamepadCoreApi.Update(Time.unscaledDeltaTime)
// App Quit   → GamepadCoreApi.Shutdown()

직접 관리해야 하는 경우에는 다음 순서를 지킵니다.

수동 수명주기
private void Awake()
{
    if (!GamepadCoreApi.Initialize())
        Debug.LogError(GamepadCoreApi.LastError);
}

private void Update()
{
    GamepadCoreApi.Update(Time.unscaledDeltaTime);
}

private void OnApplicationQuit()
{
    GamepadCoreApi.Shutdown();
}
GamepadCoreApi.Update()는 연결 감지와 함께 각 패드의 HID 입력 및 USB/Bluetooth 햅틱 큐를 처리합니다.

3. 입력, 자이로와 기울기

모션과 터치 데이터는 명시적으로 활성화해야 합니다. 버튼, 스틱, 트리거 값은 TryGetState()로 한 번에 가져옵니다.

입력 및 기울기 읽기
using GamepadCore.Unity;
using UnityEngine;

public class PadInputExample : MonoBehaviour
{
    public int padIndex;

    private void Start()
    {
        GamepadCoreApi.EnableMotion(padIndex, true);
        GamepadCoreApi.EnableTouch(padIndex, true, gesture: true);
        GamepadCoreApi.ResetMotionOrientation(padIndex);
    }

    private void Update()
    {
        if (!GamepadCoreApi.TryGetState(padIndex, out GamepadState state))
            return;

        Vector2 move = state.LeftStick;
        Vector3 tiltDegrees = state.Tilt;
        Vector3 gyroDegreesPerSecond = state.Gyroscope;
        Vector3 accelerationG = state.Accelerometer;

        if (state.IsPressed(GamepadButtons.Cross))
            Debug.Log("Cross pressed");
    }
}

Tilt

가속도 기반 X/Y 기울기(도). ResetMotionOrientation() 호출 시 현재 자세를 영점으로 사용합니다.

Gyroscope

보정된 각속도. 빠른 회전 반응이나 카메라 조준에 적합합니다.

Accelerometer

보정된 G 단위 가속도. Gravity는 m/s² 값입니다.

Touch

접촉 여부, 좌표, 상대 좌표, 손가락 수와 터치 ID를 제공합니다.

4. 일반 진동

세기는 0.0f에서 1.0f 범위입니다. 좌측과 우측 모터를 독립적으로 제어합니다.

일반 진동
// 강한 왼쪽, 약한 오른쪽
GamepadCoreApi.SetVibration(0, left: 1.0f, right: 0.3f);

// 정지
GamepadCoreApi.SetVibration(0, 0f, 0f);
PCM 햅틱 재생 후 일반 진동을 사용하면 내부 진동 모드가 기본 Rumble 모드로 전환됩니다.

5. PCM 오디오 햅틱

DualSense USB 오디오 햅틱은 48 kHz, signed 16-bit, interleaved stereo PCM을 사용합니다. 배열은 L, R, L, R... 순서입니다.

PCM 전체 재생
short[] pcm48kStereo = LoadOrConvertPcm();
int result = GamepadCoreApi.PlayPcm16(0, pcm48kStereo);

if (result != 1)
    Debug.LogError($"PCM haptics failed: {result}");
실시간 Unity 오디오 스트림
private void OnAudioFilterRead(float[] data, int channels)
{
    if (channels != 2)
        return;

    int frameCount = data.Length / channels;
    GamepadCoreApi.ProcessUnityAudio(0, data, frameCount);
}
오디오 스레드 주의: OnAudioFilterRead는 Unity 메인 스레드가 아닙니다. 연결 검사나 Unity API 호출을 이 콜백에 추가하지 마세요.
Bluetooth: 임의 PCM 배열을 직접 보내는 방식이 아닙니다. QueueBluetoothHapticPacket()에는 DualSense 형식으로 인코딩된 정확히 64바이트 패킷이 필요합니다.

6. DualSense 적응형 트리거

GamepadHand.Left, Right, Both를 사용할 수 있습니다. 효과의 바이트 인자는 컨트롤러 프로토콜 범위이므로 작은 값부터 조정하세요.

저항, 활, 기관총 효과
// 기본 저항
GamepadCoreApi.SetTriggerResistance(
    0, startZone: 80, strength: 180, GamepadHand.Right);

// 활 당김
GamepadCoreApi.SetTriggerBow(
    0, startZone: 40, snapBack: 150, GamepadHand.Both);

// 기관총
GamepadCoreApi.SetTriggerMachineGun(
    0, startZone: 30, behavior: 1,
    amplitude: 2, frequency: 25, GamepadHand.Right);

// 효과 해제
GamepadCoreApi.StopTrigger(0, GamepadHand.Both);
커스텀 10바이트 트리거 리포트
byte[] triggerReport =
{
    0x21, 0x50, 0xA0, 0x00, 0x00,
    0x00, 0x00, 0x00, 0x00, 0x00
};

GamepadCoreApi.SetTriggerCustom(
    0, GamepadHand.Right, triggerReport);

제공 효과

Resistance, GameCube, Bow, Galloping, Weapon, MachineGun, Machine, Custom

안전한 해제

씬 전환이나 일시 정지 시 StopTrigger(...Both) 또는 ResetGamepad()를 호출하세요.

7. 라이트바와 LED

라이트 제어
// Unity Color 사용
GamepadCoreApi.SetLightbar(0, new Color(0.1f, 0.7f, 1.0f));

// DS4 라이트바 점멸 — 시간 단위는 초, 최대 2.5초
GamepadCoreApi.SetLightbarFlash(
    0, Color.red, brightSeconds: 0.2f, darkSeconds: 0.35f);

// DualSense 5-bit 플레이어 LED 마스크
GamepadCoreApi.SetPlayerLed(0, mask: 0x04, brightness: 255);

GamepadCoreApi.SetMicrophoneLed(0, enabled: true);
GamepadCoreApi.ResetLights(0);

8. 초기화와 정리

게임패드 상태 초기화
// 한 대: 진동, 트리거, 라이트, PCM, 모션 영점 초기화
bool reset = GamepadCoreApi.ResetGamepad(0);

// 연결된 모든 패드
GamepadCoreApi.ResetAllGamepads();

ResetGamepad()는 진동을 정지하고 트리거 효과를 해제하며 기본 라이트, 기본 Rumble 모드, 모션 영점 상태로 되돌립니다. 라이브러리 자체 종료는 Shutdown()을 사용합니다.

9. 통합 사용 예제

GamepadGameplayExample.cs
using GamepadCore.Unity;
using UnityEngine;

public sealed class GamepadGameplayExample : MonoBehaviour
{
    [SerializeField] private int padIndex;

    private void Start()
    {
        GamepadCoreApi.EnableMotion(padIndex, true);
        GamepadCoreApi.EnableTouch(padIndex, true);
        GamepadCoreApi.ResetMotionOrientation(padIndex);
        GamepadCoreApi.SetLightbar(padIndex, Color.cyan);
    }

    private void Update()
    {
        if (!GamepadCoreApi.TryGetState(padIndex, out var state))
            return;

        transform.Rotate(
            state.Tilt.y * Time.deltaTime,
            -state.Tilt.x * Time.deltaTime,
            0f);

        if (state.IsPressed(GamepadButtons.Cross))
        {
            GamepadCoreApi.SetVibration(padIndex, 0.8f, 0.45f);
            GamepadCoreApi.SetTriggerResistance(
                padIndex, 60, 180, GamepadHand.Both);
        }
        else
        {
            GamepadCoreApi.SetVibration(padIndex, 0f, 0f);
            GamepadCoreApi.StopTrigger(padIndex, GamepadHand.Both);
        }
    }

    private void OnDisable()
    {
        if (GamepadCoreApi.IsConnected(padIndex))
            GamepadCoreApi.ResetGamepad(padIndex);
    }
}

11. 문제 해결

DllNotFoundException

DLL이 Assets/Plugins/x86_64에 있는지, Unity와 빌드 타깃이 x86_64인지 확인합니다.

연결 수가 0

Update()가 매 프레임 호출되는지 확인하고 1초 이상 기다립니다. Steam Input 등 독점 접근 프로그램도 종료해 봅니다.

기울기가 0

EnableMotion(index, true)를 먼저 호출하고 GamepadCoreApi.Update()가 실행 중인지 확인합니다.

PCM이 동작하지 않음

DualSense가 USB인지, 데이터가 48 kHz / 16-bit / Stereo인지 확인합니다.

트리거가 동작하지 않음

DualSense/Edge 장치인지 확인합니다. DS4에는 적응형 트리거 하드웨어가 없습니다.

종료 후 출력이 남음

씬 종료 전 ResetAllGamepads(), 앱 종료 시 Shutdown()을 호출합니다.
