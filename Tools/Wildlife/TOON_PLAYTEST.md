# 환경 동물 툰 셰이딩 확인

## 적용 결과

- 대상: `Assets/03.Prefabs/Environment/Wildlife/`의 APD 25종, Wolf, Songbird. 머티리얼은 `Assets/10.Datas/World/Wildlife/`의 APD 25개, Wolf 3개, Songbird_AmericanRobin 1개.
- URP Lit을 lilToon으로 변경했다. APD_Butterfly는 기존 알파 컷오프를 유지하는 `Hidden/lilToonCutout`을 사용한다.
- 명암 경계 0.5, 경계 흐림 0.08, 그림자 색 `(0.72, 0.76, 0.83)`, 노멀 강도 0.35로 설정했다. 반사와 림은 끄고 외곽선 패스는 추가하지 않았다. 수치는 각 머티리얼에서 조정할 수 있다.
- 기존 머티리얼과 프리팹의 GUID를 유지했다. 원본 ExternalAssets, 배치 좌표, 프로필, 모션, 사냥 데이터는 수정하지 않았다. 기존 프리팹 연결을 통해 씬에 반영되므로 별도 프리팹이나 재배치는 필요 없다.
- 이미 스타일화된 Dreamscape 사슴·돼지와 별도 자연 에셋의 Butterfly_01~03은 이번 변환 대상에 포함하지 않았다.

## 수행한 검사

- Unity 편집 모드: 적용 머티리얼 29개 모두 셰이더 지원 및 셰이더 오류 검사 통과, 컴파일 진행 중 아님.
- 프리팹 27개: Missing Script 및 비툰/누락 머티리얼 검사 오류 0.
- LakeVillageWorld: 관련 렌더러 89개에서 비툰/누락 머티리얼 오류 0. 씬 저장이나 배치 변경 없이 반영되며 씬 dirty 아님.
- 변환 전 파일과 비교: 메인 텍스처, UV 스케일·오프셋, 노멀맵, 기본색, 알파 컷오프, 컬링 보존 오류 0. 색상 비교에는 직렬화 부동소수점 오차를 허용했다.
- 검사 시 Unity Console 오류 0건.
- Editor Play Mode 및 사람의 시각적 품질 판정: **사용자 테스트 대기**. Player 빌드 미수행.

## 사용자 확인 절차

준비: Unity 6 (6000.3.21f1)의 `Assets/01.Scenes/Scenario/OpenWorld/LakeVillageWorld.unity`를 연다. 편집 화면에서는 Hierarchy의 동물을 선택하고 F로 가까이 볼 수 있다. Play Mode 확인은 기존 플레이 시작 절차와 평소 사용하는 키보드·마우스 또는 게임패드를 사용한다. 저장 슬롯 초기화는 필요 없다.

| ID | 실행 절차 | 기대 결과와 실패 기준 |
|---|---|---|
| T01 | 편집 화면에서 APD_Bear, APD_Boar, APD_Deer, APD_Wolf를 차례로 선택해 밝은 면과 그늘진 면을 확인한다. | 털 무늬와 고유색이 유지되면서 명암이 단계적으로 나뉜다. 분홍색, 검은 실루엣, 번들거리는 표면, 노멀의 심한 얼룩은 실패다. |
| T02 | APD_Butterfly를 가까이서 보고, 흰 토끼·흰 닭과 Wolf·Songbird도 확인한다. | 나비 날개에 사각형 배경이 없고 무늬가 유지된다. 흰 동물의 밝은 면이 과하게 날아가거나 눈·코의 색이 사라지면 실패다. |
| T03 | Play Mode에서 동물에게 접근한 뒤 멀어지며 대기·이동·도주 중 외관을 확인한다. | 움직이는 몸에서도 셰이딩이 유지되고 검은 면·깜빡임·분홍색이 없다. 기존 배치와 행동이 유지된다. Console 예외는 외관 판정과 별도로 실패로 기록한다. |
| T04 | 플레이에서 관찰 가능한 햇빛과 그늘, 저녁·야간에 같은 동물을 확인한다. | 배경과 함께 어두워지며 형태를 알아볼 수 있다. 낮에만 적절하고 그늘이나 밤에 지나치게 밝거나 검게 뭉치면 조정 대상으로 기록한다. |

실패 시 동물 이름, 항목 ID, 조명·시간대, 편집 모드/Play Mode, 실제 증상과 가능하면 화면 또는 Console 오류를 전달한다. 입력 관련 문제가 있다면 사용 장치도 덧붙인다.

회신 형식: `T01 / 통과·실패·미수행 / 실제 결과 / 화면 또는 로그`.
