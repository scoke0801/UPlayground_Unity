펫 시스템 V2 구현 및 사용자 검수

2026-11-10 · Unity 6000.3.21f1 / URP. 설계서와 구현 요청문을 기준으로 코드·데이터·메뉴를 반영했다. 실제 추종 감각, 좌석 접촉, 수영 경계, 패드 조작은 사용자 테스트 대기다. 이 문서는 플레이 검수 완료 선언이 아니다.

반영 범위

  • PetBrain의 생성·표시·일반 복귀를 분리했다. 근거리 경로 실패, 막힘, 일반 점프, 메뉴 닫힘은 복귀 조건이 아니다. 경로 실패는 정지 후 재경로한다. 원거리 연속 이탈 1초와 복귀 유예 3초를 모두 만족해야 한다. 안전 후보가 없으면 기다린다. 복귀 후보는 완전 NavMesh 경로·캡슐 여유·경사·층 높이·수면 여부를 검사한다.
  • 실제 IsGliding과 ActiveView를 확인해 한 번 탑승한다. KCC·캡슐 충돌을 끈 뒤 좌석에 붙이고 기존 Sit 클립의 Hold MotionSet을 사용한다. 탈것 해제 직전 부모를 분리하며 착지는 월드 자세를 유지한 채 KCC 낙하로 처리한다. 공중 해제는 마지막 지상 자세에서 숨김 대기한다. 수영 종료 뒤 안정 접지 0.3초를 확인한다.
  • 기존 UI_Scene_PetMenu에 모델/외형과 스킬 탭, 순수 모델 3D 미리보기, 적용·선택·강화·저장 재시도를 연결했다. 프리뷰에는 Animancer만 있으며 PetActor·GAS·회수·서비스 등록이 없다. 기존 메뉴 오브젝트 ID 53개는 모두 보존했다.
  • modelId와 appearanceId를 분리했다. 검수 가능한 등록 모델은 원숭이 1종, 외형 10종이다. 모델 변경 계약은 위치와 공용 성장을 유지하고 교체 실패 시 이전 액터를 보존한다. 서로 다른 두 동물 모델의 실기 교체는 미확보·미검증이다.
  • 다섯 스킬 Lv.1~5와 강화 비용은 PetSkills.asset, 지원 수치·지속·공통 쿨다운은 해당 GAS SO가 소유한다. 탐색 반경은 플레이어 중심이며 실효 leash 최대 18m < 일반 복귀 20m다. 획득은 기존 드롭 예약·실제 도착·단일 지급 경로를 사용한다. Z 및 질주 입력은 수정하지 않았다.
  • 지원은 현재 플레이어의 Prepare/Commit/End와 GameplayEffectController를 사용한다. 명시적 InstantEffect 실행은 무료 단일 대상 Effect 성공 뒤에만 쿨다운을 확정한다. 회복은 기존 GAS HealingExecution을 사용한다. 공격·방어는 실제 Combat.AttackPower / Combat.Defense의 Percent modifier다. 0.04는 4% 증가를 뜻한다.
  • 지원 공통 그룹 Pet.Support는 캐릭터 교체에도 유지되는 PlayerActor 범위다. 버프는 스킬별 안정 stackingKey와 최대 1스택을 사용하고, 선택 변경·동행 해제 시 펫 전용 정의의 버프만 정리한다. 적용 당시 레벨은 레벨별 Effect ID와 남은 시간으로 저장한다.
  • 강화는 기대 레벨·비용·데이터 revision·잔액·최대 레벨·조작 상태를 다시 검사한다. 골드 차감과 레벨 상승은 변경 이벤트 전에 확정하며 같은 프레임 중복 요청과 거래 중 저장을 차단한다. 파일 저장 실패는 확정한 레벨·골드를 되돌리지 않고 재시도만 제공한다.
  • 저장 버전은 3.6이다. 3.5 이전 펫은 다섯 스킬 Lv.1·자동 줍기 켜짐·회복 선택으로 보정한다. 무펫 저장에는 펫을 지급하지 않는다. 알려지지 않은 ID와 미등록 스킬의 원본 레벨은 보존하며 실행을 보류한다. 좌석·경로·예약·트윈은 저장하지 않는다.

리소스와 재현

ImageGen 기본 도구로 Pickup, PickupRange, Heal, AttackBuff, DefenseBuff, Frame, Button, Title의 8개 PNG를 생성했다. 원본과 전체 프롬프트는 Tools/PetUI/Source/, 실제 런타임 Sprite는 Assets/04.Images/UI/Pet/다. 실제 알파 채널과 아이콘 최대 256px, FullRect, Clamp, 프레임/버튼 9-slice 경계를 확인했다. 텍스트·레벨·선택 표시는 TMP와 Unity 상태로 처리한다.

저작/재연결 진입점은 UPlaygroundToolCatalog.TryExecute("PetSystem.ApplyV2", out string error)다. 기존 메뉴의 버튼 보정과 탭 글리프는 PetSystem.AddV2TabPrompts로 다시 적용할 수 있다. 일회성 도구를 툴 런처에 등록하지 않았다. 공용 행글라이더의 PetSeatAnchor는 CanopyBankPivot 아래이며 13개 View 프리팹에서 좌석 누락 0을 확인했다. 실제 접촉 위치는 T01에서 확인한다.

자동 검사와 알려진 제한

검사 결과와 스냅샷은 프로젝트의 Logs/PetV2/에 보관한다. 메뉴 캡처는 Edit Mode의 임시 Canvas·카메라·모델을 이용한 표시 검사다. 게임 입력·패드·NavMesh 플레이를 검증한 자료가 아니다. 임시 스테이지는 정리했다.

  • Unity 컴파일 오류 0. 펫 메뉴·게임 액터·순수 프리뷰의 Missing Script 0. 메뉴 기존 오브젝트 ID 삭제 0.
  • 펫 저장·복귀·거래·실제 Attribute/Effect snapshot·공통 쿨다운·기존 GAS EditMode 검사를 수행했다. 최종 실행 개수는 Logs/PetV2/results.json을 따른다.
  • GAS 전수 데이터 검사에서 펫 관련 오류·경고 0. 별도 기존 데이터 오류 7건: PlayerDefaultAttackData의 HitPhase 누락 2건, CharacterPassiveDatabase의 ID 중복 4건과 Triggered Effect 참조 누락 1건. 관련 데이터는 수정하지 않았다.
  • 기존 Editor PlayMode GAS 수직 검사 최종 4개 모두 통과. 첫 실행에서는 리안 공격 실행 유지 assertion 1개가 실패했으며, 신규 재진입 보호의 적용 범위를 InstantEffect로 한정한 최종 코드에서 전체 4개를 다시 실행해 통과했다. 최초 실패와 최종 통과를 별도로 기록했다. 테스트 하네스의 미등록 서비스 경고는 실제 Boot 플레이의 경고 0 검증으로 대체하지 않는다.
  • 두 번째 실제 모델은 확보하지 못했다. 서로 다른 동물 간 적용 실패·리그 전환의 실기 검증은 미수행이다. 회차 전환은 기존 일반 로드 경로에서 성장 유지이며 별도 미구현 회차 진입점을 만들지 않았다.
  • Player/Addressables 빌드와 커밋은 수행하지 않았다. 파일 쓰기 실패 복구, 실제 패드, 추종·좌석·수영 품질의 최종 판정은 아래 사용자 검수를 따른다.

사용자 Play Mode 준비

클릭·표시 회귀 수정: 자체 Canvas의 GraphicRaycaster 누락을 보완했고, 메뉴의 “동행 펫”과 “나가기”가 640px 버튼으로 겹치던 배치를 300px 두 버튼으로 분리했다. 메뉴·일시정지 중에는 지상 펫의 표시를 유지하며 회수·지원을 중단한다. NavMesh 지면 투영 허용치는 5.5cm 캡슐 반경에서 분리해 프로필의 navGroundTolerance(초기 0.25m)로 조정한다. 현재 NavMesh 복셀 크기 약 0.167m와 비교해 지나치게 엄격했던 검사를 완화하되 층 높이 한계·물·경로·캡슐 여유 검사는 유지한다. 클릭과 투영 경계 자동 검사는 별도 회귀 검사이며 실제 필드의 표시 빈도는 재검수한다.

  1. Boot 씬에서 별도 테스트 슬롯으로 시작한다. 실제 사용 중인 슬롯을 덮어쓰지 않는다. 구버전 검사는 3.5 저장의 복사본을 별도 슬롯에 준비한다. 현재 에디터 작업을 저장한 뒤 진행한다.
  2. NavMesh가 있는 지상·문·계단·막힌 통로, 수영 가능한 해안, 슈퍼 점프/활공이 가능한 구간을 준비한다. 메뉴의 기존 “동행 펫” 버튼을 사용한다.
  3. 키보드/마우스와 실제 패드 각각으로 실행한다. 모든 단계에서 Console 예외와 서비스 경고는 화면 품질과 별도로 기록한다. 별도 검증용 Player 빌드는 필요 없다.
  4. 펫 진단 수치는 활성 PetActor의 GroundRecallCount / SpawnPlacementCount / BoardingCount다. 최초 생성·지상 복귀·활공 탑승을 섞어 세지 않는다.

후속 수정: 노드 그래프와 함께하기

펫 스킬 화면은 기존 스킬 트리의 UISkillTreeCurve와 SkillTreeFlowCanvas Shader Graph 머티리얼을 공유한다. 탐색 2개와 지원 3개를 고정 노드로 배치하고, 효과·비용·강화 버튼을 오른쪽 상세 패널로 분리했다. 연결선은 분류를 나타내며 새 선행 강화 조건은 만들지 않았다. 저장 안내와 재시도는 하단 버튼 위 별도 행에 둔다. 흐름 시계는 unscaled DOTween 하나로 갱신하며 화면 종료 시 해제한다.

“이 모습으로 함께하기”는 외형 적용 성공 후 동행도 켠다. 이미 동행 중이면 다시 켜거나 소환하지 않는다. 최초 배치는 기본 추종 위치를 사용하며 시야 밖 선호는 기존 펫의 원거리 복귀에만 적용한다. 기존 25% 모델 크기와 안전 지면·물·경로 검사는 유지한다.

필드 재현과 수정: LakeVillageWorld 신규 진입에서 플레이어가 접지 상태인데도 생성된 펫은 숨겨진 채 최초 배치를 기다렸다. 후보 지면 51.827m와 NavMesh 52.257m의 차이 0.430m가 기존 0.25m 허용치를 넘어섰고, 소유자 위치에서도 약 0.493m 차이를 확인했다. MonkeyFollow의 navGroundTolerance를 0.6m로 조정한 뒤 실제 필드에서 펫이 2.059m 뒤 안전 지면에 한 번 배치되고 렌더러 active/enabled/isVisible=true로 복귀했다. 경로 코너 도달도 높이 오차를 제외한 지면 평면 거리로 판단하도록 수정했다. 모델 크기·물·캡슐 여유·완전 경로·층 높이 제한은 유지한다. 장시간 이동과 수영/활공 왕복은 V03 사용자 테스트 대기다.

활공 접촉 높이와 도착 FX

보조 검증: Unity 컴파일 오류 0. 새 접촉 간격 검사와 FX 참조/비반복/축소 검사 2개는 Edit Mode에서 해당 NUnit 메서드를 직접 실행해 통과했다. Test Runner는 다른 실행이 점유해 별도 작업을 시작하지 않았으며, 정식 Test Runner 결과로 집계하지 않는다. 실제 활공 화면과 이동 중 FX의 시각 검수는 아래 A01/A02 사용자 확인 대기다.

PetSeatAnchor의 CanopyBankPivot 기준 Y를 0.18m에서 0.07m로 낮췄다. 실제 날개 중앙 보강대 상단은 약 0.054m이며, 25% 모델의 Sit 마지막 자세 중앙 하단은 루트보다 약 0.014m 낮다. 수정 후 중앙 접촉 간격은 약 2mm다. 좌석의 부모·회전·스케일과 착지 분리 방식은 유지한다.

첫 안전 지면 배치, 원거리 복귀, 활공 좌석 탑승이 실제 완료됐을 때 도착 위치에서 FX를 한 번 재생한다. 기존 PlayerSwap의 비반복 효과를 0.16배로 재사용하며 GameObjectManager의 기존 FX 수명 관리로 2초 뒤 정리한다. PetDefinitionSO의 arrivalFxKey/Scale/Duration/Offset에서 조정한다. 안전 지면 실패·일반 추종·메뉴 왕복·단순 숨김 복원에서는 재생하지 않는다.
