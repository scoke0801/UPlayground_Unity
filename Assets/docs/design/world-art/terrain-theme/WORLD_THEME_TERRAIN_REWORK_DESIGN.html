0.1 잘못된 결정과 교정

잘못된 진행교정할 결정실행에서 달라질 점
첫 장면보다 지역 분할·13개 역할의 산출물 운영이 앞섰다.한 구간을 지형·재료·빛·식생까지 한 책임자가 완성한다.첫 장면 검수 전 다른 테마의 제작·빌더·전체 조사 착수 보류. 역할 목록을 동시 작업 지시로 쓰지 않는다.
보존 mask 안에서 도색 가능한 부분을 골랐다.대표 화면의 문제를 해결하는 공간 범위를 먼저 정한다.보이는 반대편 호안·배경 사면까지 영향 범위에 포함해 검토한다. 보호 지점은 고정하되 주변 비콘텐츠 형상 변경을 일괄 금지하지 않는다.
수정 셀 수·꽃 수·파일·검사 통과를 진행의 중심으로 보고했다.같은 조건에서 실제 화면이 어떻게 달라졌는지를 첫 증거로 삼는다.매 제출은 전후 화면 → 남은 결함 → 다음 수정 → 관련 보존 검사 순서. 양적 수치는 부록이며 미술 합격 근거가 아니다.
명백한 미술 실패까지 사용자 인수로 넘겼다.제작 책임자가 먼저 반려하고 수정한다.긴 색 띠·빈 사면·반복 무늬·약한 목적지가 남으면 사용자 최종 검수를 요청하지 않는다. 취향 선택과 명백한 결함 수정을 구분한다.
공통 시험의 설정값을 다음 지역의 기준으로 고정했다.실제 장면에서 채택된 재료 조합과 빛을 기준으로 축적한다.수조 시험은 필요한 물 속성 확인에만 사용. 별도 시험장 확대와 셰이더 개발을 첫 장면의 선행 목표로 두지 않는다.

0.2 호수에서 먼저 바꿀 화면

기존 F01 사진을 다시 확인하면 수면·초록 호안·산이 수평으로 겹치고, 사당 지붕이 거목 옆에서 작게 묻힌다. 전경 모래의 큰 무늬와 수면의 고른 잔물결이 넓게 반복된다. 이는 과거 검토 사진의 관찰이며 최신 본편에서도 동일하다고 단정하지 않는다. 제작 시작 시 해당 화면에 영향을 주는 변경분만 재확인한다.

영역재작업 결정화면에서 확인할 변화 / 반려
진입과 전경실제 접근길을 기준으로 가까운 호안 한쪽이 물 쪽으로 들어오고 반대쪽은 열리는 비대칭 구성을 시험한다. 낮은 흙·돌 선반으로 지형을 잇고 기존 거석 정리와 ApproachMeadow는 보존한다.길에서 물가로 시선이 이어지고 물이 열려야 한다. 화면 아래 전체를 모래 띠가 차지하거나 큰 바위로 빈 공간을 가리면 반려.
중경 물가장식용 돌 산개 대신, 기존 해안의 굴곡과 얕은 선반을 몇 개의 연결된 덩어리로 다듬는다. 현 수면 경계·교량·섬과 단면을 대조한 뒤 비콘텐츠 지형에서 시험한다.앞뒤 호안이 겹쳐 거리감이 생겨야 한다. 모든 가장자리가 같은 폭의 모래/초록 띠로 남으면 반려.
거목과 사당기존 위치를 유지하고 주변 지면·수관 배경·겹침을 조정해 거목 실루엣과 사당 지붕·접근 요소를 분리한다. 카메라 줌이나 랜드마크 확대를 기본 해법으로 쓰지 않는다.거목을 본 뒤 사당과 접근 방향을 찾을 수 있어야 한다. 꽃·수련만 먼저 눈에 띄거나 사당이 계속 묻히면 배경과 접근 구성을 재작업.
배경 사면대표 화면에 크게 잡히는 사면을 암반 면·흙·수관 군락으로 나누고 능선 겹침을 만든다. 실제 경사와 재료에 맞춰 저작하며 기존 24도 제한을 표면 전체에 적용하지 않는다.멀리서 큰 재료와 명암이 읽혀야 한다. 균일한 잎무늬 또는 거대한 돌 텍스처 반복이 남으면 반려. 안개로 결함만 숨기지 않는다.
재료·수면·빛마른 호안→젖은 흙→얕은 바닥→깊은 물의 연속을 만들고 사람 크기에서 텍스처 축척을 맞춘다. 최신 본편 하늘과 조명 소유권 아래서 재질과 국소 대비를 조정한다.밝은 초지 하나가 장면을 지배하지 않고 수면에 시선이 쉴 면이 있어야 한다. 전체 채도 감소·Bloom 증가만으로 합격시키지 않는다.
식생 마감호안의 굽음과 경계에 낮은 군락을 연결한다. 대표 수면·목적지·중앙 보행선·카메라 공간은 비우고, 효과 없는 기존 장식은 이번 패치 범위에서 줄일 수 있다.식생을 가려도 구도가 성립하고 다시 켰을 때 더 좋아야 한다. 작은 소품을 더 놓아야 큰 빈 면을 견딜 수 있다면 앞 단계로 복귀.

위 결정은 공간 구성안이다. 실제 좌표·높이·반경은 아직 확정하지 않는다. 새 섬·폭포·거목·서사 이벤트는 기본안에 포함하지 않는다. 기존 자원으로 축척·형태·스타일을 맞출 수 없는 부분만 사진 근거를 붙여 신규 자원 후보로 분리한다.

0.3 편집 범위와 보호 범위를 함께 정한다

  1. 화면 영향 범위: 입구·대표 물가·활동 공간에서 보이는 전경, 건너편 호안, 목적지 배경 사면을 한 묶음으로 표시한다. 기존 core를 출발 한계로 삼지 않는다.
  2. 고정 보호 대상: 진행 ID, 실제 연결 배치, 교량·도착점·상호작용 지점, 기존 조우와 경로·지지면, 서사 수위를 최신 자료로 대조한다. 옛 좌표나 Renderer bounds만으로 보호를 확정하지 않는다.
  3. 변경 가능 대상: 보호 대상 밖 지형 형상·재료·비콘텐츠 장식은 검토 사본에서 조정한다. 다른 지역과 맞닿는 곳은 전이 영역까지 함께 설계한다.
  4. 충돌 해결: 고정 지점을 건드려야만 그림이 성립한다면 대안 구도를 먼저 만든다. 여전히 변경이 필요하면 정확한 대상·변경 전후·플레이 영향·복구 방법을 제시한다. 작은 도색으로 요구 품질을 몰래 낮추지 않는다.

0.4 제작과 판단을 한 번에 작게 반복한다

R0는 첫 제작을 위한 최소 확인이다. 최신 씬의 저장/미저장 상태, 실제 접근 경로, 변경된 보호 콘텐츠, 현재 하늘·RP·게임 카메라를 확인하고 기존 조사 중 달라진 부분만 갱신한다. 세 위치의 변경 전 화면과 수정 대상 표시가 마련되면 R1로 간다. 전 지역 재조사나 통합 도구 완성을 기다리지 않는다.

고정 화면보여줄 경험판단 질문
입구기존 접근길에서 물과 목적지가 처음 열리는 순간.어디로 가고 싶은지 보이는가? 전경이 길을 안내하는가?
대표 물가가까운 젖은 호안, 중경 수면, 거목·사당과 배경의 겹침.긴 가로 띠가 깨졌는가? 재료와 거리감이 한 장소로 묶이는가?
활동 공간기존 조우/보행 공간에서 목적지를 바라보고 되돌아보는 시점.한 장의 사진 밖에서도 공간이 이어지는가? 이동·적·회피를 읽을 여지가 있는가?

첫 제작에서 같은 위치·방향·FOV·해상도·시간/날씨를 전후 쌍으로 기록한다. 기준 카메라를 움직여 개선처럼 보이게 하지 않는다. 구도 후보를 고르기 위해 위치를 바꾼 사진은 별도 후보로 표시하고, 채택 위치에서 변경 전 화면을 확보한다. 초기 Editor 정지 화면은 구도 판단용이며 실제 TPS 검증이라고 부르지 않는다.

R1의 덩어리 단계에도 방향광과 간단한 재료 구분을 둔다. 깊이·목적지·접근선이 실패하면 바로 고친다. R2~R3에서도 구도가 무너지면 앞 단계로 돌아간다. 모든 단계가 한 번씩 끝나야 되돌아갈 수 있는 순차 작업으로 운영하지 않는다. 같은 결함이 두 번 남으면 소품을 보태지 않고 범위·형상·대형 지물 선택을 다시 정한다.

0.5 책임·검수·보고의 변경

제작 책임자가 화면 전체의 미술 판단을 소유한다. A00는 통합 관리자뿐 아니라 목표 구도 선택·반려·수정의 책임자다. A01/A02 기능은 첫 구간의 필요 작업으로 묶고, A12 검토는 화면 결함부터 확인한 뒤 보존 검사를 확인한다. 이 역할 구분은 추가 에이전트나 동시 실행을 요구하지 않는다.

  • AI 자체 검토: ART-01~04의 명백한 실패를 먼저 수정한다. 각 항목에 사진 위치와 남은 결함을 적고 기술 검사와 별도로 판정한다.
  • 첫 사용자 공유: R1 실제 3구도와 짧은 수정 판단. 방향 선택이 필요한 부분은 구체적인 후보로 제시한다. 이 공유는 최종 미술 인수나 전체 확대 승인이 아니다.
  • 실제 플레이 검수: R4에서 실행 가능한 씬·시작점·격리 저장 슬롯·입력·경로를 기입한다. 진입/교전/후퇴·카메라·물가 복귀를 사용자 테스트로 확인한다. 장시간 자동 조작 도구 제작으로 대체하지 않는다.
  • 확대 조건: 첫 구간의 실제 화면 개선에 대한 사용자 판단과 필요한 플레이 결과를 받은 뒤 다음 지역으로 간다. 미수행은 대기이며 보존 검사 통과로 보상하지 않는다.
  • 중간 보고: “무엇이 예뻐졌는가 / 아직 무엇이 어색한가 / 다음에 무엇을 바꾸는가”를 먼저 쓴다. 파일·셀·프리팹 수는 필요할 때만 뒤에 둔다.

0.6 첫 구간 이후와 완료의 의미

호수 검수 후에는 인접 진입로와 마을의 문→마당→우물→길 관계를 잇는다. 꽃을 가려도 생활 공간이 읽히는 구성을 먼저 만든다. 다음 붉은숲에서는 수관 군집·어두운 가장자리·열린 활동 공간과 흙/부식층을 함께 바꾼다. 나머지 지역도 5장의 경관 목표를 하나씩 실제 화면으로 완성한다. 첫 호수 성공을 전체 월드 완료로 확대하지 않는다.

지역 상태는 설계 / 제작 중 / 자체 미술 수정 중 / 사용자 검수 대기 / 검토 사본 인수 / 본편 반영·확인으로 구분한다. 최종 목표 달성은 인수된 환경이 본편에서 보존 조건과 플레이 확인을 만족할 때다. 첫 장면 이전의 통합 자동화·전 지역 handoff 양식 채우기는 보류하고, 보호·복구에 필요한 기록은 실제 변경과 함께 유지한다.

3. 다음에는 호수 대표 장면 하나부터 다시 만든다

첫 목표: 실제 TPS로 물가에 들어섰을 때, 가까운 호안에서 물과 낮은 지형이 이어지고, 기존 중심 나무와 사당이 가고 싶은 목적지로 읽히는 장면을 완성한다. 첫 장면의 미술 검수 전에는 다른 테마의 본제작을 확대하지 않는다.

호수를 선택하는 이유는 물·지형·재료·식생·랜드마크·원경을 한 장면에서 함께 검수할 수 있기 때문이다. 기존 거목과 사당을 중심으로 삼고, 새 거목·폭포·이벤트를 추가하는 방향은 기본안에 넣지 않는다. 핵심은 같은 자원으로도 좋은 풍경을 구성할 수 있는지 먼저 증명하는 것이다.

완성할 공간과 화면

  • 전경: 화면 양옆의 낮은 식생과 일부 돌이 호안을 잡되, 중앙 이동선과 물은 열린다. 모래가 화면 아래 전체를 단일 띠로 차지하지 않게 한다.
  • 중경: 물가가 굽으며 얕은 바닥·낮은 선반·군락이 겹친다. 마른 흙→젖은 호안→얕은 물→깊은 물을 같은 장면에서 읽게 한다.
  • 목적지: 기존 중심 나무의 실루엣과 사당의 지붕·진입 요소가 구분된다. 가까운 수련이나 꽃이 그보다 먼저 눈에 들어오지 않게 한다.
  • 배경: 넓은 사면을 같은 풀 무늬로 채우지 않는다. 능선 겹침·암반의 큰 면·수관 군락·대기 원근으로 거리와 재료를 나눈다.
  • 이동: 실제로 걸을 수 있는 지점에서 처음 풍경을 보고, 호안을 따라 돌면 물과 목적지의 겹침이 달라진다. 사진 한 곳만 성립하는 세트로 끝내지 않는다.

도식은 화면 전체를 평평한 가로 띠로 나누지 않는 구성 원리만 설명한다. 새 섬·진입로·랜드마크 이동을 승인한 배치도가 아니며 실제 좌표와 콘텐츠 계약을 확인한 뒤 공간을 정한다.

작업 범위 결정법을 바꾼다

이번 호수 core의 작은 수중 영역만 반복해서 수정하면 F01 전체를 지배하는 반대편 호안·나무와 사당·배경 사면은 바뀌지 않는다. 재작업에서는 먼저 대표 TPS 화면에 보이는 문제 영역과 보호 콘텐츠를 함께 표시한다. 그 결과를 근거로 A00가 충분한 core와 seam을 새로 정한다. 기존 mask와 경사 제한을 그대로 다음 제작 범위로 재사용하지 않는다.

기존 사진 위치 (972,83.636,736)와 (1037,79.063,781)은 과거 비교 위치다. 다음 장면의 편집 권한·실제 보행 가능 위치를 뜻하지 않는다. 실제 접근 동선에서 새 카메라 위치와 목표 풍경을 정하며, 보기 좋게 만들려고 게임 카메라의 FOV만 바꾸지 않는다.

높이를 바꾸는 편이 좋다는 판단이 나오면 “보존 때문에 표면만”으로 축소하지 말고, 비콘텐츠 영역의 형상 변경과 지지면·경로 영향을 검토 사본에서 구체화한다. 진행 개체·교량·도착점·기존 서사 수위는 고정 계약으로 보호한다. 변경이 필요한 예외는 근거와 변경표가 있어야 한다.

재료 전이물에 젖는 곳, 밟힌 곳, 흙이 노출된 곳, 수관 밑의 부식층, 급사면의 암반.그럴듯한 위치에 다른 재료가 있어야 한다. 도색 가능한 평지에만 작은 패치를 만들지 않는다.
작은 식생·소품호안과 생활 경계를 연결하는 선택적 군락.낮음/중간/높음의 역할을 나누고 길·전투·상호작용 중심은 비운다. 수량과 총밀도를 성과로 삼지 않는다.

경사24도 같은 배치 안전값은 풀·소품의 입지 검사와 구분한다. 급사면 전체를 표면 저작에서 제외해 초록 잎무늬를 남기는 규칙으로 사용하지 않는다. 실제 재료·경사·수관 투영·침식 흔적을 기준으로 암반/흙/식생을 배분하고, 물리 높이를 바꾸는 작업은 별도로 검증한다.

풀의 렌더 수정과 InstanceCountMode는 보존한다. 근접 풀의 축척과 배치를 검토하되, 이미 해결된 미렌더 문제로 재분류하지 않는다. 근경의 큰 풀 조각에서 중경의 빈 지면으로 갑자기 끊기는 장면은 중간 군락·지면 재료로 연결하며 표시 거리 확대를 기본 해법으로 두지 않는다.

물과 호안

  1. 실제 수면 삼각형·섬·연결길·수중 바닥의 단면부터 확정한다. Renderer 상자 전체를 호수로 보거나 건조 표본 비율을 오류 비율로 환산하지 않는다.
  2. 마른 흙·젖은 재료·얕은 바닥·깊은 중심을 이어 준다. 잔디가 물 아래까지 같은 모양으로 이어지지 않게 한다.
  3. 잔잔하게 읽힐 넓은 면과 바람을 받는 면의 위계를 만든다. 전체 수면을 같은 잔물결과 반짝임으로 채우지 않는다.
  4. 기존 물 셰이더의 수심색·반사·굴절 기능 목록과 실제 화면의 효과를 먼저 확인한다. 반사 경로가 어떤 하늘·지형을 담는지 확인한 뒤 조정하며, 기능 추가 자체를 미술 성과로 세지 않는다. 프로브 비용·팝은 측정 없이 합격시키지 않는다.
  5. 거품·수초는 얕음과 물가의 형태를 설명하는 위치에 쓴다. 물 전체와 대표 실루엣을 장식으로 덮지 않는다.

6. 다음 제작 순서와 멈춰야 할 기준

단계제출할 실제 결과다음 단계로 가는 조건
R0 · 기준 갱신최신 저장/미저장 상태, 현재 하늘·RP·카메라·NavMesh, 바뀐 보호 콘텐츠를 정리. 첫 호수의 실제 접근 시점과 같은 조건의 기준 사진.이전 manifest를 재사용할 때 파일 hash와 변경분을 확인. 기존 조사 전체를 반복하지 않음. 보호 계약을 식별할 수 있어야 함.

R3 · 식생과 소품중간 군락·선택적인 근경, 바람과 그림자. 보호·통로·카메라 공간을 남긴 장면.세부가 초점과 동선을 강화함. 수량/밀도가 증가했어도 중심이 흐려지면 반려. 실제 결손이 있을 때만 A11 후보 제작.

  • Editor 한 명: lease는 현재 작업의 조작권과 시간 범위를 분명히 한다. 오래된 history만으로 현재 동시 실행을 단정하지 않으며 실제 시간·작업 상태를 확인한다. 다른 작업의 하늘·RP 변경은 보존하고 필요하면 같은 새 버전에서 전후를 다시 맞춘다.
  • 연결 실패: timeout/close는 결과 파일·작업 ID로 실행 여부를 확인한다. 명시 사전거절과 실행 중 응답 손실을 구분한다. 복구에 작업을 계속 소모하지 말고 미완료 단계를 정확히 남긴다. 사용자 미저장 변경을 저장·폐기하거나 Editor를 강제 재시작하지 않는다.
  • 신규 자원: 기존 자원 비교 후 실제 결손과 제작 규격을 정한다. Blender/ImageGen은 스킬을 먼저 읽고 Candidate에서 제작. 실척·사방/근접·반복/접합·테마 조명·기술 한계·버전/hash를 제출하고 해당 버전의 사용자 명시 승인 전 최종 환경/본편 연결 금지.
  • 통합: 검수된 결과만 A00가 별도 Host 검토 사본의 단일 Terrain에 GUID·정확 경로·설정 remap으로 합성한다. 영역 밖·원본/사용자 변경을 보존한다. 현재 미술 실패본은 통합 승인 대상이 아니다.

기존 13개 역할은 후속 지역의 책임 참고 목록으로만 남긴다. 첫 대표 장면은 0.5의 제작 책임 아래 완성하며 별도 역할마다 산출물을 만드는 것을 목표로 두지 않는다. 다른 테마의 반복적인 전체 조사·빌더 작성은 확대 조건을 통과한 뒤 진행한다. A11은 실제 결손이 있을 때만 가동한다.

8. 근거·현재 한계·인계

본 문서는 원래 제작 설계의 보존·소유권·납품·신규 자원 승인 계약을 폐기하지 않는다. 이번 실패의 해석과 다음 제작의 미술 우선순위·확대 조건은 이 재작업 설계를 우선한다. 새 미술 방향은 제안이며 사용자의 승인이나 실제 개선을 이미 확보한 것으로 기록하지 않는다.

  • 원래 제작 설계의 E01~E08 영상 근거와 C01~C06 구조 사진: 꽃 개체 수가 아니라 군락·길·물가·수직 지형·빛의 구성 원리를 참고한다. 조감도 그대로의 밀도나 신규 폭포/화산 요구가 아니다.
  • 기존 비주얼 설계, 특히8.7~8.8 · 풀 렌더 수정13~14장 · 최신 저작 보존 지침.
  • A01 시험의 실제 범위 · 호수 전후 · 마을 전후 · 붉은숲 비교 자료.
  • 호수의 국소 완화·잔존 문제 · 마을의 제한된 개선 · 연결 보호 콘텐츠 조사와 미해결 항목.
  • 테스트 작업 지침: 문서 변경은 내용·링크·diff 확인. 미술 인수와 기술 검사를 구분하고, 긴 플레이/체감은 사용자 명세로 전달. 별도 지시 없는 Player·Addressables 빌드와 커밋 금지.

이번 설계에서는 실제 과거 사진을 다시 열어 미술 한계를 평가했다. 새 Scene/Terrain·재질·런타임 코드·셰이더·게임 콘텐츠는 수정하지 않는다. Unity 컴파일·Play Mode·새로운 GPU 측정·새 장면 미술 인수는 수행하지 않는다. 사진 링크는 같은 작업공간의 output/WorldThemeProduction/ 자료에 의존하므로 문서를 옮길 때 함께 보관한다.

다음 제작의 첫 납품: 호수 대표 구간의 실제 큰 구성3장과 미술 판정. 셀 수·프리팹 수·기술 통과표가 앞에 오지 않는다. 보기 좋은 한 장면이 실제 이동 속에서도 성립하는지 확인한 뒤 확대한다.
