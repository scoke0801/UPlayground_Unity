# 설계 문서

무엇을 어떻게 만들지 정한 **설계 정본**이다. 목표·구조·계약·의도한 동작을 담고, 구현 진행과 검증 결과는 `docs/work-status/`에서 따로 관리한다. 반복 작업의 절차·규칙은 [guide](../guide/)에 있다.

## 하위 폴더

| 폴더 | 내용 |
|---|---|

| [content/](content/) | **콘텐츠 설계** — 스토리, 퀘스트, 세계관 설정, 연출에 관한 설계. |
| [dev-tools/](dev-tools/) | **개발 도구·구조** — BT 에디터 UI 개선안, 카메라 프레임워크 구조, 디버그 기즈모 설계. |
| [npc/](npc/) | **NPC 설계** — NPC 생활 AI 확장, 의상·외형 베리에이션 설계. |

| [world-art/](world-art/) | **월드·아트 설계** — 월드 제작, 환경, 지형 테마, 마을 비주얼에 관한 설계. |
