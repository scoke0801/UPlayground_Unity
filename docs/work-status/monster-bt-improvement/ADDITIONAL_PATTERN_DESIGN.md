# 추가 행동 패턴 조사·설계

- 날짜: 2026-11-14. 판정: 조사·설계 반영, 구현 미수행.
- 정본: [행동 개선 설계 §6](../../../Assets/docs/design/combat/monster/MONSTER_BT_BEHAVIOR_IMPROVEMENT_DESIGN.md#6-추가-행동-패턴-상세-설계-2026-11-14-조사).
- [전투 위키](../../wiki/combat.md) · [전체 상태](STATUS.md).
- 현행 노드 카탈로그, Bow Rules JSON, PlayerRead 메모리, Intent 서비스, NodeFactory의 Wait 생성, P3~P5 설계와 최신 검증 기록을 대조했다. 외부 공식 BT 자료는 설계에 출처를 남겼다.
- 발견: 후방 조건은 적 기준이다. 차지 견제·지연 공격·슬롯 양보는 이미 존재한다. 추가안은 원형별 실행/중단/실패 계약과 관측 반응, 재배치로 구체화했다.
- 기존 미커밋 코드·데이터·문서를 보존하고 기존 설계에 절을 추가했다. 런타임·JSON·에셋 연결은 변경하지 않았다.
- 문서 로컬 링크·diff 확인을 수행한다. Unity 컴파일·import·플레이·빌드는 문서 작업이므로 미수행. 과거 테스트 수치를 이번 검증으로 승계하지 않는다.
- 남은 작업: P2a 사용자 공략 기회 확인과 급경사 경로 문제, 대표 원형 선정, Ability/Motion 실물 대조, Sequence 중단·중간 조건 재검사 계약 확인. 새 행동의 플레이 품질은 사용자 테스트 대기다.
- 임시 부산물: 해당 없음. 커밋하지 않음.
- 검증 결과: 변경 문서 4개의 로컬 파일 링크 정상. 전투 위키 diff 공백 검사 통과. 전체 작업 트리 diff 검사는 기존 Generated 에셋의 trailing whitespace로 실패했으며 이번 문서 작업에서 해당 에셋을 수정하지 않았다.
