## 라온 비교 시제품

### 원본 선호 판정과 겉옷 반사 H

G까지 비교한 사용자 판정은 원본 A가 가장 좋다는 것이다. 라온의 플레이어 외형 기준은 A다. 정면에서 G의 붉은 깃이 구릿빛으로 밝아지고 뒤에서 자수가 눈에 띄는 반면, A에서는 붉은 깃과 검은 등판이 큰 색면으로 읽힌다. 이는 캡처 관찰이며 사용자의 구체적인 선호 이유는 미확정이다.

H는 원본 인스턴스에서 겉옷 재질만 복제해 원본 반사 마스크·큐브맵의 환경 반사를 켠 실험이다. 큐브 색 배율은 RGB 0.32다. [같은 포즈의 정면·후면, 왼쪽 A와 오른쪽 H](raon-toon-original-trim.png). Unity에서 저장 씬을 다시 읽고 겉옷 슬롯 4개와 두 루트 위치 일치를 확인했다. 상체 전체 구도에서 변화는 작다. 미술 개선으로 채택하지 않았으며 H의 별도 성능 측정은 미수행이다.

### G 의상·눈·월드 조명

비교 씬의 G는 F에서 출발했다. 원본 의상 아틀라스의 색과 광택 무늬에서 금속 테두리와 붉은 띠의 실을 분리하고, 라온 등판 UV에 작은 쌍운문을 더했다. 가까이에서는 직조 무늬가 보이고 전투 거리에서는 띠의 방향이 먼저 읽히도록 첫 시안에서 금사 세기를 낮췄다. 자수 문양과 홍채색은 미술 확인 대기다.

[A·F·G 의상 비교](raon-toon-fabric.png) · [A·F·G 표정 확대](raon-toon-iris.png) · [F 위/G 아래, 직사광·차광·횃불](raon-toon-light-response.png)

[비교 씬](../../Assets/Test/RaonToon/RaonToonComparison.unity)에서 G를 단독으로 보거나 [G 검토용 프리팹](../../Assets/Test/RaonToon/PlayerModel_Raon_ToonReview.prefab)을 별도로 배치할 수 있다. 얼굴과 모발에는 원본 선 마스크로 안쪽 윤곽을 제한했다. 머리 방향과 피격색을 렌더러의 같은 프로퍼티 블록에 병합해 고개를 돌릴 때도 피격색을 보존한다. 근접 디더와 피격색 관련 EditMode 검사 12개 통과. 검토용 프리팹의 스킨 렌더러 18개에서 누락 재질 0개, 신규 재질 7개의 셰이더 패스 바인딩과 컴파일 메시지를 확인했다.

기본 눈동자는 얼굴 기본색 아틀라스에서 읽는다. G는 같은 아틀라스의 양쪽 홍채에 적갈색 결, 하단 호박색과 동공 테두리를 그렸다. 나머지 얼굴 픽셀과 원본 알파를 보존하고 원본과 같은 임포트 설정을 사용한다. 별도 눈 부품·표정 슬롯과 캐치라이트는 기존 자산이다. 앞머리의 실제 메시와 투명 마스크를 이용해 얼굴에서 3.8cm 안쪽의 가림을 세 방향으로 구웠다. 얼굴의 색광과 그림자 세기를 별도로 조정해 어두운 곳에서도 눈·입선을 읽도록 했다.

[RiverBasin4km 전투 자세 F 왼쪽/G 오른쪽](raon-toon-fabric-world.jpg) · [동작 비교 영상](raon-toon-fabric-motion.mp4)

월드 좌표 (1170, 73.19, 2250)의 실제 지형과 씬 조명을 사용했다. 방어·연속 베기 클립에서 동일 자세를 샘플해 보고, 연속 베기의 72개 포즈를 24fps로 기록했다. 검은 촬영용 복제본에서 손 위치를 맞췄다. 이 자료는 에디터 포즈 비교이며 입력·무기 장착·충돌·천 물리가 동작하는 실게임 검증은 남아 있다.

**근접 디더.** CharacterToon 네이티브 재질 복제·원본 복구 경로를 연결했다. Unity EditMode의 ActorCameraProximityDitherTests 7개 통과. 전용 128×128 평면에서 가시도 1 / 0.75 / 0.5 / 0.25 / 0의 밝은 픽셀은 16,384 / 15,997 / 9,550 / 626 / 0이었다. 프로젝트의 기존 노이즈를 써서 중간값에서 남는 픽셀 수는 비선형이다. 혼합 슬롯의 실제 플레이 카메라 접근·복원 및 컷신 클로즈업은 사용자 테스트 대기다.

**최종 F/G 성능.** RTX 3060 Ti·D3D11 Editor, 1280×720 비교 씬의 카메라 전체를 측정했다. 인원별로 F→G→G→F 순서로 각 24프레임을 그렸고 구간마다 첫 8프레임을 제외했다. 총 128표본에서 GPU 마커가 각 1회 기록됐다. [원시 표본](raon-toon-fabric-performance.csv)

| 라온 수 | F GPU 중앙값 / P95 | G GPU 중앙값 / P95 |
|---:|---:|---:|
| 1명 | 0.339 / 0.356 ms | 0.343 / 0.361 ms |
| 4명 | 0.797 / 2.125 ms | 0.745 / 2.588 ms |

4명에서 G는 중앙값이 0.052ms 낮고 P95는 0.463ms 높았다. 이 에디터 측정만으로 실제 전투의 프레임 예산을 확정하기는 어렵다.

### 얼굴과 재질 표면 비교

사용자 판정은 E가 D보다 낫지만 상용 게임 수준에는 미달이다. 비교 씬의 F는 라온 얼굴 UV에 볼·콧등·턱의 좌우 전환각을 다시 굽고 같은 지도의 B 채널에 입술·볼·코끝 채색량을 기록한다. E와 같은 머리 본 방향으로 평가한다. 피부 전용 색과 경계 폭은 얼굴 재질에서 조절한다.

머리와 겉옷의 큰 명암면은 기하 노멀로 계산하고 작은 광택과 MatCap에는 원본 노멀을 반영한다. F는 모발 방향 지도와 머리·의상 광택 영역을 읽는다. 첫 촬영에서 정수리 광택이 희게 몰려 머리 강도를 0.42에서 0.11로 낮췄다. 투명 앞머리, 눈 재질, 캐릭터 모델과 표정은 기존 자산을 사용한다.

[A·E·F 얼굴과 후방](raon-toon-surface.png) · [E 위/F 아래, 광원·시점 세 조건](raon-toon-surface-lighting.png) · [F 얼굴 마스크](../../Assets/Test/RaonToon/RaonFacePlanes.png)

대기 클립 0.4초, 같은 위치와 노출에서 4× MSAA로 다시 촬영했다. 측광에서 F의 볼과 턱에 따뜻한 면이 생기고, 반대편에서는 앞머리 다발의 밝은 면을 구분할 수 있다. 후방 검은 등판과 소매의 차이는 여전히 작고, 얼굴 확대에서 입선이 가늘다. 실제 전투 거리의 동작 가독성 및 사용자 미술 판정은 대기다. 원본 플레이어 프리팹에는 적용하지 않았다.

**E/F 성능.** RTX 3060 Ti·D3D11 Editor, 1280×720 카메라, 인원·버전별 32표본. 카메라 GPU 중앙값/P95는 1명 E 0.334/0.365ms, F 0.342/0.356ms, 4명 E 0.710/1.942ms, F 0.723/2.820ms였다. 측정 뒤 얼굴 채색 상수만 조정했다. [원시 표본](raon-toon-surface-performance.csv)

### 외형 재조정과 디더 확인

사용자 피드백으로 D의 미술 채택을 보류했다. [동일 구도의 A·D·E 무손실 비교](raon-toon-painted.png)는 왼쪽부터 기존 lilToon, 직전 시제품, 수정본이다. E는 라온 원본의 따뜻한 피부 그늘색과 얼굴 MatCap 마스크를 다시 사용하고, 모발 광택과 옷의 림 강도를 줄였다. 옷의 MatCap·영역 마스크와 보랏빛 간접 반사색으로 검은 소매와 뒤쪽 옷단을 분리했다. 칼날은 원본 재질을 사용한다. 같은 측광에서 D보다 그늘 쪽 눈과 붉은 깃이 잘 보인다. E의 옷단은 A보다 회색 기운이 남는다. 비교 씬의 E 루트만 켜면 볼 수 있다. E의 성능과 사용자 미술 인수는 대기다.

**디더링 여부.** 라온 원본의 스킨 재질 12개 중 해당 속성이 있는 11개 모두 평상시 `_UseDither=0`이었다. 나머지 하나는 앞머리 가짜 그림자다. CharacterToon의 컷아웃은 텍스처 알파와 고정 임계값 비교이며 화면 좌표 패턴을 사용하지 않는다. [카메라 근접 페이드](../../Assets/02.Scripts/GameActor/Component/Common/ActorCameraProximityDither.cs)는 지원하는 lilToon 슬롯을 전환한다. 신규 CharacterToon 슬롯은 대상에서 빠진다. 이는 재질과 코드 확인 결과이며 실게임 카메라 접근 시 혼합 슬롯의 동작은 미검증이다.

### 림라이트와 금속 반사 비교

[A·C·D 대기 자세](raon-toon-rim-metal.jpg) · [C·D 카타나 확대](raon-toon-metal.jpg) · [성능 원시 표본](raon-toon-performance.csv)

비교 씬에서 A/B/C/D 중 한 루트만 켠다. D는 C의 얼굴 마스크와 헤어 광택을 유지하고 피부 0.025, 모발 0.11, 겉옷 0.16의 방향성 림 강도를 사용한다. 빛을 받는 소매 바깥쪽에 보랏빛이 좁게 돌아 배경과 분리된다. 뒤쪽 옷 전체의 보라색은 A가 가장 잘 남는다. 림은 그림자 안쪽의 원단색을 복구하는 기능과 별개다.

금속 BRDF는 귀걸이와 카타나에 적용했다. 칼날의 균일한 흰 띠가 줄고 회색 면과 날 경계가 보인다. 단색 배경의 비교 씬에서는 D의 칼끝이 C보다 어둡다. 실제 월드 반사 환경에서 칼끝이 공격 궤적을 따라 읽히는지와 칼자루 전용 금속 마스크의 필요성은 사용자 확인 항목이다. 카타나 확대 촬영에서는 원본 프리팹의 비활성 무기 슬롯을 임시로 켰다.

**성능 측정 조건.** Unity Editor, D3D11, GeForce RTX 3060 Ti, PC 품질의 PC_RPAsset, 1280×720 렌더 타깃, 고정 카메라와 주광. 1명은 중앙, 4명은 앞뒤 두 줄에 놓았다. 인원별 A→B→C→D 및 역순으로 각각 24회 렌더링하고 매 구간 첫 8회는 제외했다. 각 칸은 32개 표본이다. GPU는 Camera.Render 전후 CommandBuffer의 GPU 마커로 측정했다. CPU 측 수치는 제출 호출 경과 시간이며 GPU 대기를 포함할 수 있다. 원시 자료에는 화면 중앙 한 픽셀을 동기 읽기 한 뒤의 총 경과 시간도 담았다. GPU 값은 지연 보고되므로 같은 구간의 분포를 비교한다.

기본 모델 슬롯 구성으로 비교했으며 일부 눈·앞머리는 lilToon을 공유한다. 기존 외곽선 등 활성 패스 차이도 합산된다. 표는 캐릭터가 있는 카메라 한 번의 비용이다. 월드 전체 프레임 비용, 무기를 든 전투, 추가광이 많은 장면, GPU별 성능은 별도 검증 대상이다.

|---:|---|---:|---:|---:|
| 1 | A | 0.762 | 2.682 | 5.49 |
| 1 | B | 0.319 | 0.943 | 4.15 |
| 1 | C | 0.316 | 0.333 | 4.88 |
| 1 | D | 0.317 | 1.298 | 5.32 |
| 4 | A | 5.510 | 8.554 | 11.67 |
| 4 | B | 0.665 | 2.013 | 4.79 |
| 4 | C | 0.662 | 1.146 | 5.44 |
| 4 | D | 1.018 | 1.671 | 5.41 |

최종 256개 표본 모두 GPU 마커 횟수 1을 확인했다. D와 C의 GPU 중앙값 차이는 1명에서 0.001ms 미만, 4명에서 +0.356ms다. 1명에서도 D의 P95는 C보다 높아 중앙값만으로 추가 비용을 판정하기 어렵다. 4명 D는 A보다 GPU 중앙값이 낮았다. 검을 켜는 경우와 실제 월드 반사 프로브의 변화는 이 수치에 포함되지 않는다.

**무기 노출 추가 측정.** 같은 4명 배치에서 각 인물의 카타나 슬롯을 켜고 C→D→D→C로 다시 측정했다. 각 32개 표본의 GPU 중앙값/P95는 C 0.684/1.483ms, D 0.683/1.859ms였다. 이 반복에서는 중앙값 차이가 작았고 D의 긴 프레임이 더 길었다. 별도 실행 간 변동이 커서 위 표의 비무장 결과와 뺄셈하여 칼날 단독 비용을 추정하기 어렵다. [무기 노출 원시 표본](raon-toon-armed-performance.csv)

### 첫 시제품 기록

2026-11-27. [비교 씬](../../Assets/Test/RaonToon/RaonToonComparison.unity)은 동일한 위치에 라온 프리팹 인스턴스 세 개를 둔다. A는 기존 lilToon, B는 원본 기본색 텍스처와 신규 조명, C는 B에 라온 얼굴 UV의 좌우 전환각 마스크와 탄젠트 기반 모발 광택을 더했다. 얼굴 마스크는 원본 얼굴 메시의 좌우 위치·콧등 위치에서 구운 512×512 초안이다. 별도의 헤어 흐름 텍스처는 사용하지 않는다. 눈·투명 앞머리·가짜 그림자는 기존 재질을 유지한다.

[셰이더](../../Assets/06.Shaders/CharacterToon.shader) · [머리 방향 바인딩](../../Assets/02.Scripts/GameActor/Component/Common/CharacterToonHeadFrame.cs) · [기본 자세](raon-toon-abc.jpg) · [카타나 대기 클립 0.4초 표본](raon-toon-idle.jpg)

두 이미지 모두 왼쪽부터 A/B/C, 위는 얼굴, 아래는 후방이다. 신규 재질에서 측광을 받은 볼과 턱의 경계가 드러나고 C는 뒤통수 상단에 광택 띠가 생긴다. 후방 옷자락의 보랏빛은 A가 더 잘 보인다. 대기 표본은 클립을 한 프레임 샘플한 것으로 무기 소켓의 플레이 중 갱신을 포함하지 않는다.

**Editor 확인.** 저장 씬을 다시 열어 세 인스턴스의 스킨 재질 누락 0개, 머리 본 50도 회전 시 셰이더 전달축 변화 50.00001도, Forward·DepthOnly·DepthNormalsOnly·ShadowCaster 네 패스 SetPass 성공, 해당 셰이더 진단 0건을 확인했다. 비교 이미지 2장을 동일 카메라·동일 주광으로 촬영했다.

**사용자 미술 확인.** 비교 씬을 열면 A가 활성화된다. Hierarchy에서 A/B/C 중 하나씩 켜고 Game 뷰에서 비교한다. 주광을 옆과 뒤로 돌려 눈 아래와 콧등 경계가 튀는지, 후방에서 머리 광택이 흰 얼룩으로 보이는지 확인한다. 의견에는 조명 방향과 선호한 버전, 부위를 기록한다.

**실게임 적용 전 남은 항목.** 외곽선·전투 디졸브·카메라 근접 페이드 연동, 이동 중 명암 안정성, 낮·밤과 다중 광원, 대상 장치 GPU 시간은 미검증이다. 후방 의상의 그늘색 보정과 얼굴 마스크 수작업 여부는 미술 비교 후 결정한다.
