# 몬스터 BT 개선 작업 상태

설계: [행동 개선](../../../Assets/docs/design/combat/monster/MONSTER_BT_BEHAVIOR_IMPROVEMENT_DESIGN.md) · [요청서](../../../Assets/docs/requests/MONSTER_BT_IMPROVEMENT_TASK_PROMPTS.md) · [전투 위키](../../wiki/combat.md)

## 현재 상태

- 사용자 정상 컴파일 뒤 직접 MCP 재검증: 변경 관련 EditMode 43/43(신규 충돌 2건 포함), AI 전체 151/152(로컬 모의 HTTP 응답 1건 실패). E01 60초 구르기 0회/최대 17.904m/복귀 재교전 확인. 실제 공격은 두 궁수에 명중했지만 구르기 후 공격 기회는 미검증이다. E03 급경사 복귀는 `PathPartial`로 실패했으며 지형·NavMesh 연결 확인이 남는다. 효과가 불충분한 Hot Reload 실험은 소스/런타임 원복했고 최종본은 사용자 컴파일본과 같다. [위치·재현·개별 결과](MCP_VALIDATION.md).

- 2026-11-14 구현 시작. 최초 git status에서 확인한 기존 이동·수영·문서·아트 변경을 보존한다. [P1 중 작업 트리 스냅샷](INITIAL_WORKTREE.txt)은 이번 P1 변경도 일부 포함한다. 커밋하지 않는다.
- 새 타입·필드·에디터 코드는 Hot Reload allowlist 밖이므로 열린 단일 Editor에서 정상 컴파일한다. Play Mode는 시작 당시 꺼져 있었다.
- P1: 검사·감사 구현, 현행 JSON 27종 오류 0/경고 0. 최종 EditMode 11/11 통과. [인계](P1_VALIDATOR.md).
- P0: GUID 보존 승격·참조 13개 재검증 완료. 미확정 몬스터 연결은 결정 대기, 플레이 확인은 사용자 테스트 대기. [인계](P0_ASSIGNMENT.md).
- P2: 조건·캐시·슬롯 조회·궁수 차지 견제 구현, 관련 EditMode 31/31 통과. 화면/체감과 적 가드 파괴 시나리오 확인은 대기. [인계](P2_PLAYER_READ.md).
- P2a: 전투 구역·복귀·회피 제한 구현, 최신 관련 EditMode 63/63 통과. [인계](P2A_TERRITORY_EVASION.md)·[최종 데이터 검사](FINAL_VALIDATION.txt). 실제 회피/경로/체감은 [사용자 테스트 대기](USER_TESTS.md).
- P3/P4/P5: 미구현. 요청서 4단계의 P2a 사용자 검수 선행 조건이 미충족이다. P0 미확정 연결과 P3 대표 범위의 사용자 결정도 아직 응답이 없다. 직접 플레이 합격을 자동 검사로 대체하지 않는다.
- 임시 부산물: 하네스 준비표 외 해당 없음. 작업 트리·감사·검사 원본은 재개 근거로 보존한다. Python 조회용 uv 캐시는 경로 확인 후 제거했다. 추적 밖 Wolf_Behavior 설정은 원본 대조 불가로 임의 원복하지 않고 보존했다.

## 사용자 확인

2단계 몬스터 연결 결정, 4단계 대표 원형 범위를 비동기 질문으로 요청했다. 결과가 없으면 미확정 연결을 바꾸지 않는다. 사용자 테스트 명세는 런타임 단계 인계에 기록한다.

## 추가 조사·설계

[추가 패턴 설계 기록](ADDITIONAL_PATTERN_DESIGN.md): 설계 §6에 대표 원형별 행동 및 실패/중단 계약을 구체화했다. 구현·연결 변경은 없으며 기존 선행 검수는 유지한다.

## 지연 행동 실행 전제 개선

[구현·검증·직접 테스트](DELAY_RECHECK.md): Wait 뒤 그룹/규칙 조건 재검사와 지상 공격 직전 사선 검사를 반영했다. Wait 사용 BT 10개의 GUID를 보존해 재생성했다. 대표 원형 분화와 기존 사용자 검수는 계속 남아 있다.

## 지연 개선 MCP 전투 관찰

[관찰·미완료·정리](DELAY_RECHECK_MCP.md): 궁수 정상 교전 20초, 실제 게임패드 회피 3회, 임시 엄폐 12초, 대검 교전 15초를 확인했다. 엄폐 중 공격 표본 0. 일반 궁수는 Signature가 등급 Set에서 제외돼 Wait 후 취소는 재현하지 못했다. dt>0 Assert의 원인도 미확인이다. 전체 체감 합격은 보류한다.
