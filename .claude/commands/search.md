# 프로젝트 검색

사용자가 제공한 인자(`$ARGUMENTS`)를 키워드로 삼아 **문서(docs)** 와 **코드(Scripts)** 를 병렬 검색하고, 결과를 섹션별로 정리하여 출력한다.

## 인자 파싱

`$ARGUMENTS` 형식: `<키워드> [추가키워드...]`

- 키워드가 여러 개면 공백 구분 — OR 검색(각 키워드 개별 검색) 또는 복합 패턴으로 사용.
- 따옴표로 묶으면 구문 검색 (예: `"PlayMotion AnimKey"`).
- 인자가 없으면 사용법을 안내한다.

## 실행 단계

### 1단계: 병렬 검색 실행

아래 두 검색을 동시에(병렬로) 실행한다.

**문서 검색** — `Assets/docs/` 폴더의 모든 `.md` 파일:
- 키워드가 포함된 줄과 앞뒤 2줄 컨텍스트를 Grep으로 수집.
- 파일명에도 키워드가 있으면 해당 파일을 우선 표시.

**코드 검색** — `Assets/02.Scripts/` 폴더의 모든 `.cs` 파일:
- 키워드가 포함된 줄과 앞뒤 2줄 컨텍스트를 Grep으로 수집.
- 매칭된 파일 목록을 확인하고, 핵심 파일(클래스 정의, public API)을 우선 표시.
- 결과가 50개 초과면 파일명 목록만 먼저 보여주고 상세 내용은 파일별로 정리.

### 2단계: 결과 출력

아래 형식으로 출력한다. 검색 결과가 없는 섹션은 "결과 없음" 한 줄로 표시.

---

```
## 📄 문서 검색 결과 — "<키워드>"

### <파일명>.md
> <매칭된 줄과 주변 컨텍스트>
  파일 경로: Assets/docs/<파일명>.md

(파일이 여러 개면 파일별로 소제목 구분)

---

## 💻 코드 검색 결과 — "<키워드>"

### <파일명>.cs  (Assets/02.Scripts/<상대경로>)
```<언어>
<매칭된 줄 + 앞뒤 2줄>
```
(줄 번호 포함)

(파일이 많으면 파일 목록 → 주요 파일 상세 순서로)
```

---

### 3단계: 추가 탐색 제안

검색 결과를 보고 다음 중 하나를 제안한다:

- 관련 파일을 더 자세히 읽고 싶다면 → 파일 경로 안내
- 키워드를 좁혀 재검색할 수 있다면 → 더 정확한 키워드 제안
- 연관 문서 가이드가 있다면 → 해당 `.md` 파일명 언급

## 주의사항

- `.meta`, `.asset`, `.unity`, `.prefab` 등 바이너리/에셋 파일은 검색에서 제외한다.
- 대소문자 구분 없이(`-i` 플래그) 검색한다.
- 결과가 너무 많으면 **파일 목록 요약 → 핵심 파일 상세** 순서로 단계적으로 출력한다.
- 코드 검색 결과는 반드시 `파일경로:줄번호` 형식을 포함해 사용자가 IDE에서 바로 탐색할 수 있게 한다.
