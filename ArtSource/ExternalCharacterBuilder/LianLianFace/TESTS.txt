R03-A / 기본·대체 헤어
정면과 좌우 비스듬한 각도, 이마·관자놀이 확대에서 떠 있는 헤어 뿌리와 두피 관통을 확인한다.
정수리 아래로 배경이 관통하지 않고 눈썹·눈이 헤어에 부자연스럽게 가려지지 않아야 한다.
증거: output/LianLianHairFitR03/Final 및 HairlineFront. 전체 헤어 카탈로그는 미검증이다.

R03-B / BodyOnly
세 번째 모델은 Face02·Chest·Leg만 보여야 한다. Hair·Armor를 켜지 않은 상태에서
뒤통수의 열린 구멍, 목 옆 세로 줄무늬, 목-몸통 접합 틈을 정면/좌우/후면/턱 아래에서 확인한다.
Lip_aa와 고개 회전에서도 접합면이 갈라지지 않아야 한다. 피부색·광택의 최종 선호는 사용자 확인 대기다.

R03-C / 재사용·동작
빌더에서 기본/대체 프리셋을 다시 불러온 뒤 동일한 얼굴 및 Hair03/11 피팅이 유지되는지 확인한다.
실제 사용할 게임 경로의 Play Mode에서 걷기·대화·고개 회전 시 추종·컬링·Console 오류를 확인한다.
현재 Review 씬은 생활 AI/전투 동작을 검증하는 씬이 아니다.

회신: 항목 ID / 통과·실패·미수행 / 실제 결과 / 각도·동작·입력 장치 및 화면 또는 로그.
아래 r02 헤어 수치와 이미지는 이전 기록이며 r03을 우선한다.
R00 / r02 헤어 위치 검수 — 사용자 확인 대기
현재 검수 씬 또는 기본 프리팹에서 이마 비율, 정수리·귀 뒤·목덜미를 확인한다.
두피는 헤어용 변형을 제거했고 Hair03은 아래 2.5cm/뒤 1cm, Hair11은 뒤 1cm 이동했다.
P09 빌더에서 프리셋을 다시 불러와도 같은 위치와 머리 형태여야 한다.
고개 회전 시 헤어가 함께 따라가고 두피 돌출이 없어야 한다.
기본/대체 외의 긴 머리·투구·물리 조합은 미검증이다.
회신: R00 / 통과·실패·미수행 / 실제 결과 / 문제가 보이는 각도·동작과 화면.

LianLian P09 r01 — 사용자 확인 대기

준비
현재 작업 씬을 원하는 방식으로 보존하고 Assets/01.Scenes/Tests/Equipment/LianLian_P09_Review.unity를 연다.
기본/대체 모델 외형 검수 씬이다. 기존 Lian 액터나 월드 배치가 교체되지는 않았다.
Unity 버전, r01, 사용 입력 장치를 결과와 함께 기록한다.

V01 / 눈 크기·인상
output/LianLianP09/Compare_Before_0.png와 Compare_After_0.png를 비교한다.
눈이 과장되어 보이지 않고, 좌우 눈매·눈썹·입·턱이 자연스러우면 통과.
이후 검수 씬에서 정면/35도/측면과 대화 거리·전신 거리로 확인한다.

V02 / 표정
활성 Female_Face_02의 SkinnedMeshRenderer에서 Eye_Blink, Eye_Blink_L/R,
Mouth_Smile, Lip_aa/ii/uu/ee/oo를 각각 0→100으로 확인하고 다시 0으로 되돌린다.
눈이 완전히 닫히고 속눈썹·안구가 튀어나오지 않아야 한다. 입안이 열리고 치아·입술이 정상이어야 한다.
알려진 제한: 안구 시선은 원본 Lookat BlendShape 방식이며 현재 P09 36표정에는 포함하지 않았다.

V03 / 목·머리·의상
검수 씬에서 Play 후 카메라 거리와 각도를 바꾸며 두 모델을 관찰한다.
표시·재질·컬링 오류가 없어야 한다. 목 좌우/위아래 회전은 Editor 표본을 이미 검사했으나
실제 게임의 시선 추종·걷기·대화 시 머리·의상이 지연 추종하지 않는지는 별도 확인한다.

V04 / 빌더 재사용
P09 빌더에서 LianLian_P09_BuildPreset.asset을 불러오고 Hair03/11, 의상03/05로 바꾼다.
FaceMeshProfile이 LianLian_P09_Face로 유지되고 새 얼굴이 사라지지 않아야 한다.
그 외 긴 머리·투구·망토·MagicaCloth 조합은 별도 관통/물리 검수가 필요하다.

V05 / 향후 게임 통합
실제 적용할 인물/배치가 정해지면 그 등장 경로에서 접근·대화·이동·야간·재진입을 확인한다.
Player/Enemy로 사용할 경우 무기·GAS·모션·충돌 통합을 별도로 수행한다.
현재 검수 씬을 생활 AI나 전투 동작 검증으로 판정하지 않는다.

회신: 항목 ID / 통과·실패·미수행 / 실제 결과 / 각도·동작 및 화면 또는 Console 로그.
