# 생명의 호수에서 이어지는 월드 확장 콘셉트

> 목적: 현재 게임월드의 지형과 분위기를 바탕으로, 앞으로 추가할 지역·생활·모험·연결 방향을 설계한다.

**거대한 바위 기둥 사이로 숲과 물길이 이어지고, 사람들은 그 틈에 길을 내고 살아간다. 익숙한 호수를 떠나 고개를 넘으면 다른 삶이 있고, 끊어진 옛길을 따라가면 지도에 없던 풍경을 만난다.**

현재 맵을 더 큰 세계 안에 놓는다. 생명의 호수는 사람들이 처음 정을 붙이는 곳, 풍요의 대지는 생활의 넓이를 보여주는 곳, 잊혀진 회랑은 땅 아래의 깊이를 보여주는 곳이다. 이 셋의 성격을 출발점으로 고개·숲·물목·고원·해안을 추가한다.

## 1. 세계를 확장하는 기준

### 이미 있는 세계에서 가져오는 것

- **지형:** 풀과 나무가 얹힌 거대한 층상 암봉, 바위 사이의 낮은 길, 중앙의 물과 멀리서 보이는 나무.
- **생활:** 목조 가옥, 우물, 풍차, 밭, 짐을 옮기는 길. 사람의 규모가 큰 자연 안에서 작게 보인다.
- **오래된 공간:** 석조 회랑과 방, 끊어진 발판. 현재 마을과 다른 시간이 남아 있는 장소다.
- **이야기:** 아름다운 풍경 안에 실제로 살아가는 사람이 있고, 전투의 결과가 그들의 삶에 남는다.

### 바깥으로 넓히는 것

호수의 신앙 이야기를 모든 지역에 반복하지 않는다. 고개에서는 길을 쓰는 권리, 숲에서는 사람이 차지하는 땅의 경계, 물목에서는 떠나고 남는 선택, 고원에서는 고립과 환대, 해안에서는 돌아오는 사람과 남겨진 사람을 다룬다.

세계 지도에는 지형에서 따온 이름을 쓴다. 아래 새 지명은 모두 가칭이다. 코드·제작 용어는 내부 설명에만 쓰며, 대사와 퀘스트 표시 문구는 후속 저작한다.

## 2. 주제와 여행의 동력

**주제:** 낯선 땅에서 함께 살아갈 방법을 발견한다.

**여행의 제안:** 동료들과 호수 바깥으로 나선 여행자가 끊어진 길과 서로 다른 사정에 막히고, 그곳의 사람들과 문제를 풀면서 다시 오갈 수 있는 세계를 넓혀 간다.

여행의 이유는 매번 달라야 한다. 맡은 물건을 전하러 갈 수도 있고, 동료가 만나려는 사람을 찾아갈 수도 있으며, 높은 곳에서 본 풍경이 궁금해서 길을 바꿀 수도 있다. 모든 지역을 피난민 구조로 시작하거나, 정해진 보스들을 쓰러뜨린 대가로 다음 땅을 열지 않는다.

호수 이야기의 결말은 그대로 완결된다. 새로운 모험은 귀환과 회복을 본 다음 별도의 의뢰·동행·탐험으로 시작한다. 루시아를 더 큰 적의 부하로 바꾸거나, 마지막 장면에 세계 멸망을 예고하지 않는다.

## 3. 세계의 규칙과 과거사 제안

### 이 땅이 지금의 모습이 된 이유

**길이 이어져 있던 때.** 바위 사이의 고개와 강의 얕은 곳을 따라 사람들이 왕래했다. 높은 곳에서는 돌과 금속을, 낮은 곳에서는 곡식을, 해안에서는 소금과 말린 생선을 옮겼다. 돌다리와 길가의 쉼터는 이런 왕래가 남긴 흔적이다.

**길이 끊어진 뒤.** 산사태, 물길 변화, 숲의 확장, 사람 사이의 다툼이 서로 다른 시기에 길을 끊었다. 같은 시대의 길도 어느 마을에서는 여전히 쓰고, 다른 곳에서는 숲 아래 묻혀 있다. 모든 폐허를 하나의 대재앙이나 사라진 제국으로 설명하지 않는다.

**지금.** 사람들은 가까운 길을 고쳐 쓰며 살지만, 더 멀리 가는 길에는 오래된 기억과 소문이 앞선다. 여행자는 알려진 길의 끝을 조금씩 넘어간다. 아직 다녀오지 않은 곳이 많아도 세계의 규칙을 뒤집지 않고 지역을 추가할 수 있다.

### 신비와 생활의 관계

이 세계에는 사람의 손으로 설명되지 않는 힘이 실제로 있다. 그러나 모든 마을이 같은 신을 믿거나 같은 방식으로 힘을 쓰지는 않는다. 신비는 나무와 물, 돌과 오래된 장소에 구체적인 흔적으로 드러난다. 주민의 설명이 항상 진실인 것도 아니다.

붉은 나무가 물과 양분을 끌어온다는 규칙은 생명의 호수의 확정 사실이다. 이를 모든 마법의 공통 대가로 확대하지 않는다. 새 지역의 신비를 추가할 때는 그 지역에서 관찰할 수 있는 징후와 한계부터 정한다.

| 항목 | 확장 시 지킬 기준 |
|---|---|
| 지역 사건 | 각 지역의 사람과 장소에 책임이 있는 문제로 만든다. 하나의 적이 모든 사건을 일으켰다고 합치지 않는다. |
| 해결의 결과 | 구한 사람, 열린 길, 달라진 관계가 남는다. 지역을 떠났다고 없던 일이 되지 않는다. |
| 회복의 한계 | 죽음과 잃은 수확이 승리와 동시에 복구되지 않는다. 호수의 확정 규칙을 유지한다. |
| 동료 | 기존 플레이어블의 외형·능력·합류 사실을 보존한다. 출신지와 가족사는 지도 제작만으로 배정하지 않는다. |
| 반복 전투 | 일반 적의 재등장을 지역 전체의 시간 회귀로 설명하지 않는다. |
| 이동 | 지상 보행과 현재 전투를 기반으로 설계한다. 수영·항해·비행·갈고리를 확장의 필수 조건으로 두지 않는다. |

## 4. 월드 지도와 지리

![기존 월드에서 바깥으로 이어지는 확장 지도](../../../output/worldbuilding/world-expansion-concept-v01.png)

**기존 환경을 참고한 확장 콘셉트 지도다.** 원본 생명의 호수의 암봉·중앙 나무·남쪽 물길, 풍요의 대지의 밭과 골짜기를 시각적 출발점으로 삼았다. 대륙 전체의 실측 지도나 현재 씬들의 접합 결과는 아니다. 내부 제작은 현재 시작 맵 `LakeOfLifeScenario`의 배치를 유지하고, 바깥 접속부를 별도로 설계한다.

### 큰 지리

북쪽의 높은 땅에서 내려온 물이 낮은 분지를 지나 남쪽으로 흐른다. 생명의 호수는 암봉에 둘러싸인 동쪽 분지, 풍요의 대지는 그 서쪽의 낮고 긴 농경 생활권으로 제안한다. 호수 남쪽 물길과 서쪽 유역의 물이 갈대 물목에서 만나 남동쪽 해안으로 이어진다.

풍요의 대지 미니맵의 넓은 갈색 골짜기를 강으로 확정하지 않는다. 그림 속 농경지 서쪽 강과 다른 지역까지 이어지는 물길은 이번 확장안에서 추가한 지리다.

북서쪽 고개는 높은 땅으로 오르는 길이고, 동쪽 숲은 호수의 익숙한 나무가 더 크고 깊어지는 방향이다. 남쪽 물목에서는 물이 넓어지며 삶의 방식이 바뀌고, 그 끝에서 처음 바다가 보인다. 식생·바위·경사·건축이 중간 지대에서 서서히 달라지게 한다.

### 연결 관계 제안

| 연결 | 연결되는 풍경 | 역할 |
|---|---|---|
| 생명의 호수 ↔ 풍요의 대지 | 숲길 → 낮은 고개 → 밭과 가옥 | 기존 생활권을 넓히는 첫 연결 |
| 풍요의 대지 ↔ 돌등 고개 | 수레길 → 돌 절개지 → 옛 돌다리 | 곡식이 높은 땅으로 올라가는 길 |
| 돌등 고개 ↔ 구름등 고원 | 굽은 산길 → 바위 어깨 → 열린 초지 | 높이와 시야가 크게 달라지는 전환 |
| 생명의 호수 ↔ 구름등 고원 | 북쪽 산자락 → 고갯마루 | 나중에 연결해 북쪽 여행의 순환을 만드는 길 |
| 생명의 호수 ↔ 그늘숲 | 익숙한 숲 → 빽빽한 나무 → 그늘 아래 수로 | 숲의 밀도와 생태가 달라지는 확장 |
| 호수·농경지 → 갈대 물목 | 개울·작은 하천 → 낮은 둑 → 갈대밭 | 두 생활권이 만나 물자를 바꾸는 지점 |
| 갈대 물목 ↔ 소금바람 해안 | 넓은 물길 → 기수역 → 절벽 아래 포구 | 바다를 처음 만나는 긴 조망 |
| 생명의 호수 → 잊혀진 회랑 | 바위 아래 입구 → 석조 실내 | 원본 맵의 목적지 선언이 있는 연결. 현재 시나리오 접속은 별도 설계 |
| 잊혀진 회랑 ⇢ 돌등 고개 | 지하 통로 → 다른 산사면의 출구 | 장기 확장 후보. 발견하면 지역 관계를 새로 이해하는 지름길 |

길은 선형 진행 순서가 아니다. 처음에는 일부 구간만 열고, 후속 지역을 만들 때 실제로 연결한다. 양끝이 구현되지 않은 길은 지나갈 수 있는 길처럼 안내하지 않는다.

현재 씬 연결은 **피해 마을(`DroughtVillage`) ↔ 생명의 호수 ↔ 소금바람항**, **생명의 호수 ↔ 돌등성 ↔ 소금바람항**이다. 피해 마을과 두 도시 사이에 직접 출구를 추가하지 않는다. 피해 마을은 호수 가까운 생활권으로 유지하고, 방문한 지역 사이의 반복 이동은 지도 거점을 사용한다. 피해 마을의 고유 지명과 지도 목록 공개는 이름 승인 후 반영한다.

현재의 **갈대 물목은 소금바람항 씬 남쪽 진입 구간**이다. 위 표의 독립 지역 구상과 구별하며, 호수·돌등성에서 도착한 뒤 갈대와 얕은 물 사이 마른 길을 지나 시장으로 들어간다. 별도 씬은 보류한다. 독립 사건과 돌아올 이유가 확정되고, 실제 보행 거리·성능 측정에서 분리 필요성이 확인될 때 별도 지역화를 검토한다.

## 5. 지역별 콘셉트

### 생명의 호수 — 다시 돌아올 곳 / 기존

붉은 나무와 호수가 방향의 기준이 되고, 숲 아래 작은 마을에서 여행의 얼굴을 만난다. 여행이 길어져도 처음 먹었던 식사와 익숙한 사람을 기억하게 하는 곳이다.

확장 뒤의 역할은 모든 일을 접수하는 본부가 아니라 **돌아올 이유가 있는 고향 같은 장소**다. 호수에서 해결한 일은 남아 있고, 먼 곳에서 가져온 물건이나 소식이 주민의 생활에 작은 변화를 만든다. 새 지역마다 호수로 의무 복귀하게 하지는 않는다.

### 풍요의 대지 — 넓게 펼쳐진 사람의 생활 / 기존 환경 확장

밭과 가옥, 길게 이어지는 골짜기를 중심으로 계절의 준비를 보여준다. 풍경의 주인공은 거대한 성보다 잘 정리된 밭과 짐이 쌓인 마당이다.

- **기억할 풍경:** 낮은 둑 위에서 한눈에 보이는 경작지와 곳곳의 작은 집.
- **먹고사는 방식:** 농사, 저장, 가축 돌봄, 수레 운송.
- **사건의 씨앗:** 운송을 늦추면 다른 마을이 굶지만, 너무 많이 내보내면 다음 파종 몫이 사라진다.
- **탐험 경험:** 열린 공간에서 위험을 먼저 보고, 밭 사이 길과 골짜기 우회로를 선택한다.
- **남는 변화:** 살아난 운송로와 다시 일하는 마당. 농사 시뮬레이션을 새로 요구하지 않고 장면과 배치로 보여준다.

### 잊혀진 회랑 — 익숙한 땅 아래의 깊이 / 기존 환경 확장

현재의 석조 방·통로·단차를 살린다. 사람들이 떠난 뒤에도 사용 흔적이 남은 장소다. 원래 용도는 조사 후 정하며 이번에는 옛 보관소·피난처라는 해석을 후보로 둔다.

- **기억할 풍경:** 좁은 통로 끝에서 갑자기 넓어지는 돌방, 아래층으로 이어지는 발판.
- **사건의 씨앗:** 밖으로 반출하려는 물건과 누군가가 남겨두려는 흔적이 충돌한다.
- **탐험 경험:** 문을 열기 전 퇴로를 살피고, 다른 높이에서 이전 방을 다시 보며 구조를 이해한다.
- **확장 역할:** 깊은 방이나 다른 출구를 나중에 붙일 수 있다. 모든 지역의 비밀을 설명하는 중앙 유적으로 만들지 않는다.
- **장기 보상:** 돌등 고개 쪽 출구가 생긴다면 새 전리품뿐 아니라 실제 이동 관계가 달라지는 발견이 된다.

### 돌등 고개 — 사람들이 놓고 간 돌길 / 신규

호수에서 보던 층상 바위가 더 가까이 다가오고, 길이 산허리를 따라 접힌다. 오래된 채석장과 돌다리 사이에 짐꾼들의 작은 쉼터가 남아 있다.

- **기억할 풍경:** 멀리서는 하나로 이어져 보이지만 가까이 가면 한 구간이 무너진 돌다리.
- **먹고사는 방식:** 채석, 운송, 길 수선, 고갯길 안내.
- **사건의 씨앗:** 빠른 재개통을 원하는 상단과 다시 무너질 것을 아는 일꾼들이 부딪힌다. 폐쇄된 채석장 쪽에서 움직이는 돌의 흔적이 발견된다.
- **탐험 경험:** 높은 곳에서 접근로를 읽고, 절개지·작업장·넓은 바위턱을 돌아간다. 대형 전투는 좁은 다리 위가 아니라 채석장 바닥에 둔다.
- **되돌아올 이유:** 수선한 통로가 귀환을 짧게 만든다. 다리 전체 복구와 통행 가능 구간을 구분한다.

기존 바위·석조·골렘 계열을 활용할 여지가 크다. 새 광산 채굴 시스템이나 실시간 붕괴 시뮬레이션을 전제하지 않는다.

### 그늘숲 — 사람이 쓰는 숲과 숲이 살아가는 곳 / 신규

호수의 숲이 이어지다가 큰 나무가 빛을 막고, 땅 위의 길과 오래된 목재 수로가 나뉜다. 숲 가장자리에는 사람의 흔적이 많고 안으로 갈수록 그 흔적이 끊긴다.

- **기억할 풍경:** 어두운 수관 아래에서 오직 작은 빈터와 흐르는 물만 밝게 보이는 길.
- **먹고사는 방식:** 목재·수지·약초 채취, 도구 수선, 숲길 안내.
- **사건의 씨앗:** 새 벌목 구역이 열리면서 몬스터의 이동 경로가 마을 쪽으로 바뀐다. 숲을 닫자는 사람도 겨울 연료는 필요하다.
- **탐험 경험:** 멀리 보는 개활지와 달리 가까운 소리·발자국·가려진 출구로 위험을 읽는다. 공격 예고와 카메라 시야는 식생에 묻히지 않게 한다.
- **남는 변화:** 사람이 이용할 구간과 비워 둘 구간이 구별된다. 숲 전체를 정화하고 모든 몬스터를 없애는 결말로 닫지 않는다.

붉은 뿌리나 타락한 거목을 반복하지 않는다. 나무의 크기와 밀도, 빛이 드는 방식만으로도 호수와 다른 숲을 만든다.

### 갈대 물목 — 머물기와 떠나기가 만나는 곳 / 신규

낮은 둑과 갈대밭 사이로 물길이 갈라졌다 모인다. 높은 터에 지은 작은 마을과 나루에서 여러 지역의 짐이 바뀐다. 멀리 보이는 땅에 곧장 걸어갈 수 없어 길을 읽는 방식이 달라진다.

- **기억할 풍경:** 넓은 갈대밭 위로 지붕과 둑길만 드러나는 낮은 시야.
- **먹고사는 방식:** 어획, 갈대 가공, 짐 옮기기, 나루 운영.
- **사건의 씨앗:** 무너진 둑을 고칠지, 물이 덜 닿는 곳으로 마을을 옮길지 의견이 갈린다. 둘 다 당장 손이 필요한 선택이다.
- **탐험 경험:** 높은 둑길과 낮은 빈터를 연결하며 우회로를 파악한다. 보이는 섬마다 전투를 배치하기보다 건너갈 길을 찾는 여백을 둔다.
- **남는 변화:** 안전한 통행로와 주민의 거처가 달라진다. 떠난 사람과 남은 사람을 모두 존중한다.

범람·수위 변화는 필요하면 장면 전후의 상태로 구현한다. 첫 제작부터 동적 수리 계산이나 자유 수영을 요구하지 않는다.

### 구름등 고원 — 멀리 볼 수 있지만 서로에게 닿기 어려운 곳 / 신규

층층이 솟은 암봉의 윗면이 이어진 높은 초지다. 아래 골짜기에 구름이 고이고, 바람을 피한 바위 뒤에 집과 겨울 창고가 모여 있다. 먼 능선의 눈은 다음 확장을 암시하는 풍경으로 남긴다.

- **기억할 풍경:** 발밑의 구름 너머로 지나온 호수 방향을 알아보는 넓은 조망.
- **먹고사는 방식:** 방목, 털과 가죽 가공, 저장식, 산길 안내.
- **사건의 씨앗:** 겨울 전에 내려가려는 사람과 터를 지키려는 사람이 같은 창고의 물자를 나눠야 한다. 흩어진 일행을 만날 때 선택의 무게가 드러난다.
- **탐험 경험:** 바위가 바람을 가리는 자리, 능선과 낮은 안부를 구분한다. 넓은 조우와 조용한 이동을 교차한다.
- **남는 변화:** 외부 사람도 쉴 수 있는 쉼터와 재개된 길. 지역 주민이 전부 떠나거나 전부 남는 단일 답을 강요하지 않는다.

바람은 먼저 풀·천·소리로 느끼게 한다. 상시 밀림 물리나 동상 수치가 반드시 있어야 하는 지역으로 설계하지 않는다.

### 소금바람 해안 — 여행의 끝에서 다시 열리는 길 / 신규

강 하류를 따라 내려가면 바위의 색이 밝아지고, 절벽 사이로 처음 바다가 보인다. 작은 포구와 염전, 바람에 기운 나무, 물이 빠진 바위 밑의 옛길이 풍경을 만든다.

- **기억할 풍경:** 절벽길이 열리며 포구와 바다, 얕은 곳에 걸린 오래된 배가 한 번에 보이는 순간.
- **먹고사는 방식:** 어획, 소금 만들기, 선박 수선, 연안 교역.
- **사건의 씨앗:** 돌아오지 않은 배의 짐이 해변에 닿는다. 항구를 떠나려는 사람과 소식이 올 때까지 남으려는 사람의 선택이 갈린다.
- **탐험 경험:** 절벽 위 조망과 해안 아래 동굴을 오간다. 배경의 바다를 넓게 보여주면서 실제 전투는 충분한 폭의 육상 공간에 둔다.
- **남는 변화:** 다시 드나드는 포구와 받아들인 귀환자. 수평선 너머는 후속 섬 지역의 여지로 둔다.

초기 해안은 도보 완결형이다. 항해는 후속 기능으로 선택할 수 있지만 이 지역의 이야기를 완성하는 필수 조건은 아니다.

## 6. 여행의 감정 곡선

| 이동 방향 | 바뀌는 감각 | 플레이어가 기대할 것 |
|---|---|---|
| 호수 → 농경지 | 개인적인 환대에서 넓은 생활로 | 누가 이 사람들을 먹여 살리는가 |
| 농경지 → 고개 | 익숙한 길에서 높은 위험으로 | 저 돌다리를 넘으면 무엇이 보일까 |
| 호수 → 깊은 숲 | 보이는 풍경에서 들리는 징후로 | 길 너머에 무엇이 숨어 있을까 |
| 고개 → 고원 | 압박감에서 탁 트인 고요함으로 | 이렇게 먼 곳에서는 어떻게 살까 |
| 농경지·호수 → 물목 | 뚜렷한 길에서 갈라지는 길로 | 어느 길이 다시 사람들에게 이어질까 |
| 물목 → 해안 | 익숙한 물에서 처음 보는 바다로 | 여기서 끝난 여행과 시작되는 여행은 무엇일까 |
| 새 지역 → 호수 | 낯섦에서 익숙함으로 | 돌아온 내가 전에 보던 것을 다르게 볼까 |

모든 지역에서 더 큰 위기만 쌓지 않는다. 호수의 진실 공개 뒤에는 열린 농경지의 생활, 긴장된 회랑 뒤에는 바람이 부는 바깥, 해안의 넓은 조망 뒤에는 작은 포구의 일상을 둔다.

## 7. 지역 이야기와 퀘스트의 확장 방식

각 지역은 그곳의 삶에 관한 중심 사건 하나로 완결한다. 다음 지역은 결말의 설명을 대신하는 떡밥이 아니라 이미 보아 온 길·물건·사람의 목적지로 연결한다.

예를 들어 호수에서 본 곡식 자루가 농경지의 작업 마당에서 다시 보이고, 고개에서 만든 돌 부품이 물목의 둑에 쓰일 수 있다. 반복되는 물건은 세계의 연결을 보여주되 같은 수집 임무를 반복시키지는 않는다.

지역을 추가할 때마다 기존 결말을 무효화하거나 이전 마을을 다시 멸망 직전으로 되돌리지 않는다. 지역 간 방문 순서가 달라도 각 지역의 인물 동기를 이해할 수 있게 한다. 구체적인 퀘스트·대화·저장 데이터는 후속 구현 범위다.

## 8. 인물과 세력의 방향

새 지역의 중심에는 서로 다른 사정이 있는 사람이 필요하다. 고개의 일꾼은 위험을 알면서도 일터를 잃고 싶지 않고, 숲의 채취자는 숲을 아끼면서도 내일 쓸 연료가 필요하다. 물목 주민의 귀향과 고원 주민의 정착은 같은 선택이 아니다.

교역 상단, 길을 함께 수선하는 마을들, 오래된 터를 지키는 주민을 느슨한 관계로 제안한다. 어느 조직도 일괄적인 선역·악역으로 고정하지 않는다. 대규모 국가 정치가 필요해질 때 실제로 충돌하는 생활권부터 구체화한다.

기존 동료는 전투뿐 아니라 관찰과 행동의 차이로 새 땅을 경험한다. 캐릭터의 확정되지 않은 고향이나 과거를 이용해 지역 입장의 열쇠로 만들지 않는다. 새 주요 인물은 그곳에 있는 이유, 주인공과 부딪히는 이유, 이후 남거나 떠나는 이유, 기억하는 것을 정한 뒤 저작한다.

## 9. 후속 제작에 열어 둘 구조

### 권장 제작 순서

| 묶음 | 범위 | 먼저 만드는 이유 | 새로 필요한 작업 |
|---|---|---|---|
| 첫 확장 | 풍요의 대지의 이야기 + 돌등 고개 일부 | 기존 농경지와 암석·석조 환경을 활용하면서 호수와 다른 개방감·높이차를 만든다. | 지역 접속부, 고개 공터·다리, 주민과 독립 사건 |
| 다음 선택 | 그늘숲 또는 갈대 물목 | 숲의 밀도와 낮은 물가 중 다음에 필요한 경험을 고른다. 둘을 동시에 만들 필요는 없다. | 숲의 시야 구성 또는 둑·나루·얕은 물 경계 |
| 먼 확장 | 구름등 고원, 소금바람 해안 | 넓은 조망과 강한 분위기 전환으로 여행의 범위를 확장한다. | 원경·구름·바람 연출 또는 절벽·포구·염전·해안 소품 |
| 틈새 확장 | 잊혀진 회랑의 깊은 방·추가 출구 | 기존 지역 사이에 짧은 탐험과 새로운 연결을 붙이기 좋다. | 실내 공간의 차별화, 연결부·카메라·보행 검수 |

이는 제작 우선순위이며 플레이 순서나 레벨 순서가 아니다. 실제 자산 적합성은 지역 제작 전에 확인한다.

### 처음부터 확보할 연결부

호수 생활권의 서쪽·북쪽·동쪽·남쪽에 모두 새 출구를 즉시 만드는 것이 아니라, 각 방향의 기존 외곽 길 중 연결 후보를 정한다. 씬의 정확한 좌표와 방식은 별도 배치 검토에서 확정한다.

- 서쪽: 풍요의 대지로 이어질 낮은 길.
- 북쪽: 고원으로 향하는 산자락 길.
- 동쪽: 그늘숲으로 깊어지는 숲길.
- 남쪽: 갈대 물목을 향하는 하류 방향의 길.
- 지하: 잊혀진 회랑의 추가 방과 다른 출구를 붙일 여지.

확장마다 새 이동 능력을 요구하지 않으면 어느 지역부터 제작할지 선택하기 쉽다. 지역 간 이동은 우선 현재 씬 전환 방식으로 표현할 수 있게 설계하고, 하나의 거대한 연속 지형이나 새로운 스트리밍 시스템을 선행 조건으로 두지 않는다.

### 세계의 끝을 닫지 않는 법

북쪽 고원의 능선 너머, 동쪽 숲 너머, 남동쪽 바다 너머는 이름과 정치 관계를 비워둔다. 지금은 원경과 여행자의 목적지 정도만 필요하다. 나중에 북부 산지·더 깊은 숲·연안 섬을 추가해도 기존 지도를 뒤집지 않게 여백을 남긴다.

정확한 대륙 크기, 전 세계의 신 목록, 최종 적의 계보, 모든 캐릭터의 출신지는 이번에 확정하지 않는다. 먼저 만들어 볼 지역의 생활과 탐험 경험부터 충분히 구체화한다.

## 11. 시나리오맵에서 항구도시로 이어지는 첫 여정

### 11.1 방향과 범위

**호수 마을에서 쓰던 물건의 출처를 따라가다, 그 물건을 만들고 실어 보내는 사람들의 도시를 만난다.** 이것을 첫 해안 여행의 중심으로 삼는다. 도시 규모보다 출발지와 목적지 사이의 생활 관계를 먼저 만든다.

소금바람 해안의 작은 포구를 **항구도시 ‘소금바람항’(가칭)**으로 구체화한다. 한꺼번에 큰 성벽과 여러 세력을 추가하지 않고, 어촌에서 교역 거점으로 자라난 흔적을 둔다. 낮은 물가에는 오래된 작업집, 높은 터에는 밀집한 주거지, 그 사이에는 나중에 넓힌 시장과 창고가 있다. 호수 마을보다 많은 사람이 서로 다른 일을 하며 같은 길을 쓰는 것이 도시의 첫인상이다.

이번 제안은 9절의 제작 선택지에 **해안 우선 경로**를 추가한다. 항구도시를 먼저 만들 경우 풍요의 대지·돌등 고개 전체 제작을 선행 조건으로 두지 않는다. 갈대 물목은 우선 짧은 연결 지역으로 만들고, 독립된 마을 이주 이야기는 후속으로 남긴다. 두 지역의 중심 사건을 첫 여행에 한꺼번에 넣지 않는다.

### 11.2 연결 지도와 풍경의 변화

```mermaid
flowchart LR
    A[호수 마을] <--> B[남쪽 숲길]
    B <--> C[갈대 물목의 둑길과 짐터]
    C <--> D[하구 절벽길]
    D <--> E[소금바람항 시장]
    E <--> F[주거 언덕]
    F <--> G[수선 부두]
    G <--> E
    G <--> H[바깥 방파제와 옛 작업장]
    P[풍요의 대지] -. 후속 연결 .-> C
    H -. 후속 탐험 .-> I[해식동굴과 연안 섬]
```

실선도 **제안 동선**이며 현재 연결된 길이 아니다. 세계 방위는 기존 확장안의 남쪽 물목·남동쪽 해안을 따른다. 원본 `LakeOfLife`의 남쪽 강을 현재 `LakeOfLifeScenario`의 유출로로 간주하지 않는다. 시나리오의 남쪽 마을 외곽에서 실제로 걸을 수 있는 출구를 조사한 뒤 접속점을 정한다. 새 물길은 이 조사와 지형 설계로 성립시킨다.

| 구간 | 플레이어가 먼저 보는 것 | 이동과 활동 | 이어지는 이유 |
|---|---|---|---|
| 호수 마을 → 남쪽 숲길 | 포장 중인 약재, 빈 소금 자루, 바깥으로 향한 수레 자국 | 익숙한 작업 마당을 떠나 낮은 숲길로 걷는다. 출발 직후 전투는 두지 않는다. | 호수와 해안 사이에 이미 왕래가 있었다는 흔적 |
| 숲길 → 갈대 물목 | 나무 사이로 넓어지는 하늘, 낮아지는 지면, 갈대 너머 짐터 | 둑길과 높은 마른 길을 골라 짐터에 닿는다. 물을 건너뛰거나 수영할 필요가 없다. | 육상 운반물이 작은 배의 짐과 바뀌는 장소 |
| 물목 → 하구 절벽길 | 강폭이 넓어지고 바위에 바닷물 자국이 남는다. 먼 돛과 지붕 일부가 먼저 보인다. | 물가를 잠깐 벗어나 완만한 절벽길에 오른다. 굽이를 돈 뒤 항구 전경을 공개한다. | 바다를 갑자기 배경에 붙이지 않고 하류의 끝으로 발견 |
| 절벽길 → 항구 시장 | 짐 내리는 사람, 말리는 그물, 수선 중인 배 | 짐이 향하는 길을 따라 생활 공간으로 들어간다. 시장에서 첫 휴식과 거래가 가능하다. | 목적지가 풍경에서 사람의 생활로 가까워짐 |

숲의 벌레 소리에서 갈대·물새, 바람·파도, 부두 작업 소리로 청각 중심도 바꾼다. 실제 사용할 소리·식생·배 자산은 아직 조사 전이다. 조망에서 카메라를 강제로 돌리지 않고 길의 굽힘과 열린 시야로 바다를 발견하게 한다.

첫 도착까지는 걷기·관찰·짧은 선택 활동을 포함해 **10~15분을 조율 시작값**으로 둔다. 순수 달리기 시간을 채우기 위해 지형을 늘리지 않는다. 체감이 늘어지면 필수 전투를 추가하기보다 길을 줄인다. 정확한 거리와 경사는 실제 보행 후 정한다.

### 11.3 작은 도시를 만드는 네 공간

| 공간 | 사람의 생활과 배치 | 플레이 역할 | 다른 공간과의 연결 |
|---|---|---|---|
| 시장·짐마당 | 곡식 창고, 소금 자루, 식사 자리, 운송 수레. 운반 통로와 가게 앞을 분리한다. | 첫 도착, 기존 거래·휴식 기능, 물자 행선지 확인 | 절벽길에서 자연스럽게 닿고 부두와 언덕을 모두 볼 수 있음 |
| 주거 언덕 | 바람을 피한 밀집 가옥, 공동 우물, 빨래, 오래된 계단. 문마다 상인을 넣지 않는다. | 조용한 탐색과 주민 생활, 항구를 내려다보는 시야 | 시장에서 올라가 부두 옆으로 내려오는 순환로 |
| 수선 부두 | 육지로 올린 배, 목재 작업장, 그물 건조대, 식사 중인 일꾼 | 지역 사건의 중심, 작업 전후 변화, 귀환자를 맞는 자리 | 시장까지 넓은 작업길, 언덕까지 짧은 계단길 |
| 바깥 방파제·옛 작업장 | 부서진 외항 시설, 밀려온 짐, 비어 있는 작업터 | 선택 탐험과 첫 지역 사건의 조사·육상 전투 | 부두에서 출발해 높은 귀로로 돌아옴. 도시 안으로 적이 추격하지 않도록 실제 감지·추격 경계를 검증 |

첫 제작은 생활 가로 하나와 순환로 하나에 집중한다. 시장의 짐이 부두로 옮겨지고 일꾼이 언덕 집으로 돌아가는 관계가 읽혀야 한다. 원경 건물은 도시의 깊이를 보완하되 열린 문과 길로 접근 가능한 곳처럼 속이지 않는다.

주 통행로 3.5~4m, 생활 샛길 2~2.5m, 일반 전투 공터 유효 지름 16~24m를 기존 공간 명세의 시작값으로 삼는다. 부두 가장자리·계단에 전투를 몰아넣지 않고, 회피와 카메라 회전이 가능한 옛 작업장에 조우를 둔다. 수치 충족만으로 통행과 전투 품질을 통과 처리하지 않는다.

### 11.4 여행할 이유와 첫 사건

**첫 여행의 제안:** 호수의 귀환·회복 장면을 마친 뒤, 마을에서 준비한 약재를 해안의 거래처에 전하고 돌아올 소금 짐의 사정을 알아보는 선택 의뢰로 출발한다. 기존 결말 장면 안에 새 의뢰를 끼워 넣거나 항구 방문을 호수 구원의 필수 조건으로 바꾸지 않는다. 의뢰 수락 전 탐험으로 먼저 도착해도 시장과 왕복 길은 이용할 수 있게 한다.

항구에서는 돌아오지 않은 연안 운송선의 짐 일부가 바깥 작업장에 밀려와 있다. 배 수선과 내륙 물자 출발을 책임지는 사람은 운송을 재개해야 하고, 돌아올 사람을 기다리는 주민은 남은 흔적을 먼저 찾으려 한다. 항구 전체를 폐쇄하거나 한쪽을 탐욕스러운 악역으로 만들지 않는다. 기존 5절의 사건 씨앗을 잇는 초안이며 인물 이름·외형·관계·대사와 구체적인 행방은 후속 플롯에서 정한다.

인과는 다음과 같이 구성한다.

1. 소금 짐의 출발이 늦어졌기 때문에 약재를 전달한 여행자가 부두 사정을 살핀다.
2. 기다리는 배의 짐이 다른 곳에 닿았기 때문에, 항구에서 보이는 옛 작업장으로 육로를 따라 조사한다.
3. 짐과 이동 흔적이 이어지기 때문에, 정해진 적 처치 수 대신 안전한 길과 사람의 행방을 확인하는 것이 목표가 된다.
4. 확인한 소식과 통행 가능한 길이 생겼기 때문에, 주민이 수색과 운송을 나누어 다시 움직일 수 있다.
5. 부두의 일이 다시 시작되기 때문에, 돌아왔을 때 비어 있던 작업 자리와 내륙으로 향하는 짐이 달라져 있다.

전투는 조사 길의 위험 한 구간에 집중하고 호위 대상의 느린 이동이나 제한 시간으로 길이를 늘리지 않는다. 이미 확보한 길은 반복 소탕을 요구하지 않는다. 실종자의 최종 행방과 누구를 직접 만나는지는 플롯 확정 전까지 비워 둔다. 첫 장의 정서적 끝은 새 거대 적 공개가 아니라 처음 도착했던 부두에서 달라진 일을 보는 장면이다.

| 구간 | 플레이어의 질문 | 다음으로 가는 동력 |
|---|---|---|
| 호수 출발 | 이 물건은 어디로 가는가? | 익숙한 생활 밖의 거래처를 만나고 싶음 |
| 물목 | 이 많은 짐은 어디서 오는가? | 여러 길이 만나는 곳에서 바다 쪽으로 향함 |
| 첫 항구 조망 | 저기서는 어떻게 살아갈까? | 가까이 가서 사람과 작업을 봄 |
| 부두의 빈자리 | 돌아올 사람에게 무슨 일이 생겼을까? | 보이는 흔적을 직접 따라감 |
| 항구 귀환 | 내가 알아낸 것이 무엇을 바꾸었나? | 다시 일하는 부두와 달라진 관계 확인 |

### 11.5 왕복·저장·반복의 경계

| 항목 | 설계 계약 |
|---|---|
| 기존 본편 | 기존 퀘스트·지역·도착점 ID와 GUID를 보존한다. 호수 내부 귀환 지점을 항구 출구로 전용하지 않는다. |
| 먼저 도착한 경우 | 지역 방문과 발견 사실을 수락 여부와 별도로 보존하고, 후속 의뢰가 이를 인정한다. 돌아가서 같은 단서를 다시 누르게 하지 않는다. |
| 남는 변화 | 발견한 길, 전달한 소식, 정상 종료한 지역 사건, 관계와 일회성 보상 수령. 지역을 왕복하거나 일반 적이 재등장해도 유지한다. |
| 반복되는 것 | 일반 적·채집·일상 작업은 현행 정책을 따른다. 선박 실종·짐 전달·길 확보 사건 전체를 반복시키지 않는다. |
| 중단 복구 | 조사 직후, 대화 도중, 지역 이동 직전·직후 저장을 나누어 확인한다. 대화 시작만으로 소식 전달 완료를 기록하지 않는다. |
| 보상과 물품 | 의뢰 물품은 팔기·소모로 진행이 막히지 않게 설계한다. 기존 의뢰 물품 계약부터 확인한다. 완료 지급은 단일 소유자가 맡고 중복 지급을 막는다. |
| 왕복 길 | 첫 방문부터 호수로 돌아갈 수 있다. 다음 지역의 사건 완료를 귀환 조건으로 삼지 않는다. 단축로는 발견 보상으로 두되 유일한 탈출구로 쓰지 않는다. |

호수 `RegionInfo.asset`의 지도 거점 5개는 호수 자신으로 도착하는 항목이다. 반대편으로 나가는 현장 출구와 역할이 다르므로 이 목록으로 해안 왕복 여부를 판정하지 않는다. 현재 두 도시의 출구·도착점과 자기 지역 지도 거점은 13.2절에 기록한다.

### 11.6 제작 묶음과 완료 판단

| 단계 | 만드는 것 | 완료 판단 |
|---|---|---|
| 접속부 조사 | 현재 시나리오 남쪽의 보행·지형·농장·주민 동선 확인, 사용할 출구 후보 선정 | 기존 시작·본편·생활 동선을 해치지 않는 접속 위치와 근거 확보 |
| 첫 왕복 공간 | 짧은 갈대 물목, 하구 조망, 항구 시장·부두의 기본 공간, 양방향 지역 이동 | 출발·첫 조망·도착·귀환을 직접 플레이해 방향과 거리 확인 |
| 도시 생활 | 주거 언덕 순환로, 실제 사용할 건물·배·작업 소품, 소수 주민의 생활 | 시장·집·일터의 관계가 읽히고 NPC·카메라·플레이어 동선이 막히지 않음 |
| 지역 사건 | 별도 확정 플롯, 인물별 사정, 조사·대화·전투·귀환 변화와 저장 연결 | 정상·역순·중단·저장/로드·재방문 통과 및 텍스트 검수 |
| 후속 가지 | 풍요의 대지 접속, 물목 독립 사건, 해식동굴, 섬 | 양끝을 제작·검증한 연결만 개방 |

현재 구현은 기존 씬 전환 방식을 사용한다. 굽은 길 전후의 지형·노면·진행 방향을 맞추되 로딩이 있으므로 심리스라고 표현하지 않는다. 물목은 항구 씬의 진입 구역으로 두고, 별도 지역화는 4절의 독립 사건·보행·성능 조건이 충족될 때 검토한다. 새 스트리밍·수영·항해 기능은 이 여행의 선행 조건이 아니다.

11절의 최초 작성 단계에서는 설계문서만 변경했다. 이후 항구와 성 도시의 씬·건축 자산·왕복 연결을 제작했으며, 현재 구현과 검증 범위는 13절을 따른다. 새 인물의 사정과 지역 사건, 직접 보행·시야·전투 감각, 저장/로드 검수는 후속 작업으로 남아 있다.

## 12. 돌등성 — 고갯길과 농경지 사이의 성 도시

**성문 밖에서 모인 짐이 장터를 지나 성 안의 생활로 이어진다.** 돌등 고개와 풍요의 대지 사이에 놓이는 내륙 교역 거점으로 제안한다. 바닷길과 배 수선이 중심인 소금바람항과 달리, 오래 머물며 식량을 저장하고 수레와 도구를 고치는 도시다. 대륙의 수도·왕국·지배 가문은 이번에 정하지 않는다.

외형은 밝은 석조 성벽, 붉은 기와, 목조 골조와 회벽 주택을 사용한다. 성문 양옆의 탑과 안쪽 본성이 멀리서 방향을 알려준다. 호수 마을의 목재·바위 재질을 잇되 초가지붕 마을을 그대로 복제하지 않는다.

| 공간 | 역할 | 동선 |
|---|---|---|
| 성문 밖 장터 | 들어오는 수레의 짐을 풀고 거래하는 자리 | 도착길 → 외부 가게 → 성문. 귀환은 사건 완료와 무관하게 가능 |
| 쌍탑 성문 | 도시의 경계와 안쪽 광장을 함께 보여주는 문 | 실제 통로를 지나며 본성 방향을 계속 읽음 |
| 성 안 생활 거리 | 집·작업장·장터가 가까운 생활권 | 광장 양쪽의 가로와 집 사이 길로 돌아 나옴 |
| 광장 | 여행자가 쉬고 다음 방향을 고르는 장소 | 시장·본성 앞·성문으로 갈라짐 |
| 본성 앞마당 | 큰 건축물에 다가가는 도착 경험 | 본성 외관까지 접근. 실내와 정치 이야기는 후속 범위 |

후속 지역 사건은 길을 지키는 책임과 도시 밖 사람들의 통행을 중심으로 검토한다. 호수의 축복 은폐나 항구의 실종선 이야기를 반복하지 않는다. 인물·갈등·퀘스트·보상은 이번 건축 작업에서 확정하지 않는다.

제안 지리는 **풍요의 대지 ↔ 돌등성 ↔ 돌등 고개**다. 현재 남쪽 이동은 **돌등성 → 소금바람항 씬 안의 갈대 물목 → 시장**으로 이어진다. 물목은 항구의 진입 구간이며 독립 지역은 보류한다. 호수에서 두 도시로 가는 출구와 도시 간 이동을 사용하고, 풍요의 대지와 돌등 고개에는 아직 출입구가 없다.

## 13. 두 도시의 실제 제작 범위

### 13.1 공간과 자산

- 항구 씬: [SaltwindHarbor.unity](../../01.Scenes/Scenario/SaltwindHarbor.unity). 물목의 갈대와 얕은 물, 접근길, 주택·시장·창고·부두·배·등대를 배치했다.
- 성 도시 씬: [StonegateCitadel.unity](../../01.Scenes/Scenario/StonegateCitadel.unity). 성문 밖 장터, 통행 가능한 성문, 성벽·탑, 주택, 광장, 본성 외관을 배치했다.
- 모델 원본: [WorldCities.blend](../../../ArtSource/WorldCities/WorldCities.blend), [WorldCityDetails.blend](../../../ArtSource/WorldCities/WorldCityDetails.blend). Blender MCP에서 메시·UV를 제작하고 FBX 17종으로 내보냈다.
- 텍스처: [CityMaterialsAtlas.png](../../04.Images/Environment/WorldCities/CityMaterialsAtlas.png). 내장 ImageGen으로 만든 석재·판재·회벽·청록 슬레이트·붉은 기와·골조 목재 6칸 아틀라스다.
- 프리팹: `Assets/03.Prefabs/Environment/WorldCities/`. 기존 수목·바위·갈대 프리팹도 사용한다.
- 배치 원본: [항구 배치](../../../ArtSource/WorldCities/harbor-layout.csv), [성 도시 배치](../../../ArtSource/WorldCities/castle-layout.csv). 제작·연결·검사 스크립트는 같은 폴더의 `.py`·`.csx`다. `.csx`는 Unity MCP 실행용 제작 기록이며 런타임 코드가 아니다.

건물 내부, 새 대사·도시 퀘스트·전투 사건은 아직 제작하지 않았다. 11절의 배 실종 사건이나 약재 전달 의뢰가 이미 동작하는 것으로 안내하지 않는다. 후속 돌등성 개선에서는 주민 12명, 여행용품 상점, 재료 매입 공방, 분수 뒤 회복 쉼터를 추가하고 거리·식재·조명을 정리했다. 기존 NPC 런타임과 역할별 경량 외형, 거래·휴식 기능을 사용하며 신규 대화나 본편 진행 조건은 추가하지 않았다. 상점은 독립된 저장 ID를 사용한다. 실제 입력·거래·회복·저장 검수와 최신 NavMesh 검증 상태는 `ArtSource/WorldCities/Validation/CITADEL_IMPROVEMENT_RESULT.txt` 및 같은 폴더의 `CITADEL_IMPROVEMENT_TESTS.txt`를 따른다. 항구에는 이 주민·시설 추가를 적용하지 않았다.

### 13.2 실제 출입구와 저장 계약

| 출발 | 길 표식 위치 X/Z | 목적지 |
|---|---|---|
| 호수 마을 남동쪽 | 1125 / 380 | 소금바람항 |
| 호수 마을 서쪽 | 1005 / 430 | 돌등성 |
| 소금바람항 접근길 | 176 / 40 | 생명의 호수 |
| 소금바람항 갈대 물목의 마른 길 | 184 / 64 | 돌등성 |
| 돌등성 접근길 | 176 / 40 | 생명의 호수 |
| 돌등성 바깥 장터 | 220 / 102 | 소금바람항 |

기존 `PortalActor`의 상호작용 이동과 `SceneArrivalPoint`를 사용한다. 길 표식에 접근해 상호작용하면 기존 로딩을 거쳐 이동한다. 심리스 월드나 전체 교역로의 연속 보행 구현은 아니다. 왕복 출구와 도착점은 떨어져 있어 도착하자마자 재이동하지 않는다.

방향별 도착 ID는 `worldcities.<도착 씬>.from.<출발 씬>`이다. 기존 도착 ID·포털 ID·기본 시작 맵·본편 퀘스트를 보존한다. 두 도시를 맵 데이터베이스와 빌드 목록에 등록하고, 각각 실제 배치로 촬영한 2048×2048 미니맵을 연결했다.

돌등성에서 오는 항구 도착점은 기존 ID를 유지한 채 X186/Z70으로 옮겼다. 호수 도착점 X180/Z55와 함께 갈대 물목(Z48~112)을 거쳐 시장으로 들어간다. 성 방향 길 표식과 도착점의 XZ 간격은 약 6.32m다. 물목을 위해 새 씬·새 연결 지역·새 포털을 만들지 않았다.

첫 방문은 현장 상호작용 출구를 쓰고, 도착 성공 뒤 도시별 발견 키 하나를 해금한다. 돌등성의 모든 도착점은 `worldcities.StonegateCitadel.plaza`, 항구의 모든 도착점은 `worldcities.SaltwindHarbor.market`를 공유한다. 지도 항목은 각각 자기 씬의 `worldcities.<도시 씬>.fast_travel`로 도착한다. 돌등성은 분수 뒤 광장 X180/Z204, 항구는 시장 어귀 X180/Z144이며, 첫 방문의 진입 풍경과 반복 방문의 짧은 생활 동선을 구분한다. 두 항목 모두 발견 전에는 숨긴다. 예전 저장에서 도시를 방문했더라도 새 키는 없으므로 한 번 더 도착해야 한다. 저장 이관은 추가하지 않는다.

이번 연결 정리의 검사 결과·이름 승인 대기·직접 플레이 항목은 [연결 정리 보고](../../../ArtSource/WorldCities/Validation/TRAVEL_CONNECTION_RESULT.txt)와 [연결 정리 테스트](../../../ArtSource/WorldCities/Validation/TRAVEL_CONNECTION_TESTS.txt)를 따른다. 아래 최초 제작 검사를 이번 변경의 플레이 검증으로 대신하지 않는다.

### 13.3 검증과 남은 작업

Unity 데이터 검사에서 두 도시 모두 Missing Script 0, 잘못된 재질 0을 확인했다. 항구 내부 5개·성 도시 내부 4개 주요 목적지의 NavMesh 경로가 완전 연결되며, 출구 6개·도착점 6개와 각 출구까지의 경로를 검사했다. 이는 플레이어가 직접 걸은 검증과 다르다.

최초 호수 서쪽 숲 출구는 시작 마을과 NavMesh 경로가 이어지지 않아 탈락시켰다. 호수 마을 서쪽의 연결된 길로 옮긴 뒤 재검사했다. 초기에 잘못 지정한 출구 레이어도 기존 `InteractableObject`로 수정했다. 원본 씬을 백업과 비교해 사용자 변경을 보존하며 새 연결 오브젝트만 추가했는지 확인한다.

검사 결과와 후속 Player 빌드·실행 결과는 [제작 및 검증 기록](../../../ArtSource/WorldCities/Validation/RESULT.txt)을 따른다. 직접 보행·상호작용·왕복·저장/로드와 실제 패드 검수는 [사용자 확인 절차](../../../ArtSource/WorldCities/Validation/USER_TEST_SPEC.txt)에 분리한다. 미확인 항목을 이 문서로 통과 처리하지 않는다.
