# P2 반환 운동·피해 출처

`ProjectileRuntime`을 확장했다. 접촉 중심에서 원 sweep을 종료하고 새 소유자/타깃 마스크/방향/시작·이전점/트레일/속도·수명을 확정한다. 최초 발사자에 한해 30도·35m·SphereCast 사선 보정을 한 번 적용하며 상수 속도×1.25(maxSpeed 상한), 반환 수명 2초, 생애 반사 1회다. 타깃·부모·barrel offset을 비우며 마스크/공간 실패는 후속효과 없이 흡수한다.

충돌은 초기 겹침을 검사하고 NonAlloc 32→128→512칸 재조회 후 완전한 집합을 정렬한다. 상한 포화는 효과 없는 소멸, 동률은 장애물 우선이다. Guard 접촉시각은 Time.time에서 sweep 진행률로 역산하며 지원 탄은 owner LocalTimeScale을 사용하지 않는다.

최초 수치/속성/치명을 `ProjectileDamageSource`에 고정하고 반사자의 진영/전투 ID/캐릭터 귀속을 분리한다. 대상의 현재 방어·취약·면역 파이프라인은 유지한다. 반환탄은 일반 NotifyAttackHit/proc/추가타와 카운터/강제 반응 우회 플래그를 사용하지 않는다. 풀 반환에서 요청·원 발사자·접촉·반사 상태를 비운다.

## 실제 자동 검사

- Unity 정상 컴파일 뒤 새 계약 타입 로드 확인. Console error 0 확인.
- 관련 EditMode `CombatTuningPolicyTests` + `ProjectileAttackDataTests`: **39/39**, 실패 0. [MCP 원본 진행·완료 기록](p2-editmode.json). Domain Reload 이후 상세 result는 보존되지 않아 completed/total/status/실패 목록 원본을 기록한다.
- Editor PlayMode `StaffMagicProjectilePlayModeTests` + `EncounterProjectileCleanupTests`: **5/5 통과**, 실패/건너뜀 0. [MCP 원본 결과](p2-playmode.json). 실제 Staff VFX 2종 명중/풀 재사용, 조우 소유자 정리, 1회 반사/2초 수명/이전 세대 취소, 40·130·520 초기 겹침, 1000m/s·30fps 벽 차단 검사.
- 테스트 도중 MCP 연결 종료가 발생해 SessionState의 기존 job ID로 결과를 회수했다. Editor 재시작/두 번째 Editor/중복 강제 실행 없음. 다른 작업의 Pet 검사 기록은 이번 작업의 결과로 승계하지 않는다.

이후 귀속 캐릭터와 Player 피해 Resolver 스냅샷 확장을 추가했으므로 최종본의 영향 검사는 P4에서 재실행한다. 실제 플레이어 입력→가드→원격 반응/보스 면역/구독자 보상 전체를 위 5건으로 인수한 것은 아니다. 그 경계는 추가 자동 검사와 PP01~PP10 사용자 확인으로 남는다.

임시 테스트 오브젝트는 finally에서 제거한다. 장면/데이터 저장 없음. 다음 P3는 실제 두 phase의 opt-in과 형태/음향 연결이다. [전투 위키](../../wiki/combat.md).
