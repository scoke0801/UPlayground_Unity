다온 얼굴·목 피부 경계 수정 — 후속 검토

사용자가 이전 NECK_FIX_RESULT의 미술 품질 판정을 거부했다.
이전 수정은 메시 틈만 해결했으며 서로 다른 피부 재질·UV 때문에 얼굴/목 경계가 보였다.

저장 완료
- Daon_P09_Head.asset의 목 UV를 얼굴 아틀라스 경계와 정확히 연결했다.
- 얼굴·목 삼각형을 동일 서브메시 0으로 묶어 얼굴 재질을 공유한다.
- 원본 얼굴의 4개 UV 절개선을 유지하려고 경계 정점 12개만 복제했다.
- 정점 7095 → 7107. 삼각형 수·본·표정·얼굴 조형은 변하지 않았다.
- 기존 프로파일/프리팹 호환을 위해 6개 재질 슬롯은 유지하고, 기존 목 슬롯 5는 빈 서브메시로 남긴다.
- 공용 P09 피부 재질·얼굴 텍스처는 변경하지 않았다.

검증
- UV 경계 32개가 원본 얼굴 경계와 동일. 같은 재질이므로 경계의 텍스처·조명 설정도 동일.
- 원본 얼굴 7015점의 위치·노멀·탄젠트·UV·가중치·표정 델타·삼각형 보존.
- 173개 표정 프레임 및 목·머리 자세 7개 검사 통과. 이음새 최대 오차 0m.
- Missing Script 0, 본·메시·재질 누락 0.
- 실제 SkinnedMeshRenderer 정면·55도·90도 캡처 확인.
- Console의 기존 GPU 버퍼 오류 5건은 이전 작업의 기록이며 이번 렌더로 증가하지 않았다.
- Play Mode 사용자 검수·Player 빌드는 미수행.

전용 피부 적용 완료
사용자가 최종 시안 적용과 공유 프리팹·항구 주민 외형 보존 저장을 명시적으로 승인했다.
Daon_P09_Skin.mat을 생성해 정규 다온·독립 검수 프리팹과 P09_Daon_ToonLook 제작 프로파일에 연결했다.

몸 피부에만 있던 BumpMap·Rim 효과는 모두 0이다. 공용 재질은 수정하지 않았다.
BodyTrial_55.png는 승인된 미리보기이며 Applied_55.png가 실제 저장된 프리팹의 렌더다.

저장 및 보존 검사
apply_p09_skin_surface.csx 실행 성공. 공유 프리팹 6개와 항구 주민 2명의 모든 재질 슬롯이 적용 전 스냅샷과 일치했다.
