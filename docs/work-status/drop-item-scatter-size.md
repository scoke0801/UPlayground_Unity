# 드롭 아이템 분산·크기 개선

2026-11-14 사용자 요청: 아이템이 겹치지 않도록 퍼뜨리고 다소 큰 월드 표현을 줄인다.
정본: [월드 모델 저작 지침](../../Assets/docs/guide/DROP_ITEM_WORLD_MODEL_AUTHORING_GUIDE.md). 이전 [모델/이름표 작업](drop-item-presentation.md)·[모델 확장](drop-item-world-model-expansion.md)의 사용자 변경을 보존한다.

## 조사·구현

기존 SpawnItems는 반경0.6m 안에서 독립 무작위 위치를 선택하며 최소 간격 검사가 없었다. 착지 실패 시 원천 좌표로 돌아왔고, 표시 모델은 긴 변0.55m·부유0.5m였다. 이름표는 화면 겹침 시 위로 이동시키며 원천부터 포물선 투척 연출은 이미 구현되어 있었다.

| 항목 | 변경 전 | 적용 수치 |
|---|---|---|
| 분산 반경 | 고정0.6m | 아이템 수의 제곱근×목표 간격, 최대1.2m |
| 목표 중심 간격 | 없음 | 0.55m |
| 최대 착지 높이 차/경사 | 검사 없음 | 원천 바닥 대비0.6m/45도 |
| 모델/메달 긴 변 | 0.55m | 0.38m(약31% 축소) |
| 부유 높이/진폭 | 0.5m/0.07m | 0.35m/0.04m |
| 투척 시작 높이/호 높이 | 0.9m/0.8m | 0.7m/0.55m |
| 이름표 기준 높이 | 1.2m | 0.75m |
| 고급/희귀/유니크/전설 빛기둥 | 1.2/2.2/3.2/4.5m | 0.8/1.4/2.0/2.8m |

수치 원본은 [GroundDropSettings.asset](../../Assets/10.Datas/Pet/GroundDropSettings.asset)이다. 링은 tokenSize를 사용하므로 함께 축소되고 빛기둥 폭도 모델 크기에 비례하도록 수정했다. 모델/메달 선택·원본 모델/재질·희귀도 색·획득 거리4m·이름표 크기·획득 판정 콜라이더는 유지한다.

같은 맵의 미획득 드롭과 수평 간격을 비교한다. 같은 보상의 여러 항목뿐 아니라 인근 연속 처치 보상도 고려한다. 최대24개 후보를 검사하고 목표 간격이 나오는 첫 후보를 채택한다. 간격 부족 시 원천 바닥과 유효 후보 중 가장 빈 곳을 선택한다. 바닥 경사·높이 차·모델 중심 높이의 벽 차폐를 검사하며, 좁은 발판에서는 간격보다 안전한 착지를 우선한다. 모든 후보/바닥이 없더라도 원천 좌표의 보상 기록을 보존하고 기존 표시 재시도 경로를 사용한다.

기존 저장된 좌표·아이템 수량·랜덤 옵션은 재배치/재추첨하지 않는다. 앞으로 SpawnItems로 생성되는 위치에 적용하며 고정 씬 배치 RegisterPlaced는 저작 위치를 유지한다.

## 사용자 직접 확인

LakeVillageWorld의 테스트 저장 슬롯, 평소 입력 장치로 확인한다. 저장 초기화·아이템 강제 주입 없이 기존 몬스터 드롭을 사용한다.

| ID | 절차 | 기대/실패 기준 |
|---|---|---|
| DS01 | 평지에서 아이템 여러 개를 주는 적을 연속 처치 | 좁은 범위로 흩어지고 서로 겹침 감소. 인근 기존 아이템도 피한다. 공간이 충분한데 계속 한 점으로 뭉치면 실패 |
| DS02 | 벽 옆/절벽 가장자리/좁은 발판에서 처치 | 벽 뒤/급격히 낮은 아래층으로 분산되지 않는다. 좁은 곳의 간격 축소는 정상. 보상 소실/획득 불가면 실패 |
| DS03 | 무기·방어구·정수·물약을 가까이/약8m, 낮/밤/풀밭에서 관찰 | 이전보다 작고 낮으며 링·기둥이 모델을 압도하지 않음. 알아볼 수 없을 만큼 작거나 풀에 완전히 묻히면 크기/높이 재조정 |
| DS04 | 이름표 클릭/패드 포커스/수동 획득·펫 수거 | 이름/모델/획득 대상 일치, 이전 획득 거리 유지. 포커스 선택 오류·펫 접근 실패·이중 지급이면 실패 |
| DS05 | 미획득 상태로 저장/로드·지역 재진입 | 확정 위치와 아이템 유지, 재분산/보상 재추첨/소실 없음 |

회신: DS번호 / 통과·실패·미수행 / 증상·아이템·장소·입력 장치 / 로그. 실제 화면 크기·낙하 느낌·획득·저장 회귀는 **사용자 테스트 대기**다.

## 한계·부산물

최소 간격은 목표이며 좁거나 과밀한 지형에서는 보장하지 않는다. 화면상 원근 겹침은 기존 이름표 회피가 담당한다. Raycast/Linecast는 설정된 groundMask/visibilityMask에 속하는 정적 표면을 기준으로 하며 전체 NavMesh 도달 가능성이나 물 표면 안전 판정은 추가하지 않았다.

구매/MCP 원본·기존 meta·장비/드롭 밸런스 데이터 보존. 빌드·커밋 없음. 신규 아트/씬·합성 테스트 에셋 파일 생성 없음. 테스트용 GameObject는 종료 시 정리한다. 작업 전 스냅샷은 사용자 변경 보호 근거로 준비표 폴더에 보존한다.

최종 준비표는 output/harness의 이번 분산·크기 작업 review.md에서 추적한다. 임시 삭제 대상은 해당 없음이며 검증 JSON·실측 텍스트·신규 테스트/meta는 재검증 근거로 보존한다.
