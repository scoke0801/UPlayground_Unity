## 본편 연결과 상태 소유

기존 `quest_main_red_tree_return_next` ID와 GUID `fbaa0a0832a7d0b4f8a056e86c769f0b`, 제목 ‘마을에 알릴 일’, 목표 이벤트 `lake.red_tree.return_work_started`를 보존했다. 마커만 R09 조이 앞 시작점으로 연결했다. 새 대기를 추가하지 않고 시작 대화 정상 종료로 기존 목표를 마감하여 `quest_main_red_tree_s13` ‘돌려보내는 짐’을 시작·추적한다. QuestDatabase에는 한 번만 등록한다.

아래 키에는 `lake.red_tree.` 접두사가 붙는다. 모든 일회성 사실은 GlobalFlag가 소유하고 SaveManager가 저장한다. Quest는 안내·진행 표시, Flow는 조건과 대화 조율, Presentation은 복원된 배치만 소유한다. 새 게임 외에는 초기화하지 않는다.

## 화면·말투와 재사용

기존 `output/RedTreeR01/players.png`, `npcs.png` 일러스트 모음과 이번 `models-before.png`의 현행 씬 모델을 직접 비교했다. 작업용 편집 모드 캡처는 T자 자세이며 실제 플레이 자세·원본 의상 정상 표시의 검증이 아니다. 묘묘 의상, 세라 얼굴, 최초 아린의 런타임 모델 교체 검증은 별도로 남긴다.

R01 CAST의 관계와 Voice Profile을 유지한다. 조이는 짧고 부드러운 해요체로 먹을 몫을 걱정하고, 리안·세라·연화는 실무적인 해요체로 소유와 부족한 몫을 구별한다. 묘묘는 먼저 묻고 주민은 반입을 제한한다. 릴리는 재방문을 약속하되 감사·용서를 요구하지 않는다. 설아는 관찰을 설명문 대신 다음 작업 요청으로 잇는다. 주인공과 미선택 주인공은 기존 자연스러운 해요체를 유지한다. 장면마다 전원 발언을 요구하지 않는다.

기존 수레·자루·끈·그릇·작업 모션·R08 물 메시/재질을 재사용한다. 외부의 소량 물은 R08 중앙 관찰점과 별도 오브젝트다. S03 빈집과 시든 작물은 바꾸지 않는다. 새 운송 모션·음성·전원 승리 포즈는 없으며, 물자 인계의 소품 전환과 작업 인물의 보행/기존 자세는 전용 포장·운송 애니메이션과 구별한다. 대화는 기존 카메라/입력/HUD 반환 경로를 사용한다.

결말 이후 조이와 남은 주민의 생활 대화는 반복 가능하다. 완료 플래그·보상·적재·출발을 다시 생산하지 않는다. 자동 새 게임, 저장 초기화, 장비/성장/동료 제거, 타이틀 이동, 시간 도약은 없다.
