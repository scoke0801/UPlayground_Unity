Siuha Hair03 부착 위치 수정

사용자가 Siuha임을 확인한 이마·헤어 사이의 뜬 간격을 수정했다.
Hair03의 Head 로컬 위치를 (0, -0.025, 0)에서 (0.018, -0.025, 0)으로 변경했다.
이 리그에서 Head 로컬 +X는 캐릭터 뒤쪽이다. 뒤로 18mm 이동하며 높이는 보존했다.
0~50mm 후보를 비교했고 35mm 이상에서는 두피가 헤어를 관통하여 제외했다.
얼굴·두피·헤어 정점, 모든 스케일, Hair11, 재질·눈·목 연결은 변경하지 않았다.

저장 대상: Siuha_P09_Face 프로필, Siuha_P09Compatible / Siuha_P09_Alternate 프리팹,
Siuha_P09_Review 씬의 기존 3개 인스턴스. 씬 배치와 BodyOnly 가시성을 보존했다.
R04 제작 파일은 이전 위치의 이력이다. 재현 시 R04 복원 후 apply_position.csx를 실행한다.
이번 수정은 공용 빌더·런타임 코드 변경이 없는 기존 부착값 조정이다.
backup/manifest.json의 28개 백업을 검증하고 저장했다. 복구 시 변경된 4개 파일만 복구한다.

검증
저장 프리팹과 씬 재로드 시 위치 일치, 프로필 2회 재적용 통과.
머리·헤어 스케일 1, 원본 Hair03/11 메시 참조 유지, 얼굴 정점 11,560개 R02와 정확 일치.
Idle/Walk에서 헤어 bounds 24회 통과. BodyOnly 렌더러 3개 보존.
정면·좌우 45도·후면, 숙인 자세의 Unity 렌더를 확인했다. Console 오류 조회 0.
Evidence/Siuha_45.png는 저장된 프리팹의 수정 후 확대 화면이다.
Play Mode·물리·Player 빌드는 미수행. 사용자 미술 확인과 Editor 검사 결과는 구분한다.
