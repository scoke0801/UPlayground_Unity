# UPlayground 기반 스토리 문서

> 작성일: 2026-04-26  
> 문서 목적: 메인 스토리, 캐릭터 동기, 지역 진행, 퀘스트/대화 데이터 작성 기준을 정리한다.

---

## 개요

UPlayground는 무너진 변경 지대에서 세 명의 플레이어블 캐릭터가 각자의 이유로 같은 재앙의 근원을 추적하는 싱글플레이 TPS 액션 게임이다.

핵심 방향은 다음과 같다.

- 빠른 액션과 짧은 스토리 트리거가 번갈아 이어지는 구조
- 지역 진입, 보스 처치, 핵심 NPC 대화를 기준으로 `StoryManager.CurrentProgress` 상승
- 메인 스토리는 3인 파티의 목적이 충돌하다가 하나의 위협으로 수렴하는 흐름
- 대화는 짧고 목적 중심으로 작성하되, 캐릭터 성격은 전투 전후의 반응으로 드러낸다.

---

## 세계관

### 변경 지대

대륙 중앙에는 과거 연구 도시였던 `오르타 림`이 있다. 오르타 림은 인공 생명, 무기 공명, 기억 보존 기술을 연구하던 도시였지만, 어느 날 중심 시설에서 발생한 폭주로 도시 전체가 뒤틀렸다.

폭주 이후 도시와 주변 숲, 폐광, 수로, 연구 구역은 하나의 거대한 변경 지대가 되었다. 이곳에서는 생물과 장비, 기억의 잔상이 뒤섞여 몬스터와 이상 현상을 만들어낸다.

### 공명핵

재앙의 중심에는 `공명핵`이라 불리는 동력원이 있다. 공명핵은 사람의 기억과 감정을 에너지로 증폭시키는 장치였지만, 현재는 남겨진 기억을 몬스터의 본능으로 변환하고 있다.

플레이어가 마주하는 적과 스토리 이벤트는 대부분 공명핵이 남긴 잔향이다.

### 바이탈 오브

전투 중 등장하는 `VitalOrb`는 공명핵의 파편이 생명력 형태로 굳어진 것이다. 게임 시스템상 회복 자원이지만, 스토리상으로는 변경 지대가 아직 완전히 죽지 않았다는 증거다.

## 주요 세력

| 세력 | 역할 | 스토리 기능 |
|------|------|-------------|
| 조사대 | 변경 지대 외곽을 통제하는 생존자 집단 | 튜토리얼, 장비, 기본 퀘스트 제공 |
| 잔향체 | 공명핵에 의해 변질된 몬스터와 의식 파편 | 일반 적, 엘리트, 보스 |
| 오르타 연구국 | 재앙 이전의 연구 조직 | 문서, 폐시설, 보스 기원 |
| 회수자 | 변경 지대에서 유물과 무기를 회수하는 독립 집단 | 서브 퀘스트, 상점, 도덕적 갈등 |
| 봉인파 | 공명핵을 완전히 파괴하려는 세력 | 후반 선택지와 충돌 |

## 플레이어블 캐릭터

### Bokusei

| 항목 | 내용 |
|------|------|
| 무기 | 카타나 |
| 전투 이미지 | 정면 돌파, 정확한 간격, 빠른 마무리 |
| 기본 동기 | 실종된 스승의 마지막 흔적을 찾는다. |
| 내적 갈등 | 스승이 재앙을 막으려 했는지, 이용하려 했는지 확신하지 못한다. |
| 스토리 역할 | 플레이어가 세계의 핵심 진실에 접근하는 관찰자이자 추적자 |

Bokusei는 말수가 적고 판단이 빠르다. 대화에서는 상황을 요약하고 다음 행동을 제안하는 역할이 어울린다.

### Honoka

| 항목 | 내용 |
|------|------|
| 무기 | 쌍도끼 |
| 전투 이미지 | 강한 압박, 넓은 범위, 높은 리스크 |
| 기본 동기 | 변경 지대에서 사라진 가족의 행방을 찾는다. |
| 내적 갈등 | 복수심 때문에 구해야 할 사람과 쓰러뜨려야 할 적을 구분하지 못할 때가 있다. |
| 스토리 역할 | 감정의 폭발과 인간적인 선택지를 담당 |

Honoka는 감정 표현이 직접적이다. 전투 전 대사는 짧고 거칠게, 전투 후 대사는 죄책감이나 분노가 섞이도록 작성한다.

### LianLian

| 항목 | 내용 |
|------|------|
| 무기 | 채찍 |
| 전투 이미지 | 거리 조절, 구속, 변칙적인 공격 |
| 기본 동기 | 공명핵 기술의 원본 기록을 회수한다. |
| 내적 갈등 | 진실을 공개하면 더 큰 혼란이 올 수 있다는 사실을 안다. |
| 스토리 역할 | 연구국과 공명핵에 대한 정보를 해석하는 인물 |

LianLian은 단서를 모아 설명하는 캐릭터다. 단, 긴 설명 대신 핵심 단서와 추론을 짧게 던지는 식으로 작성한다.

## 메인 스토리 흐름

```
프롤로그
  └─ 외곽 조사 캠프
      └─ 변경 숲
          └─ 폐광 수로
              └─ 오르타 하층 연구구
                  └─ 기억 보존 시설
                      └─ 공명핵 중심부
```

### 진행도 기준

현재 스토리 시스템은 `StoryEntrySO.requiredProgress`와 `StoryManager.CurrentProgress`를 기준으로 대화 그래프를 선택한다. 아래 값은 메인 진행도를 잡기 위한 권장 기준이다.

| Progress | 구간 | 주요 사건 | 해금/변화 |
|----------|------|-----------|-----------|
| 0 | 프롤로그 | 플레이어가 외곽 캠프에 도착한다. | 기본 조작, 첫 전투 |
| 10 | 변경 숲 | 첫 잔향체 무리를 처치하고 공명핵 파편을 발견한다. | Story_Main_0 계열 |
| 20 | 폐광 수로 | 조사대의 실종 기록과 Honoka의 단서를 연결한다. | 엘리트 몬스터, 회수자 NPC |
| 30 | 연구구 진입 | LianLian이 연구국 기록을 해독한다. | 연구 시설 대화, 잠긴 구역 |
| 40 | 기억 보존 시설 | Bokusei의 스승이 공명핵 봉인에 관여했음이 드러난다. | 보스 전초전 |
| 50 | 중심부 | 공명핵을 파괴할지, 봉인할지 결정해야 한다. | 최종 보스, 엔딩 분기 |

## 챕터 상세

### 프롤로그: 외곽 조사 캠프

플레이어는 변경 지대 외곽에 있는 조사 캠프에서 시작한다. 캠프는 안전하지만 자원이 부족하고, 내부 인물들은 공명핵을 두려워한다.

목표:

- 기본 전투와 상호작용 학습
- 조사대 NPC를 통해 변경 지대의 위험 소개
- 첫 `StoryTriggerZone`으로 메인 대화 시작

핵심 대화:

- 조사대 가이드가 “안쪽에서 돌아온 사람은 몸보다 기억이 먼저 망가진다”고 경고한다.
- Bokusei는 스승의 검집에 남은 공명 반응을 확인한다.

### 1장: 변경 숲

변경 숲은 공명핵의 영향이 자연에 먼저 스며든 지역이다. 몬스터는 동물형과 식물형 잔향체가 중심이다.

목표:

- 첫 필드 탐색 구간 구성
- VitalOrb와 회복 자원의 세계관 의미 암시
- 첫 엘리트 몬스터 처치 후 진행도 `10`으로 상승

스토리 트리거 예시:

| Story ID | Progress | 내용 |
|----------|----------|------|
| `main_forest_entry` | 0 | 변경 숲 진입 대화 |
| `main_forest_orb` | 0 | VitalOrb 발견 반응 |
| `main_forest_elite_clear` | 10 | 엘리트 처치 후 공명핵 파편 발견 |

### 2장: 폐광 수로

폐광 수로는 회수자들이 드나드는 위험 지역이다. 이곳에서 Honoka의 가족이 회수 작업에 동원되었다는 기록이 발견된다.

목표:

- 회수자 세력 등장
- Honoka의 개인 동기 강화
- 조사대와 회수자의 이해관계 충돌

주요 갈등:

- 회수자는 공명핵 파편을 팔아 생존하려 한다.
- 조사대는 파편 반출을 금지한다.
- Honoka는 회수자를 협박해서라도 가족 기록을 얻으려 한다.

### 3장: 오르타 하층 연구구

연구구에서는 공명핵이 단순한 에너지원이 아니라 기억을 저장하고 증폭하는 장치였다는 사실이 드러난다.

목표:

- LianLian의 정보 해석 역할 강화
- 연구국 문서와 환경 스토리텔링 배치
- 보스의 기원을 인간적인 사건으로 연결

핵심 반전:

오르타 연구국은 재앙을 실수로 만든 것이 아니라, 전쟁 억제를 위한 감정 증폭 병기를 만들고 있었다.

### 4장: 기억 보존 시설

기억 보존 시설은 공명핵에 흡수된 인물들의 잔향이 가장 강하게 남은 지역이다. Bokusei의 스승도 이곳에 흔적을 남겼다.

목표:

- Bokusei의 개인 서사 회수
- 과거의 선택과 현재의 선택을 연결
- 최종 분기 조건 제시

주요 장면:

- 스승의 잔향은 공명핵을 파괴하면 흡수된 기억도 모두 사라진다고 말한다.
- Honoka는 가족의 잔향이 남아 있을 가능성 때문에 파괴를 망설인다.
- LianLian은 봉인이 실패하면 변경 지대가 더 넓어진다고 경고한다.

### 5장: 공명핵 중심부

최종 구간에서는 세 캐릭터의 목적이 충돌한다.

선택 방향:

| 선택 | 결과 방향 | 엔딩 톤 |
|------|-----------|---------|
| 파괴 | 변경 지대 확산은 멈추지만 남은 기억은 사라진다. | 희생과 정리 |
| 봉인 | 기억은 보존되지만 언젠가 다시 폭주할 위험이 남는다. | 미완의 희망 |
| 회수 | 공명핵 기술을 밖으로 가져가지만 새 갈등이 시작된다. | 불안한 진실 |

초기 구현에서는 하나의 정식 엔딩만 사용하고, 나머지는 후속 확장용 플래그로 남겨도 된다.

## 대화 작성 기준

### 톤

- 한 노드는 1~3문장 안에서 끝낸다.
- 액션 흐름을 끊지 않도록 전투 전후 대화는 짧게 쓴다.
- 설명은 LianLian, 감정 반응은 Honoka, 판단과 결론은 Bokusei에게 우선 배치한다.
- 같은 정보를 NPC가 반복하지 않는다. 반복이 필요하면 다른 감정이나 이해관계를 붙인다.

### 대사 예시

```text
Bokusei: 이 흔적, 검집에 남은 반응과 같다.
Honoka: 그럼 안쪽에 답이 있다는 거네. 좋아, 길만 열어.
LianLian: 서두르지 마. 이건 생명 반응이 아니라 기억 반응이야.
```

```text
조사대 가이드: 안쪽으로 갈수록 적은 강해지지 않습니다. 더 익숙해질 뿐입니다.
Bokusei: 우리를 기억한다는 뜻인가.
조사대 가이드: 아니요. 우리가 두려워하는 방식을 배웁니다.
```

## StoryEntrySO 작성 규칙

스토리 데이터는 `Assets/10.Datas/Story/` 아래의 `StoryEntrySO`와 `DialogueGraphSO`를 기준으로 작성한다.

### Story ID 규칙

| 타입 | 형식 | 예시 |
|------|------|------|
| 메인 | `main_<area>_<event>` | `main_forest_entry` |
| 캐릭터 | `char_<character>_<event>` | `char_honoka_mine_record` |
| 보스 | `boss_<area>_<event>` | `boss_lab_h09_defeat` |
| 시스템 테스트 | `test_<purpose>` | `test_dialogue_branch` |

한번 저장 데이터에 들어간 `storyId`는 변경하지 않는다. 이름을 바꿔야 하면 새 `StoryEntrySO`를 만들고 기존 ID는 레거시로 남긴다.

### Progress 사용 규칙

- `requiredProgress`는 해당 대화가 노출될 최소 진행도다.
- 같은 위치에서 진행도별 대사가 필요하면 `variants`를 사용한다.
- 보스 처치, 핵심 아이템 획득, 주요 NPC 대화 완료 시점에만 `StoryManager.SetProgress()`를 호출한다.
- 일반 필드 발견 대화는 진행도를 올리지 않는다.

### 트리거 배치 규칙

| 위치 | 권장 트리거 |
|------|-------------|
| 지역 입구 | `StoryTriggerZone` |
| 보스 클리어 | 전투 종료 이벤트에서 `TryTriggerStory()` 또는 진행도 상승 후 대화 |
| NPC 대화 | `DialogueGraphSO`와 퀘스트 조건 조합 |
| 반복 확인 대화 | `variants` 또는 별도 `storyId` 사용 |

## 퀘스트 연결 기준

메인 스토리는 퀘스트 시스템과 느슨하게 연결한다. 스토리 진행도는 큰 장의 잠금 해제에 사용하고, 세부 목표는 `QuestSO`가 담당한다.

| 스토리 구간 | 퀘스트 예시 | 완료 조건 |
|-------------|-------------|-----------|
| 변경 숲 | `quest_main_001` | 숲 입구 조사, 첫 잔향체 처치 |
| 폐광 수로 | `quest_main_002` | 회수자 기록 3개 회수 |
| 연구구 | `quest_main_003` | 연구국 단말 2개 확인 |
| 기억 시설 | `quest_main_004` | 스승의 잔향과 대화 |
| 중심부 | `quest_main_005` | 최종 보스 처치 |

퀘스트 이름은 구현 데이터와 맞춰 나중에 조정한다. 이 문서에서는 스토리 구조와 작성 방향만 고정한다.

## 지역별 반복 소재

| 소재 | 사용 방법 |

## 확장 포인트

- 캐릭터별 개인 퀘스트를 추가해 메인 엔딩 선택에 영향을 줄 수 있다.
- `GlobalFlagManager`를 사용해 파괴/봉인/회수 성향 플래그를 누적할 수 있다.
- `StoryEntrySO.variants`로 같은 지역을 재방문했을 때 대사를 바꿀 수 있다.
- 보스 처치 후 남는 잔향 대화를 별도 `storyId`로 두면 회고형 스토리 연출이 가능하다.
- 회수자 세력을 상점/제작 시스템과 연결하면 서브 퀘스트의 보상이 자연스러워진다.

---

## 작성 체크리스트

- `storyId`는 저장 데이터에 들어가므로 변경 금지로 취급한다.
- 메인 진행도는 너무 자주 올리지 않는다.
- 대화 그래프 하나에 설명을 몰아넣지 않는다.
- 전투 직전 대화는 입력 흐름을 끊지 않도록 짧게 작성한다.
- 지역마다 캐릭터 3인의 반응이 모두 필요하지는 않다. 해당 장의 주인공을 정하고 나머지는 보조 반응으로 둔다.
