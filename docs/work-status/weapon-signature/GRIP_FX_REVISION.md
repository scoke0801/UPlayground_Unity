# 궁극기 손·무기 결합과 FX 재작업

2026-11-15. 사용자 지적: 손과 무기의 결합 불일치, FX 품질 부족. [전투 위키](../../wiki/combat.md) · [설계 정본](../../../Assets/docs/design/combat/player/ULTIMATE_MOTION_REDESIGN.md).

## 현재 판정

12명 파지 수정 클립과 FX 변경을 적용했다. 관련 EditMode 29/29 통과, 격리 프리뷰 확인까지 수행했다. 이전 버전의 사용자 품질 반려를 취소하지 않는다. 이번 수정본의 실전·미술 인수는 아직 받지 않았다.

## 확인한 원인과 수정

- 12명 중 11명의 기존 클립에 범위 밖 손가락 근육 커브가 있었다. 파지 손은 닫힌 자세로 재저작하고 자유손은 기존 연기를 유지하며 범위를 제한했다. 레이네는 투척 해제·재파지 구간을 따로 유지한다.
- 화린의 보조손 목표는 일부 프레임에서 팔 길이보다 멀었다. 화린·세라·릴리는 주손을 도달 가능한 위치로 조정하고 자루를 기준으로 보조손 팔을 재베이크했다. 몸통·하체·루트·타격 시각은 보존한다.
- 라온의 검 추가 본 위치를 실제 파지 손에 맞춰 재베이크했다. 설아의 활 위치 보정 후 시위 당김·해제 커브도 다시 계산했다. 유라 양검은 각각 보정한다.
- Constraint 위치를 클립에 직접 넣은 첫 후보는 다음 클립으로 바꿔도 값이 잔류했다. 적용 전에 해당 커브를 제거하고 `WeaponGripOffsetEvent`와 기존 `PlayerEquipment` 슬롯 캐시로 구간 적용·종료 복구를 처리했다. 모델 교체·사망·장비 정리 경로도 같은 복구를 사용한다. 이벤트 발화 중 계층 탐색은 추가하지 않았다.
- 화린: 한 번만 나오던 흰 참격을 회전 5타의 불꽃 호로 교체, 손 본에 붙인 중복 트레일 제거. 기존 무기 트레일은 유지한다.
- 아린: 금빛 참격과 짧은 잔광. 라온: 참격 효과 종료를 앞당겨 회수 동작을 가리지 않게 했다.
- 연화·묘묘: 빔에 레이저용 재질·중심광·외곽광 적용, 과한 검은 입자·반복 충격파 제거. 충전은 지팡이 머리에 부착하고 빔 시작은 해제 자세에서 측정한 머리 위치를 사용한다. 빔 방향은 기존 전방 판정과 같으며 회복 자세 이전에 끝난다. 머리를 매 프레임 추적하는 빔은 아니다.
- 리안: 몸 주변의 별도 원형 문양 제거, 실제 채찍 끝 잔상 폭·수명 조정. 세라·릴리·레이네·묘령: 충격광·지면 링·먼지의 색과 수명 분리. 설아 발사광은 활에 부착. 유라 회오리의 입자 밀도·불투명도 축소, 묘령 방패의 중첩 문양 완화. 무기 회수 섬광의 크기·수명 축소.

## 산출물과 보존

- 실행 클립: `Assets/07.Animations/Player/UltimateRedesign/*_GripRevision.anim` 12개. 이전 클립·구매 원본·모델 프리팹은 보존한다.
- MotionSet: `Assets/10.Datas/Actor/Animation/ActorMotion/MotionSet/Player/UltimateRedesign/*_Ultimate.asset` 12개. 기존 MotionKey·Ability·피해·비용·쿨다운을 바꾸지 않는다.
- FX: `Assets/03.Prefabs/Effects/Signature/GripRevision/` 13개. 구매 원본 `Simple Stylized Slash/Prefabs/fireslash.prefab`, `Hovl Studio/HSFiles/Materials/Laser1.mat`, `Laser2.mat`와 기존 프로젝트 Signature 프리팹에서 파생했다. 구매 파일은 수정하지 않았다.
- 투사체 2개는 외형 참조만, FX 데이터베이스는 기존 창·방패 착탄 키의 프리팹 참조만 교체했다.
- [변경 전 백업](../../../ArtSource/Animation/UltimateGripRevision/Before/)은 기존 미커밋 데이터를 포함하므로 보존한다. [적용 목록](../../../ArtSource/Animation/UltimateGripRevision/applied.txt) · [파지 위치](../../../ArtSource/Animation/UltimateGripRevision/grip-offsets.txt).
- [저작·진단 본문](../../../Tools/UltimateRedesign/README.md)은 자동 실행 코드가 아니다. 기존 후보·백업이 있으면 생성·적용 본문을 그대로 재실행하지 않는다.

## 검증 범위

[최종 산출물·meta 준비표](../../../output/harness/20261115-143752-4aa27936/review.md). 준비표 해시는 검사 실행 증명과 구분한다.

- 정상 컴파일 종료 및 Console 오류 0 확인. 새 타입·필드 추가는 Hot Reload 지원 범위 밖이므로 Edit Mode에서 정상 컴파일했다.
- 파지 중첩·해제 순서·사망·모델 정리와 기존 무기 숨김 관련 EditMode 9/9, 기존 시그니처 데이터·이벤트 20/20 통과. [MCP 원문](GRIP_FX_EDITMODE_RESULTS.json). 실제 전투에서 이벤트를 통한 중단·교대 복구는 별도 확인 대상이다.
- 최종 클립 12개에 NaN/Infinity 값·ParentConstraint 잔류 커브 없음. FX 13개에서 Missing Script·메시 누락 없음, 활성 본체/트레일 재질의 셰이더 지원 확인. 사용하지 않는 trailMaterial의 null은 오류로 세지 않는다.
- [게임플레이 이벤트 보존 대조](GRIP_FX_GAMEPLAY_PRESERVATION.json): 기존 충돌·투사체·이동 관련 선택 이벤트 블록이 백업과 동일하다. 전체 게임플레이 회귀 검사를 대체하지 않는다.
- 확대 정지 캡처와 입자 시간 샘플은 격리 프리뷰다. Constraint를 수동 계산한 접촉 확인은 실제 Player 실행 검증이 아니다. Shader 시간과 파티클 샘플 시간도 동일하다고 가정하지 않는다.
- 실전 입력, 피격 취소·교대 후 일반 공격, 실제 카메라에서의 파지와 FX 자연스러움은 사용자 테스트 대기다. Player·Addressables 빌드와 커밋은 수행하지 않는다.

## 직접 확인

최종 FX 샘플에서 유라의 층층이 쌓인 링을 나선 리본 메시와 직접 생성한 부드러운 투명 텍스처로 교체했다. URP Particles/Unlit 재질을 사용한다. 대검·창·방패 충격광 4종의 뾰족한 입자는 6개로 줄이고 크기를 축소했다. 유라 메시·재질·텍스처와 meta는 FX 폴더에 보관하며 구매 원본을 수정하지 않았다. 회오리의 실제 이동 중 연결감은 추가 실전 확인 대상이다.

[손·무기 확대 샘플](../../../output/ultimate-redesign/grip-revision/) · [FX 시간 샘플](../../../output/ultimate-redesign/fx-revision/). 이 캡처는 비교·재개 근거로 보존한다. 제작 본문과 변경 전 사용자 데이터 백업도 보존하며 삭제할 일회성 빌드 산출물은 없다.

기존 열린 전투 씬에서 12명 각각 궁극기를 사용한다. FX 없는 몸·무기와 FX 포함 화면을 구분해 본다.

1. 화린·세라·릴리: 준비·정점·타격·회수 동안 양손이 자루를 잡는지, 팔꿈치가 뒤집히지 않는지 확인한다.
2. 라온·아린·유라·리안: 손바닥과 자루 접촉, 검·채찍 회수, 궁극기 뒤 일반 공격의 장착 위치를 확인한다.
3. 설아·레이네·묘령: 시위 접점과 해제, 투척 때 손가락 열림, 무기 복귀 후 파지를 확인한다.
4. 연화·묘묘: 충전광이 지팡이 머리에 붙고 빔이 그 근처에서 나오는지, 회복할 때 빔이 남지 않는지 확인한다.
5. 중단 가능한 구간의 피격·회피, 사망·교대 후 무기 위치·표시·FX 잔류를 확인한다. 손에서 이탈하거나 무기 위치가 남으면 실패다.
6. 공격 궤적과 착탄 지점이 읽히고 캐릭터·적을 FX가 가리지 않는지 판단한다. 수치 검사 통과를 미술 통과로 바꾸지 않는다.
