RiverBasinWorld 저작 원본

제작 결과·미술 결함 / 사용자 직접 테스트

현재 독립 씬은 실제로 생성·저장된 1차 제작본이다. 기존 시나리오나 LakeVillageWorld에서 씬 배치를 가져오지 않았다. Player/Addressables 빌드와 커밋은 실행하지 않았다. 미술·플레이 인수는 대기다.

입력과 산출물

  • world-plan.json / prepare-plan.mjs: 작업 시작 전 존재한 초기 계획. 보존한다.
  • production-plan.json / prepare-production.mjs: 실제 교량 방향·착지·사당 이동·중심선 높이·수목 군락을 보정한 입력. production-routes.svg는 같은 입력에서 생성한다. 최종 입력의 A=2.315km, B=1.598km, C=2.472km / 대표 구간 평면354.8m.
  • Generated/*.f32: 전용 Terrain 9장 높이·지표 가중치. 매 타일 공유 경계 표본을 사용한다.
  • build-world.csx: 최초 독립 씬 제작 기록. 기존 씬·데이터가 있으면 중단한다. 이미 적용했으므로 현재 씬에 재실행하지 않는다.
  • revise-stage.csx / revise-stage.mjs: 이번 작업의 전용 GeneratedEnvironment 지형·군락 반복 수정 기록. 수동 변경과 충돌할 수 있으므로 일반 갱신 도구처럼 재실행하지 않는다. ManualGameplay 루트는 이 루틴의 대상이 아니다.
  • finish-stage.csx / finish-water.csx: 전용 지도 계약·재질·수면 굽이 접합의 마무리 기록. 현재 씬에 적용했다.
  • place-encounter.csx: 검병 1명과 발견 상자 1개 배치 기록. 고정 ID가 이미 있으면 중단한다. 원본 BT/GAS/MotionSet을 수정하지 않는다.
  • audit-world.csx: 전용 씬의 읽기 검사. 결과 output/RiverBasinWorld/audit.json.
  • capture-world.csx: 고정 Editor 카메라 6구도와 조감도. 플레이어 높이 렌더는 게임 LOD·안개를 보존한다. 조감도는 LOD0 강제·안개 해제한 비교용이다. 실제 보행·미술 인수의 대체 검사가 아니다.
  • asset-sources.json: 설치 팩/프로젝트 원본과 새 자산·진행 ID의 대장.
  • Source/: 기존 작업에서 인계받은 Blender 원본·제작 Python·ImageGen 원본 PNG와 프롬프트. 외부 모델 신규 다운로드 없음.

수동 최종 배치

기존 형태가 통로를 막던 회색 거점의 바닥·벽은 제거하고 통로 밖 7×14×6m 표식으로 바꿨다. 사당의 회색 표식은 제거하고 기존 Shrine_Main 프리팹을 사용했다. 카메라 규칙을 공유 편집하지 않기 위해 새 교량 인스턴스는 기존 Castle_Moat_Bridge 패턴, 사당은 House_Shrine 패턴의 이름을 사용한다. 실제 지붕 콜라이더도 검사했다.

현재 씬은 수동 최종 배치를 포함한 결과의 원본이다. 위 기록을 순서대로 재실행하면 항상 같은 최종 씬이 나온다고 보장하지 않는다. 재생성 필요 시 현재 씬·전용 데이터·메타와 ManualGameplay의 ID부터 보호하고 재검수한다. 기존 OpenWorld 생성기와 과거 일회성 스크립트는 실행하지 않는다.

검수 상태

정적 지지면·통행 중심선·양방향 NavMesh 통과. 카메라 이름 규칙 8/8. 단독 Play 초기화 Ready와 실제 카메라 렌더 확인. 미등록 서비스 2건과 무게 프로필 폴백 1건 경고가 남아 있다. 실제 입력·전투·카메라·물가 복귀·밤·저장/재진입·성능은 사용자 테스트 대기다. P5 정규 등록·지도 배경·정상 맵 전환은 아직 제작하지 않았다.
