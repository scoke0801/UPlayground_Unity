조합(Chord) 구조

게임패드의 LB(leftShoulder) 가 modifier 겸 단독 액션으로 다중 사용된다. InputManager.Chord.cs의 RebuildChordCatalog / SubmitToChordArbiter가 modifier 조합과 단독 입력의 우선순위를 중재한다.

LB + RBDodge
LB + RTSkillUltimate
LB + D-PadQuickSlot_Up / Right / Down / Left
