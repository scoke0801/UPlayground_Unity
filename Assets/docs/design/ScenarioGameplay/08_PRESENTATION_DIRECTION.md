## 1 적용 범위와 우선 문서

필수 선독: [플롯 저작](../../guide/STORY_PLOT_AUTHORING_GUIDE.md), [자연스러운 한국어 대사](../game_dialogue_natural_korean_guide.md), [콘텐츠 저작](../../guide/CONTENT_SYSTEM_AUTHORING_GUIDE.md), [전투 저작](../../guide/COMBAT_SYSTEM_AUTHORING_GUIDE.md), [UI 저작](../../guide/UI_UX_AUTHORING_GUIDE.md). 기존 가이드의 옛 사이클 예시를 새 이야기 설정으로 이식하지 않는다. 현행 사실은 [대화 개정 v3.1](../LAKE_OF_LIFE_DIALOGUE_REVISION_V3.md)과 실제 연결 데이터를 대조한다.

시작 대상은 Bokusein 사용자 표기에 대응하는 현행 Raon과 Arin이다. 선택한 서사 주인공과 전투 중 활성 캐릭터를 구별한다. 파티는 현재 교체 중심이며 모든 동료가 상시 따라오는 AI를 전제하지 않는다. 동료 대역의 짧은 이동과 장면 배치를 우선한다.

## 3 공통 연출 규칙

### 3.1 주목점과 조작권

한 순간의 주목점은 하나다. 얼굴을 읽어야 할 때 영입 배너·보상·튜토리얼을 함께 띄우지 않는다. 일상 반응은 플레이를 유지하고, 관계 전환과 정체 공개에만 짧은 장면을 사용한다. 텍스트 읽기 시간은 강제 컷 길이에 맞추지 않는다.

| 등급 | 사용 장면 | 조작과 종료 |
|---|---|---|
| 생활 반응 | 작업, 시선, 짧은 인사 | 이동·카메라 유지. 놓쳐도 진행 가능 |
| 주목 유도 | 천, 흔적, 조망 | 환경 구도 우선. 강제 회전 없음. 선택적 주목 기능은 실제 지원 확인 후 사용 |
| 짧은 사건 장면 | 재회, 합류 의사, 오인 해소 | 안전 확보 후 대화·행동 실행. 일반 대사 넘김과 명시적 장면 스킵을 구분 |
| 핵심 공개 | 같은 얼굴, 귀로 마무리 | 제한 범위·종료 조건 명시. 정상·스킵·취소·이탈 모두 입력·카메라 반환 |

전투 위험·피격·사망은 생활 반응보다 우선한다. 이미 전투 중이면 비필수 대화와 풍경 카메라는 시작하지 않는다. 핵심 장면은 기존 전투 보류 계약으로 안전을 먼저 확보한다. 단순히 무적만 걸고 주변 적이 계속 때리게 두지 않는다.

### 3.2 장면 저작 카드

각 장면은 다음 항목을 채운 뒤 연결한다. 다음 항목은 문서 양식이며 현재 엔진에 같은 이름의 필드가 있다는 뜻은 아니다.

| 항목 | 반드시 적을 내용 |
|---|---|
| 식별 | Sxx/Exx/Nxx, 실제 Quest·Flow·Dialogue·Entity ID 및 GUID |
| 감정과 정보 | 장면 전후 무엇을 느끼며 새로 알게 되는가, 하나씩 |
| 조건 | 선행 사실, 현재 전투·대화·활성 캐릭터, 재생 여부 |
| 참가자 | 서사 주인공/활성 캐릭터/동료 대역 역할, 중복 방지 방법 |
| 외형과 말투 | 실제 모델 캡처·NPC 일러스트 경로, Voice Profile, 관계·존대 수준·발화 동기 |
| 공간 | 발 위치·이동 목적지·시선·소품 socket·카메라 장애물·대체 정지점 |
| 시간표 | 행동 시작→시선→말→응답→다음 행동, 서로 기다릴 조건 |
| 표현 | 모션·소리·VFX·이미지 실제 에셋, 미확보 항목과 대체 표현 |
| 조작 | 잠기는 입력, 유지되는 입력, 패드 취소·명시적 스킵 |
| 결과 | 진행 확정 시점, 보상·영입의 단일 소유자, 알림 순서 |
| 복구 | 취소/사망/이탈/로드/이동 실패에서 보존 사실과 해제 목록 |
| 합격 | 플레이 영상 구간, 데이터 검증, 미검증 항목 |

### 3.3 NPC 이미지 확인과 말투 캐스팅

**기존·신규 NPC 모두 대사를 쓰거나 검수하기 전에 실제 일러스트와 씬 모델을 직접 열어 본다. 파일 이름이나 직업만 보고 어투를 정하지 않는다.** 기존 플로우의 대사도 이 절차로 재검수한다. 외형과 설정이 어긋나면 어느 쪽이 의도인지 기록하고, 말투로 억지 봉합하지 않는다.

Voice Profile에는 추정 연령대·인상·자세·복장·기존 성격, 듣는 상대와의 관계, 기본 종결어미, 문장 길이, 감정 표현, 피할 표현을 쓴다. 성별·갑옷만으로 반말을 고정하지 않는다. 초면의 예의와 인물의 무게감을 함께 표현한다. 존댓말 자체가 실패가 아니라 과도한 공손함·어린 말투·안내 직원 같은 문구가 인물과 충돌하는 것이 실패다.

예시 캐스팅: 중년 갑옷 남성, 현장 경험이 많고 초면의 여행자를 걱정하는 상황. 낮고 담담한 목소리를 상정하고 간결한 해요체나 캐릭터에 맞는 하오체 중 하나를 선택한다. 하오체는 시대극 과장이 생기면 쓰지 않는다. 기존 설정 근거 없이 무례한 반말로 일괄 치환하지 않는다.

| 검수 예시 | 판단 |
|---|---|
| “여행자님, 위험하실 수 있으니 부디 조심해 주시겠어요?” | 중년 경장·갑옷 남성의 담백한 현장 말투라면 과잉 존대·완곡함을 덜어낸다 |
| “숲에 들어갈 거예요? 해 지기 전에는 돌아와요.” | 초면의 예의를 유지하면서 우려를 직접 말하는 후보. 실제 인물 성격에 맞는지 확인 |
| “그쪽은 막혔어. 이리 와.” | 이미 친하거나 즉시 구조해야 하는 상황의 후보. 초면 평상시 기본값으로 쓰지 않는다 |

예시는 현재 NPC의 확정 대사가 아니다. 최종 문장은 [자연스러운 한국어 가이드](../game_dialogue_natural_korean_guide.md)로 소리 내어 읽듯 검수한다. 같은 인물이 플로우마다 존대·반말을 바꾸면 관계 변화 근거가 있어야 한다. 일러스트의 미소 때문에 부상·위기 장면에서도 쾌활한 대사를 쓰지 않는다.

## 4 동료 연출

### 4.1 만남에서 동행까지

관찰 가능한 행동 → 함께 해결한 일 → 개인적인 반응 → 동행 의사 → 실제 영입 → 짧은 확인 순서를 따른다. 처음부터 친밀한 농담이나 희생 맹세를 넣지 않는다. 관계 변화는 시선과 기다리는 거리, 먼저 움직이는 이유로 전달한다.

| 장면 | 행동·구도·소리 | 확정과 복구 |
|---|---|---|
| S03 화린 구출 | 접근 시 싸우는 대상과 퇴로가 함께 보인다. 승리 뒤 무기를 정리하고 리안이 사라진 방향부터 확인. 대화는 둘의 얼굴과 길을 같이 읽는 중경. 전투 음악을 내려 말과 숨 쉴 틈 확보 | 전투 해결 보존. 대화 정상 종료/명시적 스킵 계약에서만 영입. 취소하면 구출 전투 반복 없이 대화 재개 |
| S04 리안 재회 | 화린이 먼저 리안에게 향하고 리안은 몸을 돌려 안부를 확인. 플레이어가 두 사람 사이를 가리지 않는 삼각 배치. 5~8초 목표의 짧은 여유에 표정·자세 변화를 보여준 뒤 이동 | 재회에 없는 동료를 생성하지 않음. 재회가 끝나기 전에 새 흔적 해설을 끼우지 않음 |
| S05 묘령 충돌 | 부상 자세→얼굴 확인→거리 확보→경고. 충돌이 멈추면 공격 자세부터 풀고 공간을 내준다. 어깨 가까운 위압 카메라·승리 포즈·친밀한 미소 금지 | 기존 약 12초 짧은 충돌 계약을 대조. HP를 깎아야만 의심이 풀리는 이야기로 바꾸지 않음. 경계의 유보와 영입 확정 분리 |
| S08 같은 얼굴 | 선택 주인공과 상대 얼굴의 유사성을 실제 모델로 보여준 후 묘령의 반응. 새 설정 해설 대신 멈춘 시선·낮춘 무기. 전투 개시 전 플레이 카메라와 입력 복구 | 현재 교체 캐릭터가 아닌 서사 주인공 기준. 공개 취소 시 전투 보류·재시도. 신규 삽화가 실시간 얼굴 확인을 가리지 않음 |
| S09 귀로 | 고정된 안전 합류점에서 동료들이 기다림. 플레이어가 다가오면 한 사람이 먼저 돌아서고 나머지가 뒤따름. 5~8m 짧은 보행, 말 사이에 발소리·호숫바람 | 보스가 쓰러진 임의 위치에서 강제 장거리 보행 금지. 이동 실패 시 안전한 정지 구도로 마무리 가능. 취소 시 보스 승리 보존·귀로 재개 |

### 4.2 영입 알림과 교체 체험

영입 대화가 끝나고 실제 보유 명단이 바뀐 뒤 알림을 1회 보여준다. 감정 장면 중 이름 카드·보상·교체 안내를 겹치지 않는다. 대화 닫힘→영입 확인→안전한 교체 안내 순서로 배치한다. 문구·색·열기/닫기는 기존 UI 규칙을 따른다. 카드를 보기 위해 추가 버튼 연타를 요구하지 않는다.

교체는 플레이어가 직접 해본다. 특정 버튼을 누를 때까지 다음 퀘스트를 막지 않는다. 실패·취소·로드로 영입 알림을 반복하지 않는다. 기존의 영입 완료 사실을 알림 재생 사실과 혼동하지 않는다.

### 4.3 동료의 존재감과 대역 한계

P0에서는 만남·단서 확인·재회·귀로에 장면 대역을 사용한다. 장면 밖에서 보이지 않는 동료가 눈앞 일을 계속 해설하지 않게 한다. 비출전 인물의 대사는 장소와 표현 방식이 성립하는 경우에만 허용한다. 상시 추종·전투 협력·상황 대사 시스템 확장은 별도 작업으로 산정한다.

장면 시작 전에 동일 인물이 플레이어·임시 아군·NPC 대역 중 어디에 존재하는지 확인한다. 활성 화린과 화린 대역이 한 화면에 둘 나타나면 실패다. 임시 소품·이동·시선·모션·카메라·전투 보류는 정상 종료뿐 아니라 취소와 씬 이탈에서도 해제한다.

## 5 퀘스트와 생활 연출

### 5.1 발견·수락·행동·결과

부탁 전에 사정이 보이게 한다. NPC가 플레이어만 기다리며 정면으로 서 있지 않게 작업점과 쉬는 방향을 둔다. 수락 뒤 세계가 갑자기 처음 생기는 것처럼 단서를 생성하지 않는다. 선행 조사와 미수락 획득은 기존 퀘스트 누적 계약에 따른다.

| 사건 | 받기 전 | 플레이 중 단서 | 해결 뒤 보이는 변화 |
|---|---|---|---|
| 미아·준 | 미아가 약속 장소와 길을 번갈아 봄 | 준의 짐과 다친 발, 돌아갈 수 있는 경로 | 준이 미아 곁에 있음. 짐은 실제 회수 여부에 맞게 배치 |
| 헤이즐·소담 | 작업대의 빈 약재 자리, 분류 중인 손 | 채집 가능한 약초와 일반 풀을 형태로 구별 | 받은 양에 맞는 약 꾸러미·병, 검증된 손 모션으로 정리 |
| 페니 | 작업대에 손상된 등갓 | 길의 등불 상태를 가까이 관찰 | 조사 완료만 했다면 수선 준비까지만. 수리 완료 사실 없이 모든 등불을 켜지 않음 |
| 모건·연목 | 끊긴 짐끈·수레 수선 | 수레 방향과 주변 흔적 | 확인한 원인에 맞는 수선 행동. 확인하지 않은 범인을 단정하지 않음 |
| 메인 수색 | 천이 길과 사람 사이에 의미를 가짐 | 매듭 형태·높이·길의 굴곡으로 다음 방향 | 이미 본 단서에 같은 설명을 반복하지 않고 다음 행동으로 연결 |

완료 UI와 보상은 실제 진행 확정 직후 짧게 피드백한다. 주민의 긴 후일담은 선택 대화로 남긴다. 마을에 돌아올 때 여러 NPC가 일제히 칭찬하지 않는다. 직접 도움받은 사람의 변화가 먼저 읽히게 한다.

### 5.2 길 안내와 시선 설계

입구에서는 지붕·열린 길, 숲에서는 표식·수레, 호수에서는 넓어진 하늘과 수면, 신전에서는 건축 실루엣이 주목점이다. 퀘스트 화살표만 따라가면 장면을 뒤에서 보게 되는 배치는 고친다. 실제 플레이 높이와 역방향 진입에서 확인한다.

단서는 색 하나에 의존하지 않는다. 붉은 잎 속 천은 매듭·밝은 가장자리·주변 여백으로 구별한다. 청각 단서는 물체나 인물의 시각 반응과 연결한다. 보조 HUD 안내는 유지하고, 환경 안내를 이유로 접근성 정보를 없애지 않는다.

길찾기 보조 대사는 플레이어의 정체·반복 오진입을 실제로 판별하는 기능이 있을 때만 조건부로 붙인다. 시간만 지나면 정답을 반복하는 구현은 금지한다. 기능이 없으면 NPC 선택 대화나 기존 목표 확인 경로를 제공한다.

### 5.3 생활 움직임과 음향

건물마다 대표 행동 1개와 휴지 동작 1개를 먼저 만든다. 빵집은 음식 정리, 약집은 약초 분류, 풍차 옆은 수선, 경계는 길 확인. 여러 주민의 반복 모션 시작을 일치시키지 않는다. 없는 애니메이션을 대사로 보완하지 말고 지원되는 서 있는 작업·소품 배치로 표현한다.

생활음은 가까운 작업 소리, 구역 환경음, 먼 배경음으로 구분한다. 동일 망치 소리가 모든 집에서 같은 박자로 나지 않게 한다. 대화 중 주변 소리를 조금 낮추는 기능은 실제 믹서 지원을 확인한다. 보이스가 없으면 음성이 재생된 것처럼 납품하지 않고, 자막·모션·환경음으로 성립시킨다.

S06 호수 조망은 2~3초 정도 시야가 열리는 경험부터 만든다. 강제 180도 회전이나 긴 줌으로 감상을 강요하지 않는다. 전투·잠금 시에는 풍경 연출을 보류한다. 귀환길은 같은 장소의 작업 재개와 기다리는 사람으로 달라진 의미를 보여준다.

## 6 전투 연출

### 6.1 예고→판단→접촉→반응→회복

| 단계 | 플레이어가 읽을 것 | 저작·검수 |
|---|---|---|
| 예고 | 공격 주체·방향·위험 형태 | 몸의 준비 자세와 무기 궤적을 우선. 강공격 효과가 몸을 가리지 않음 |
| 판단 | 피할 방향, 막을 수 있는지, 대응할 시간 | 바닥 대비·카메라 거리·퇴로를 함께 검수. 색 외에 자세·소리·형태로 구별 |
| 접촉 | 맞음/막음/회피 결과 | 실제 HitPhase와 모션 접촉 일치. 빗나갔는데 명중음·피격 섬광 없음 |
| 반응 | 누가 얼마나 흔들렸는지 | 리액션·짧은 소리·국소 VFX가 먼저, 필요한 강타에만 셰이크 |
| 회복 | 다음 선택이 가능한 시점 | 후딜·캔슬·선입력의 실제 계약. 연출 종료 대기 때문에 입력 유실 없음 |

판단은 BT, 결과 수치는 GAS, 모션과 판정·VFX/SFX 타이밍은 MotionSet에 둔다. 연출 전용 코드가 별도 피해를 적용하거나 임의로 적을 죽이지 않는다. 적을 카메라에 담으려고 플레이어 입력을 반복적으로 덮어쓰지 않는다.

강공격 예고는 기존 04 문서의 설계 범위를 출발점으로 실제 애니메이션에서 측정한다. 빠른 공격까지 모두 같은 긴 예고를 붙이지 않는다. 새로운 공격의 학습 기회를 주되, 두 번째 조우부터 배운 대응을 활용하게 한다.

### 6.4 전투 중 정보 우선순위

즉시 위험 예고 → 방어·피격·타격 결과 → 현재 목표의 짧은 갱신 → 선택적 동료 반응 → 장식 순서다. 대형 이펙트는 적 실루엣·바닥·퇴로의 핵심 정보를 가리지 않는다. 다인 조우에서 모든 적이 동시에 크게 울부짖지 않는다. 공격 슬롯·압박 조율은 기존 BT 책임에 둔다.

상황 대사를 추가할 경우 실제 발화 가능한 화자, 관찰한 사실, 현재 전투 상태를 검사한다. 비필수 발화는 처음 조율 시 전역 12초 이상 간격, 같은 문장 90초 이상 재사용 간격으로 시작하고 테스트로 조정한다. 사건 대사는 해당 사건당 1회. 이는 신규 정책 제안이며 구현되어 있다고 간주하지 않는다. 긴급 경고는 이 간격과 별도지만 같은 위험에 중복 발화하지 않는다. 사망·씬 전환 시 지난 발화 대기열을 버린다.

## 7 카메라·오디오·이미지 공통 제작 계약

카메라 컷은 장소 관계를 먼저 보여주고 필요한 표정에 가까워진다. 얼굴·무기·소품을 모두 담으려다 인물이 작아지는 구도는 장면 목적에 맞춰 나눈다. 시선 방향·이동 방향이 컷마다 반전되지 않게 하고, 나무·처마·큰 장비 관통을 양쪽 주인공 체형에서 검사한다. 입력 반환 직후 이동 방향이 예상과 달라지지 않게 플레이 카메라 복귀를 검증한다.

전투 직전에는 조작 가능한 화면으로 돌아온 뒤 공격 예고가 시작돼야 한다. 자동 잠금·보간·카메라 기록 기능은 실제 지원 범위를 조사하고 사용한다. Camera 모듈의 프로젝트 연결은 기존 어댑터를 통한다. 새 직접 매니저 의존을 만들지 않는다.

장면 음향은 필요한 소리부터 확보한다. 발소리·옷·소품→환경→음악 순으로 빈틈을 확인한다. 음악이 관계 변화를 전부 대신하지 않게 한다. 같은 곡을 구역 경계 왕복마다 처음부터 재시작하지 않는다. 동적 믹싱·레이어 전환·자막 방향 표시·셰이크 설정이 없으면 기능 추가 항목으로 등록하고 구현 전 완료 표시하지 않는다.

신규 NPC 일러스트는 [03의 필수 ImageGen 절차](03_NPC_AND_P09.md)를 따른다. 장면 삽화는 [05](05_ART_PRODUCTION.md)의 이미지 발주와 별개로 관리한다. 일러스트에 대사·이름·UI를 구워 넣지 않는다. 핵심 얼굴 공개는 실시간 모델을 사용한다. 일반 UI 프레임·아이콘은 기존 자산을 재사용한다.

## 8 실행과 복구 계약

연출의 실제 구현은 기존 FlowGraph·Dialogue 사건·스토리 대역을 조합한다. [최근 구현 기록](../../../../docs/reviews/LAKE_NARRATIVE_OVERHAUL_IMPLEMENTATION.md)의 대화 이동·소품·정상 종료/취소·전투 보류를 현재 코드에서 다시 확인한다. 기록만 보고 새 씬에서도 검증됐다고 가정하지 않는다.

| 종료 원인 | 보존 사실 | 반드시 할 일 |
|---|---|---|
| 정상 완료 | 실제 확정된 전투·퀘스트·영입 | 확정 1회, 알림 정리, 입력·카메라 복원 |
| 명시적 스킵 | 해당 장면 완료 계약에 정의된 결과 | 결과와 안전한 최종 배치 적용. 앞으로 발생할 전투 승리를 대신 확정하지 않음 |
| Cancel | 이미 발생한 전투 승리·획득 | 미완료 대화/영입은 소진하지 않음. 임시 상태 정리·재시도 가능 |
| 사망·이탈·로드 | 저장된 진행 사실 | 임시 연출을 완료로 간주하지 않음. 대역·소품·이동·카메라·hold 재구성/해제 |
| 이동 시간 초과 | 이전 확정 사실 | 허공 이동·보행 무한 대기 금지. 사전 지정 정지 구도 또는 장면 재시도 |

완료 사실은 권위 진행 데이터가 소유한다. 연출 재생 여부만 보고 영입·보상을 두 번 지급하지 않는다. 일반 대사 넘김이 아직 끝나지 않은 필수 동작을 누락하지 않게 한다. UI 트윈은 SetUpdate(true), 숨김/파괴에서 Kill을 적용한다. 연출 수치는 SO·기존 직렬화 데이터에 두고 인물 이름 분기로 구현하지 않는다.
