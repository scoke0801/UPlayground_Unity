# 레벨 / 등급 기반 전투 시간 밸런스 정책

## 목적과 변경 이유

Weak·Normal은 공격을 이어가며 무리를 정리하는 소탕전, Elite는 흐름을 끊는 중간 위협, Boss는 패턴을 읽는 결투를 담당한다.
Normal 한 마리에 18초를 요구하던 기존 기준은 6~10마리 소탕과 충돌하므로 단일 대상 집중 처치 시간을 3~6초로 줄인다.
보스는 120초(90~180초)를 유지한다. Elite 45초는 브레이크·대응 기회를 보존하기 위해 유지하며 무리 전체 시간과 충돌하면 실제 로그로 별도 조정한다.

## 목표 처치 시간

| 구분 | 기본 목표 | 허용 범위 | 역할 |
|---|---:|---|---|
| Weak | 1.5초 | 1~2초 | 짧은 선제 공격으로 정리 |
| Normal, 동레벨 단일 대상 집중 | 4.5초 | 3~6초 | 짧은 콤보로 행동권을 빼앗음 |
| Normal 무리 6~10마리 | 35초 | 25~45초 | 이동·회피·대상 전환 포함 |
| Elite, 동레벨 | 45초 | 35~60초 | 회피·패리·브레이크 후 집중 공격 |
| Elite, +1~+3레벨 | 60초 | 45~80초 | 별도 시나리오 오버라이드 |
| Boss | 120초 | 90~180초 | 페이즈·자원 운영·반격 기회 |

위 값은 초기 실험 목표이며 실측 결과가 아니다. 무리 목표는 Normal 중심 편성 기준이다.
중간에 Elite가 합류하는 시나리오 A는 단일 Elite 목표를 더해서 판정하지 않고 병렬 피해와 브레이크 확산을 포함해 따로 측정한다.
레벨 차이는 몬스터 레벨 - 플레이어 레벨이다. 저레벨 Normal은 동레벨보다 빨리, 고레벨은 느리게 처치하되 이유 없이 Elite 수준의 체력 벽을 만들지 않는다. 예전 6/18/28초 표를 재사용하지 않는다.

## 단일 데이터 원본과 도구

기본 목표는 `Assets/10.Datas/Combat/Resources/CombatBalanceTargets.asset`에서 저작한다.
`BalanceCombatEstimator`는 명시 시나리오 → 명시 입력 → 이 SO의 유효 등급 목표 순서로 적용한다.
기존 `BalanceScenarioAsset.targetDuration`은 명시 오버라이드이므로 자동으로 덮어쓰지 않는다.
Weak를 Normal과 분리하고 Boss 도구 기본값 90초를 정책과 같은 120초로 맞춘다.

몬스터 등급·레벨은 `ActorDefinitionSO.EffectiveGrade` / `EffectiveLevel` 기준이다.
수치 조정은 `MonsterScalingSO`의 등급 배율에서 시작하고 `MonsterStatCalculator`로 산출한다.
개별 HP를 손으로 조정하지 않는다. 재베이크할 때 기존 Attribute Profile GUID를 보존한다.
HP·강인도 외의 값과 보상은 별도 근거 없이 함께 바꾸지 않는다.

## 계산과 해석

몬스터 처치 예상 시간 = MaxHealth / (플레이어 루프 DPS × AttackPower × (1 - 몬스터 Defense)).
플레이어 생존 예상 시간 = 플레이어 MaxHealth / 적의 예상 유효 DPS.

도구의 Ability 평균 피해와 공격 간격 기반 추정은 실제 콤보 타임라인의 완전한 시뮬레이션이 아니다.
캐릭터, 무기, 레벨, 기준 AbilitySet, 공격 간격, 브레이크 포함 여부를 결과에 반드시 기록한다.
선제 공격으로 적의 공격 시도가 취소되는 Weak·Normal에 단일 대상 최소 2~4회 공격을 강제하지 않는다.
무리의 실제 위협은 그룹 슬롯, 원거리 텔레그래프, 정예 합류로 평가한다.

## 판정 기준

- 처치 시간이 허용 하한 미만이면 TooEasy 후보, 상한 초과면 체력·방어·공격 가동률을 확인한다.
- 플레이어 생존 시간이 전투 목표보다 짧으면 TooLethal 후보로 조사한다. 소탕전은 무리 전체 공격 빈도로 재평가한다.
- 유효 공격이 없거나 무적·대기·거리 때문에 진행하지 못하면 Stalled로 조사한다.
- 데이터·Motion 연결이 빠졌으면 InvalidData이며 수치 조정으로 숨기지 않는다.
- 도구의 종합 점수·기존 상태 라벨만으로 합격을 선언하지 않고 원시 지표와 실제 플레이를 함께 본다.

## 조정 순서

1. 기준 플레이어의 실제 Ability 구성과 공격 간격을 확인한다.
2. Weak·Normal HP 등급 배율로 처치 시간을 맞춘다.
3. 강인도와 브레이크 빈도, 캔슬·히트스톱이 공격 흐름을 방해하는지 확인한다.
4. 그룹 근접 슬롯 2, 원거리 슬롯 1~2, 공격 후 휴지 0.8초, 피격 후 휴지 0.45초, 화면 밖 공격 적합도 배율 0.3을 첫 실험값으로 쓴다.
5. 같은 무리의 보상 총량과 시간당 수급을 분리해 보고한다. 승인 없이 보상을 변경하지 않는다.
6. Boss는 HP보다 읽을 수 있는 텔레그래프, 확실한 후딜, 욕심에 대한 대응을 우선한다.

## 검증

관련 EditMode와 데이터 연결 검사 후 소탕·결투·전환 시나리오를 확인한다.
전투 자동 실행과 Player 빌드 기준은 `guide/TEST_VALIDATION_GUIDE.md`를 따른다.
자동 수치 검사 통과를 전투 감각 검증으로 표현하지 않는다.
