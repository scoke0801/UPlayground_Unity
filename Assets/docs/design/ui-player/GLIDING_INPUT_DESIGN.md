# 공중 비행 입력 계약

슈퍼 점프 후 탈것에 탑승한 비행은 입력 없이 현재 진행 방향으로 자동 전진한다. W/이동 세로축 양수는 상승, S/음수는 하강이며 키를 놓으면 부드럽게 고도를 유지한다. A/D/가로축은 진행 방향 기준 좌우 선회다. 카메라 회전은 고도·진행 방향을 바꾸지 않는다. 일반 낙하·슈퍼 점프 도약과 접촉 전 이동은 기존 계약을 유지한다.

세로축은 아날로그 크기를 보존하고±1로 제한한다. 상승 최대 속도는 기존 `PlayerGlidingSettingsSO.climbSpeed`, 하강 최대 속도는 `descentSpeed`이며 수렴 시간은 `descentBlendTime`이다. 전진 속도는 W/S와 독립적으로 `cruiseSpeed`에 수렴하고 기존 가속 요청 중에는 `boostSpeed`에 수렴한다. W/S에 의한 전진 가감속과 카메라 피치 기반 고도 조절 설정은 제거한다. 기존 스태미나·공중 재도약·놓기·충돌·착지 규칙을 유지한다.

구현·자동 검증·사용자 확인은 [작업 상태](../../../../docs/work-status/gliding-input.md)에서 관리한다.
